# Technology Stack

**Analysis Date:** 2026-02-17

## Languages

- **Kotlin** 2.3.0 - DSL framework, IR nodes, code generation, all game constructs

**Secondary:**

- **JVM (Java Virtual Machine)** - Target: Java 21+ (jvmToolchain(21))

- **Gradle** 9.0+ - Primary dependency and build orchestration
- **Maven Central** - Dependency repository

- **GitHub Packages** - Alternative publishing repository

## Frameworks & Build Tools

**Core Framework:**
- Kotlin Multimodule Project Structure with 7 modules:
  - `gbkt-core` - DSL, IR, game constructs (platform-agnostic)
  - `gbkt-backend-api` - Backend contract/interface
  - `gbkt-backend-gbdk` - Game Boy/GBC code generation
  - `gbkt-gradle-plugin` - Gradle build integration (composite build)
  - `gbkt-cli` - Command-line interface
  - `gbkt-intellij-plugin` - IDE plugin (IntelliJ Platform)
  - `gbkt-bom` - Bill of Materials version coordinator

**Code Quality & Linting:**
- **Spotless** 8.1.0 - Code formatting and license header management
  - ktfmt() with Kotlin language style
  - Automatic license header injection (MPL 2.0 or Apache 2.0)
  - Enforces trailing whitespace removal and newline endings

- **Detekt** 1.23.8 - Static code analysis for Kotlin
  - Custom detekt.yml configuration at project root
  - Baseline tracking (detekt-baseline.xml) for incremental cleanup
  - Platform: Parallel execution enabled

- **SonarQube** 7.2.2.6593 - Code quality and security analysis
  - Integrated with SonarCloud (https://sonarcloud.io)
  - Organization: svachmic
  - Project key: svachmic_gbkt
  - Coverage integration with Kover (JaCoCo XML reports)

**Testing:**
- **Kotest** 5.9.1 - Property-based testing (`kotest-property`)
- **Kotlin Test** (stdlib) - Unit testing framework
- **JUnit 5** (Jupiter) 6.0.1 - Test runner used in gradle-plugin integration tests
- **JUnit Platform Launcher** - Test discovery and execution
- **kotlinx-coroutines-test** 1.9.0 - Coroutine testing utilities
- **Gradle Test Kit** - Plugin integration testing (gbkt-gradle-plugin)

**Coverage:**
- **Kover (kotlinx.kover)** 0.9.4 - Code coverage measurement and reporting
  - Generates JaCoCo XML reports at build/reports/kover/report.xml
  - Coverage analysis runs on gbkt-core tests for SonarCloud integration

**IDE & IntelliJ Plugin:**
- **IntelliJ Platform Gradle Plugin** 2.10.5 - IntelliJ plugin build management
- **IntelliJ IDEA Community** 2024.2 (intellijVersion = "2024.2")
  - sinceVersion: 242 (2024.2+)
  - Bundled with Java and Kotlin plugins
- **Plugin Verifier** - Validates plugin compatibility
- **Zip Signer** - Signs plugin distributions

**Publishing & Distribution:**
- **Maven Publish** plugin - Maven Central (OSSRH) and GitHub Packages publishing
- **Signing** plugin - GPG signing for release artifacts
- **Gradle Plugin Publish** 1.3.1 - Publishes gbkt-gradle-plugin to Gradle Plugin Portal
  - Website: https://github.com/svachmic/gbkt
  - VCS: https://github.com/svachmic/gbkt.git

## Platform Requirements

**Development:**
- JDK 21+ (Eclipse Temurin distribution used in CI)
- Gradle 9.0+
- IntelliJ IDEA (Community or Ultimate) for plugin development
- Git for version control

**GBDK Compiler Integration (Runtime):**
- **GBDK-2020** (https://github.com/gbdk-2020/gbdk-2020/releases)
  - lcc compiler (for C → ROM compilation)
  - Libraries and headers (lib/gb/)
  - Discovery via:
    1. Explicit `gbdt { gbdkHome.set("/path") }` configuration
    2. GBDK_HOME environment variable
    3. Common installation paths: /opt/gbdk-2020, ~/gbdk-2020, etc.

**Emulator Integration (Optional):**
- **mGBA** (https://mgba.io/) - Game Boy emulator
  - Auto-detection on macOS (.app bundles), Linux, Windows
  - Live reload support via Lua scripting (optional)
  - Detected from standard installation paths

**Web Export (Optional):**
- **EmulatorJS** - Browser-based GB/GBC emulator for web deployment
