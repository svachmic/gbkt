<objective>
Unify all Gradle plugin and library versions behind `gradle/libs.versions.toml`. Today the catalog covers 11 libraries and ~8 of ~24 build scripts; plugin versions live in root `pluginManagement` plus four standalone inline pins, JUnit BOM is inlined 6x, and `org.json:json` is hardcoded once. This refactor does a FULL `[plugins]` migration so there is a single bump point.

Purpose: One place to bump every plugin/library version; eliminate the live drift bug where the serialization compiler plugin (2.3.0) lags Kotlin (2.3.20).

Output: A `[plugins]` catalog section, catalog JUnit/json entries, every `plugins {}` block on `alias(libs.plugins.*)`, and machine-diffable snapshots proving the only resolution change is the intended serialization bump.
</objective>
