## BCPD Slot 0 Palette RAM Confirmation

BCPD slot 0 bytes 0-7 from `bcpd-frame60.json`:

```
[0xFF, 0x7F, 0xB5, 0x56, 0x4A, 0x29, 0x00, 0x00]
```

Decoded as 4 × 15-bit little-endian GBC colors:

| Color Index | Raw bytes | 15-bit value | Interpretation |
|-------------|-----------|--------------|----------------|
| 0 | 0xFF, 0x7F | 0x7FFF | White (max) |
| 1 | 0xB5, 0x56 | 0x56B5 | Light gray |
| 2 | 0x4A, 0x29 | 0x294A | Dark gray |
| 3 | 0x00, 0x00 | 0x0000 | Black |

This matches the `_gbkt_default_bg_pal[4] = {0x7FFF, 0x56B5, 0x294A, 0x0000}` constant defined in GBDKPipelineV2.kt, confirming:
- The `set_bkg_palette(0u, 1u, _gbkt_default_bg_pal)` call wrote to BCPD slot 0 correctly
- BCPS auto-increment behavior under the GBDK helper works as expected
- The BG palette write path is NOT the regression site
