## Accomplishments

- `handleReadMemory returns hex bytes for valid hex address and count` — covers the happy path with count=3 and three distinct byte values. Asserts JSON envelope shape (`address`, `count`, `bytes` array) AND each byte at each index.
- `handleReadMemory observes LCDC bit 7 transition across DISPLAY_ON simulation` — two-phase mockMemory swap (LCDC=0x00 → LCDC=0x91) across two read invocations; asserts `(byte and 0x80) == 0` then `== 0x80`. Wave 0 V-3 sanity gate.
