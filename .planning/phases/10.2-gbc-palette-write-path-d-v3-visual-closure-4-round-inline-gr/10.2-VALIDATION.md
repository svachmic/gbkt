## Sampling Rate

- **After every task commit:** Run quick run command (the 5 locked tests stay GREEN).
- **After every plan wave:** Run full suite command (JVM + clean ROM build smoke).
- **Before phase-close (D-16):** clean `:gbkt-examples:metasprites:buildRom` mandatory; `:gbkt-examples:metasprites-stress:buildRom` IFF bisect-named site touches files locked by 10.1 D-21 stress gate.
- **Visual evidence (D-15, CLAUDE.md Visual Evidence Rule):** Runtime PNG via MCP `emulator_screenshot` is binding for closure — JVM GREEN alone is NEVER sufficient for D-V3.
- **Max feedback latency:** ~90s for quick (JVM contract preservation), ~110s with ROM smoke.
