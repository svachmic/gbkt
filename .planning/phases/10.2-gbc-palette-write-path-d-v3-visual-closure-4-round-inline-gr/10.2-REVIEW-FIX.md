### WR-01: handleWriteMemory silently accepts out-of-range integer values

**Files modified:**
- `gbkt-mcp-server/src/main/kotlin/io/github/gbkt/mcp/ToolHandlers.kt`
- `gbkt-mcp-server/src/test/kotlin/io/github/gbkt/mcp/ToolHandlersTest.kt`
**Commit:** `f97ddacb`
**Applied fix:** Replaced the silent `value and 0xFF` masking in `handleWriteMemory` with an explicit range check: `if (value !in 0..255)` returns an `errorResult("value $value is out of range (0..255). emulator_write_memory writes exactly one byte.")`. The `session.writeMemory` call now passes the raw validated `value` directly (no masking needed since range is enforced). The existing test that verified the silent masking behaviour (`value=0x1FF stores 0xFF`) was updated to instead assert that `value=511` now produces an error result containing "out of range".
