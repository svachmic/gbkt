## Decisions Made

1. **cfe41ad7 anchor substitution:** cbe81d29 (original plan spec) does not build under GBDK lcc because `game.h` at that commit references `metasprite_t` without the `#include <gbdk/metasprites.h>` that was added in commit 20fdd8e8. cfe41ad7 is the earliest pre-Plan-19/20 buildable commit; it includes the metasprites.h fix and Plan 18's 4-row-period checker literal but excludes Plans 19/20/22's palette-bootstrap changes. User confirmed: "Keep cfe41ad7; document + proceed (recommended)."

2. **64-byte protocol (not fallback):** The Wave 1 spike (Plan 02) confirmed `emulator_write_memory` works. The BCPS/OCPS pre-write loop succeeded on Coffee-GB with bit 7 auto-increment OFF; all 64 bytes returned non-zero for the active slots. The 16-byte fallback was NOT needed.

3. **Tile-order defect acknowledged as non-confounding:** mirrorDedup (Plan 10.1-16, commit 607a3e64) integrated AFTER Plan 10.1-20's palette-bootstrap fix (7b86049f) via worktree-merge ordering. At cfe41ad7, metasprite tile-flip arithmetic emits wrong-ordered tiles — the same defect class seen in Phase 10.1 B&W debugging. Decision (user, 2026-05-19): tile-order will be consistently wrong across ALL probes (baseline + A + B + C), so it does NOT confound the color signal. D-V3 hunts the GBC palette write path, not tile geometry.
