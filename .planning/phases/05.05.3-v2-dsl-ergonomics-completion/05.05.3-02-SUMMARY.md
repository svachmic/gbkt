## Decisions Made

- **ExprVisitor backward compat:** Added companion object with static `visit(expr)` and `sanitizeVarName(name)` delegating to `ExprVisitor()` (no actors). This preserves all existing `ScriptOpVisitor` call sites without rewriting ~30 usages, while the actor-aware path flows through `ScriptOpVisitor.visit(op, exprVisitor)` with a ThreadLocal.
- **HitboxDef fields:** Plan pseudocode used `.w/.h` but the actual fields are `.width/.height` — confirmed by reading ActorIR.kt source.
- **PongV2 paddle collision:** Kept as nested `whenever` blocks using coordinate-range checks instead of `ball.collides(paddle1)` AABB — plan explicitly noted that coordinate-range precision is important for Pong gameplay feel.
- **ExplorerV2 simpleBattle callbacks:** Kept as `navigate("gameplay")` and `navigate("gameover")` strings — `simpleBattle` builder parameters accept String, not SceneRef.
- **Circular scene navigation pattern:** Each example game has a title→game→gameover→title cycle; the cycle-break is always at the earliest-defined scene (gameover navigates to "title" as string with comment explaining the circular dependency).

## Deviations from Plan

None — plan executed exactly as written. The plan explicitly called out all edge cases: PongV2 keeping coordinate-range collision, ExplorerV2 simpleBattle using strings, and circular navigation patterns.
