## Accomplishments

- Created `InputBuilders.kt` with `InputRef` class, `object dpad`, `object buttons` — game code can now use `dpad.up.held`, `dpad.left.pressed`, `buttons.a.pressed`, `dpad.any` returning typed `Expr` for `whenever()` conditions
- Added `ActorDelegate` class with `provideDelegate` to `ActorBuilder.kt` and `actor(block): ActorDelegate` overload to `GameBuilder.kt` — `val paddle by actor { position(16,64) }` infers actor name "paddle" from Kotlin property
- Created `ColorConstants.kt` with `object DmgColor` providing `WHITE=0`, `LIGHT_GRAY=1`, `DARK_GRAY=2`, `BLACK=3` as compile-time integer constants
- Added `@Deprecated(WARNING)` to all 5 string-based input methods (`dpadHeld`, `dpadPressed`, `buttonPressed`, `buttonHeld`, `dpadAny`) — gradual migration with backward compatibility
