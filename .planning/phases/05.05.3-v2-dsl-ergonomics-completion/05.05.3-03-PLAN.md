Use Serena `find_symbol("GameBuilder/scene")` to locate the existing `scene()` method, then add `sceneRef()` near it using `insert_after_symbol`.

Add this method to `GameBuilder`:

```kotlin
/**
 * Creates a forward-declared [SceneRef] for use in navigate() before the scene is defined.
 *
 * Use this to break circular scene navigation dependencies:
 * ```kotlin
 * val titleRef = sceneRef("title")       // forward-declare
 * val gameScene = scene("game") {
 *     frame { whenever(buttons.start.pressed) { navigate(titleRef) } }
 * }
 * val titleScene = scene("title") { ... } // defined later
 * ```
 *
 * The scene MUST be defined later via [scene] with the same ID. If no matching scene
 * is defined, the ref will still work at codegen (NavigateTo uses the string ID internally)
 * but refRegistry validation will catch it if enabled.
 */
fun sceneRef(id: String): SceneRef = SceneRef(id)
```

This is intentionally minimal — `SceneRef` is already a `data class SceneRef(val id: String)`, and `ScriptBuilder.navigate(sceneRef: SceneRef)` already exists and just uses `sceneRef.id`. No registration is needed because `scene(id, block)` will register the scene when it's defined later.

Do NOT register the sceneRef with refRegistry here — that would cause a duplicate registration error when `scene()` is called later with the same ID.
