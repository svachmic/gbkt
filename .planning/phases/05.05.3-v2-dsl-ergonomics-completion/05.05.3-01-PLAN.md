**Actor Delegate (in ActorBuilder.kt):**

1. Add `ActorDelegate` class at the bottom of `ActorBuilder.kt`:
   ```kotlin
   class ActorDelegate(
       private val nameOverride: String?,
       private val block: ActorBuilder.() -> Unit
   ) : ReadOnlyProperty<Any?, ActorRef> {
       private var ref: ActorRef? = null

       operator fun provideDelegate(thisRef: Any?, property: KProperty<*>): ReadOnlyProperty<Any?, ActorRef> {
           val name = nameOverride ?: property.name
           val gameBuilder = GameBuilderContext.current
               ?: error("actor {} must be called inside a game {} block")
           ref = gameBuilder.registerActor(name, block)
           return this
       }

       override fun getValue(thisRef: Any?, property: KProperty<*>): ActorRef =
           ref ?: error("ActorDelegate not initialized — was provideDelegate called?")
   }
   ```
   Import `kotlin.properties.ReadOnlyProperty`, `kotlin.reflect.KProperty`, and `GameBuilderContext` from `VariableBuilders.kt` (it is `internal` — both are in the same module so this is fine).

2. Add `registerActor` method to `GameBuilder.kt` (if not present):
   ```kotlin
   internal fun registerActor(id: String, block: ActorBuilder.() -> Unit): ActorRef {
       // Same logic as the existing actor(id, block) function body
       refRegistry.register(id, RefKind.ACTOR)
       val builder = ActorBuilder(id).apply(block)
       actorBuilders += builder
       return ActorRef(id)
   }
   ```
   Then refactor the existing `fun actor(id: String, block: ...)` to call `registerActor(id, block)` internally.

3. Add no-name `actor` overload to `GameBuilder.kt` returning `ActorDelegate`:
   ```kotlin
   fun actor(block: ActorBuilder.() -> Unit): ActorDelegate = ActorDelegate(null, block)
   ```
   This overload returns `ActorDelegate`, not `ActorRef`. The `by` delegate pattern triggers `provideDelegate` which infers name from the Kotlin property.
