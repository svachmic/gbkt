## Decisions Made
- `sceneRef()` creates `SceneRef` without `RefRegistry.register()` — avoids duplicate registration error when `scene()` is called later with the same ID. The ref is a pure data object; the scene definition is the authoritative registration.
- Pong retains nested whenever blocks for paddle collision — coordinate-range checks (x 4..20, x 148..156) provide tighter gameplay precision than AABB hitbox overlap. Exception is explicitly documented in code comment.
- Explorer simpleBattle callbacks can use `navigate(SceneRef)` — `onVictory { navigate(gameplayRef) }` compiles because `SimpleBattleBuilder.onVictory(block: ScriptBuilder.() -> Unit)` takes a ScriptBuilder block which has the `navigate(SceneRef)` overload. The STATE.md note "builder accepts String not SceneRef" was incorrect.
