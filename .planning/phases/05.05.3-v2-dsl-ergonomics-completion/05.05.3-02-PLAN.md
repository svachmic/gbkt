**Collision codegen via ExprVisitor special-casing:**

The `ActorRef.collides(other)` DSL method emits `CallExpr("collides", [VarRef(this.id), VarRef(other.id)])`. Currently, the generic `ExprVisitor.visitCallExpr` converts this to `CCall("collides", _ball, _paddle)` which is **invalid C** — `_ball` and `_paddle` are not variables, and no `collides()` C function exists.

**Context:** V2 actors are stored as individual globals (`_ball_x`, `_ball_y`, `_paddle_x`, `_paddle_y`), not arrays. Hitbox dimensions come from `ActorIR.sprite.hitbox`.

**Implementation approach — ExprVisitor special-case dispatch:**

1. **Convert `ExprVisitor` from `object` to `class`** with a constructor parameter `actors: List<ActorIR>` (default to `emptyList()` for backward compatibility). `ExprVisitor` is currently a stateless `object` (see `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/visitor/ExprVisitor.kt`, line 37). Converting to a class is needed because collision resolution requires actor metadata at visit time.

2. **Update all call sites** that reference `ExprVisitor.visit(expr)` to construct `ExprVisitor(actors).visit(expr)` where actors are available, or `ExprVisitor().visit(expr)` where they are not. Use Serena `find_referencing_symbols` on `ExprVisitor` to find all call sites.

3. **Override `visitCallExpr`** to special-case `"collides"`:
   ```kotlin
   override fun visitCallExpr(expr: CallExpr): CExpr {
       if (expr.function == "collides" && expr.args.size == 2) {
           val aId = (expr.args[0] as? VarRef)?.name ?: error("collides() first arg must be VarRef")
           val bId = (expr.args[1] as? VarRef)?.name ?: error("collides() second arg must be VarRef")
           val actorA = actors.find { it.id == aId } ?: error("Unknown actor: $aId")
           val actorB = actors.find { it.id == bId } ?: error("Unknown actor: $bId")
           val hbA = actorA.sprite?.hitbox ?: error("Actor $aId has no hitbox for collision")
           val hbB = actorB.sprite?.hitbox ?: error("Actor $bId has no hitbox for collision")
           // Emit inline AABB: (ax < bx+bw) && (ax+aw > bx) && (ay < by+bh) && (ay+ah > by)
           // Using position globals: _ball_x, _ball_y, _paddle_x, _paddle_y
           // And hitbox width/height as integer literals from ActorIR
           return buildAABBExpr(aId, bId, hbA, hbB)
       }
       return CCall(expr.function, expr.args.map { visit(it) })
   }
   ```

4. **Add `buildAABBExpr` helper** that constructs a compound `CBinaryExpr` tree:
   - `_${aId}_x < _${bId}_x + ${hbB.w}` AND `_${aId}_x + ${hbA.w} > _${bId}_x` AND
   - `_${aId}_y < _${bId}_y + ${hbB.h}` AND `_${aId}_y + ${hbA.h} > _${bId}_y`
   - Use `CBinaryExpr` with `&&` operator to chain the four conditions, and `CVariable`/`CLiteral` for operands.
   - Wrap in `CGroupExpr` (parentheses) for correct C precedence.

5. **Verify hitbox field access:** Use Serena `find_symbol("ActorIR", depth=1)` to check the exact field path for hitbox width/height (likely `sprite.hitbox.w` and `sprite.hitbox.h`, or similar). Adapt field names accordingly.

**Custom Actor Properties (in ActorBuilder.kt):**

1. Add `ActorPropDelegate` class:
   ```kotlin
   class ActorPropDelegate(
       private val type: VariableType,
       private val initialValue: Int,
       private val actorBuilder: ActorBuilder
   ) : ReadOnlyProperty<Any?, ActorPropertyRef> {
       private var ref: ActorPropertyRef? = null

       operator fun provideDelegate(thisRef: Any?, property: KProperty<*>): ReadOnlyProperty<Any?, ActorPropertyRef> {
           val propName = property.name
           val varName = "${actorBuilder.id}_${propName}"
           // Register as a prefixed global variable via GameBuilderContext
           GameBuilderContext.current?.registerVariable(
               VariableDef(varName, type, initialValue)
           )
           // Store the custom prop name for ActorRef lookup
           actorBuilder.registerCustomProp(propName)
           ref = ActorPropertyRef(actorBuilder.id, propName)
           return this
       }

       override fun getValue(thisRef: Any?, property: KProperty<*>): ActorPropertyRef =
           ref ?: error("ActorPropDelegate not initialized")
   }
   ```

2. Add factory functions in `ActorBuilder`:

   ```kotlin
   fun i8Prop(initial: Int = 0): ActorPropDelegate = ActorPropDelegate(VariableType.INT8, initial, this)

   ```

3. Add `registerCustomProp(name: String)` to `ActorBuilder` that accumulates custom prop names in a list.
