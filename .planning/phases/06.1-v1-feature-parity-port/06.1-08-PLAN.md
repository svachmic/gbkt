<objective>
Wire A* pathfinding walkability to scene collision maps by replacing the non-functional `_pf_collision_fn` (UINT8=0 stub) with a direct call to `_map_collision(nx, ny)`. The `_map_collision()` function already exists as a switch-based dispatch (generated by `buildCollisionDispatchFunction` in GBDKPipelineV2) that routes to per-scene `_map_collision_{sceneId}()` functions based on `current_scene`. This approach is consistent with the existing collision architecture (which explicitly avoids function pointers for C89/GBDK compatibility) and requires no new C AST types.

Purpose: Makes NPC pathfinding respect wall/obstacle tiles at runtime. Without this fix, A* treats all tiles as walkable and NPCs pathfind through walls.
Output: A* uses `_map_collision(nx, ny)` for walkability; `_pf_collision_fn` variable removed; tests updated.
</objective>
