## Decisions Made

- **PhysicsStep = acceleration+gravity+velocity only (no floor bounce)**: Floor/ceiling detection is scene-specific game logic via `whenever()` conditions. PhysicsStep does the universal part only.
- **Velocity as INT8, position update via CCast(CU8)**: Velocity must be signed for direction. Position coordinates are UINT8 in GBDK. Cast is required at position-update time, matching existing ActorVisitor convention.
- **Bounce stored as UINT8 0-255**: Integer math avoids floats. The DSL accepts `Float` for ergonomics and converts internally. Runtime multiply-then-shift-by-8 is idiomatic Game Boy C.
