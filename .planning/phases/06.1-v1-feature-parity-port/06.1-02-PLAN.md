    1. In GBDKSystemVisitor.kt, rewrite `visitSaveSystem()` to generate typed C AST:
       a. Generate two functions: `save_game_{id}(slotIndex)` and `load_game_{id}(slotIndex)`.
       b. SRAM layout: Slot N starts at address `0xA000 + (slotIndex * slotSize)`. slotSize = savedVarCount + (useChecksum ? 1 : 0) + 1 (sentinel byte).
       c. Save function body (typed C AST):
          - `CExprStatement(CCall("ENABLE_RAM", emptyList()))` — GBDK macro. Note: ENABLE_RAM is a macro but CCall("ENABLE_RAM") will emit `ENABLE_RAM()` which works in GBDK. If not, use CRawCode("ENABLE_RAM;") as a documented GBDK macro exception.
          - `CVarDecl("sram", CPointer(CU8), CRawExpr("(volatile UINT8 *)(0xA000 + slotIndex * SLOT_SIZE)"))` — pointer to slot start. Note: CRawExpr is acceptable for type casts/GBDK-specific expressions per existing pattern.
          - For each non-transient variable: `CExprStatement(CBinaryExpr(CArrayAccess(CVar("sram"), CLiteral(idx)), "=", CVar("_${varName}")))` — write var to SRAM
          - Sentinel byte: `CExprStatement(CBinaryExpr(CArrayAccess(CVar("sram"), CLiteral(sentinelIdx)), "=", CLiteral(0xAB)))` — write sentinel (0xAB)
          - If useChecksum: add checksum byte after sentinel. Checksum = sum of all saved bytes & 0xFF. Generate a CFor loop that accumulates into a `checksum` local var, then write it.
          - `CExprStatement(CCall("DISABLE_RAM", emptyList()))` — always last statement, no matter what
       d. Load function body (typed C AST):
          - ENABLE_RAM, declare sram pointer
          - If useChecksum: compute checksum first, compare with stored; if mismatch, set error flag and DISABLE_RAM + return
          - Check sentinel: `CIf(CBinaryExpr(CArrayAccess(CVar("sram"), CLiteral(sentinelIdx)), "!=", CLiteral(0xAB)), errorBlock, loadBlock)`
          - Load block: for each non-transient var, `CExprStatement(CBinaryExpr(CVar("_${varName}"), "=", CArrayAccess(CVar("sram"), CLiteral(idx))))`
          - DISABLE_RAM always last
       e. Filter out transient variables: iterate `game.variables.filter { it.name !in system.transientVarNames }` to get saved vars list.
       f. Generate `SLOT_SIZE` as a CDefine: `#define SAVE_SLOT_SIZE {slotSize}` — include in header.

       - `save system with 3 slots generates correct slot offsets` — slots=3 generates SAVE_SLOT_SIZE define and slot arithmetic
       - `save system excludes transient variables` — transientVarNames=setOf("temp") skips _temp in save/load
       - `save system with checksum generates checksum loop` — useChecksum=true produces CFor accumulator
       - `save system pairs ENABLE_RAM and DISABLE_RAM` — verify DISABLE_RAM is always the last statement in both functions
       - `load function checks sentinel before loading` — verify CIf sentinel check exists
       - Test strategy: create SaveSystem IR + variables list, call visitSaveSystem(), inspect CFunction list, verify C AST structure and emitted text.
