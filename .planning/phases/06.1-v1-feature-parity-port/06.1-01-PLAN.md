            ```

            // rawX = (INT16)_hero_x - 80
            // _camera_x = rawX < 0 ? 0 : (rawX > boundsWidth - 160 ? boundsWidth - 160 : rawX)
            ```

            `CIf(CBinaryExpr(CVar("_camera_shake_timer"), ">", CLiteral(0)), thenBlock, elseBlock)`

            elseBlock: write SCX_REG/SCY_REG directly from _camera_x/_camera_y
