## Decisions Made

- **Cross-module smart cast**: Kotlin cannot smart cast `followActorId`/`boundsWidth`/`boundsHeight` as they are public API properties from a different module. Captured into local `val` before use.
- **CRawCode exception for register writes**: `SCX_REG = _camera_x + offset` stays as CRawCode because GBDK hardware register macros are lvalues that cannot be represented via CBinaryExpr assignment target.
- **CTernary over CCall for clamp**: C89 has no standard `max()`/`min()` — CTernary generates valid inline conditional expression.

## Deviations from Plan

None - plan executed exactly as written.

## Issues Encountered

- **Kotlin inline recursive function limitation**: `collectOfType<T>` helper in test was initially `inline fun` with recursion — Kotlin forbids recursive inline functions. Fixed by splitting into two non-inline helpers (`collectVarDecls`, `collectExprStatements`).
- **Cross-module smart cast compile error**: IR fields from different module require local val capture before use in `if (field != null)` blocks. Fixed by adding local val captures at function start.
