- pulls `GameBuilderContext.current` (or errors "actor {} must be called inside a game {} block")

For LevelCardSceneDelegate the analog is exact except:
- Returns `SceneRef` instead of `ActorRef`
- Error messages substitute "levelCardScene" for "actor" and "LevelCardSceneDelegate" for "ActorDelegate"
- Inside `provideDelegate`, instead of calling `registerActor`, the delegate calls `builder.materialize(gb)` on a `LevelCardSceneBuilder` that has been `.apply(block)`-ed. `materialize(gb)` calls `gb.scene(name) { ... }` and returns the resulting `SceneRef`.

```
class LevelCardSceneBuilder(val id: String) {
    private var gameplaySceneRef: SceneRef? = null
    private val sceneBuilderBlock = mutableListOf<SceneBuilder.() -> Unit>()
    fun onStartPress(gameplayScene: SceneRef) { gameplaySceneRef = gameplayScene }
    fun scene(block: SceneBuilder.() -> Unit) { sceneBuilderBlock += block }
    internal fun materialize(gb: GameBuilder): SceneRef = gb.scene(id) {
        sceneBuilderBlock.forEach { it() }
        frame {
            whenever(buttons.start.pressed) {
                cEmit("setup_current_level();")
                navigate(gameplay)
            }
        }
    }
}
```
The `frame { whenever(buttons.start.pressed) { ... } }` block uses the existing DSL surface from gbkt-lang (`SceneBuilder.frame`, `whenever`, `buttons.start.pressed`, `cEmit`, `navigate`).
