## DISCOVERED scene-frame function name in bank1.c

**`nextLevelScene_frame`** — verbatim from the Kotlin property name
`nextLevelScene`. The naming chain:

1. `val nextLevelScene by levelCardScene { ... }` →
   `LevelCardSceneDelegate.provideDelegate(thisRef, property)` reads
   `property.name == "nextLevelScene"`
   (`PlatformerExtensions.kt:843`).
2. `LevelCardSceneBuilder("nextLevelScene")` propagates the name as the scene id
   (`PlatformerExtensions.kt:848`).
3. `LevelCardSceneBuilder.materialize` calls `gb.scene("nextLevelScene") { ... }`
   (`PlatformerExtensions.kt:792`).
4. `SceneVisitor.visit` emits the frame function as `"${scene.id}_frame"`
   (`SceneVisitor.kt:291`), producing the literal C function name
   `nextLevelScene_frame`.

The planner's case-folding fallback (PLAN action step 5: "case may differ") was
not needed — the case is preserved end-to-end through the delegate-pattern
helper.
