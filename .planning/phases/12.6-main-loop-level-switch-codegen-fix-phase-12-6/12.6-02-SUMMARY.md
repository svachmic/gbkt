# Phase 12.6 Plan 02: trim-mainloop-guard-and-invert-emission-test Summary

DEFECT-1 substrate-tier closure: trimmed `buildMainLoopLevelSwitchGuardIfNeeded` so the
main()-loop guard's `thenBody` contains only `navigate_to_scene(SCENE_NEXTLEVEL)` (no
`setup_current_level()` call); widened the scene-id gate from exact-match to substring
`contains` so the future `nextLevelScene` delegate property-name id still satisfies the
gate; converted the corresponding positive emission assertion in `LevelSwitchEmissionTest`
to `assertFalse` so the inversion is now a live JVM-tier regression guard. The trimmed
guard codegen + the inverted assertion lock the substrate side of DEFECT-1; the runtime
new-level VRAM stomp can no longer happen in the same main-loop iteration as
`navigate_to_scene`. The `setup_current_level()` call will be reintroduced inside the
new `levelCardScene` scene's Start-press path by Plans 12.6-04 + 12.6-05.
