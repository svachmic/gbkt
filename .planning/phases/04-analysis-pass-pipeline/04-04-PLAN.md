<objective>
Implement `VRAMLayoutPass` — per-scene VRAM tile allocation with hybrid deduplication strategy. Common tiles (UI, fonts) get fixed global slots. Sprite tiles are reserved per-scene based on actor analysis. Scene-specific BG tiles fill the remaining budget. Overflow produces actionable error messages per locked decision (scene name + breakdown by source + splitting suggestions).

Purpose: VRAM is the most constrained resource on Game Boy (384 tiles total). Automatic allocation with clear overflow diagnostics prevents the most common GB development error.

Output: A tested VRAMLayoutPass that populates vramAssignments on PassContext and produces actionable tile overflow errors.
</objective>

    **VRAMLayoutPass.kt:**
    ```kotlin
    class VRAMLayoutPass : AnalysisPass {
        override fun run(context: PassContext): PassResult {
            val game = context.game
            val inventory = context.inventory
                ?: return PassResult.Failed(listOf(Diagnostic("ANLZ-03", Severity.ERROR, "ResourceInventory not available — run ResourceInventoryPass first")))

            val diagnostics = mutableListOf<Diagnostic>()
            val vramAssignments = mutableMapOf<String, VRAMRange>()

            // 1. Count global tiles (fonts, UI)
            val globalTiles = countGlobalTiles(game)

            // 2. For each scene, compute tile budget
            for (scene in game.scenes) {
                val sceneActors = game.actors.filter { it.id in scene.actorIds }
                val spriteTiles = sceneActors.sumOf { computeSpriteTileCount(it) }
                val bgTilesAvailable = 384 - spriteTiles - globalTiles

                // Check if scene has tileset/tilemap data
                val bgTilesUsed = estimateBgTiles(scene, game)

                val totalUsed = spriteTiles + globalTiles + bgTilesUsed

                if (totalUsed > 384) {
                    diagnostics.add(buildTileOverflowError(scene, spriteTiles, sceneActors, bgTilesUsed, globalTiles, game))
                    // Continue checking other scenes instead of failing immediately
                } else if (totalUsed > context.config.vramTileWarningThreshold) {
                    diagnostics.add(Diagnostic(
                        id = "ANLZ-03",
                        severity = Severity.WARNING,
                        message = "Scene '${scene.id}' uses $totalUsed / 384 VRAM tiles (${totalUsed * 100 / 384}%)",
                        location = "scene '${scene.id}'",
                    ))
                }

                // Assign VRAM ranges
                // Sprites: 0..spriteTiles-1
                // Global: spriteTiles..spriteTiles+globalTiles-1
                // BG scene-specific: spriteTiles+globalTiles..spriteTiles+globalTiles+bgTilesUsed-1
                vramAssignments[scene.id] = VRAMRange(
                    start = spriteTiles + globalTiles,
                    end = spriteTiles + globalTiles + bgTilesUsed,
                )

                // Also assign per-actor VRAM ranges
                var spriteOffset = 0
                for (actor in sceneActors) {
                    val tileCount = computeSpriteTileCount(actor)
                    vramAssignments[actor.id] = VRAMRange(start = spriteOffset, end = spriteOffset + tileCount)
                    spriteOffset += tileCount
                }
            }

            // Fail if any errors
            val errors = diagnostics.filter { it.severity == Severity.ERROR }
            if (errors.isNotEmpty()) {
                return PassResult.Failed(diagnostics)
            }

            return PassResult.Success(context.copy(
                vramAssignments = context.vramAssignments + vramAssignments,
                diagnostics = context.diagnostics + diagnostics,
            ))
        }
    }
    ```

    **Key helper methods:**
    - `computeSpriteTileCount(actor: ActorIR)`: If actor.sprite != null, return (sprite.size.width / 8) * (sprite.size.height / 8). Else 0. (Check SpriteDef for actual field names.)
    - `countGlobalTiles(game: GameIR)`: Count font tiles (check if game.assets has FONT type assets, estimate 36 tiles for standard font; 0 if no fonts). Count UI frame tiles if applicable. This is a heuristic — font presence implies ~36 tiles.
    - `estimateBgTiles(scene: SceneIR, game: GameIR)`: Look for tileset/tilemap AssetRefs associated with this scene (via scene.id matching asset naming or a scene→asset mapping). If no tilemap data, return 0. If tilemap data exists, estimate based on asset metadata or return a conservative default.
    - `buildTileOverflowError(scene, spriteTiles, actors, bgTiles, globalTiles, game)`: Build Diagnostic with id="ANLZ-03", severity=ERROR, message containing scene name, total tiles required, limit 384, breakdown (Sprites: N tiles from actor1, actor2...; Background: N tiles; UI: N tiles), and suggestion "Consider splitting tileset X into a sub-scene" or "Reduce actor sprite frame count".
