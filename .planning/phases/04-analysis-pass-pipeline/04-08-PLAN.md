Trampoline pattern for GBDK:
```c
// In HOME bank (main.c) — always accessible
void gameplay_enter_trampoline(void) {
    gameplay_enter();  // Calls into bank N via BANKED calling convention
}

// In bank N (bankN.c)
void gameplay_enter(void) BANKED {
    // actual scene code
}
```
The GBDK linker handles the `BANKED` calling convention — when `gameplay_enter()` is called from HOME, GBDK's `__sdcc_banked_call` stub switches to bank N, executes, and returns to HOME. The trampoline wrappers in HOME are thin forwarding functions that give HOME-resident code (like `navigate_to_scene()`) a non-banked entry point.

    private fun buildTrampolineStubs(game: GameIR): List<CFunction> {
        return game.scenes
            .filter { it.bankSlot != null && it.bankSlot!!.bank > 0 }
            .flatMap { scene ->
                val stubs = mutableListOf<CFunction>()
                if (scene.enterOps.isNotEmpty()) {
                    stubs += CFunction(
                        name = "${scene.id}_enter_trampoline",
                        returnType = CVoid,
                        body = listOf(CStatement.ExprStatement(
                            CExpr.FunctionCall("${scene.id}_enter", emptyList())

                        bank = 0, // HOME
                        isBanked = false,
                        sectionComment = "Trampoline: ${scene.id}_enter (bank ${scene.bankSlot!!.bank})",
                    )
                }
                // Similar for _frame and _exit if non-empty
                stubs
            }
