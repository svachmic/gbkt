    **Part A — Update estimateBgTiles in VRAMLayoutPass:**

    Replace the body of `VRAMLayoutPass.estimateBgTiles(scene, game)` to read `scene.tilesetRef`:

    ```kotlin
    private fun estimateBgTiles(scene: SceneIR, game: GameIR): Int {
        val tileset = scene.tilesetRef ?: return 0
        // Heuristic: estimate tile count from tileset asset metadata.
        // A standard Game Boy tileset PNG is organized as columns of 8x8 tiles.
        // Without file I/O at analysis time, use a conservative heuristic:
        // if a tilesetRef is present, assume a full 256-tile background set.
        // The actual tile count will be refined by the asset pipeline in Phase 5.
        return BG_TILES_DEFAULT_ESTIMATE
    }
    ```

    Add a companion constant: `private const val BG_TILES_DEFAULT_ESTIMATE = 256`

    Remove the `@Suppress("UnusedParameter", "FunctionOnlyReturningConstant")` annotation — the parameters are now used and the function no longer returns a constant.

    Update the KDoc on `estimateBgTiles` to document the new behavior: when `tilesetRef` is non-null, returns `BG_TILES_DEFAULT_ESTIMATE` (256 tiles); when null, returns 0.

    **Part B — Add BG-tile overflow test to VRAMLayoutPassTest:**

    Add a new test method `scene with tilesetRef exceeding budget fails with BG tile overflow error`:
