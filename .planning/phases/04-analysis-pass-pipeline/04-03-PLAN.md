Key constants:
- ROM_BANK_SIZE = 16,384 bytes (16 KB)
- MBC bank limits: ROM_ONLY=2, MBC1=32, MBC3=128, MBC5=256
- AnalysisConfig.bytesPerStatement = 6 (conservative heuristic for SDCC output)
- AnalysisConfig.bankFillWarningThreshold = 0.85 (85%)
- AnalysisConfig.bankFillErrorThreshold = 1.0 (100%)

Algorithm (from research):
- Code units = scene functions (enter+frame+exit), system init functions, asset data blocks
- Size estimation: count ScriptOp statements * bytesPerStatement
- Sort code units by estimated size descending (FFD)
- For each unit, assign to first bank with sufficient remaining capacity
- Tie-break: prefer bank that already contains a scene this one transitions to (scene locality)
- Bank 0 is HOME — reserved for main(), navigate_to_scene(), forward decls, trampolines

    **BankingAnalysisPass.kt:**
    ```kotlin
    class BankingAnalysisPass : AnalysisPass {
        override fun run(context: PassContext): PassResult {
            val game = context.game
            val config = context.config
            val bankCapacity = 16_384 // ROM_BANK_SIZE
            val effectiveCapacity = (bankCapacity * config.bankFillErrorThreshold).toInt()

            // 1. Build code units from scenes
            val codeUnits = buildCodeUnits(game, config.bytesPerStatement)

            // 2. Build scene transition graph for locality
            val transitionGraph = buildTransitionGraph(game)

            // 3. FFD bin-packing: sort by size desc, assign to first-fit bank
            // Bank 0 is HOME — skip it. Start packing from bank 1.
            val banks = mutableMapOf<Int, Int>() // bank number -> bytes used
            val assignments = mutableMapOf<String, BankSlot>()
            val sorted = codeUnits.sortedByDescending { it.estimatedBytes }

            for (unit in sorted) {
                val preferredBank = findPreferredBank(unit, assignments, transitionGraph)
                val assignedBank = findFirstFit(unit.estimatedBytes, banks, effectiveCapacity, preferredBank, config.maxBanks)
                    ?: return bankOverflowError(unit, config.maxBanks)
                banks[assignedBank] = (banks[assignedBank] ?: 0) + unit.estimatedBytes
                assignments[unit.id] = BankSlot(assignedBank)
            }

            // 4. Generate diagnostics for bank fill levels
            val diagnostics = generateBankDiagnostics(banks, bankCapacity, config)

            val newContext = context.copy(
                bankAssignments = context.bankAssignments + assignments,
                diagnostics = context.diagnostics + diagnostics,
            )
            return PassResult.Success(newContext)
        }
    }
    ```

    **Internal helper methods:**
    - `buildCodeUnits(game, bytesPerStatement)`: For each scene, estimate bytes = (enterOps.size + frameOps.size + exitOps.size) * bytesPerStatement. Each scene is one code unit.
    - `buildTransitionGraph(game)`: Walk all ScriptOp lists in all scenes. For each ScriptOp.EnterScene, record an edge from current scene to target scene.
    - `findPreferredBank(unit, assignments, transitionGraph)`: If any scene this unit transitions to (or from) is already assigned, prefer that bank.
    - `findFirstFit(bytes, banks, capacity, preferredBank, maxBanks)`: Try preferred bank first. If it doesn't fit, try banks 1..maxBanks-1 in order. Return null if none fit.
    - `bankOverflowError(unit, maxBanks)`: Return PassResult.Failed with diagnostic: "Bank overflow: cannot fit '{unit.id}' ({unit.estimatedBytes} bytes). All {maxBanks} banks are full."
    - `generateBankDiagnostics(banks, capacity, config)`: For each bank, if fill > warningThreshold, emit WARNING diagnostic with bank number and fill percentage.
