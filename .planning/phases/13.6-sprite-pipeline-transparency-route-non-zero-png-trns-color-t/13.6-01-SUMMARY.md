## A2 VERDICT — CRITICAL CROSS-PLAN HANDOFF

**A2 HOLDS — Plan 03 MUST USE Option i (ImageIO.write)**

The JVM PNG encoder (`javax.imageio.ImageIO.write`) on a `BufferedImage` backed by an `IndexColorModel` **preserves indexed color-type 3** in the written PNG's IHDR byte at offset 25.

- Written IHDR color-type byte at offset 25 = `0x03` (indexed/colormap)
- Expected: `0x03` (PNG_COLOR_TYPE_INDEXED_SHARED)
- Result: MATCH — the JVM does NOT upgrade to RGBA

**Plan 03 implementation implication:** The `prePermuteIndexedPng` function in Plan 03 Task 1 must use `ImageIO.write(img, "PNG", tempFile)` (Option i). Raw PNG chunk manipulation (Option ii) is NOT required.

This verdict is pinned in `ImageIoIndexedRoundTripTest.kt` as a CI-passing assertion. If the JVM PNG encoder behavior changes in a future JVM version, that test will catch it.
