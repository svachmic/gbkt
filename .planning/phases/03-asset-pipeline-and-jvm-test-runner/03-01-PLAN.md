    - Use `optJSONArray("properties")` to handle layers without properties gracefully

    **LdtkParser (new file):**
    Create `LdtkParser` object in `gbkt-core/src/main/kotlin/io/github/gbkt/core/`:
    - Parse LDtk JSON format (`.ldtk` files) using `org.json.JSONObject` (already a dependency)
    - Data classes: `LdtkMap(tileSize: Int, layers: List<LdtkLayer>)`, `LdtkLayer(identifier: String, type: String, gridSize: Int, cWid: Int, cHei: Int, intGridCsv: List<Int>, gridTiles: List<LdtkTilePlacement>, isCollision: Boolean)`, `LdtkTilePlacement(px: Pair<Int,Int>, t: Int)`
    - `parse(content: String): LdtkMap` — parses JSON, reads first level's layerInstances
    - Layer types: "Tiles", "IntGrid", "Entities", "AutoLayer"
    - Collision detection via `fieldInstances` array: look for `__identifier == "gbkt_collision"` with `__value == true`
    - Read `intGridCsv` for IntGrid layers, `gridTiles` + `autoLayerTiles` for tile placement
    - Validate `jsonVersion` field — emit clear error if unsupported format version
    - Pin support to LDtk format version 1.5.x

    **AssetManifest (new file):**
    Create manifest data model and JSON writer in `gbkt-core/src/main/kotlin/io/github/gbkt/core/`:
    - `AssetManifest(version: Int = 1, assets: List<AssetManifestEntry>)`
    - Sealed `AssetManifestEntry` with: `SpriteEntry(path, tileCount, uniqueTileCount, widthInTiles, heightInTiles, palette, frameWidth, frameHeight, frameCount)` and `TilemapEntry(path, width, height, hasCollision, tilesetPath)`
    - `fun toJson(): String` using `org.json.JSONObject` with 2-space indentation
    - `companion object { fun fromJson(content: String): AssetManifest }` for reading manifests back
    - Filename constant: `const val MANIFEST_FILENAME = "asset-manifest.json"`
