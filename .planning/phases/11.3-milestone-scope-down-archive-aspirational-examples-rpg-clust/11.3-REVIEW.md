# Phase 11.3 Code Review

## Summary

The five tooling/markdown files cleanly satisfy SPEC Requirements 1, 2, 6, and 7 — the
gitignore rule is path-locked per D-04, `settings.gradle.kts` has exactly 7
`gbkt-examples:` includes (the kept set), and `gbkt-examples/README.md` /
`gbkt-examples/SPRITE-SPECS.md` are scrubbed of all 6 archived names. Two in-scope
warnings: `gbkt-examples/CLAUDE.md` was only partially scrubbed (the illustrative tree
at lines 8-22 still shows all 6 archived dirs as active and references the non-existent
`gbkt-examples/settings.gradle.kts`), and the top-level `README.md:171` documents a
build command (`./gradlew :gbkt-examples:explorer:buildRom`) that will now FAIL because
the include was removed in this phase. Five info-level lingering references in
`context/*.md` are outside Requirement 7 scope but should be tracked.

## Findings

### Warnings

#### WR-01: gbkt-examples/CLAUDE.md illustrative tree still lists 6 archived dirs as active

- **File:** `gbkt-examples/CLAUDE.md:8-22`
- **Severity:** Warning
- **Issue:** The `Module Structure` code block at the top of the file shows the directory
  tree with `platformer/`, `platformer-gbc/`, `rpg-lite/`, `dungeon/`, `explorer/`, and
  `shmup/` listed as active subprojects, immediately after stating "Each example is a
  standalone Gradle subproject under `gbkt-examples/`". The new `## Archived examples`
  ledger at the bottom of the same file (lines 101-154) correctly enumerates all 6 as
  archived. The two halves of the file now contradict each other in a single doc — a
  reader scanning the top of CLAUDE.md will believe these games are still buildable.
  This was explicitly flagged in `11.3-CONTEXT.md` under `code_context > Reusable
  Assets`: "Planner note: when editing CLAUDE.md, decide whether the illustrative
  `gbkt-examples/` tree comment at lines ~9–20 should also drop the archived entries
  (probably yes, for consistency with the new active matrix) — flag for the planner."
  The planner / executor missed this flag.

  Additionally, line 9 (`├── settings.gradle.kts        # includes each example as a
  subproject`) perpetuates the SPEC-corrected myth that a `gbkt-examples/settings.gradle.kts`
  exists. The SPEC explicitly states (line 26): "The ROADMAP Phase 11.3 entry refers to
  `gbkt-examples/settings.gradle.kts` — no such file exists. The actual
  `include(...)` lines live in the root `settings.gradle.kts`." Same fix should drop or
  correct this line.

- **Recommendation:** Update the tree block to show only the 7 kept dirs (`pong/`,
  `breakout/`, `simple-physics/`, `metasprites/`, `metasprites-stress/`, `banks/`,
  `racer/`) and remove the misleading `settings.gradle.kts` line — or rewrite it to point
  at the root settings file (e.g., `# included via root settings.gradle.kts`).

#### WR-02: Top-level README.md documents a now-broken build command (explorer)

- **File:** `README.md:162`, `README.md:169-171` (root)
- **Severity:** Warning
- **Issue:** The top-level project README has an "Examples" table that lists
  `**Explorer** | Advanced | Zones, camera follow, exploration system, save/load` (line
  162) followed by a code block (lines 169-171) showing:
  ```
  # Or try breakout / explorer
  ./gradlew :gbkt-examples:breakout:buildRom
  ./gradlew :gbkt-examples:explorer:buildRom
  ```
  As of this phase, `:gbkt-examples:explorer` is no longer in `settings.gradle.kts` —
  the documented command will fail with a Gradle "project not found" error. SPEC
  Requirement 7 only listed `gbkt-examples/README.md` and `gbkt-examples/SPRITE-SPECS.md`
  as scrub targets, so this is technically out of declared scope; nonetheless the phase
  delivered a user-facing regression in the project's primary entry-point doc.

- **Recommendation:** Either (a) replace `explorer` with a kept example
  (e.g., `racer` or `banks`) in lines 162 and 171, or (b) add a follow-up phase /
  micro-fix to scrub the top-level README. Given the SPEC scope cap, option (b) is
  consistent with "no master pollution" — open a SEED or a 11.4 micro-fix for the
  top-level docs sweep.
