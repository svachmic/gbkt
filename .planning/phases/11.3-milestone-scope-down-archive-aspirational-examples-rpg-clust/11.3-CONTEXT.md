<decisions>
## Implementation Decisions

### Commit shape & ordering

- **D-01:** Land the phase as **5 stepped commits** (each commit GREEN; clean bisect surface):
  1. `chore: gitignore gbkt-examples/.archive/` — adds the ignore rule only. No working-tree files moved yet. Build remains GREEN (no graph change).
  2. `chore(examples): archive 6 aspirational subprojects` — `git rm -r` each of the 6 original tracked paths AND relocate working-copy contents to `gbkt-examples/.archive/<name>/` (now ignored thanks to commit 1) AND drop the 6 `include("gbkt-examples:<name>")` lines from root `settings.gradle.kts` — all in **one commit** so the build graph and the on-disk subprojects flip together. Build must be GREEN at this commit.
  3. `docs(examples): CLAUDE.md archive ledger` — append `## Archived examples` section to `gbkt-examples/CLAUDE.md` (6 `###` subsections, format locked in D-04).
  4. `docs(examples): scrub README + SPRITE-SPECS` — remove the 6 archived rows from `gbkt-examples/README.md` "Examples Overview" table and remove archived-game sections from `gbkt-examples/SPRITE-SPECS.md` (scrub style locked in D-05).
  5. `docs(planning): ROADMAP 12/13 sweep targets + SEED-018 archive note` — add `Regression sweep targets:` line to Phase 12 + Phase 13 Success Criteria; append `## Archive note (Phase 11.3, 2026-05-21)` to `SEED-018-rpg-character-codegen-extern-decl-mismatch.md`.
- **D-02:** **Smoke gate position** — `./gradlew clean build` runs as the verification step **after commit 2** at minimum (this is the only commit that changes the build graph) and again as a final phase-close smoke. Commits 3–5 are docs-only and cannot break the build; they may still be sanity-checked but a clean build is not required between each.
- **D-03:** **Move mechanic** — for each of the 6 archived dirs, the move must be: (a) ensure the relocation destination is already covered by `.gitignore` (commit 1 landed first); (b) `git rm -r gbkt-examples/<name>` to detach from git; (c) move the working-tree contents to `gbkt-examples/.archive/<name>/` via a plain shell `mv` (NOT `git mv` — the destination is gitignored so git would refuse / no-op the rename). This sequence is what makes the archive a true local stash, not a tracked rename.

### Gitignore rule wording

- **D-04 (gitignore):** Root `.gitignore` gains exactly the path-locked rule `gbkt-examples/.archive/` (with a one-line preceding comment noting Phase 11.3 origin). Rejected alternatives: `**/.archive/` and `.archive/` — both have the same hide-by-default risk if some other future `.archive/` directory appears anywhere in the tree. Path-locking matches the SPEC's literal wording and keeps the surface area explicit.

### Archive ledger format (`gbkt-examples/CLAUDE.md`)

- **D-04 (ledger format):** Section `## Archived examples` uses **one `### <name>` subsection per archived game**, each followed by a bulleted list of the 5 required fields:
  - `- Original path: gbkt-examples/<name>/`
  - `- Archive path: gbkt-examples/.archive/<name>/`
  - `- Reason: <reason>`
  - `- Revival condition: <condition>`
  - `- Date archived: 2026-05-21`
  Rejected: single 5-column table (long cells wrap awkwardly; harder to extend per-game), GFM definition list (inconsistent rendering across IDEs).
- **D-05 (per-game reasons / revival conditions for the ledger):**
  - `explorer` — Reason: `SEED-018 RPG character codegen extern/decl mismatch (full 7-stat set, :buildRom fails)`. Revival: `after SEED-018 is fixed and routed to a phase`.
  - `rpg-lite` — Reason: `SEED-018 RPG character codegen extern/decl mismatch`. Revival: `after SEED-018 is fixed`.
  - `dungeon` — Reason: `SEED-018 RPG character codegen extern/decl mismatch`. Revival: `after SEED-018 is fixed`.
  - `platformer` — Reason: `Phase 07.5 platformer genre codegen gap (deferred)`. Revival: `after Phase 07.5 ships`.
  - `platformer-gbc` — Reason: `Phase 07.5 platformer genre codegen gap (deferred); shares platformer codegen path`. Revival: `after Phase 07.5 ships`.
  - `shmup` — Reason: `polish backlog — F-A pool-pool collision + F-B stale OAM on scene re-entry (UAT-shmup.md)`. Revival: `owner: TBD; after F-A and F-B are routed to a phase`.

### README/SPRITE-SPECS scrub treatment

- **D-06:** **Remove rows/sections entirely** in both `gbkt-examples/README.md` and `gbkt-examples/SPRITE-SPECS.md`. The README "Examples Overview" table drops the 6 archived rows (resulting table has exactly 7 active rows). `SPRITE-SPECS.md` drops the entire `## RPG-Lite`, `## Platformer`, `## Shmup` (and any other archived-game) sections. - **D-07:** **README "Nine example games" headline copy** — update the lead sentence to reflect the new count: "Seven example games demonstrating the gbkt DSL..." (or equivalent). Active table must have exactly 7 rows; the headline must agree.
- **D-08:** **SPRITE-SPECS lead paragraph** — the current lead refers to Platformer/Shmup as games with GBDK equivalents; that aside is no longer relevant once those sections are removed. Rewrite the lead to reflect only the active set, or remove the now-orphaned reference entirely.
