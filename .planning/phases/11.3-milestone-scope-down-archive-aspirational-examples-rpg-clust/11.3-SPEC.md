**Created:** 2026-05-21

## Goal

Narrow the v1.0 active `gbkt-examples/` matrix from 13 game subprojects down to the 7 framework-validated ones (`pong`, `breakout`, `simple-physics`, `metasprites`, `metasprites-stress`, `banks`, `racer`) by moving the 6 aspirational subprojects (`explorer`, `rpg-lite`, `dungeon`, `platformer`, `platformer-gbc`, `shmup`) into a gitignored local-stash directory `gbkt-examples/.archive/`, dropping their `include(...)` lines from root `settings.gradle.kts`, and recording the 7-game sweep contract explicitly in the ROADMAP Phase 12 + Phase 13 entries — so Phase 12 (next port) and Phase 13 (framework primitives) inherit a clean regression-sweep matrix, not a bloated one conflating archived-aspirational failures with framework regressions.

## Background

**Current example matrix.** `gbkt-examples/` contains 13 game subprojects, all included in the root `settings.gradle.kts` (lines 50–62):

- Kept 7 (framework-validated by reference ports): `pong`, `breakout`, `simple-physics`, `metasprites`, `metasprites-stress`, `banks`, `racer`.
- Archive 6 (aspirational; require unproven domain capabilities): `explorer`, `rpg-lite`, `dungeon`, `platformer`, `platformer-gbc`, `shmup`.

**Pre-existing build blockers in the archive set:**

- `dungeon`, `explorer`, `rpg-lite` — `:buildRom` fails on SEED-018 (RPG character extern/declaration mismatch, full 7-stat set). Pre-dates Phase 11.1.
- `platformer`, `platformer-gbc` — blocked on Phase 07.5 (platformer genre codegen fix; deferred).
- `shmup` — documented polish defects in `UAT-shmup.md` (F-A pool-pool collision, F-B stale OAM on scene re-entry).

These contribute noise to every regression sweep without surfacing fresh framework bugs.

**ROADMAP path correction.** The ROADMAP Phase 11.3 entry refers to "`gbkt-examples/settings.gradle.kts`" — no such file exists. The actual `include("gbkt-examples:<name>")` lines live in the **root `settings.gradle.kts`**. This SPEC targets the root file.

**Archive semantics — deviation from ROADMAP.** ROADMAP entry says "archive = move, not delete — preserves examples as future port targets". User clarified during Round 1: the archive is a **local-disk stash** under `gbkt-examples/.archive/`, added to `.gitignore`, **not preserved in master**. Future repurposing or deletion is decided later, off the master branch. SPEC.md reflects this revised intent.

**Genre modules.** `gbkt-genre-rpg`, `gbkt-genre-platformer`, `gbkt-genre-puzzle`, `gbkt-genre-sport` are library modules under root `include(...)` (not under `gbkt-examples/`). They remain in-tree, untouched; their JVM unit tests continue to run.

**Regression-sweep contract.** No single "v1.0 milestone regression sweep" block exists in ROADMAP today — the doctrine is referenced from Phase 11.1, 11.2 close gates. User clarified during Round 2: Phase 12 + Phase 13 entries each get an explicit "Regression sweep targets" line enumerating the 7 kept games. No new top-level block.

## Constraints

- **Gitignore-before-move ordering**: `gbkt-examples/.archive/` MUST be added to root `.gitignore` and the gitignore commit landed before the working-copy contents are moved into `.archive/`. Otherwise, even though the originals are `git rm`'d, the relocated working-tree files may appear as untracked-but-visible in `git status` until the ignore takes effect, polluting the working state.
- **Path target correction**: The ROADMAP entry's reference to `gbkt-examples/settings.gradle.kts` is incorrect (file does not exist). Phase 11.3 acts on the **root** `settings.gradle.kts`. Planners must not search for or create a `gbkt-examples/settings.gradle.kts`.
- **No master pollution before done**: User constraint (Q1). Intermediate states with the archive dir tracked or with the include lines still pointing to moved dirs must not land on master. The phase should land as atomic-as-feasible — at minimum, the gitignore + .gradle includes + file moves should be coordinated so that no intermediate commit leaves the build broken.
- **No IR / codegen changes**: Hard scope cap from ROADMAP.
- **Genre modules in-tree, dormant**: `gbkt-genre-*` modules remain in `settings.gradle.kts`; their unit tests remain GREEN. No regression-guard replacement is required (existing tests are the contract).
- **`./gradlew build` is the smoke gate**: After the archive lands, a clean build of the narrowed matrix is the primary acceptance signal.
