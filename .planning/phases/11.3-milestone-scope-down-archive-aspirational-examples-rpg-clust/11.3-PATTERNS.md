### Archive move: 6 directories under `gbkt-examples/` → `gbkt-examples/.archive/<name>/`

**Analog:** none. No prior phase in this repo has performed a `git rm -r` + working-copy-preserve pattern. The 14 prior `gbkt-examples/*` directories were all created (`git log --diff-filter=A` shows pure adds — `scaffold` commits for pong/breakout/banks/metasprites/etc.). This is first-of-kind.

**Current state (verified by `ls -d gbkt-examples/*/`):**
- 6 dirs to archive: `explorer/`, `rpg-lite/`, `dungeon/`, `platformer/`, `platformer-gbc/`, `shmup/`
- 7 dirs to keep: `pong/`, `breakout/`, `simple-physics/`, `metasprites/`, `metasprites-stress/`, `banks/`, `racer/`
- 1 tooling dir to ignore: `build/` (already gitignored)

**Edit mechanic (D-03 — locked):**
Per archived dir N:
1. `git rm -r gbkt-examples/<N>` — detaches from index. Working-tree contents are deleted by `git rm -r`.
2. **Stash-rescue:** since `git rm -r` removes the working-copy too, the contents must be either (a) restored from a fresh checkout of HEAD~1 (cleanest), OR (b) preserved by copying to `.archive/` BEFORE running `git rm -r`.
   - **Recommended sequence (atomic per dir):**
     ```
     mkdir -p gbkt-examples/.archive
     mv gbkt-examples/<N> gbkt-examples/.archive/<N>   # plain mv, NOT git mv
     git rm -r --cached gbkt-examples/<N>              # remove from index only (working copy already moved)
     ```
   - Using `--cached` is the cleanest one-shot — index is updated, working copy is the moved `.archive/<N>/`, and (because commit 1 already landed) `.archive/` is gitignored so no untracked-status pollution.
3. After all 6 moves, run `git status` — should show:
   - 6 dirs deleted from `gbkt-examples/`
   - No untracked files under `gbkt-examples/.archive/` (because gitignored)
   - 1 modification to `settings.gradle.kts` (the 6 deletions)

**Format conventions to preserve:**
- Archive layout matches original layout 1:1 — no rename within the archive; `gbkt-examples/explorer/` → `gbkt-examples/.archive/explorer/`.
- No source edits inside any archived dir (SPEC §Boundaries, Hard scope cap).

**Atomicity (D-01 step 2):** This commit MUST also drop the 6 `include(...)` lines from `settings.gradle.kts` in the same commit. Two reasons: (a) the build graph would point at deleted dirs between commits, breaking bisect; (b) the SPEC §Constraint "No master pollution before done" forbids intermediate broken states on master.

**Smoke gate (D-02):** `./gradlew clean build` MUST exit 0 after this commit and again at phase close. JVM tests are not sufficient — see user memory `feedback_rom_build_smoke_test_for_codegen_phases.md`. (Phase 11.3 doesn't touch codegen, but the smoke gate is cheap insurance against forgotten `include(...)` drift.)

**`git mv` is wrong here:** Destination is gitignored after commit 1, so `git mv` would refuse the rename (`fatal: <dest> ignored` or no-op). Use plain shell `mv` (D-03 locked).

### Append-section to existing Markdown doc

**Source:** itself for each file; closest cross-file analog is the per-phase `##` section style used across `.planning/phases/<N>/<N>-CONTEXT.md` files.

**Convention:**
- Two-hash `## ` for top-level sections.
- Blank line before and after the heading.
- Inline `## ` headings always start at column 0.
- Section body uses bullet lists (`- `) for structured fields, prose paragraphs for narrative, fenced code blocks for verbatim content.

**Source:** `.gitignore` lines 42–49 (Phase 10 reference-ROM block — full paths, not globs).

**Apply to:** `.gitignore` D-04 (Phase 11.3 archive rule).
