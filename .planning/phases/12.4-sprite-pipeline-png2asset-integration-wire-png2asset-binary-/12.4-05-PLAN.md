<objective>
Add a pre-codegen validation gate in `GenerateCTask` that throws `GradleException` if any
`MetaspriteIR` has `spritePath == null`. Closes CONTEXT D-01b ("IR field is OPTIONAL during
migration; REQUIRED at codegen") + supports SPEC REQ-3 (sprite() binder mandatory) and
REQ-5 (fail-fast policy).

Purpose: The migration window keeps `MetaspriteIR.spritePath` nullable so existing tests
compile (per D-01b). Once Plans 12.4-09 + 12.4-10 + 12.4-11 migrate the 3 in-tree games
(metasprites, metasprites-stress, platformer-template) to call `sprite(asset(...))`, this gate
becomes the contract: any FUTURE metasprite added without a `sprite()` binding fails the build
at codegen time with an actionable message. No silent "spritePath stays null → sidecar skips →
ConvertSpritesTask never sees the metasprite → no output `.c` → lcc 'undefined sprites_<id>_tiles'"
error trail.

Per RESEARCH Scout Target 4c: this is an inline GradleException in GenerateCTask, NOT a new
analysis pass (SemanticValidationPass is NOT modified).

Output: Validation block in `GenerateCWorkAction.execute()` (or `executeV2Path()`) + 1 RED→GREEN
unit test.
</objective>

    // Phase 12.4 D-01b validation gate: every metasprite MUST have an explicit sprite(asset(...))
    // binding by codegen time. The MetaspriteIR.spritePath field is nullable in IR (migration
    // window per D-01b) so existing tests compile; this gate enforces the contract at the
    // codegen boundary. Mirrors Phase 12.4 D-04 fail-fast pattern in ConvertSpritesTask
    // (silent-skip would surface as 'undefined sprites_<id>_tiles' at lcc link time).
    val metaspritesField =
        gameIR.javaClass.getMethod("getMetasprites")
            ?: throw GradleException("GameIR has no getMetasprites() method")
    @Suppress("UNCHECKED_CAST")
    val metasprites = metaspritesField.invoke(gameIR) as List<Any>
    for (ms in metasprites) {
        val spritePath = ms.javaClass.getMethod("getSpritePath").invoke(ms) as String?
        if (spritePath == null) {
            val id = ms.javaClass.getMethod("getId").invoke(ms) as String
            throw GradleException(
                "Metasprite '$id' is missing sprite(asset(...)) — add " +
                "sprite(asset(\"<path>\")) to your metasprite { } block (Phase 12.4 D-01b). " +
                "Every metasprite MUST declare its PNG asset explicitly so " +
                "ConvertSpritesTask can resolve it via the game_metadata.json sidecar."

    }
