<objective>
Lock the SPEC § Constraints back-compat invariant: generated sprite C for metasprites/elephant +
metasprites-stress/elephant + metasprites-stress/tiger MUST be byte-identical pre/post-12.4.
Covers SPEC REQ-3 acceptance ("metasprites + metasprites-stress UAT tests stay GREEN") and the
back-compat constraint that the Phase 10/10.1 UAT GREEN screenshots reproduce after Phase 12.4.

Purpose: Plans 12.4-01..06 refactor the path that drives png2asset (sidecar instead of main.c
grep) but should NOT change the `-noflip` flag combination for any of the 3 in-tree metasprite
PNGs (`mirrorDedup` stays false → `-noflip` ON, same as pre-12.4 `isMetaspriteBound`-forced
behavior). The flag combination plus the unchanged PNG bytes means png2asset emits byte-identical
output. This plan captures that output as a committed baseline + asserts it via a regression test.

If a future change accidentally flips the `-noflip` arg, drops a flag, or alters the sidecar
schema in a way that mutates png2asset output, this test goes RED with a clear diff.

Output: 2 test files + 3 committed `.baseline` files (one per generated sprite C output).
</objective>
