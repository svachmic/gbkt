# Phase 12.4 Plan 04: Fail-Fast GradleException Replacement + Stub Generators Deleted — Summary

**One-liner:** Delete `generateStubCFile`/`generateStubHeader` and replace all 4 silent-stub paths in `ConvertSpritesTask` with `throw GradleException(...)`, with 4 RED→GREEN unit tests.

## What Was Built

Replaced the 4 silent-placeholder fallback paths in `ConvertSpritesTask` (that previously emitted a 64-byte checkerboard stub on failure) with fail-fast `GradleException` throws, and deleted the two helper methods that generated the stubs. This is the Phase 12.4 D-04 implementation, mirroring the Phase 12.2 Defect 7 full-delete pattern (`ConvertZoneTilesetsTask.synthesizeScreenTilemap()` removal).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed exec/exception separation to prevent GradleException re-wrapping**
- **Found during:** Initial test run for Path 2 and Path 3
- **Issue:** The original `try { ... throw GradleException } catch (e: GradleException) { throw e }` pattern caused Gradle's own process-launch GradleException to be re-wrapped with message `"A problem occurred starting process..."` instead of `"png2asset threw..."`. Test 3 assertion on `"png2asset threw"` failed.
- **Fix:** Separated `exec()` into its own try-catch block; exit-value check moved OUTSIDE the try block so the exit-nonzero throw is never re-caught.
- **Files modified:** `ConvertSpritesTask.kt`
- **Commit:** a6701b25 (included in same commit)

**2. [Rule 1 - Bug] Fixed ConvertSpritesTaskSidecarTest writeSpritePng helper**
- **Found during:** Full suite run after commit
- **Issue:** `ConvertSpritesTaskSidecarTest.sidecar_drives_pngfile_resolution` broke because the synthetic 8×16 PNG (TYPE_INT_ARGB, all pixels at default zero/transparent) caused png2asset to produce a `_tiles[0] = {}` zero-size array. With Path 4 now throwing instead of silently generating a stub, the sidecar happy-path test began throwing.
- **Fix:** Replaced `BufferedImage.TYPE_INT_ARGB` with `TYPE_INT_RGB` checkerboard (black/white per-pixel). png2asset produces `_tiles[32] = { ... }` for an 8×16 checkerboard = non-empty, GREEN.
- **Files modified:** `ConvertSpritesTaskSidecarTest.kt`
- **Commit:** a6701b25 (included in same commit)
