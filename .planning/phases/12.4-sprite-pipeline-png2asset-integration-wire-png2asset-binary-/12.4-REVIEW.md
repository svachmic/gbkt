## Triage Notes

### WR-01 (Windows path separator in error message)
Accept for Phase 12.4. gbkt's primary development platform is macOS/Linux. The functional correctness is not affected. Fix in a future cleanup pass when Windows CI is added. Severity: cosmetic.

### WR-02 (Malformed sidecar JSON surfaces as raw org.json exception)
Accept for Phase 12.4. The sidecar is machine-generated; `game_metadata.json` malformation would indicate a pipeline bug detectable at the source. ConvertZoneTilesetsTask has the same pattern — fixing only ConvertSpritesTask creates asymmetry. Route to a shared "error experience" improvement plan. Severity: DX issue, not a correctness bug.

### WR-03 (No JVM test for actor sprites in sidecar)
**Recommend adding test before phase close.** The 12.4-13 regression fix (actor sprite emission into `sprites[]`) is the highest-risk late change in the phase — it repaired a regression that broke all actor-sprite games (pong, breakout, banks, simple-physics). A ROM smoke test validated the fix, but JVM-tier coverage would make the regression structurally undetectable in future CI without GBDK. The test addition is one new test method in an existing file. Low effort, high value.
