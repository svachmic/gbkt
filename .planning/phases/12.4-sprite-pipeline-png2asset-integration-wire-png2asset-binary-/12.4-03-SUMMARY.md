## RESEARCH Open Question 2 Closure

elephant.png dimensions: `64 x 240` (verified via `file` command and Python IHDR read).

Height 240 >= 16 → `spriteModeFromHeight()` returns `SPR8x16`. This is the correct behavior under the Phase 12.4 sidecar contract: the old `isMetaspriteBound` SPR8x8 override is removed because `mirrorDedup` from the sidecar entry now controls the `-noflip` flag, which is the actual tile-layout concern. The height heuristic picks the mode independently.

No hardcoded `SPR8x8` fallback needed.
