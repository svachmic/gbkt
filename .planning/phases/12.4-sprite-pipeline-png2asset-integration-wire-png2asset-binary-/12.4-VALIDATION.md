| **D3** State transitions | Pre-12.4 `player.c` = 64-byte checkerboard; post-12.4 `player.c` = real png2asset output; metasprites + metasprites-stress generated sprite C byte-identical | Byte-identity test (planner module-of-record TBD) + generated-C `wc -c` assertion |
| **D4** Integration | `GenerateCTask` → `GBDKPipelineV2.buildMetadataFile()` emits `sprites[]` → `ConvertSpritesTask` reads sidecar → resolves `assetDir/{spritePath}` → invokes `png2asset` → writes `build/gbkt/generated/sprites/<id>.c` → `lcc` links → emulator renders | `PlatformerTemplateUatTest.anchor4MetaspriteAnimation` end-to-end |
| **D5** Boundary | All 6 active games build clean (`:buildRom` exit 0); archived games (Phase 11.3) unchanged; `gbkt-emulator` `GameMetadata` parser ignores `sprites[]` (additive) | 6-ROM `:buildRom` sweep + `GameMetadataParserAdditiveTest` (or grep-equivalent) |
| **D6** Failure modes | 4 fail-fast paths in `ConvertSpritesTask` (missing PNG, png2asset exit≠0, png2asset throws, zero-size array) + `spritePath==null` codegen gate | `ConvertSpritesTaskFailFastTest` (4 cases) + D-01b null-gate test |
| **D7** Performance | png2asset invocations ≤3 per clean build (1 per metasprite block); task is `@CacheableTask` with `@get:InputFile metadataFile` | Gradle build-scan metric / log inspection (planner: optional) |
| **D8** Regression | metasprites + metasprites-stress UAT stay GREEN; platformer-template anchor 4 pixel-diff > 5% (facing-right vs facing-left in metasprite-occupied region) | Existing UAT suite + `VisualDiff.compare()` (already at `gbkt-emulator/.../VisualDiff.kt:58`) |
