## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Codegen pipeline → build artifact | `game_metadata.json` is written to `build/gbkt/generated/` — an attacker with write access there could tamper with `sprites[]` to redirect png2asset to malicious PNG paths. **In-scope threat is low** because (a) `build/` is gitignored and developer-local; (b) ConvertSpritesTask runs locally with developer privileges; (c) path-traversal guard belongs in the resolver (Plan 12.4-03 / Plan 12.4-04). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12.4-02-T | Tampering | `game_metadata.json` write to `build/` | accept | Build artifact; existing trust boundary (the entire `build/` tree is developer-writable). No mitigation at this seam. |
| T-12.4-02-I | Information disclosure | `spritePath` strings leak file layout under `res/` | accept | `res/` paths are already visible in `main.c` (via `#include "sprites/<stem>.h"`) and in the source tree. No new disclosure. |
