# Phase 12.4 Plan 01: MetaspriteIR.spritePath + MetaspriteBuilder.sprite(AssetRef) Summary

**One-liner:** Additive `spritePath: String?` field on `MetaspriteIR` plus `sprite(AssetRef)` DSL binder on `MetaspriteBuilder` — typed foundation seam for the Phase 12.4 png2asset pipeline (REQ-3).

## What Was Built

### Task 1: MetaspriteIR.spritePath field (gbkt-ir leaf module)

Added `val spritePath: String? = null` to the `MetaspriteIR` data class, positioned after `mirrorDedup` and before `sourceLocation`. The field is nullable with a null default, preserving the D-01b migration window: existing metasprites that do not call `sprite()` remain valid throughout Phase 12.4.

- KDoc paragraph describes the D-02 sidecar emitter flow and the Plan 12.4-05 validation gate
- Module boundary check GREEN — no new gbkt dependencies introduced
- 4 test cases in `MetaspriteIRSpritePathFieldTest`: null default, explicit value, copy semantics, no field-shift regression

### Task 2: MetaspriteBuilder.sprite(AssetRef) binder (gbkt-lang)

Added three changes to `MetaspriteBuilder.kt`:
1. `import io.github.gbkt.core.ir.AssetRef`
2. `internal var spriteAssetPath: String? = null` backing field after `rotVar`
3. `fun sprite(asset: AssetRef)` public binder method after `rot()` — captures only `asset.path`, discards `AssetType`
4. `spritePath = spriteAssetPath,` wired into `MetaspriteIR(...)` constructor call in `build()`

The `asset()` factory was confirmed at `gbkt-lang/src/main/kotlin/io/github/gbkt/core/dsl/AssetRegistry.kt:43` — same package as the test, no extra import needed.

### Task 3: MetaspriteSpriteDslTest (RED→GREEN — 2 cases)

Created `MetaspriteSpriteDslTest.kt` in `gbkt-lang/src/test/kotlin/io/github/gbkt/core/dsl/`:
- Test 1 (`sprite_binder_captures_asset_path`): full DSL build with `sprite(asset("sprites/foo.png"))` — asserts `MetaspriteIR.spritePath == "sprites/foo.png"`
- Test 2 (`no_sprite_binder_leaves_path_null`): metasprite without `sprite()` call — asserts `spritePath == null`

Both tests were RED before Task 2's implementation landed and GREEN after.
