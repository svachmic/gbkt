```kotlin
package io.github.gbkt.backend.gbdk.codegen.emit

object CEmitter {
    fun emit(file: CFile): String = buildString { ... }
}
```

Implementation rules (from locked decisions and research):
- **Fixed formatting:** 4-space indentation, K&R braces (`{` on same line as statement)
- **Bank pragma:** `#pragma bank N` at file top when CFile.bank > 0
- **BANKED keyword:** Appended to function signature when isBanked=true: `void foo(void) BANKED {`
- **Section comments:** `// Section comment` on line before function when sectionComment != null
- **Blank lines:** Between functions, after includes block, after defines block
- **Generated header:** `// Generated by gbkt` as first line
- **Unsigned literals:** CLiteral with non-negative value gets `u` suffix (GBDK convention). Negative values are signed (no suffix).
- **Exhaustive when:** The `when(stmt)` and `when(expr)` and `when(type)` blocks MUST cover all sealed subtypes with NO `else` branch. The Kotlin compiler enforces this.
- **CType to C string mapping:** CU8→"UINT8", CU16→"UINT16", CI8→"INT8", CI16→"INT16", CVoid→"void", CPointer(T)→"${emitType(T)}*", CArray(T,n)→"${emitType(T)}", CConst(T)→"const ${emitType(T)}"

Internal structure of CEmitter:
- `fun emit(file: CFile): String` — main entry point
- `private fun emitFunction(fn: CFunction, indent: Int = 0): String`
- `private fun emitStatement(stmt: CStatement, indent: Int): String` — exhaustive when
- `private fun emitExpr(expr: CExpr): String` — exhaustive when
- `private fun emitType(type: CType): String` — exhaustive when
- `private fun pad(indent: Int): String` = `"    ".repeat(indent)`
