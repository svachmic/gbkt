<objective>
Build the C AST sealed data class hierarchy in the GBDK backend codegen module.

Purpose: Establish the typed representation of generated C code that replaces string-based emission. Bank assignment as a typed field on CFile and CFunction eliminates the mutable `var currentBank = 0` state that causes bank-leak bugs (documented in MEMORY.md). This is the foundation layer that the emitter (02-02) and visitors (02-03) both depend on.

Output: Six Kotlin files in `gbkt-backend-gbdk/.../codegen/ast/` defining CFile, CFunction, CStatement (sealed), CExpr (sealed), CType (sealed), CDeclaration, plus a comprehensive test file.
</objective>

Create six files in `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/ast/`:

**CType.kt** — Sealed interface with data object/class subtypes:
- `CU8`, `CU16`, `CI8`, `CI16` (data objects matching VarType enum values from ir.v2.Types)
- `CVoid` (data object)
- `CPointer(val pointedType: CType)` (data class)
- `CArray(val elementType: CType, val size: Int?)` (data class)
- `CConst(val inner: CType)` (data class — wraps another type with const qualifier)
Package: `io.github.gbkt.backend.gbdk.codegen.ast`

**CExpr.kt** — Sealed interface with data class subtypes:
- `CLiteral(val value: Int)` — integer literal
- `CStringLiteral(val value: String)` — string literal
- `CVar(val name: String)` — variable reference
- `CBinaryExpr(val left: CExpr, val op: String, val right: CExpr)` — binary operation (op is the C operator string: "+", "-", "==", etc.)
- `CUnaryExpr(val op: String, val operand: CExpr)` — unary operation ("!", "-", "~")
- `CCall(val function: String, val args: List<CExpr>)` — function call expression
- `CTernary(val condition: CExpr, val thenExpr: CExpr, val elseExpr: CExpr)` — ternary conditional
- `CArrayAccess(val array: CExpr, val index: CExpr)` — array indexing
- `CCast(val type: CType, val expr: CExpr)` — type cast
- `CRawExpr(val code: String)` — escape hatch for GBDK-specific expressions
Package: `io.github.gbkt.backend.gbdk.codegen.ast`

**CStatement.kt** — Sealed interface with data class subtypes:
- `CIf(val condition: CExpr, val thenBody: List<CStatement>, val elseBody: List<CStatement> = emptyList())`
- `CFor(val init: CStatement?, val condition: CExpr?, val increment: CExpr?, val body: List<CStatement>)`
- `CWhile(val condition: CExpr, val body: List<CStatement>)`
- `CSwitch(val expr: CExpr, val cases: List<CSwitchCase>)` where `CSwitchCase(val value: CExpr?, val body: List<CStatement>)` (value=null → default)
- `CReturn(val value: CExpr? = null)`
- `CBlock(val statements: List<CStatement>)` — scoped `{ ... }` block
- `CVarDecl(val name: String, val type: CType, val initializer: CExpr? = null, val isStatic: Boolean = false, val isConst: Boolean = false)`
- `CExprStatement(val expr: CExpr)` — expression as statement
- `CRawCode(val code: String)` — escape hatch per locked decision
- `CComment(val text: String)` — comment statement for section markers
- `CBlankLine` (data object) — blank line for readability in output
CSwitchCase is a regular data class (not sealed subtype), defined in same file.
Package: `io.github.gbkt.backend.gbdk.codegen.ast`

**CDeclaration.kt** — Utility types for file-level declarations:
- `CDefine(val name: String, val value: String?)` — `#define` directive
- `CTypedef(val name: String, val definition: String)` — typedef
Both are data classes. Not sealed (these are simple file-level constructs).
Package: `io.github.gbkt.backend.gbdk.codegen.ast`

**CFunction.kt** — Data class (not sealed — there's only one kind of function):
- `val name: String`
- `val returnType: CType`
- `val params: List<CParam> = emptyList()`
- `val body: List<CStatement> = emptyList()`
- `val bank: Int? = null` — null means inherits from containing CFile
- `val isBanked: Boolean = false` — adds BANKED keyword in GBDK output
- `val isStatic: Boolean = false`
- `val sectionComment: String? = null` — e.g. "Scene: gameplay" for tracing
Where `CParam(val name: String, val type: CType)` is a data class in same file.
Package: `io.github.gbkt.backend.gbdk.codegen.ast`

**CFile.kt** — Data class (not sealed — there's only one kind of file):
- `val name: String` — e.g. "main.c", "bank1.c"
- `val bank: Int = 0` — ROM bank for this file
- `val includes: List<String> = emptyList()` — `#include` paths
- `val defines: List<CDefine> = emptyList()`
- `val typedefs: List<CTypedef> = emptyList()`
- `val variables: List<CVarDecl> = emptyList()` — file-level variable declarations
- `val functions: List<CFunction> = emptyList()`
Package: `io.github.gbkt.backend.gbdk.codegen.ast`
