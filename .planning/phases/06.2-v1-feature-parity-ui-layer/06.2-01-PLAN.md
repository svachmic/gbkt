  **1. Create `UITypes.kt`** in `gbkt-ir/src/main/kotlin/io/github/gbkt/core/ir/` with these IR data types:

  Enums:
  - `BorderStyle` — NONE, SINGLE, DOUBLE, CUSTOM
  - `MenuLayout` — VERTICAL, HORIZONTAL, GRID
  - `Anchor` — TOP_LEFT, TOP_RIGHT, BOTTOM_LEFT, BOTTOM_RIGHT, TOP, BOTTOM, LEFT, RIGHT, CENTER
  - `TextAlignment` — LEFT, CENTER, RIGHT
  - `ScrollBehavior` — AUTO_SCROLL, PAGE_BASED
  - `IconDisplayMode` — FULL_AND_EMPTY, FILLED_ONLY
  - `FontMode` — FIXED_WIDTH, VARIABLE_WIDTH (FIXED_WIDTH is default tile-based rendering; VARIABLE_WIDTH selects the VWF rendering path for GBC — both paths must be fully implemented in codegen)

  Dialog IR:
  - `DialogDef(id: String, textSpeed: Int = 1, border: BorderStyle = BorderStyle.NONE, speaker: String? = null, portrait: AssetRef? = null, boxX: Int = 0, boxY: Int = 14, boxWidth: Int = 20, boxHeight: Int = 4, customBorderTiles: List<Int>? = null, fontMode: FontMode = FontMode.FIXED_WIDTH)` — `customBorderTiles` provides user-specified tile indices for CUSTOM border style (8 tiles: TL, TR, BL, BR, H-top, H-bottom, V-left, V-right); `fontMode` selects fixed-width tile-based or variable-width font rendering
  - `DialogSegment` sealed interface with `DialogTextSegment(text: String)` and `DialogExprSegment(expr: Expr)`
  - `DialogOption(label: String, body: List<ScriptOp>)`

  Menu IR:
  - `MenuDataSource` sealed interface for dynamic data binding:
    - `InventoryDataSource(inventoryId: String)` — binds menu items to inventory contents
    - `ArrayDataSource(arrayId: String)` — binds menu items to a u8Array or similar collection
  - `MenuDef(id: String, layout: MenuLayout = MenuLayout.VERTICAL, cursorChar: String = ">", cursorSprite: AssetRef? = null, parentId: String? = null, renderOnWindow: Boolean = true, scrollBehavior: ScrollBehavior = ScrollBehavior.AUTO_SCROLL, sfxOnMove: String? = null, sfxOnSelect: String? = null, sfxOnCancel: String? = null, x: Int = 0, y: Int = 0, width: Int = 20, height: Int = 18, columns: Int = 1, dataSource: MenuDataSource? = null)` — `dataSource` enables dynamic population via `itemsFrom(inventory)` in the DSL
  - `MenuItemDef(label: String, body: List<ScriptOp>)` — static menu items
  - `MenuToggleDef(label: String, variable: String)` — toggle control
  - `MenuSliderDef(label: String, variable: String, min: Int, max: Int, step: Int = 1)` — slider control
  - `MenuOptionDef(label: String, variable: String, choices: List<String>)` — option cycle control

  HUD IR:
  - `HudDef(id: String, anchor: Anchor = Anchor.TOP_LEFT, tileX: Int? = null, tileY: Int? = null, renderOnWindow: Boolean = true, elements: List<HudElement> = emptyList())`
  - `HudElement` sealed interface:
    - `HudBar(id: String, variable: String, maxVariable: String? = null, maxValue: Int = 100, width: Int = 8, fillTile: Int = 0x01, emptyTile: Int = 0x00, fillFrames: Int = 0, gbcPalette: Int? = null)` — `fillTile` and `emptyTile` select which GBDK font/tile indices to use for the filled vs empty portions of the bar, enabling DMG-compatible pattern-based fill
    - `HudNumber(id: String, variable: String, label: String = "", format: String = "%d")`
    - `HudIcons(id: String, variable: String, maxValue: Int, fullTile: Int = 0, emptyTile: Int = 1, displayMode: IconDisplayMode = IconDisplayMode.FULL_AND_EMPTY)`

  **2. Update `ScriptOp.kt`** — Replace `ShowDialog` and `ShowMenu` with new hierarchy:

  Remove the existing `ShowDialog` data class and replace with:
  - `DialogSay(dialogId: String, segments: List<DialogSegment>, sourceLocation)` — emits text in dialog box
  - `DialogChoice(dialogId: String, options: List<DialogOption>, sourceLocation)` — shows choice menu in dialog

  Remove the existing `ShowMenu` data class and replace with:
  - `MenuShow(menuId: String, sourceLocation)` — opens and runs a menu
  - `MenuHide(menuId: String, sourceLocation)` — closes a menu

  Add new ScriptOps:
  - `HudShow(hudId: String, sourceLocation)` — shows a HUD panel
  - `HudHide(hudId: String, sourceLocation)` — hides a HUD panel
  - `PrintAt(x: Int, y: Int, text: String, fontMode: FontMode = FontMode.FIXED_WIDTH, sourceLocation)` — print text at specific tile coordinate on window layer (DSL-exposed via `printAt(x, y, text)`); `fontMode` determines whether `_win_print_at` (FIXED_WIDTH) or `_vwf_print_at` (VARIABLE_WIDTH) is called
  - `PrintCentered(text: String, row: Int, fontMode: FontMode = FontMode.FIXED_WIDTH, sourceLocation)` — centered text on screen; uses `fontMode` for rendering path selection
  - `PrintAligned(text: String, row: Int, alignment: TextAlignment, fontMode: FontMode = FontMode.FIXED_WIDTH, sourceLocation)` — aligned text; uses `fontMode` for rendering path selection
  - `ClearRegion(x: Int, y: Int, w: Int, h: Int, sourceLocation)` — clear rectangular area
  - `ScreenClear(sourceLocation)` — clears entire screen (both window and background layers)
  - `ScreenFill(tile: Int, sourceLocation)` — fills entire screen with specified tile index

  Each new ScriptOp must implement `accept(visitor: ScriptOpVisitorI<T>)` calling the corresponding `visitor.visitXxx(this)` method.
