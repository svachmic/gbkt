## Decisions Made

- `buildDialogFunctions(gameIR)` generates per-dialog `show_dialog_<id>()` functions from `DialogDef` IR — dialog ID is encoded in function name for type-safe call sites
- Border drawing uses inline `{ UINT8 _border_tile_N = N; set_win_tiles(...); }` pattern — C89 requires address-of for `set_win_tiles` tile arg; inline local variable is simplest C89-compatible approach
- `_vwf_print_at` inner bitmap composition implemented with `CRawCode` — pixel-level bit manipulation not representable in typed C AST; approved exception for hardware-level VWF rendering
- `visitMenuHide` emits `CRawCode("HIDE_WIN;")` not `CCall("hide_menu_X")` — pipeline only generates `show_menu_X`; `HIDE_WIN` macro is the correct window-layer dismiss
