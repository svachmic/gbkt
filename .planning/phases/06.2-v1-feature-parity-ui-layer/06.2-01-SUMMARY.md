## Decisions Made

- **ShowDialog/ShowMenu removed entirely** — hard removal forced immediate cleanup of all dependent modules, eliminating dead code debt instead of accumulating it
- **DialogChoice.options as List<DialogOption>** — cleaner than old Map<Int, List<ScriptOp>> for nested op traversal in analysis passes; index-based dispatch unneeded at IR level
- **MenuDef in GameIR.menus** — consistent with SoundEffectDef pattern; backend generates helpers from canonical list rather than scanning scripts for ops
- **FontMode on PrintAt/PrintCentered/PrintAligned** — backend selects _win_print_at vs _vwf_print_at at codegen time; both paths fully specified (no deferred language)
- **HudBar.fillTile/emptyTile as Int tile indices** — DMG-compatible pattern-based fill without requiring GBC palette
