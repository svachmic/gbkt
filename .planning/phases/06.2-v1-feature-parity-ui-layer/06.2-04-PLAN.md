  <name>Task 1: Implement HUD codegen — change-detection rendering, bars, numbers, icons, anchor positioning</name>
  <files>

  <action>
  **Use Serena MCP tools** for code exploration and editing.

  **Add `buildHudFunctions(gameIR: GameIR): List<CFunction>`** method to GBDKPipelineV2:

  For each `HudDef` in `gameIR.huds`, generate:

  **1. Global prev-value variables:**
  For each element in the HUD, generate a `_hud_<hudId>_<elementId>_prev` UINT8 global initialized to `0xFF` (sentinel — forces first-frame redraw). These go in the global variables section.

  **2. Visibility flag:**
  Generate `_hud_<hudId>_visible` UINT8 global initialized to 0 (hidden by default). `HudShow` sets to 1, `HudHide` sets to 0.

  **3. `update_hud_<id>()` function** (HOME bank, called every frame):
  - Early return if `!_hud_<id>_visible`: `CIf(!_hud_visible, [CReturn(null)])`
  - For each `HudElement`:
    - **Change detection**: `CIf(CBinaryExpr(CVar("_variable"), "!=", CVar("_hud_<id>_<elem>_prev")), thenBody)`
    - Inside thenBody: update prev value and redraw element

  **4. Rendering layer selection (per HudDef.renderOnWindow):**
  All tile-writing calls in the HUD use a conditional rendering path based on `hudDef.renderOnWindow`:
  - **When `renderOnWindow = true` (default):** Use `set_win_tiles(x, y, w, h, tiles)` for all tile writes and `_win_print_at` / `_win_clear_region` for text and clearing.
  - **When `renderOnWindow = false`:** Use `set_bkg_tiles(x, y, w, h, tiles)` for all tile writes and `set_bkg_tiles`-based equivalents for text and clearing. Generate `_bkg_print_at(x, y, str, len)` and `_bkg_clear_region(x, y, w, h)` helper functions (same logic as `_win_print_at` / `_win_clear_region` but calling `set_bkg_tiles` instead of `set_win_tiles`).
  - The codegen selects the correct function name at generation time — this is a static choice per HudDef, not a runtime branch. Use a local variable like `val tileFunc = if (hudDef.renderOnWindow) "set_win_tiles" else "set_bkg_tiles"` in the Kotlin codegen to parameterize all tile write calls.
  - When `renderOnWindow = false`, the `show_hud_<id>()` / `hide_hud_<id>()` functions do NOT emit `SHOW_WIN` / `HIDE_WIN` — those only apply to the window layer.

  **5. Per-element rendering:**

  **HudBar** (fill bar):
  - Calculate filled tiles: `filled = (value * width) / maxValue` via typed C AST integer math
  - CFor loop from 0 to width: `<tileFunc>(baseX + i, baseY, 1, 1, fillTile)` for i < filled, `<tileFunc>(..., emptyTile)` for i >= filled (where `<tileFunc>` is `set_win_tiles` or `set_bkg_tiles` depending on renderOnWindow) — `fillTile` and `emptyTile` come from the `HudBar` IR fields (defaulting to 0x01 and 0x00 respectively) for DMG-compatible pattern-based fill
  - If `fillFrames > 0` (animated): generate an animated update that moves `_hud_<id>_<bar>_display` toward target value by 1 per frame, rendering intermediate state. Use `CIf(display < target, [display++], [if display > target, display--])` per frame.
  - Update prev: `_hud_<id>_<bar>_prev = value`

  **HudNumber** (numeric display):
  - Generate `<printFunc>(x, y, label, labelLen)` for the label prefix — where `<printFunc>` is `_win_print_at` or `_bkg_print_at` depending on renderOnWindow
  - For the value, convert to string using a small itoa helper or direct digit extraction:
    - Generate `_hud_print_u8(x, y, value)` helper that extracts digits and writes them via `<tileFunc>`
    - For format "%04d" style, pad with leading zeros
  - Update prev: `_hud_<id>_<num>_prev = value`

  **HudIcons** (icon counter):
  - CFor loop from 0 to maxValue:
    - `CIf(CBinaryExpr(CVar("i"), "<", CVar("_variable")), thenBody = [<tileFunc>(..., fullTile)], elseBody)`
    - For FULL_AND_EMPTY mode: else draws emptyTile via `<tileFunc>`
    - For FILLED_ONLY mode: else draws space tile (clear) via `<tileFunc>`
  - Update prev: `_hud_<id>_<icons>_prev = value`

  **6. Anchor positioning:**
  Resolve anchor to tile coordinates:
  - TOP_LEFT: (0, 0)
  - TOP_RIGHT: (20 - width, 0)
  - BOTTOM_LEFT: (0, 17)
  - BOTTOM_RIGHT: (20 - width, 17)
  - TOP: (center, 0)
  - BOTTOM: (center, 17)
  - CENTER: (center, 8)
  If `tileX`/`tileY` are non-null, use those directly (override anchor).

  **7. `show_hud_<id>()` / `hide_hud_<id>()` functions:**
  - Show: set visible flag to 1, force full redraw by resetting all _prev to 0xFF. When `renderOnWindow = true`, emit `SHOW_WIN`. When `renderOnWindow = false`, skip `SHOW_WIN` (background layer is always visible).
  - Hide: set visible flag to 0, clear the HUD region using `<clearFunc>`. When `renderOnWindow = true`, optionally emit `HIDE_WIN` if no other UI is using the window layer.

  **8. `addHudUpdateCalls(gameIR, sceneFiles)`:**
  Following the pattern of `addMovementAndAnimationCalls()`, inject `CCall("update_hud_<id>", [])` at the start of each scene frame function body. Iterate all `gameIR.huds` and prepend calls.

  **9. Helper functions:**
  Generate `_hud_print_u8(x, y, value)` helper for printing UINT8 values as decimal text on window layer (digit extraction via division and modulo).

  **Wire into pipeline**: Add `buildHudFunctions(gameIR)` to `buildHomeFile()`. Call `addHudUpdateCalls()` after `addMovementAndAnimationCalls()` in the pipeline orchestration.
