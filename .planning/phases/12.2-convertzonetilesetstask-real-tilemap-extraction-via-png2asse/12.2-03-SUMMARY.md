# Phase 12.2 Plan 03: D-01 Two-Path Tilemap Extraction Summary

**`ConvertZoneTilesetsTask.convertOneTileset` now branches on `tilemapPath`: when set, runs png2asset a second time with `-maps_only -source_tileset` against the separate tilemap PNG (real png2asset bytes); when null, parses the existing first invocation's `_tileset_map[]` verbatim. The Plan 11.1-17 modulo-tile defect is no longer reached. Both paths feed a shared writer that emits `_zone_<sanitized>_tilemap.c` with `#pragma bank N`.**

## Accomplishments

- **tilemapPath plumbing** — Task 1 reads optional `tilemapPath` from each `zoneTilesets[]` metadata entry (JSONObject.NULL-aware via `entry.isNull(...)`), resolves to a File under `assetDirectory`, applies the same canonical-path traversal guard as the existing tileset PNG, and passes the result as a new nullable `tilemapPngFile: File?` parameter to `convertOneTileset`. Adds the REQ-4 fail-fast guard inside `convertOneTileset` for the "tilemap declared but file missing" case.
- **D-01 two-path logic** — Task 2 inserts the two-path block after the first png2asset invocation's success guard and before `synthesizeHeader(...)`:
  - **`tilemapPngFile != null`** runs png2asset a second time with `[tilemapPng, -c <tmpRaw>.c, -noflip, -map, -maps_only, -source_tileset, <tilesetPng>]`, writes output to `_zone_<sanitized>_tilemap_raw.c`, then parses `_zone_<sanitized>_tilemap_raw_map[]` via `parseMapArrayBytes`. Includes the 0-on-decoder-error guard (Plan 11.2-02 spike).
  - **`tilemapPngFile == null`** parses `_zone_<sanitized>_tileset_map[]` from the first invocation's `outputC` file — STRAIGHT COPY, no modulo-tiling.
  - Both paths feed `List<Int>` to a shared writer that emits `_zone_<sanitized>_tilemap.c` with `#pragma bank $zoneBank`, `#include "_zone_<sanitized>_tileset.h"`, and `const uint8_t _zone_<sanitized>_tilemap[<size>] = { ... };` (16 bytes per row, hex literals).
- **`synthesizeScreenTilemap(...)` call REMOVED** — `grep -c "synthesizeScreenTilemap("` returns exactly 1 (the function definition only). The dead body remains; Plan 04 deletes it.
- **`parseMapArrayBytes` shared helper** — handles BOTH hex (`0x..`) and decimal token forms (mirrors the existing parser at lines 554-560). Future-proofs against png2asset version drift.
- **REQ-2 core machinery in place** — Defect 7's defective code path is closed.
