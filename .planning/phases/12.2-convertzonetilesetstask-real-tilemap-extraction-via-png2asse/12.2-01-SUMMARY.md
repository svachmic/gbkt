## Decisions Made

- **R-05 closed without action.** `GameIRSerializer.kt` line 111 serializes zones via `serializeList(game.zones) { serializeSimple("ZoneIR", it.id) }` and line 179 deserializes to `emptyList()` with a TODO. Since the serializer does NOT round-trip ZoneIR fields today, adding `tilemapPath` requires zero serializer changes. Verified by grep.
- **`JSONObject.NULL` over Kotlin `null` in metadata emission.** `org.json.JSONObject.put(key, null)` would omit the key entirely from serialized JSON; `JSONObject.NULL` produces an explicit `"tilemapPath": null`, which is what `optString(key, defaultValue)` consumers expect.
- **AssetRef-only signature for `tilemap()`.** Mirrors `tileset(ref: AssetRef)` at lines 99–101 of WorldBuilders.kt; no String overload exists (`grep -c "fun tilemap(path:"` returned 0). Enforces no-magic-strings rule (memory `feedback_no_magic_strings.md`).
- **Field inserted directly after `tilesetPath`.** Planner-specified position keeps the two related path fields colocated in the ZoneIR data class for readers.
