**Overflow guard pattern** (mirrors `bankOverflowError` + `run()` structure, lines 72-135):
```kotlin
    // Phase 12.2 D-04: cumulative tilemap-size overflow guard.
    // Runs after the existing bin-packing logic; adds a NEW check for tilemap bank capacity.
    // Skips silently when assetRoot is null (JVM-only tests without real PNG fixtures).
    private fun checkTilemapBankOverflow(
        game: GameIR,
        assetRoot: java.io.File,
    ): PassResult.Failed? {
        val TILEMAP_BANK_THRESHOLD = 14_336  // 16 KB bank minus 2 KB safety margin (SPEC Constraint)
        val zonesWithSizes = mutableListOf<Pair<String, Int>>()
        var cumulative = 0
        for (zone in game.zones) {
            val pngPath = zone.tilemapPath ?: zone.tilesetPath ?: continue
            val pngFile = java.io.File(assetRoot, pngPath)
            if (!pngFile.isFile) continue
            // Mirror of ConvertZoneTilesetsTask.kt lines 209-218 (D-claude-3: duplicate inline,
            // comment points to ConvertZoneTilesetsTask.kt as the other call site).
            val img = javax.imageio.ImageIO.read(pngFile) ?: continue
            val byteCount = (img.width / 8) * (img.height / 8)  // 1 byte per tile index
            zonesWithSizes += zone.id to byteCount
            cumulative += byteCount
        }
        if (cumulative <= TILEMAP_BANK_THRESHOLD) return null
        val zoneBreakdown = zonesWithSizes.joinToString(", ") { (id, sz) -> "'$id' ($sz bytes)" }
        return PassResult.Failed(
            listOf(
                Diagnostic(
                    id = "ANLZ-12",
                    severity = Severity.ERROR,
                    message = "Tilemap bank overflow: zones sum to $cumulative bytes " +
                        "(threshold $TILEMAP_BANK_THRESHOLD bytes = 16 KB bank minus 2 KB margin). " +
                        "Zone breakdown: $zoneBreakdown. " +
                        "Add per-zone tilemap banks (SEED-PHASE-12-PER-ZONE-TILEMAP-BANKS).",
                    location = "tilemap bank",
                    suggestion = "Split tilemap data across per-zone banks " +
                        "(SEED-PHASE-12-PER-ZONE-TILEMAP-BANKS, out of scope for Phase 12.2).",
                )
            )
        )
    }
```

**Integration in `run()`** — call after existing bin-packing, return early if overflow detected:

        // Existing bin-packing logic (unchanged)
