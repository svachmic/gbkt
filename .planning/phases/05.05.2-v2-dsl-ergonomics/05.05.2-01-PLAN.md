    - `operator fun AssignableVar.plus(other: Expr): Expr` = `toExpr() + other`
    - `operator fun AssignableVar.plus(other: Int): Expr` = `toExpr() + other`

    Increment/decrement operators (enable `++score`, `score++`, `--lives`, `lives--`):
    - `operator fun AssignableVar.inc(): AssignableVar` — emits `Assign(name, BinaryExpr(VarRef(name), BinaryOp.ADD, Literal(1)), AssignOp.SET)` via ScriptBuilderContext.current, then returns `this`. Works because `var score by u8Var(0)` is a `var` delegate — Kotlin calls `inc()` then `setValue()` (which is a no-op). The side-effect emission pattern is consistent with `set` and `+=`.
    - `operator fun AssignableVar.dec(): AssignableVar` — same pattern with `BinaryOp.SUB`.
    - NOTE: These operators work with `var` delegates. `val` delegates will get a compile error from Kotlin itself, which is correct behavior.

    Comparison operators (return Expr for use in whenever/ifOp conditions):
    - `infix fun AssignableVar.isAbove(other: Int): Expr` = `toExpr() isAbove other`
    - `infix fun AssignableVar.isAbove(other: Expr): Expr` = `toExpr() isAbove other`
    - `infix fun AssignableVar.isAbove(other: AssignableVar): Expr` = `toExpr() isAbove other.toExpr()`
    - Same for `isBelow`, `isAtLeast`, `isAtMost`, `isEqualTo`, `isNotEqualTo`

    **DEFERRED — Standard Kotlin comparison operators (`>=`, `<=`, `>`, `<`, `==`):** CONTEXT.md says both standard Kotlin operators AND infix names should be supported. However, Kotlin's `>=`, `<=`, `>`, `<` desugar to `compareTo() >= 0`, etc., where `compareTo()` must return `Int` (not `Expr`). This makes them fundamentally incompatible with DSL condition recording — the result would be a Kotlin `Boolean`, not an IR `Expr` that can be captured and emitted as a C condition. Similarly, `==` maps to `equals()` returning `Boolean`. The infix names (`isAbove`, `isBelow`, `isAtLeast`, `isAtMost`, `isEqualTo`, `isNotEqualTo`) ARE the idiomatic solution for DSL condition expressions. This is a hard Kotlin language constraint, not a missing feature. If a future Kotlin language feature allows custom comparison return types, this can be revisited.

    Boolean auto-wrap (enables `ball.visible = true`, `flag = false` per CONTEXT.md):
    - `infix fun AssignableVar.set(value: Boolean)` — emits `Assign(name, Literal(if (value) 1 else 0), AssignOp.SET)` via ScriptBuilderContext.current

    Logical operators:
    - `infix fun AssignableVar.logicalAnd(other: Expr): Expr`
    - `infix fun AssignableVar.logicalOr(other: Expr): Expr`
    - `fun AssignableVar.not(): Expr` (using existing `not()` on Expr)

    **NOTE on `&&`/`||`/`!` operators:** CONTEXT.md says both `&&`/`||`/`!` AND `and`/`or`/`not` should be supported. However, `&&` and `||` are built-in Kotlin operators that cannot be overloaded — they short-circuit on `Boolean` operands and are hard-wired into the language. `!` (the `not()` operator) CAN be overloaded but would need to return `Expr`, which is unusual. The infix names `logicalAnd`, `logicalOr`, and `not()` provide the DSL equivalent. Bitwise `and`/`or` are separate operators (also provided). This is a hard Kotlin language constraint.

    Bitwise operators:

    - `infix fun AssignableVar.and(other: AssignableVar): Expr`
    - Same for `or`, `xor`, `shl`, `shr`, plus `fun AssignableVar.inv(): Expr`

    **2. Create ArrayVar class + update ArrayDelegate:**

    In VariableBuilders.kt, add `ArrayVar` class (returned by ArrayDelegate instead of AssignableVar):
    ```kotlin
    data class ArrayVar(val name: String, val elementType: VarType, val arraySize: Int) {
        fun toExpr(): Expr = VarRef(name) // array as whole expression

        /** Compile-time array size as a Literal expression. Enables `forOp("i", 0, bricks.size)`. Uses `size` (not `length`) for consistency with Kotlin collections. */
        val size: Int get() = arraySize

        /** Returns a bounds-check expression: `index >= 0 && index < size`. For use in conditions. */
        fun exists(index: AssignableVar): Expr = BinaryExpr(
            BinaryExpr(index.toExpr(), BinaryOp.GTE, Literal(0)),
            BinaryOp.AND,
            BinaryExpr(index.toExpr(), BinaryOp.LT, Literal(arraySize))
        )
        fun exists(index: Expr): Expr = BinaryExpr(
            BinaryExpr(index, BinaryOp.GTE, Literal(0)),
            BinaryOp.AND,
            BinaryExpr(index, BinaryOp.LT, Literal(arraySize))
        )
        fun exists(index: Int): Expr = exists(Literal(index))

        // Bracket read operators
        operator fun get(index: AssignableVar): Expr = ArrayAccessExpr(name, index.toExpr())
        operator fun get(index: Expr): Expr = ArrayAccessExpr(name, index)
        operator fun get(index: Int): Expr = ArrayAccessExpr(name, Literal(index))

        // Bracket write operators
        operator fun set(index: AssignableVar, value: Expr) {
            ScriptBuilderContext.current?.arrayAssign(name, index.toExpr(), value)
                ?: error("Array set called outside a ScriptBuilder block")
        }
        operator fun set(index: AssignableVar, value: Int) = set(index, Literal(value))
        operator fun set(index: Expr, value: Expr) {
            ScriptBuilderContext.current?.arrayAssign(name, index, value)
                ?: error("Array set called outside a ScriptBuilder block")
        }
        operator fun set(index: Expr, value: Int) = set(index, Literal(value))
        operator fun set(index: Int, value: Expr) = set(Literal(index), value)
        operator fun set(index: Int, value: Int) = set(Literal(index), Literal(value))
    }
    ```
