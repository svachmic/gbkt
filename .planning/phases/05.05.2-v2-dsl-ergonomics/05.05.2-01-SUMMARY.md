# Phase 05.05.2 Plan 01: DSL Ergonomics Infrastructure Summary

ScriptBuilderContext ThreadLocal + full AssignableVar/ActorPropertyRef/ArrayVar operator extension set enabling Kotlin-idiomatic game DSL syntax.

## What Was Built

### Task 1: ScriptBuilderContext + ScriptBuilder/SceneBuilder Wiring

Created `ScriptBuilderContext.kt` — a ThreadLocal holder for the active ScriptBuilder, matching the `GameBuilderContext` pattern exactly. This enables operator extension functions to find the active builder without explicit receiver threading.

Wired into all 6 block-executing methods in ScriptBuilder:
- `whenever()`, `ifOp()`, `elseOp()`, `whileOp()`, `forOp()`, `fade()`

Wired into all 3 scene lifecycle methods in SceneBuilder:
- `enter()`, `frame()`, `exit()`

Added `forOp(variable: String, from: Int, to: Int, block)` overload for Int bounds auto-wrapping.

### Task 2: Operator Extensions + New DSL Types

**AssignableVar operators** (in VariableBuilders.kt):
- Assignment: `set(Expr)`, `set(Int)`, `set(AssignableVar)`, `set(Boolean)` (auto-wraps true→1, false→0)
- Compound assignment: `+=`, `-=`, `*=`, `/=`, `%=`
- Increment/decrement: `++`, `--` (emit Assign ops as side effects, return `this`)
- Arithmetic: `+`, `-`, `*`, `/`, `%`, unaryMinus (return Expr)
- Comparison: `isAbove`, `isBelow`, `isAtLeast`, `isAtMost`, `isEqualTo`, `isNotEqualTo`
- Logical: `logicalAnd`, `logicalOr`, `not()`
- Bitwise: `and`, `or`, `xor`, `shl`, `shr`, `inv()`

**ActorPropertyRef** (in ActorBuilder.kt):
- Same operator set as AssignableVar
- `set(Boolean)` — enables `ball.visible set false`
- `inc()`, `dec()` — same side-effect pattern

**ActorRef** (extended in ActorBuilder.kt):
- `val x: ActorPropertyRef`
- `val y: ActorPropertyRef`
- `val visible: ActorPropertyRef`
- `fun moveTo(x: Int, y: Int)` — extension function using ScriptBuilderContext
- `fun collides(other: ActorRef): Expr` — collision expression

**ArrayVar** (new class in VariableBuilders.kt):
- `operator fun get(index)` — bracket read (Expr, AssignableVar, Int overloads)
- `operator fun set(index, value)` — bracket write (all combinations)
- `val size: Int` — compile-time size (consistent with Kotlin collections naming)
- `fun exists(index): Expr` — bounds check expression

**ArrayDelegate** (updated in VariableBuilders.kt):
- Now returns `ArrayVar` instead of `String`
- Infers name from property name by default
- Optional `name` override for custom C identifier

**u8Array()** (signature updated):
- Old: `fun u8Array(name: String, size: Int)`
- New: `fun u8Array(size: Int, name: String? = null)`

**Int left-side extensions** (in ExprBuilder.kt):
- `Int.plus(Expr)`, `Int.plus(AssignableVar)`, `Int.plus(ActorPropertyRef)`
- Same for `minus`, `times`, `div`, `rem`
