- **After every task commit:** Run `./gradlew :gbkt-ir:test :gbkt-lang:test :gbkt-backend-gbdk:test`
- **After every plan wave:** Run `./gradlew test`
- **Before `/gsd-verify-work`:** Full suite GREEN **+** all `:buildRom` smokes EXIT 0 (same-or-smaller bytes) **+** MCP screenshots captured (title / gameplay-level / NextLevel-card)
- **Max feedback latency:** ~90 seconds (JVM codegen tests)
