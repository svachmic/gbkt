# Phase 13.5 Plan 05: Banks.kt Exit-Trick Migration Summary

**One-liner:** Banks.kt exit-trick removed; play_exit BANKED auto-synthesized by Req #15 isMbcGame gate, deduplicated to pause_exit, trampoline preserved.

## Objective

Migrate `Banks.kt` off the empty `exit { hideSprites() }` codegen trick. After removal, the framework auto-synthesizes `play_exit` BANKED for the bank-1 scene (MBC5_RAM_BATTERY, maxRomBanks=256 → isMbcGame true), preserving the enter/frame/exit BANKED triplet that INV-1 guards.

## What was done

### Task 1 — Remove exit-trick from Banks.kt and update INV-1

**Banks.kt changes:**
- Deleted the `exit { hideSprites() }` line from the `play` scene
- Deleted the 4-line BANKED-triplet rationale comment (lines 82-85) explaining why the explicit exit block was needed
- Added a concise Req #15 comment: "Req #15 (Phase 13.5): the framework auto-emits play_exit BANKED for MBC games (MBC5_RAM_BATTERY, maxRomBanks=256 → isMbcGame true). No explicit exit block needed."

**BanksEmissionTest.kt INV-1 changes:**
- Updated the INV-1 comment block to document the Req #15 auto-synthesis mechanism and the deduplication behavior
- Added explicit `exitBody.isNotEmpty()` presence assertion for the direct-definition case
- Added deduplication-aware assertion: the auto-synthesized `play_exit` (empty body) is correctly merged by `FunctionDeduplicationPass` with `pause_exit` (also empty body, also BANKED) — the test accepts either direct BANKED definition OR dedup-to-BANKED-function
- The play/frame/exit BANKED triplet is preserved: `play_exit_trampoline` in main.c routes through `pause_exit` BANKED

**Deduplication finding:** When `exit { hideSprites() }` was present, `play_exit` emitted `HIDE_SPRITES;` — not deduplicated. After migration to auto-synthesis, `play_exit` is an empty function, identical to `pause_exit` — so `FunctionDeduplicationPass` merges them. The bank1.c line `/* Deduplicated: see pause_exit */` replaces the full `play_exit` definition. The `play_exit_trampoline` in main.c correctly calls `pause_exit()` (BANKED). The Req #15 contract is fully satisfied.

## Deviations from Plan

### Auto-discovered: Deduplication behavior

**Found during:** Task 1 (initial INV-1 run)

**Issue:** The plan said to add `exitBody.isNotEmpty()` assertion for `play_exit`. However, the auto-synthesized `play_exit` (empty body) is deduplicated by `FunctionDeduplicationPass` into `pause_exit` (also empty body). The `extractFunctionBody(bank1C, "play_exit")` helper returns empty string since no matching `void play_exit(` signature line exists.

**Fix:** Updated INV-1 to accept both cases:
1. Direct BANKED definition: `exitBody.contains(" BANKED")` (if not deduplicated)
2. Deduplicated to BANKED target: `bank1C` contains a dedup comment for exit AND `pauseExitBody.contains(" BANKED")`

This is Rule 1 (auto-fix bug) — the test assertion needed to reflect actual codegen behavior.
