SceneBuilder-level method that synthesizes an internal `_screen_<sceneId>` ZoneIR riding the
EXISTING zone tileset pipeline, plus the `ZoneIR.screenMode` flag and the SceneVisitor
centered-draw superset branch. Pure framework-primitive plan — no example migrates here.

Purpose: `screen()` replaces the zone-as-screen abuse (titleZone/nextLevelZone with explicit
`size(20,9)`). It auto-derives dims from the PNG at build time (DSL never touches the
filesystem — 13.4 D-01) and auto-centers + resets sprite/scroll state ALWAYS, so a single
clean call serves both the full-screen title and the smaller centered NextLevel card.

CRITICAL (RESEARCH correction to CONTEXT D-03): `screen()` MUST live on `SceneBuilder` (parallel
to `zone()`), NOT inside `enter { }`. ScriptBuilder cannot add to `SceneIR.zoneRefs` nor register
a ZoneIR with GameBuilder. The migrated DSL reads `scene("title") { screen(asset(...)); frame { } }`.

Output: `ZoneIR.screenMode` flag + serializer round-trip + `SceneBuilder.screen(assetRef)` +
SceneVisitor screenMode superset branch + a RED→GREEN ScreenPrimitiveEmissionTest.
