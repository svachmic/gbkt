# Plan 13.5-03 Summary — Auto-Synthesize Empty `_exit` BANKED Function (Req #15 / D-07)

## Objective
Auto-synthesize an empty `${scene.id}_exit` BANKED function for cross-bank scenes in MBC games
that have no declared `exit { }` block, so authors no longer need the `exit { hideSprites() }`
codegen trick to force a banked exit stub. Single-bank (ROM_ONLY) games must gain NO new
`*_exit` functions.

## What was done

### Task 1 — `isMbcGame`-gated auto-exit synthesis + trampoline/navigate pairing
- `SceneVisitor.kt` (+28 lines): emits an empty `${scene.id}_exit` BANKED function when the scene
  needs a banked exit and the game is an MBC game, gated on `isMbcGame`.
- `GBDKPipelineV2.kt` (+46 lines): added the `isMbcGame = gameIR.config.cartridge.maxRomBanks > 2`
  source and a shared `shouldAutoEmitExit` predicate reused at BOTH the `*_exit_trampoline`
  emission site and the `navigate_to_scene` exit-case site, so every auto-synthesized `*_exit`
  links (trampoline + navigate case paired).
- Commits: `a209108a` (RED test) → `9d2a5e57` (synthesis + shared predicate).
- Acceptance greps verified: `isMbcGame` in SceneVisitor (5), `maxRomBanks > 2` in
  GBDKPipelineV2 (5), `shouldAutoEmitExit` in GBDKPipelineV2 (6 — reused at both sites).
- `AutoExitSynthesisTest.kt` (+338 lines) locks the MBC-emits / ROM_ONLY-no-emit contract with
  tier1-shape evidence (`auto-exit-mbc-*`, `auto-exit-rom-only-*`).

### Task 2 — pong + breakout no-growth regression guards (single-bank gate)
- `PongNoExitRegressionTest.kt` (+150) and `BreakoutNoExitRegressionTest.kt` (+160): assert no

  `isMbcGame` predicate keeps single-bank games at zero growth.
- Both use the brace-walk `void $functionName(` anchor (grep count 3 in pong test) per the
