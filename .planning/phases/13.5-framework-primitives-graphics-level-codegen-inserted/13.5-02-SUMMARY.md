# Phase 13.5 Plan 02: screen() Static-Full-Screen-Image Primitive Summary

Lands the `screen()` static-full-screen-image primitive (Req #18 / D-03/D-04/D-05/D-06) as a SceneBuilder-level method synthesizing an internal `_screen_<sceneId>` ZoneIR with screenMode=true, plus the SceneVisitor centered-draw superset branch, with RED→GREEN TDD evidence.

## Tasks Completed

### Task 1 (RED → GREEN): ZoneIR.screenMode flag + serializer round-trip + SceneBuilder.screen() DSL
- **Commit:** `11385201` (RED: `fc47a739`)

Added `val screenMode: Boolean = false` to ZoneIR (after bankOverride; KDoc notes it is set only by SceneBuilder.screen() and gates the SceneVisitor superset — never set by user-facing zone {} DSL). Default false preserves backward-compat for all existing ZoneIR construction sites.

Added `serializeZoneIR()` to GameIRSerializer replacing the `serializeSimple("ZoneIR", it.id)` call — new method emits id + tilesetPath + screenMode field. The `optBoolean("screenMode", false)` style is documented for future full-deserialization support (Assumption A3 backward-compat: existing serialized IR deserializes unchanged).

Added `fun screen(assetRef: AssetRef)` to SceneBuilder.kt after `zone()`:
- synthesizes `val syntheticId = "_screen_${id}"`
- builds `ZoneIR(id=syntheticId, name=syntheticId, tilesetPath=assetRef.path, screenMode=true)`
- registers via `GameBuilderContext.current?.registerZone(syntheticZone) ?: error(...)`
- guards multi-zone conflict with `require(zoneRefs.isEmpty()) { ... }`
- adds `zoneRefs += syntheticId`
