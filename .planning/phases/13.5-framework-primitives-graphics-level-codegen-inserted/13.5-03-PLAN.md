<objective>
Land Req #15 (D-07) — auto-synthesize an empty `${scene.id}_exit` BANKED function for
cross-bank scenes in genuine MBC games, removing the need for the empty `exit { hideSprites() }`
codegen trick. Pure framework-primitive plan — Banks.kt migrates in a LATER plan; this plan
lands the predicate + trampoline pairing + the pong/breakout no-growth regression guards.

CRITICAL (RESEARCH correction to CONTEXT D-07): the CONTEXT predicate `bankSlot.bank > 0`
alone is TOO BROAD. pong (ROM_ONLY, 3 scenes) and breakout (ROM_ONLY, 4 scenes) get
`bankSlot.bank = 1` from BankingAnalysisPass FFD (ROM_ONLY's only non-HOME bank), so the
bare bank>0 predicate would auto-emit `title_exit`/`game_exit`/... for them, FAILING the
no-growth gate. The CORRECT discriminator threads `isMbcGame = gameIR.config.cartridge.maxRomBanks > 2`
(ROM_ONLY=2 → false; MBC1=32, MBC5_RAM_BATTERY=256 → true) from GBDKPipelineV2 into
`SceneVisitor.visit()` AND the two trampoline/navigate sites. Auto-emit only when MBC AND bank>0.

Output: `SceneVisitor.visit(isMbcGame=...)` auto-exit synthesis; GBDKPipelineV2 threads the param
and pairs the trampoline (buildTrampolinesForScene) + the navigate exit case (buildNavigateToSceneFunction)
via one shared `shouldAutoEmitExit` predicate; pong + breakout no-growth regression tests.
</objective>
