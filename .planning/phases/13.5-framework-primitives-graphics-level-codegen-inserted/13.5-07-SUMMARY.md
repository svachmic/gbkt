## What Was Built

### Task 1: Three new sections in context/DSL_REFERENCE.md

Three new documentation sections inserted between the existing "Zones" and "Scenes and Navigation" sections, using the established DSL_REFERENCE heading + worked-example idiom.

**Section 1 — "Static Full-Screen Images (screen)"**
- Shows `scene("title") { screen(asset("graphics/title-screen.png")) }` as the canonical worked example
- Includes an inter-level card example with a smaller centered PNG
- Key-property table: placement, PNG size derivation, auto-centering formula, reset sequence, single-call constraint
- Explicit guidance: `screen()` is for static pictures only; `zone { }` for scrollable maps
- Correct/incorrect example pair to clarify the zone-vs-screen boundary

**Section 2 — "Level Binding (bindCurrentLevel)"**
- Shows `enter { bindCurrentLevel() }` in a platformer gameplay scene
- Validity constraint: requires `platformerPhysics { }` + `tilemapCollision { }` system pair
- Before/after `cEmit` migration snippet (the escape hatch pattern authors are migrating FROM)
- Canonical-names note: `bindCurrentLevel()` is the only valid name; no `loadLevel()` alias

**Section 3 — "Auto-Synthesized `*_exit` Functions (MBC games)"**
- Shows a cross-bank `scene("play")` with no `exit { }` block — auto-synthesis documented
- Generated C shape example: `void play_exit(void) BANKED { }`
- Rules table covering four cases: MBC+cross-bank+no-exit, MBC+cross-bank+exit, ROM_ONLY, HOME-bank
- Before/after workaround snippet documenting the `exit { hideSprites() }` codegen trick removal
