**LOCKED DECISIONS (honor exactly):**
- Clean break DSL syntax — no backward compat with `gbGame {}`, `whenever()`, etc.
- Declarative, state-driven style inspired by Jetpack Compose
- Pure builder functions (game {}, scene {}, actor {})
- Two-layer error checking: DSL recording time + IR validation at build()
- Fail fast at first error
- Compiler-style error format
- "Did you mean?" suggestions — reuse existing `Suggestions.kt` (DO NOT rewrite)

**DISCRETION: State management** — use property delegates (var score by u8Var(0)) per research recommendation. The existing delegate infrastructure is proven.

**DslMarkers.kt:**
- `@DslMarker annotation class GbktDsl`
- Apply to all builder classes

**Errors.kt:**
- `class DSLValidationError(message: String) : Exception(message)`
- Error format: `error: Unresolved reference "X". Did you mean "Y"?`

**RefRegistry.kt:**
- `class RefRegistry` with methods: `register(id: String, kind: RefKind)`, `ref(id: String, kind: RefKind): Ref`, `resolveAll()`
- `register()` records known IDs by kind; throws on duplicate within same kind
- `ref()` records a pending reference and returns `Ref(id, kind)`
- `resolveAll()` checks all pending refs against registered IDs; throws DSLValidationError for first unresolved with "Did you mean?" via `suggestFrom()` from existing Suggestions.kt
- Constructor takes no parameters; accumulates state during DSL execution

**AssetRegistry.kt:**
- `class AssetRegistry` tracking all asset references for validation
- `fun asset(path: String, type: AssetType = AssetType.GENERIC): AssetRef`

**ExprBuilder.kt:**
- Helper functions: `literal(value: Int): Expr`, `varRef(name: String): Expr`, `stringLiteral(value: String): Expr`
- Operator extension functions on Expr for arithmetic: `Expr + Expr`, `Expr - Expr`, etc. producing `BinaryExpr`
- Comparison infix functions: `Expr isAbove Expr`, `Expr isBelow Expr`, `Expr isAtLeast Expr`, etc.

**VariableBuilders.kt:**
- Property delegate classes: `U8VarDelegate(initialValue: Int)`, `U16VarDelegate(initialValue: Int)`, `I8VarDelegate(initialValue: Int)`, `I16VarDelegate(initialValue: Int)`
- Top-level functions: `fun u8Var(initial: Int = 0) = U8VarDelegate(initial)` etc.
- Each delegate captures the property name via `getValue(thisRef, property)` and registers a `VariableDef` with the owning GameBuilder
- Delegates return `AssignableVar` (wrapping an Expr + methods like `set`, `+=`, `-=`)

**ScriptBuilder.kt:**
- `@GbktDsl class ScriptBuilder` that accumulates `List<ScriptOp>`
- Methods: `assign(target, value, op)`, `ifOp(condition, body) / elseOp(body)`, `whileOp(condition, body)`, `navigate(sceneId)`, `moveBy(actorRef, dx, dy)`, `setPosition(actorRef, x, y)`, `playSound(soundId)`, `showDialog(vararg lines)`, `showMenu(id, options, handlers)`, `print(text, vararg values)`, `fade(fadeIn, frames, after)`, `setVisible(actorId, visible)`, `spawnActor(actorId)`, `destroyActor(actorId)`, `animate(actorId, animation)`, `cameraOp(action, args)`, `waitFrames(frames)`, `callOp(function, args)`, `returnOp(value)`, `raw(code)`
- `whenever(condition: Expr, block: ScriptBuilder.() -> Unit)` — syntactic sugar producing `IfOp(condition, body, emptyList())`
- Methods for screen operations: `hideSprites()` → emits `RawOp("HIDE_SPRITES")`, `showSprites()` → emits `RawOp("SHOW_SPRITES")`, `clear()` → emits `RawOp("CLS")`
- Methods for input: `buttonPressed(button: String): Expr`, `buttonHeld(button: String): Expr`, `dpadHeld(direction: String): Expr`, `dpadPressed(direction: String): Expr`

**SceneBuilder.kt:**
- `@GbktDsl class SceneBuilder(val id: String, private val refs: RefRegistry)`
- Methods: `enter(block: ScriptBuilder.() -> Unit)`, `frame(block: ScriptBuilder.() -> Unit)`, `exit(block: ScriptBuilder.() -> Unit)`
- `fun build(): SceneIR` — returns SceneIR with the three ScriptOp lists

**ActorBuilder.kt:**
- `@GbktDsl class ActorBuilder(val id: String)`
- Methods: `position(x: Int, y: Int)`, `sprite(assetRef: AssetRef, block: SpriteBuilder.() -> Unit = {})`, `hitbox(x, y, w, h)`
- Inner `SpriteBuilder` with `size(w, h)`, `hitbox(x, y, w, h)`
- `fun build(): ActorIR`

**SystemBuilders.kt:**
- Builder classes for each SystemIR subtype
- `CameraBuilder`: `smoothing`, produces CameraSystem
- `SaveDataBuilder`: `slots`, `checksum`, produces SaveSystem
- `ExplorationBuilder`: `tileSize`, `movementStyle`, `movementSpeed`, `startZone`, `onStep`, produces ExplorationSystem
- `SoundEffectBuilder`: `preset`, produces SoundSystem entry

**GameBuilder.kt:**
- `@GbktDsl class GameBuilder(val name: String)` — the main builder
- Methods: `config(block)`, `actor(id, block): ActorRef`, `scene(id, block): SceneRef`, `camera(block)`, `saveData(id, block)`, `exploration(block)`, `soundEffect(id, block)`
- Property `start: String?` for setting the start scene
- Property delegates work inside the builder scope
- `fun build(): GameIR` — resolves all refs, validates, returns GameIR
- Top-level function: `fun game(name: String, block: GameBuilder.() -> Unit): GameBuilder`

**ActorRef and SceneRef** are lightweight wrappers (String ID + kind) returned by `actor()` and `scene()` so they can be passed to ScriptBuilder methods. They implicitly convert to String for ref resolution.
