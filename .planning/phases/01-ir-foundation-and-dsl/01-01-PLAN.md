**Types.kt** — Foundation types:
- `data class PositionDef(val x: Int, val y: Int)`
- `data class SizeDef(val width: Int, val height: Int)`
- `data class HitboxDef(val x: Int, val y: Int, val width: Int, val height: Int)`
- `data class SpriteDef(val assetRef: AssetRef, val size: SizeDef, val hitbox: HitboxDef? = null)`
- `data class SourceLocation(val file: String, val line: Int, val col: Int)`
- `enum class AssignOp { SET, ADD, SUB, MUL, DIV, MOD, AND, OR, XOR }`
- `enum class BinaryOp { ADD, SUB, MUL, DIV, MOD, AND, OR, XOR, SHL, SHR, EQ, NEQ, LT, LTE, GT, GTE, LOGICAL_AND, LOGICAL_OR }`
- `enum class UnaryOp { NEGATE, BITWISE_NOT, LOGICAL_NOT }`
- `data class CartridgeConfig(val cartridge: String = "ROM_ONLY", val romBanks: Int = 2, val ramBanks: Int = 0)`
- `data class VariableDef(val name: String, val type: VarType, val initialValue: Int = 0)`
- `enum class VarType { U8, U16, I8, I16 }`
- `enum class MathFunction { ABS, MIN, MAX, CLAMP, RAND }`

**AssetRef.kt:**
- `data class AssetRef(val path: String, val type: AssetType = AssetType.GENERIC)`
- `enum class AssetType { SPRITE, TILEMAP, TILESET, SOUND, MUSIC, FONT, DATA, GENERIC }`

**Ref.kt:**
- `data class Ref(val targetId: String, val kind: RefKind)`
- `enum class RefKind { SCENE, ACTOR, SYSTEM, VARIABLE, ASSET, ZONE }`

**PlatformAnnotations.kt:**
- `data class BankSlot(val bank: Int, val offset: Int? = null)`
- `data class VRAMRange(val startTile: Int, val endTile: Int)`
- `data class OAMSlot(val slot: Int)`
- `interface PlatformAnnotatable { val bankSlot: BankSlot?; val vramRange: VRAMRange?; val oamSlot: OAMSlot? }`

**Expr.kt** — Sealed expression hierarchy:
- `sealed interface Expr`
- `data class Literal(val value: Int) : Expr`
- `data class VarRef(val name: String) : Expr`
- `data class BinaryExpr(val left: Expr, val op: BinaryOp, val right: Expr) : Expr`
- `data class UnaryExpr(val op: UnaryOp, val operand: Expr) : Expr`
- `data class CallExpr(val function: String, val args: List&lt;Expr&gt;) : Expr`
- `data class TernaryExpr(val condition: Expr, val thenExpr: Expr, val elseExpr: Expr) : Expr`
- `data class ArrayAccessExpr(val array: String, val index: Expr) : Expr`
- `data class PropertyAccessExpr(val objectId: String, val property: String) : Expr` — for actor.x, actor.y etc.
- `data class StringLiteral(val value: String) : Expr`

**ScriptOp.kt** — Sealed instruction set:
- `sealed interface ScriptOp { val sourceLocation: SourceLocation? get() = null }`
- Control flow: `IfOp(condition: Expr, then: List&lt;ScriptOp&gt;, otherwise: List&lt;ScriptOp&gt; = emptyList())`, `WhileOp(condition: Expr, body: List&lt;ScriptOp&gt;)`, `ForOp(variable: String, from: Expr, to: Expr, body: List&lt;ScriptOp&gt;)`
- State: `Assign(target: String, value: Expr, op: AssignOp = AssignOp.SET)`, `ArrayAssign(array: String, index: Expr, value: Expr, op: AssignOp = AssignOp.SET)`
- Movement: `SetPosition(actorId: String, x: Expr, y: Expr)`, `MoveBy(actorId: String, dx: Expr, dy: Expr)`
- Navigation: `NavigateTo(sceneId: String)`
- Systems: `TriggerSystem(systemId: String, args: Map&lt;String, Expr&gt; = emptyMap())`
- Audio: `PlaySound(soundId: String)`
- Dialog: `ShowDialog(lines: List&lt;String&gt;)`, `ShowMenu(id: String, options: List&lt;String&gt;, handlers: Map&lt;Int, List&lt;ScriptOp&gt;&gt;)`
- Display: `PrintOp(text: String, values: List&lt;Expr&gt; = emptyList(), position: PositionDef? = null)`, `FadeOp(fadeIn: Boolean, frames: Int, after: List&lt;ScriptOp&gt; = emptyList())`, `SetVisible(actorId: String, visible: Boolean)`
- Entity: `SpawnActor(actorId: String)`, `DestroyActor(actorId: String)`, `AnimateOp(actorId: String, animation: String)`
- Camera: `CameraOp(action: CameraAction, args: Map&lt;String, Expr&gt; = emptyMap())` with `enum class CameraAction { FOLLOW, UNFOLLOW, SHAKE, MOVE_TO }`
- Timing: `WaitFrames(frames: Int)`
- Calls: `CallOp(function: String, args: List&lt;Expr&gt;)`, `ReturnOp(value: Expr? = null)`
- Math: `MathOp(result: String, op: MathFunction, args: List&lt;Expr&gt;)`
- Escape: `RawOp(code: String)`

**ActorIR.kt:**
- `data class ActorIR(val id: String, val position: PositionDef, val sprite: SpriteDef? = null, val hitbox: HitboxDef? = null, override val bankSlot: BankSlot? = null, override val vramRange: VRAMRange? = null, override val oamSlot: OAMSlot? = null) : PlatformAnnotatable`

**SceneIR.kt:**
