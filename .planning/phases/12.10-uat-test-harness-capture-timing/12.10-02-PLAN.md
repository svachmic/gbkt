<objective>
Add an OAM-region-aware diff path to `VisualDiff` so the anchor4 retune (Plan 03) can diff only the ~24×32 metasprite bounding box instead of the full frame.

Purpose: anchor4's full-frame `>10%` gate was calibrated against now-removed wrap-corruption BG inflation; the genuine facing-right/left diff is 6.60% full-frame, dominated by BG scroll. A region diff confined to the sprite box makes the gate measure the sprite's hflip (most pixels flip → high in-region ratio) independent of camera noise (D-07). This plan ships ONLY the diff infrastructure + its own unit coverage; anchor4 consumes it in Plan 03. (Covers R-03 infra half.)

Output: `VisualDiff.compareRegion(...)` + region unit coverage in `VisualDiffTest.kt`.
</objective>
