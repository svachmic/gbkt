# Phase 12.10 Plan 02: OAM-region-aware VisualDiff path Summary

**`VisualDiff.compareRegion(...)` — a clamped-crop region diff (via `getSubimage` + the shared `diffPixels` loop) whose `totalPixels` is the crop area, so the anchor4 retune (Plan 03) can gate on the metasprite bounding box's in-region ratio instead of the BG-scroll-dominated full frame; full-frame `compare` is left byte-identical.**

## Performance

- **Duration:** ~9 min
- **Completed:** 2026-06-02
- **Tasks:** 2
- **Files modified:** 2 (1 main, 1 test)

## Accomplishments
- Added `VisualDiff.compareRegion(expected, actual, x, y, w, h, tolerance = 0.0, diffOutputDir = null): DiffResult`. It reads both PNGs, keeps the existing matching-dimension `require`, clamps the rectangle to image bounds (`cx = x.coerceIn(0, width)`, `cy = y.coerceIn(0, height)`, `cw = w.coerceAtMost(width - cx).coerceAtLeast(0)`, `ch = h.coerceAtMost(height - cy).coerceAtLeast(0)`), crops both images via `BufferedImage.getSubimage(cx, cy, cw, ch)`, and runs the same RGB-masked pixel comparison over the crop — `totalPixels = cw * ch` yields the in-region ratio.
- Factored the per-pixel comparison out of `compare` into a private `diffPixels(expectedImg, actualImg, width, height): Pair<Int, List<Pair<Int, Int>>>`, now shared by both `compare` (full-frame) and `compareRegion` (crop). `compare`'s public signature and behavior are unchanged.
- Reused `generateDiffImage` for the optional crop-relative diff image when `diffOutputDir != null` and the region mismatches (mismatched coords are crop-local; `generateDiffImage` copies the crop).
- Added a zero-area clamp short-circuit: if `cw <= 0 || ch <= 0` (degenerate / fully off-bounds rect), returns `DiffResult(match = true, diffCount = 0, totalPixels = 0, diffImage = null)` instead of calling `getSubimage` with a zero dimension.
- Added 6 region-diff tests to `VisualDiffTest.kt` covering isolation, in-region detection, crop `totalPixels`, region-vs-full-frame ratio divergence, off-bounds clamping, and zero-area crop.

## Behaviors Proven (Task 2)
- `compareRegion isolates in-region diff from out-of-region differences` — same pair: full-frame `compare` reports the out-of-region block; `compareRegion` over the box reports `diffCount == 0` and matches. Proves the region path isolates the box.
- `compareRegion detects an in-region difference` — an 8×8 painted block inside the region → `diffCount == 64`.
- `compareRegion totalPixels equals crop area not full frame` — `totalPixels == 24*32 == 768`, asserted `!= 23040`.
- `compareRegion ratio differs from full-frame ratio for the same image pair` — in-region ratio strictly exceeds the full-frame ratio for the same diff (the §KEY FINDING the anchor4 retune relies on).
- `compareRegion clamps an out-of-bounds rectangle without throwing` — `x=150, y=-5, w=40, h=30` → clamped to `10*30 == 300`, no exception.
- `compareRegion with zero-area crop returns an empty matching result` — `x=160` (zero width after clamp) → `match=true, diffCount=0, totalPixels=0`.
