## Settle mechanism

### Q1 — Settle rule

| Option | Description | Selected |
|--------|-------------|----------|
| Frame-buffer stability | Capture when N consecutive frames pixel-identical, capped | ✓ |
| Fixed N-frame settle | Step a fixed count before capture | |
| Stability + non-blank guard | Stability AND non-uniform check | |

**User's choice:** Frame-buffer stability → D-01.

### Q2 — Stability tuning

| Option | Description | Selected |
|--------|-------------|----------|
| 2 identical, cap=30, then capture | Best-effort capture on cap, never throws | ✓ |
| 2 identical, cap then throw | Loud failure on non-settling scenes | |
| Configurable params, sensible defaults | Expose stableFrames/maxFrames/onTimeout | |

**User's choice:** 2 identical, cap=30, best-effort capture → D-02.

### Q3 — Settle input behavior

| Option | Description | Selected |

**User's choice:** Preserve held buttons → D-03 (drove API-placement to StepAgent).
