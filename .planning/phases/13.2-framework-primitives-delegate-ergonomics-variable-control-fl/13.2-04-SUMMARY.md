## Decisions Made

- **sb.whenever() delegation for easeToZero:** Used `sb.whenever(...)` approach instead of `sb.emit(IfOp(...))` directly. Both produce identical IR because `whenever` emits `IfOp(condition, bodyBuilder.build(), emptyList())`. The `whenever` approach is cleaner since `emit()` is `internal` and `whenever` is the established public API path. Pitfall 3 (two IfOp not one if-else) is guaranteed because `whenever` is called twice on two separate conditions.

- **subpixel{} as GameBuilder extension:** Placed in VariableBuilders.kt as `fun GameBuilder.subpixel(...)` since it groups variable declarations (a GameBuilder responsibility), not script ops.

- **easeToZero in ExprBuilder.kt:** The plan declares `ExprBuilder.kt` as the target file for both `toPixel` and `easeToZero`. Both are co-located in the new `// FIXED-POINT HELPERS` section per PATTERNS.md.
