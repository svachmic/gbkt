## Implementation Details

### Changes to VariableBuilders.kt

1. **`AssignableVar` data class** — added `val wrapAt: Int? = null` as the last constructor param (default null). All existing `AssignableVar("x")` call sites compile unchanged.

2. **`U8VarDelegate`** — added `val wrapAt: Int? = null` constructor param; added `getValue` override that returns `AssignableVar(resolvedName ?: property.name, wrapAt = wrapAt)` to propagate the wrap invariant to the value object. `VarDelegate.resolvedName` promoted from `private` to `protected` to enable this override.

3. **`u8Var()` factory** — signature is now `fun u8Var(initial: Int = 0, wrapAt: Int? = null, transient: Boolean = false)`. Threads `wrapAt` to `U8VarDelegate`.

4. **`isPowerOfTwo(n: Int): Boolean`** — private top-level helper: `n > 0 && (n and (n - 1)) == 0`. Runs at JVM/DSL time.

5. **`emitWrapGuard(sb: ScriptBuilder, varName: String, n: Int)`** — private top-level helper:
   - Power-of-two N: `sb.assign(varName, BinaryExpr(VarRef(varName), AND, Literal(n-1)), SET)` — bitmask path (D-15).
   - Non-power-of-two N: `sb.whenever(BinaryExpr(VarRef(varName), GTE, Literal(n))) { assign(varName, Literal(0), SET) }` — compare-reset path (D-15).

6. **`inc()`, `dec()`, `plusAssign()`, `minusAssign()`** — refactored to extract `sb` from `ScriptBuilderContext.current`, call the primary mutation, then `wrapAt?.let { n -> emitWrapGuard(sb, name, n) }` (D-16 post-mutation adjacency).

### D-15 Byte-Identity

- `rot` wrapAt=16: mask path emits `Assign("rot", BinaryExpr(VarRef("rot"), AND, Literal(15)), SET)` — byte-matches `rot set (rot and 0xF)`.
- `idx` wrapAt=5: compare-reset emits `IfOp(BinaryExpr(VarRef("idx"), GTE, Literal(5)), [Assign("idx", Literal(0), SET)])` — byte-matches `whenever(idx isAtLeast 5){ idx set 0 }`.
