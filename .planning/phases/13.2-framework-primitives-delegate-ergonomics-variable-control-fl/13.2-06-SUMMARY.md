## Deviations from Plan

**None** — plan executed exactly as written. Minor implementation notes:

- **No subpixel{} wrapper used:** The plan action mentioned using `subpixel { }` for grouping. Since `subpixel{}` is a no-op lambda, variables declared inside it are not accessible outside the lambda scope (Kotlin scoping rules). Variables were declared at top level with a comment grouping instead. This has zero IR impact.
- **Metasprites enter block:** Used explicit `posX set (80 shl 4)` / `posY set (72 shl 4)` to match the new i16FixedVar declarations (same subpixel values as INITIAL_POS_X/Y_IN_SUBPIXELS). The constants remain defined and could be reused; using explicit literals is consistent with the SimplePhysics approach.
