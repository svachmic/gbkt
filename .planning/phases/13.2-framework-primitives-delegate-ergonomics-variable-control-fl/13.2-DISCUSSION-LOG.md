## Single-frame if/unless (#2)

### Q: User-facing name for the single-frame conditional

| Option | Description | Selected |
|--------|-------------|----------|
| runIf / unless / .orElse | Plain-English names aliasing internal ifOp/elseOp; no backticks. | ✓ |
| Backticked `if`/`else`/unless | Native-looking but backticks at every call site. | |
| Keep ifOp/elseOp, add unless | Minimal churn. | |

**User's choice:** runIf / unless / .orElse.

### Q: Relationship between whenever and the new conditional

| Option | Description | Selected |
|--------|-------------|----------|
| Coexist — whenever stays reactive | Keep whenever for reactive; if/unless for single-frame. SC = zero NESTED whenever. | (basis) |
| Deprecate whenever → if everywhere | Hard-replace per 13.1 D-11. | |
| (user freeform) deprecate-as-reminder | Mark whenever deprecated as a "don't forget" signpost but don't replace yet. | ✓ (resolved) |

**User's choice:** "Deprecate whenever, but don't replace it yet. This way we don't forget about it in the future."

**Notes:** Surfaced the conflict — a literal `@Deprecated(WARNING)` would flood the many un-migrated legitimate reactive `whenever` sites with warnings, fighting this phase's clean-build / zero-`@Suppress` gate. Offered three durability mechanisms: (1) roadmap Tier-3 follow-up + pending todo, (2) literal `@Deprecated` now, (3) KDoc soft signpost. User accepted **#1 + #3**: roadmap/todo breadcrumb (the load-bearing "don't forget") + KDoc signpost on `whenever`; no `@Deprecated` annotation this phase. Migration touches only nested single-frame sites.

## Fixed-point sub-pixel (#3)

### Q: Delivery form

| Option | Description | Selected |
|--------|-------------|----------|
| Declarative type i16FixedVar | Delegate parallel to i16Var; invariant in the type. | |
| subpixel { } scope block | Scope wrapping conversions. | |
| Both | Ship the type AND the scope. | ✓ |

**User's choice:** Both. (CONTEXT records `i16FixedVar` as the primary migration form — what the oracle migrates to.)

### Q: Precision — fixed 12.4 vs configurable

| Option | Description | Selected |
|--------|-------------|----------|
| Fixed 12.4 (4 bits) | Hardcode 4 fractional bits. | |
| Configurable, default 4 | `fractionalBits = 4` default, overridable. | ✓ |

**User's choice:** Configurable, default 4. (Default-4 is the path all examples migrate to / the oracle pins.)

### Q: API surface — init units + pixel extraction

| Option | Description | Selected |
|--------|-------------|----------|
| Init in pixels + .toPixel() | `i16FixedVar(80)`; `posX.toPixel()` returns Expr. No shift leaks. | ✓ |
| Init in pixels + auto-convert moveTo | moveTo accepts fixed ref directly. | |
| Init in subpixels + .toPixel() | Keeps magic 1024 at construction. | |

**User's choice:** Init in pixels + .toPixel().

**Notes:** Hard constraint recorded — simple-physics is the codegen oracle; default-4 path must lower byte-identical (`SimplePhysicsEmissionTest` + clean buildRom).
