## Key Design Decisions

- **WrapAtTest two-path coverage (D-16):** Both power-of-two (wrapAt=16 → `& 15` bitmask Assign) and non-power-of-two (wrapAt=5 → `>= 5 → set 0` IfOp) paths are tested, plus explicit negative tests confirming no cross-contamination.

- **EaseToZeroTest Pitfall-3 guard:** An explicit test asserts `otherwise == emptyList()` on both IfOp nodes, structurally preventing a future "collapse to if-else" regression.

- **RunIfAliasTest unless approach:** Tests assert `UnaryExpr(LOGICAL_NOT, cond)` — matching the PATTERNS.md spec and the RESEARCH.md implementation note that `unless` negates via `NotExpr(cond)`.

- **VarDelegateGuardTest/SaveDataDelegateSingleUseTest scope:** Tests drive through `game { }.build()` so the guard fires in the full registration context, not just standalone.
