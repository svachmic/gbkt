Reasoning about RunIfAliasTest assertions:

- **Test 1** (`runIf produces same IfOp shape as ifOp`): `runIf` is a one-liner that calls `ifOp`, so the `IfOp` produced is structurally identical. `captureV2Location()` skips frames in `io.github.gbkt.core.dsl`, including the test class itself (same package), so `sourceLocation = null` for both calls. `assertEquals` on two identical data-class `IfOp(cond, emptyList(), emptyList(), null)` values passes.

- **Test 2** (`unless produces IfOp with LOGICAL_NOT of condition`): `unless(cond){}` calls `ifOp(UnaryExpr(UnaryOp.LOGICAL_NOT, cond), {})`. The test asserts `negated.op == UnaryOp.LOGICAL_NOT` and `negated.operand == cond`. Both match.

- **Test 3** (`runIf with orElse produces same IfOp as ifOp with elseOp`): `runIf` produces the same IfOp as `ifOp`; `orElse` delegates to `elseOp` which patches the last IfOp's `otherwise` list. The resulting IR is structurally identical.
