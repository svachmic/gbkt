### `VariableBuilders.kt` — wrapAt param on U8VarDelegate + AssignableVar.inc/dec/plusAssign/minusAssign auto-wrap (Req #9)

**Analog:** `U8VarDelegate` class (line 392-393) + `AssignableVar.inc()` (lines 193-200) + `AssignableVar.plusAssign()` (lines 128-131)

**Analog — U8VarDelegate** (lines 392-393):
```kotlin
/** Delegate for `var x by u8Var(0)` — UINT8 variable (0–255). */
class U8VarDelegate(initialValue: Int, transient: Boolean = false) :
    VarDelegate(VarType.U8, initialValue, transient)
```

**Delta for wrapAt on U8VarDelegate:** Add `wrapAt: Int? = null` parameter. Store it on the
class (the parent `VarDelegate` does NOT carry it — it is U8/I8-specific). Pass it through to
`AssignableVar` on `getValue`.

**Analog — AssignableVar.inc()** (lines 193-200):
```kotlin
operator fun AssignableVar.inc(): AssignableVar {
    ScriptBuilderContext.current?.assign(
        name,
        BinaryExpr(VarRef(name), BinaryOp.ADD, Literal(1)),
        AssignOp.SET,
    ) ?: error("++ called outside a ScriptBuilder block")
    return this
}
```

**Delta for auto-wrap:** After the primary `assign(...)` call and before `return this`, insert
a `wrapAt?.let { n -> emitWrapGuard(sb, name, n) }` call. The `emitWrapGuard` private helper
(place as a top-level private function in VariableBuilders.kt, near the operators) emits:
- Power-of-two N → `Assign(name, BinaryExpr(VarRef(name), AND, Literal(n-1)), SET)`
- Non-power-of-two N → `IfOp(BinaryExpr(VarRef(name), GTE, Literal(n)), [Assign(name, Literal(0), SET)])`

Power-of-two test at Kotlin/JVM level (runs at DSL-declaration time, not GB runtime):
```kotlin
private fun isPowerOfTwo(n: Int): Boolean = n > 0 && (n and (n - 1)) == 0
```

**AssignableVar field for wrapAt (Option A per RESEARCH.md):** Extend `AssignableVar` from
`data class AssignableVar(val name: String)` to add `val wrapAt: Int? = null`. All existing
`AssignableVar("someVar")` call sites remain valid (default null). `U8VarDelegate.getValue`
returns `AssignableVar(resolvedName ?: property.name, wrapAt = this.wrapAt)`.

**Also apply wrapAt emission to:** `dec()`, `plusAssign()`, `minusAssign()` — same pattern as
`inc()`, each calling `emitWrapGuard` after the primary mutation assign.

### `ScriptBuilder.kt` — runIf / unless / orElse aliases (Req #2)

**Analog:** `ScriptBuilder.ifOp` / `elseOp` / `whenever` (lines 140-202):

**Analog — ifOp** (lines 140-145):
```kotlin
fun ifOp(condition: Expr, block: ScriptBuilder.() -> Unit) {
    val loc = captureV2Location()
    val thenBuilder = ScriptBuilder()
    ScriptBuilderContext.with(thenBuilder) { thenBuilder.block() }
    ops += IfOp(condition, thenBuilder.build(), sourceLocation = loc)
}
```

**Analog — elseOp** (lines 154-161):
```kotlin
fun elseOp(block: ScriptBuilder.() -> Unit) {
    val lastIf =
        ops.lastOrNull() as? IfOp
            ?: throw DSLValidationError("error: elseOp() must immediately follow ifOp()")
    val elseBuilder = ScriptBuilder()
    ScriptBuilderContext.with(elseBuilder) { elseBuilder.block() }
    ops[ops.lastIndex] = lastIf.copy(otherwise = elseBuilder.build())
}
```

**Analog — whenever** (lines 197-202):
```kotlin
fun whenever(condition: Expr, block: ScriptBuilder.() -> Unit) {
    val loc = captureV2Location()
    val bodyBuilder = ScriptBuilder()
    ScriptBuilderContext.with(bodyBuilder) { bodyBuilder.block() }
    ops += IfOp(condition, bodyBuilder.build(), emptyList(), sourceLocation = loc)
}
```

**Delta — add runIf / unless / orElse:** Place in a new subsection immediately after the
`whenever` block, labelled `// Single-frame imperative conditionals`. Each is a one-line
delegate or body-copy:
```kotlin
/**
 * Single-frame imperative conditional. Lowers to [IfOp] — identical to [ifOp].
 *
 * Use for clamps, guards, and post-mutation checks that execute once per frame in
 * sequence.  For top-level reactive triggers evaluated as independent guards every
 * frame, use [whenever].
 */
fun runIf(condition: Expr, block: ScriptBuilder.() -> Unit) = ifOp(condition, block)

/**
 * Negated single-frame conditional: executes [block] when [condition] is false.
 *
 * Lowers to [IfOp] with [UnaryExpr(NOT, condition)] — identical to
 * `runIf(condition.not()) { ... }`.
 */
fun unless(condition: Expr, block: ScriptBuilder.() -> Unit) =
    ifOp(UnaryExpr(UnaryOp.NOT, condition), block)

/**
 * Else branch chained to the most recent [runIf]. Delegates to [elseOp].
 *
 * Must immediately follow [runIf] or [ifOp].
 */
fun orElse(block: ScriptBuilder.() -> Unit) = elseOp(block)
```

**Delta — KDoc signpost on `whenever`:** Prepend to the existing `whenever` KDoc (replace the
existing one-line KDoc at line 192-196):
```kotlin
/**
 * Sugar for a one-armed conditional that lowers to [IfOp] with empty otherwise list.
 *
 * Use [whenever] for top-level reactive triggers (e.g. button-held, collision, game-state
 * checks) that are evaluated every frame as independent guards.
 *
 * For **single-frame imperative conditionals** (clamps after mutation, wrap-after-increment),
 * prefer [runIf] / [unless] / [orElse] — they read as control flow, not reactive triggers.
 *
 * Equivalent to `runIf(condition) { ... }` in the generated C.
 *
 * Tier-3 roadmap: a future phase will unify `whenever` → `runIf` for reactive sites;
 * tracked as a pending todo. Not deprecated this phase.
 */
```

### `ExprBuilder.kt` — AssignableVar.easeToZero() extension (Req #8 / D-13)

**Analog:** ScriptBuilder `ifOp` pattern + `AssignableVar.plusAssign` / `minusAssign` in
VariableBuilders.kt. The method emits two `IfOp` nodes directly into the active
`ScriptBuilderContext`.

**Analog — ScriptBuilderContext.current usage** (from VariableBuilders.kt lines 128-131):
```kotlin
operator fun AssignableVar.plusAssign(value: Expr) {
    ScriptBuilderContext.current?.assign(name, value, AssignOp.ADD)
        ?: error("+= called outside a ScriptBuilder block")
}
```

**Delta — add easeToZero():** Place in the `// Fixed-point helpers` section in ExprBuilder.kt,
after `toPixel()`:
```kotlin
/**
 * Decays this variable toward zero by [by] per frame.
 *
 * Emits two [IfOp] nodes:
 * - `if (v < 0) { v += by }` (decay from negative side)
 * - `if (v > 0) { v -= by }` (decay from positive side)
 *
 * Generated C is byte-identical to the hand-rolled two-`whenever` ladder.
 * [by] defaults to 1, which is the only value used in current example ports.
 *
 * Must be called inside a `ScriptBuilder` block (scene frame/enter/exit, whenever, runIf, etc.).
 */
fun AssignableVar.easeToZero(by: Int = 1) {
    val sb = ScriptBuilderContext.current
        ?: error("easeToZero() called outside a ScriptBuilder block")
    // if (v < 0) { v += by }
    val thenBuilderNeg = ScriptBuilder()
    ScriptBuilderContext.with(thenBuilderNeg) {
        thenBuilderNeg.assign(name, Literal(by), AssignOp.ADD)
    }
    sb.emit(IfOp(
        condition = BinaryExpr(VarRef(name), BinaryOp.LT, Literal(0)),
        then = thenBuilderNeg.build(),
    ))
    // if (v > 0) { v -= by }
    val thenBuilderPos = ScriptBuilder()
    ScriptBuilderContext.with(thenBuilderPos) {
        thenBuilderPos.assign(name, Literal(by), AssignOp.SUB)
    }
    sb.emit(IfOp(
        condition = BinaryExpr(VarRef(name), BinaryOp.GT, Literal(0)),
        then = thenBuilderPos.build(),
    ))
}
```

NOTE: `ScriptBuilder` does not expose a public `emit(ScriptOp)` today. Check whether `emit`
exists or if the planner must either add it as `internal fun emit(op: ScriptOp) { ops += op }`
or use `whenever` as the emission vehicle. The `whenever` approach is the simplest — since
`whenever` is already in `ScriptBuilder`, `easeToZero` can call `this.whenever(cond) { }` on
the active builder obtained from context. Concrete alternative:
```kotlin
fun AssignableVar.easeToZero(by: Int = 1) {
    val sb = ScriptBuilderContext.current
        ?: error("easeToZero() called outside a ScriptBuilder block")
    sb.whenever(BinaryExpr(VarRef(name), BinaryOp.LT, Literal(0))) {
        assign(name, Literal(by), AssignOp.ADD)
    }
    sb.whenever(BinaryExpr(VarRef(name), BinaryOp.GT, Literal(0))) {
        assign(name, Literal(by), AssignOp.SUB)
    }
}
```
This avoids needing `emit` and reuses the `whenever` path, producing identical IR.
