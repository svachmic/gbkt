declaration: `var idx by u8Var(0, wrapAt = N)`. Mutations auto-wrap, making out-of-wrap states
unrepresentable (subsumes the Pitfall-6 `u8Var`-not-`i8Var` folklore). Per D-15 a SINGLE smart

`idx`'s `whenever(idx isAtLeast NUM_FRAMES){ idx set 0 }`). Per D-16 the guard is emitted after
each mutating op; the generated C must be same-or-smaller than the hand-rolled per-frame wrap.

`AssignableVar` value object (additive, default null) so wrap metadata travels with the value and
no context lookup is needed at op-emit time. `i8Var` wrap is deferred (no current call site).

Purpose: Replace hand-rolled `& 0xF` and `isAtLeast → set 0` wrap patterns on `idx`/`rot`; delete
the Pitfall-6 comment block in the next migration plan.
