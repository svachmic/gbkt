## Decisions Made

1. **Circular-navigate SceneRef? var pattern:** `createTwoSceneGameFixture` has titleScene→mainScene and mainScene→titleScene mutual navigates. Solved with `var mainSceneRef: SceneRef? = null` declared before titleScene; frame lambda captures by reference; `mainSceneRef = mainScene` assigned after mainScene is initialized. This is idiomatic Kotlin for deferred initialization.

2. **No architectural changes:** This is a pure API-shape migration. Generated C is byte-identical for all 6 examples (both `startScene = ref` and `start = ref.id` resolve to the same scene id string in the IR).
