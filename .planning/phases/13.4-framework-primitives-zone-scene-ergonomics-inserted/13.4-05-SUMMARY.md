# Phase 13.4 Plan 05: Migrate platformer + core test callers — zone delegate, navigate/start ref forms Summary

**One-liner:** D-12 restructure of 4 `gb.zone()` explicit-receiver tests into `game {}` delegate blocks; full `gbkt-genre-platformer` and `gbkt-core` test-tree start-clean via `startScene = sceneRef` migration.

## What Was Built

Migrated the second migration cluster: 4 test files across `gbkt-genre-platformer/dsl` and `gbkt-core/dsl` to the new primitives from Plans 13.4-01/02/03.

Key D-12 restructure: `ZonePlatformerPhysicsTest`'s 4 tests previously used `val gb = GameBuilder("test")` with explicit-receiver `gb.zone("zN") { ... }` + `gb.currentZones()` — an approach that predated the `ZoneDelegate` and would not work with the new delegate (which requires `GameBuilderContext.current` from a `game {}` block). Each test was restructured into `game("testN") { val zN by zone { ... }; val s = scene("s") { enter {} }; startScene = s }` with assertions on `ir.zones.single()` from the built GameIR.

## Key Design Decisions

- `ZonePlatformerPhysicsTest` restructured to `game { val z by zone { }; startScene = s }` — each test declares a minimal `scene("s") { enter {} }` and assigns `startScene = s` to satisfy `build()` validation. Assertions moved from `gb.currentZones().single()` to `ir.zones.single()` post-build, which exercises the full build path.
- `PlatformerInputDslTest` Tests 2 and 3: delegate form `val level1 by zone { ... }` used; builder is NOT built (`.build()` not called) so `gb.currentZones()` is still valid for mid-build assertions. Added `import io.github.gbkt.core.dsl.zone` (required per wave_context — the member `GameBuilder.zone(String, block)` would otherwise shadow the top-level `zone(block)` factory).
- `WorldBuilderTest`: all `zone("id") {}` → `val id by zone {}` with `@Suppress("UNUSED_VARIABLE")` to suppress the unreferenced val; `start = "main"` → `val main = scene("main") { enter {} }; startScene = main`; `navigate("...")` inside zone lifecycle callbacks → `navigate(SceneRef("..."))` (forward-ref form, no scene val in scope inside lambda).
- `LevelCardSceneBuilderTest`: `gameplayScene` captured as `val gameplayScene = scene("gameplay") {}` (returns SceneRef); `start = "gameplay"` → `startScene = gameplayScene`; `start = "nextLevelScene"` → `startScene = nextLevelScene` (the delegate itself returns SceneRef).
