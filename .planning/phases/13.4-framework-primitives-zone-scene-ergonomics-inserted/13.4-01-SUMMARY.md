# Phase 13.4 Plan 01: ZoneDelegate + fun zone(block) factory Summary

**One-liner:** `by zone { }` property delegate with ID-from-property-name and single-use guard, mirroring MetaspriteDelegate verbatim.

## What Was Built

Added `ZoneDelegate` class and `fun zone(block): ZoneDelegate` top-level factory to `WorldBuilders.kt`, enabling `val playZone by zone { }` syntax where the zone ID is inferred from the Kotlin property name (`"playZone"`) — eliminating the need for a duplicated magic-string argument.

## Key Design Decisions

- `ZoneDelegate` mirrors `MetaspriteDelegate` exactly: `ReadOnlyProperty<Any?, ZoneRef>`, `private var ref`, `private var delegateUsed` single-use guard, `operator fun provideDelegate` that reads `property.name`, looks up `GameBuilderContext.current`, calls existing public `GameBuilder.registerZone(ir)`, and returns `this`.
- Outside-game guard uses `error("zone {} must be called inside a game {} block")` — consistent with the metasprite error message pattern.
- Single-use guard error message: `"ZoneDelegate instance reused: was already bound to '${ref?.id ?: "<unknown>"}'. Each 'val x by zone { }' must use its own delegate instance."` — consistent with MetaspriteDelegate.
- Legacy `zone(id: String, block)` in `GameBuilder.kt` left fully intact (D-07 migrate-then-delete; deleted in 13.4-09).
- No new method added to `GameBuilder` — reused the existing public `registerZone(ZoneIR)` at line 175.
