### Scope-Boundary Notes

**GameIR.startScene field preserved:** `GameIR.startScene: String?` (IR data class field) was intentionally NOT renamed — that would require touching gbkt-ir and every backend/analysis pass that reads `gameIR.startScene`. The plan's scope is the GameBuilder DSL surface only. The one remaining `startScene` reference in GameBuilder.kt line 786 is the GameIR constructor named arg `GameIR(... startScene = startRef.id ...)` — this is correct and intentional.

**LabyrinthOfTheDragon-port zone("floorN") files remain on disk:** D-13 explicitly defers their migration. Files compile against the old API which is now deleted, so the port cannot compile — this is the expected state (the port is excluded from the build).

**Stale-ROM emulator test failures (pre-existing):** BanksUatTest (anchor 1 + anchor 2), PongStepAgentTest (paddle1 OAM mismatch), and PlayerMetaspriteGeometryTest (sprite array missing) all fail because they run against pre-built ROMs. These failures predate this plan — they require `buildRom` (GBDK toolchain) to regenerate ROMs with the updated DSL. Tracked in deferred-items.
