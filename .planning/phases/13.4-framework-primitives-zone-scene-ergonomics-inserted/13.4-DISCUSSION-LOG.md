## Size fallback semantics

| Option | Description | Selected |
|--------|-------------|----------|
| tilemap() presence drives it | tilemap present → derive from tilemap PNG; tileset-only → 20×18; explicit always wins; never 32×32. Deterministic, maps to SPEC's 3 acceptance cases, correct for all 5 active zones. | ✓ |
| Sniff tileset size, threshold fallback | Derive from map source; below a min threshold → 20×18. Heuristic, fragile, non-deterministic. | |
| You decide | Defer. | |

**User's choice:** tilemap() presence drives it.
**Notes:** banks/checker (2×2 tiles) and platformer/titleZone (full-screen) are
structurally indistinguishable in the IR — no repeating-vs-full-image flag — so deriving
from a tileset-only PNG would emit a broken 2×2 banks zone. 20×18 is the safe default.
