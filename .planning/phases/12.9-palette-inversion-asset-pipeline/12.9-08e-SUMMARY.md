### D1 — CONFIRMED (codegen-read)
`bank1.c` `nextLevelScene_enter()`: first `DISPLAY_ON;` (line 77) precedes
`fill_bkg_rect(0u,0u,32u,32u,0u)` (line 80) → LCD on before BG clear → `0F` tile composited in the
flip frame. Fix = move/gate `SceneVisitor.kt:~299` inline `DISPLAY_ON` (trailing-`DISPLAY_ON`
heuristic, no `ZoneIR` field).

### D2 — RE-SCOPED / planned fix is WRONG (codegen-read + runtime)
- `main.c`: `set_sprite_data`×1, `set_sprite_palette`×0, no `_gbkt_default_sprite_pal`.
- `sprites/player.c` conversion args have **no `-c` transparency flag**; `player_palettes` puts the
  orange sheet background at **index 2** (visible), and tile bytes confirm the 24×32 surround is
  index 2 (not transparent index 0).
- Runtime OCPS (0xFF6A)=`0xC8` = GBDK default grayscale OBJ palette; `player_palettes` never uploaded.
- **On GBC, OBJ index 0 is hardware-transparent** → the box is caused by the non-zero index-2
  surround, NOT a missing palette. The 08e plan's `_gbkt_default_sprite_pal`/`set_sprite_palette`
  fix in `buildHomeFile` (`gbkt-backend-gbdk`) would only *recolor* the box, **not remove it**.
- True fix = png2asset transparency key in `ConvertSpritesTask.buildPng2AssetArgs`
  (`gbkt-gradle-plugin`) OR re-index the source PNG. Framework asset-pipeline change.
- Evidence: `build/.../screenshots/08e-diag-box_frame696.png`.

### D3 — CONFIRMED (codegen-read)
`main.c:566/571` horizontal probe uses `player_real_x ± 4u` (halfW=4) vs reference
`PLAYER_CHARACTER_BOUNDING_BOX_HALF_WIDTH 5`. Fix = `PlatformerVisitor.buildHorizontalProbe()`
(~line 1276) `CLiteral(halfW)` → `CLiteral(halfW + 1)`. (Platformer-physics, not palette.)

### D4 — CONFIRMED mechanism; concrete spawn_y DEFERRED
`main.c:317` world2 `_current_level_non_solid_tile_count = 68u` → ground tiles ≥68 treated non-solid
→ fall-through. Level-1 grounded reference: `_playerY`=1632 (102px), `_grounded`=1 (validates read
path via `.noi` symbols). Concrete world2 spawn_y requires the flaky drive-to-level-end probe —
**deferred to fix-time** because the routing decision supersedes (if D4 routes to a sibling, that
plan owns the probe). Fix shape = `PlatformerTemplate.kt:~274` `spawn(40u,<N>u)` and/or world2
tile-solidity threshold.
