# Plan 12.9-08f Summary — Round 3 Fix (G3 RE-BIND Defects D1-D4)

## One-liner

## Defect Fixes

### D1 — 0F flip-frame artifact (SceneVisitor inline DISPLAY_ON gate)

**File:line:** `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/visitor/SceneVisitor.kt:293`
**Fix:** Added trailing-DISPLAY_ON heuristic — if the scene's enterOps already ends with a DISPLAY_ON (e.g., LevelCardSceneBuilder.materialize's `cEmit("DISPLAY_ON;")`), omit the zone-load inline DISPLAY_ON so the BG clear runs BEFORE LCD-on. Without the gate, the zone-load DISPLAY_ON turned on the LCD before the card-scene cleared the BG → GBC PPU composited a flip frame with un-cleared world1 cols 20-31 = the 0F tile.
**Test:** `LevelCardSceneEmissionTest` Test 6 — asserts `fill_bkg_rect` precedes first `DISPLAY_ON` in `nextLevelScene_enter` body (brace-walk scoped).
**RED→GREEN commit:** `9126403f`

### D2a — Player box (png2asset -keep_palette_order for indexed sprite PNGs)

**Files:lines:**
- `gbkt-gradle-plugin/src/main/kotlin/io/github/gbkt/gradle/tasks/PngUtils.kt` — new shared `isIndexedPngShared()` function
- `gbkt-gradle-plugin/src/main/kotlin/io/github/gbkt/gradle/tasks/ConvertSpritesTask.kt:buildPng2AssetArgs` — appends `-keep_palette_order` when `isIndexedPngShared(pngFile)`

**Fix:** Without `-keep_palette_order`, png2asset re-sorted the indexed palette, moving the orange sprite-sheet background from source index 0 to index 2 (opaque). On GBC, OBJ index 0 is hardware-transparent; the box appeared because the surround pixels were encoded as index 2. With `-keep_palette_order`, the source palette order is preserved: orange stays at index 0 → hardware-transparent → box disappears.
**Test:** `ConvertSpritesKeepPaletteOrderTest` — indexed PNG → args contain `-keep_palette_order`; RGB PNG → absent.
**RED→GREEN commit:** `60f9bb93`
**Deviation:** Rule 1 (auto-fix) — `generateSpriteHeader` updated to emit `extern const palette_color_t <name>_palettes[]` and `#include <gb/cgb.h>` for indexed PNGs (needed for D2b's `set_sprite_palette` call to resolve at link time).

### D2b — Character wrong colors (GBC-gated set_sprite_palette for metasprites)

**File:line:** `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/pipeline/GBDKPipelineV2.kt:buildMetaspriteSpritePaletteStatements` (new method, ~line 4930)
**Fix:** New `buildMetaspriteSpritePaletteStatements()` emits `set_sprite_palette(<slot>, 1u, <id>_palettes)` for each metasprite in main(), GBC-gated. Without it, the GBDK default grayscale OBJ palette was never replaced → character rendered with wrong (grayscale) colors.
**Test:** `MetaspriteSpritePaletteEmissionTest` — GBC game → emits `set_sprite_palette(..., player_palettes)`; DMG game and no-metasprite game → absent.
**RED→GREEN commit:** `68630c03`

### D3 — Player walks through blocks (horizontal probe halfW + 1)

**File:line:** `gbkt-genre-platformer/src/main/kotlin/io/github/gbkt/genre/platformer/codegen/PlatformerVisitor.kt:buildHorizontalProbe` (~line 1276)
**Fix:** `CLiteral(halfW)` → `CLiteral(halfW + 1)`. halfW = hitbox.width/2 = 8/2 = 4; reference `PLAYER_CHARACTER_BOUNDING_BOX_HALF_WIDTH = 5`. The 1px deficit allowed a 1px overlap before blocking. Now probes read `player_real_x + 5u` / `- 5u`.
**Test:** `TilemapCollisionEmissionTest` D3 test — asserts `player_real_x + 5u` and `player_real_x - 5u` in `platformer_physics_update` body (brace-walk scoped).
**RED→GREEN commit:** `0e1680f9`

### D4 — Level-2 player sunk (grounded reset on level switch)

**File:line:** `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/pipeline/GBDKPipelineV2.kt:buildSetupCurrentLevelFunctionIfNeeded` (~line 2537)
**Fix:** Resolved `groundedSym` from `tilemap_collision` GenericSystem config (`groundedVar` key, default `_grounded`), mirroring the `posXSym`/`vySym` resolution. Emits `${groundedSym} = 0;` after the existing `$vySym = 0;` reset in every gameplay-zone case body. Without this, `_grounded` carried 1 from the prior level's level-end trigger → gravity suppressed → player frozen at raw spawn y.
**Test:** `SetupCurrentLevelGroundedResetEmissionTest` — asserts `_grounded = 0` appears in `setup_current_level` per-case body after `_playerVy = 0`.
**RED→GREEN commit:** `946c0f4c`
