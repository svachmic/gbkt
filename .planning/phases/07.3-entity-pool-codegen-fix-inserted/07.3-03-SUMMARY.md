# Phase 07.3 Plan 03: Shmup DSL Fix and ROM Build Validation Summary

**Shmup movement ops added to forEachActive bodies, OAM free list infrastructure wired into pipeline, ROM builds and compiles to 32KB shmup.gb — awaiting human MCP play-through verification**

## Accomplishments

- Fixed Shmup.kt Pitfall 6: added `bullet.y -= 4` inside `forEachActive(bulletPool)` and `enemy.y += 1` inside `forEachActive(enemyPool)` bodies. Without these ops, bullets and enemies were stationary.
- Discovered and fixed three missing integrations in GBDKPipelineV2 that were preventing the pool codegen from working end-to-end:
  1. `ScriptOpVisitor.setGameIR(gameIR)` was never called in `buildSceneFile()` — pool context redirection was silently disabled (gameIRContext returned null → poolCtx was null → body ops used template scalars)
  2. `_oam_free_list[40]` and `_oam_free_top` globals were never generated — `spawn_actor` and `destroy_actor` referenced undefined globals
  3. `init_oam_free_list()`, `spawn_actor()`, `destroy_actor()` functions were never included in the output — GBDK reported "implicit declaration" and "too many parameters" errors
- Shmup ROM now builds successfully to 32 KB with correct per-instance pool codegen.

## Files Created/Modified

- `gbkt-examples/shmup/src/main/kotlin/io/github/gbkt/examples/shmup/Shmup.kt` - Added `bullet.y -= 4` and `enemy.y += 1` in forEachActive bodies
- `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/pipeline/GBDKPipelineV2.kt` - Added ScriptOpVisitor.setGameIR(), oamFreeListGlobals, oamFreeListFunctions, init_oam_free_list() in main()

## Decisions Made

- `setGameIR(gameIR)` is called once at the top of `buildSceneFile()` before the `gameIR.scenes.flatMap` loop. The ScriptOpVisitor is a Kotlin singleton (object) with ThreadLocal state — setting it once covers all scene iterations in the same thread.
- OAM free list infrastructure is gated on `gameIR.actorPools.isNotEmpty()` — no generated output for non-pool games (Pong, Breakout verified unaffected).
- `init_oam_free_list()` placed before `pool_<id>_init()` calls in main() because pool inits set oam[i]=0xFF (invalid slot sentinel), which is correct: slots should be in the free list, not pre-assigned.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] ScriptOpVisitor.setGameIR() was never called in GBDKPipelineV2.buildSceneFile()**
- **Found during:** Task 1 (generating C and observing `_bullet_y -= 4u` instead of `_pool_bulletPool_y[_bi] -= 4u`)
- **Issue:** Plan 02 added `setGameIR()` method to ScriptOpVisitor and `gameIRContext` ThreadLocal for pool context lookup. However, GBDKPipelineV2 never called `setGameIR()` in `buildSceneFile()`. As a result, `gameIRContext.get()` returned null, `poolCtx` was null, and body ops fell back to template actor global scalars.
- **Fix:** Added `ScriptOpVisitor.setGameIR(gameIR)` call in `buildSceneFile()` before the scene iteration. Added `ScriptOpVisitor` import to GBDKPipelineV2.kt.
- **Files modified:** `GBDKPipelineV2.kt`
- **Verification:** After fix, generated bank1.c contains `_pool_bulletPool_y[_bi] -= 4u` and `_pool_enemyPool_y[_ei] += 1u`
- **Committed in:** `7c1a6154` (Task 1 commit)

**2. [Rule 1 - Bug] OAM free list globals (_oam_free_list, _oam_free_top) were never generated**
- **Found during:** Task 1 (buildRom failed with GBDK errors about undefined spawn_actor/destroy_actor)
- **Issue:** `GBDKSystemVisitor.buildOAMFreeListGlobals()` existed but was never called in the pipeline. The generated C called `spawn_actor()` and `destroy_actor()` which referenced `_oam_free_list` and `_oam_free_top` globals that didn't exist.
- **Fix:** Added `oamFreeListGlobals` computation gated on `gameIR.actorPools.isNotEmpty()` and included in `allVariablesWithCollision`.
- **Files modified:** `GBDKPipelineV2.kt`
- **Committed in:** `7c1a6154` (Task 1 commit)

**3. [Rule 1 - Bug] init_oam_free_list(), spawn_actor(), destroy_actor() functions were never generated**
- **Found during:** Task 1 (buildRom failed with "implicit declaration" and "too many parameters" errors for spawn_actor/destroy_actor)
- **Issue:** `GBDKSystemVisitor.buildOAMFreeListInit()`, `buildSpawnActorFunction()`, and `buildDestroyActorFunction()` all existed but were never included in the `buildHomeFile()` function list. The pool lifecycle functions (`pool_<id>_spawn`, `pool_<id>_destroy`) called `spawn_actor()`/`destroy_actor()` but these were undefined at compile time.
- **Fix:** Added `oamFreeListFunctions` list (3 functions) gated on `gameIR.actorPools.isNotEmpty()` and included before `actorPoolFunctions` in the CFile function list. Added `init_oam_free_list()` call in `buildMainFunction()` before pool init calls.
- **Files modified:** `GBDKPipelineV2.kt`
- **Committed in:** `7c1a6154` (Task 1 commit)
