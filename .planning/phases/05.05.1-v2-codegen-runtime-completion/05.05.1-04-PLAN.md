    Implement the control flow, math, and data manipulation ScriptOp visitor methods in ScriptOpVisitor. Reference the v1 codegen files for patterns but produce typed C AST (not strings).

    **Control flow ops:**
    - `visitWhileOp(op)`: `CWhile(ExprVisitor.visit(op.condition), op.body.map { visit(it) }, sourceLocation=op.sourceLocation)`
    - `visitForOp(op)`: `CFor(init=CVarDecl(sanitizeVarName(op.variable), CI8, ExprVisitor.visit(op.from)), condition=CBinaryExpr(CVar(sanitizeVarName(op.variable)), "<=", ExprVisitor.visit(op.to)), increment=CUnaryExpr("++", CVar(sanitizeVarName(op.variable))), body=op.body.map { visit(it) }, sourceLocation=op.sourceLocation)`
    - `visitCallOp(op)`: **Inline expansion** — find the referenced script's body ops and emit them directly. `CBlock(scriptBody.map { visit(it) })` with a section comment `/* inlined: ${op.scriptId} */`. If the script cannot be found, emit `CRawCode("/* CallOp: script '${op.scriptId}' not found */")`.
    - `visitReturnOp(op)`: `CReturn(null)` — simple early return from inlined script block.
    - `visitArrayAssign(op)`: `CExprStatement(CBinaryExpr(CArrayAccess(CVar(sanitizeVarName(op.arrayName)), ExprVisitor.visit(op.index)), "=", ExprVisitor.visit(op.value)))` (assign to array element).

    **Wait:**
    - `visitWaitFrames(op)`: **State machine pattern** (locked decision — NOT busy-wait):
      ```
      CIf(
        condition = CBinaryExpr(CVar("_wait_counter"), ">", CLiteral(0)),
        thenBody = listOf(
          CExprStatement(CUnaryExpr("--", CVar("_wait_counter"))),
          CReturn(null)
        )
      )
      ```
      Plus: `CExprStatement(CBinaryExpr(CVar("_wait_counter"), "=", ExprVisitor.visit(op.frames)))` at the WaitFrames insertion point to SET the counter.

    **Math:**
    - `visitMathOp(op)`: Based on `op.function`:
      - `MathFunction.ABS`: `CExprStatement(CBinaryExpr(CVar(target), "=", CCall("abs", listOf(ExprVisitor.visit(op.operand)))))`
      - `MathFunction.MIN/MAX/CLAMP`: Emit ternary expressions
      - `MathFunction.RAND`: `CCall("rand", emptyList())` (requires `#include <rand.h>` in includes)
  </action>

    Implement the sound system: ScriptOpVisitor.visitPlaySound() + GBDKPipelineV2 sound driver generation + sound hardware init.

    **ScriptOpVisitor:**
    - `visitPlaySound(op)`: `CExprStatement(CCall("play_sound_${op.soundId}", emptyList()), sourceLocation=op.sourceLocation)`

    **Pipeline additions in GBDKPipelineV2 — `buildSoundFunctions(gameIR)`:**

    Generate a sound driver layer per CONTEXT.md locked decision: "Sound driver layer (not direct register writes) — handles channel allocation and priority for multiple simultaneous sounds."

    **Sound driver architecture (generated inline per game):**

    i. **Generate `sound_driver_state` struct and globals:**
       - `_sound_channels[4]` — tracks which sound is playing on each GB channel (CH1-pulse, CH2-pulse, CH3-wave, CH4-noise)
       - `_sound_priority[4]` — priority level per channel (higher = harder to preempt)
       - `_sound_duration[4]` — remaining frames per channel (0 = free)

    ii. **Generate `sound_driver_update()` function** (called once per frame in main loop):
       - Decrements `_sound_duration[ch]` for each active channel
       - When duration hits 0, marks channel as free (`_sound_channels[ch] = SND_NONE`)
       - HOME-resident (bank 0)

    iii. **Generate `play_sound(UINT8 sound_id, UINT8 channel, UINT8 priority, UINT8 duration)` core driver function:**
       - Checks if `channel` is free OR if incoming `priority >= _sound_priority[channel]`
       - If channel available: writes preset register values, sets `_sound_channels[ch]`, `_sound_priority[ch]`, `_sound_duration[ch]`
       - If channel occupied by higher priority: silently drops the request (no preemption)
       - HOME-resident (bank 0)

    iv. **Generate `play_sound_<id>()` wrapper functions** for each unique sound ID found in PlaySound ops:
       - Collect all PlaySound ops from all scene scripts
       - Look up preset from SoundSystem config in `gameIR.systems`
       - Each wrapper calls `play_sound()` with the correct channel, priority, duration, and register preset data
       - Preset data stored as `const` arrays: `static const UINT8 snd_hit_data[] = {0x16, 0x40, 0xF3, 0x83, 0xC7};` — the driver writes these to the channel's NRx0-NRx4 registers
       - Channel selection per preset type: pulse sounds -> CH1/CH2, noise sounds -> CH4, wave sounds -> CH3
       - Priority assignment: SFX (high) > ambient (medium) > music (low) — ensures collision SFX preempts background audio
       - HOME-resident (bank 0) per pitfall 4 in RESEARCH.md

    v. **Add `sound_driver_update()` call** to `buildMainFunction()` game loop, after scene frame dispatch and before `wait_vbl_done()`

    vi. **Add sound hardware init to `buildMainFunction()`:**
       - Add `NR52_REG = 0x80; NR50_REG = 0x77; NR51_REG = 0xFF;` as CRawCode statements in the main() function before the game loop. These enable the Game Boy's sound hardware. Without this, PlaySound would produce no audio.

    vii. **Add sound function prototypes** to buildHeaderFile().
  </action>
