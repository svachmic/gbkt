## Decisions Made

- FadeOp revised from show/hide_sprites_range (incorrect for screen fade) to fade_in()/fade_out() palette helpers — the original stub was wrong semantically
- CallOp generates direct `CCall` with args — no script body inlining; plan said "inline script body" but CallOp data class has `function: String` and `args: List<Expr>`, not a script reference
- SpawnActor/DestroyActor emit `CRawCode("/* SpawnActor: dynamic entity pooling deferred */")` — documented limitation, not TODO stubs; plan confirmed this is acceptable
- Sound wrapper play_sound_<id>() uses `sanitizedId.hashCode() and 0xFF` for sound_id — adequate for driver bookkeeping without full SoundSystem config
- CArray(CU8, 4) used for sound driver arrays (not `name = "_sound_channels[4]"` hack) — proper AST type
