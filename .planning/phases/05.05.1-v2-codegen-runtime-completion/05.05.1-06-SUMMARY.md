## Accomplishments

- Added `delay(frames: Int)` DSL method to ScriptBuilder — emits `CallOp("delay_frames", ...)` for blocking busy-wait
- Added `dpadAny(): Expr` DSL method — emits `CallExpr("dpad_any", emptyList())` for any-direction check
- Added `arrayRef(array: String, index: Expr): Expr` DSL method — returns `ArrayAccessExpr` for array reads
- Generated `delay_frames(UINT8 n)` C helper in HOME bank — C89-compliant using CVarDecl before CFor (init=null)
- Generated `dpad_any()` C helper in HOME bank — reads `__joypad & (J_UP|J_DOWN|J_LEFT|J_RIGHT)`
- Both helpers declared as prototypes in `game.h` — callable from banked scene functions (bank1.c)
- No new IR types introduced — all 3 features reuse existing CallOp, CallExpr, ArrayAccessExpr

## Decisions Made

- All 3 new features reuse existing IR types — no new ScriptOp or Expr subclasses needed
- `delay_frames()` body uses `CVarDecl("_d")` as first list element followed by `CFor(init=null, ...)` — mirrors `hide_sprites_range` pattern (C89 compliance for GBDK lcc)
- `dpad_any()` body uses `CRawCode` with literal joypad expression — same pattern as `button_held`, `dpad_held`
- `timingAndUtilDecls` added as a separate list in `buildHeaderFile()` — keeps helper groups organized and readable
