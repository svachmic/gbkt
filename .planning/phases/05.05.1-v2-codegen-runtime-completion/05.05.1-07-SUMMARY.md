## Accomplishments

- Added `ArrayDef(name: String, elementType: VarType, size: Int)` data class to `Types.kt`

- **PongV2.kt:** 2 raw() delay loops → `delay(30)` (zero raw() calls remain)

- **ExplorerV2.kt:** dpad raw() → `dpadAny()`; torch raw() → `logicalAnd` + bitwise `and`; delay raw() → `delay(60)`; combat raw() block → sequential print/delay/ifOp/elseOp

- ArrayDef uses emptyList() default on GameIR — zero breaking changes to existing tests and fixtures
- Intermediate brick collision variables (_bc, _brow, _bidx) declared as game-scope u8Var — needed because assign() ops reference them; they become global C vars via pipeline

- ExplorerV2 combat scene uses ifOp/elseOp/delay — replaces monolithic raw() block with clean sequential DSL; Navigator op removed (HP check already done with navigate() after delay)
- BinaryExpr constructor with BinaryOp.SHR used directly — no `shr` infix sugar needed (already exists in ExprBuilder.kt but explicit constructor also valid)
