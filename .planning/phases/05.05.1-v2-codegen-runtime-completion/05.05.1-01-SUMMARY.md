# Phase 05.05.1 Plan 01: Unseal IR Interfaces and Create Visitor Pattern Summary

**ScriptOp/Expr/SystemIR unsealed from sealed to open interfaces with visitor dispatch via accept(), enabling external modules to define their own IR node types**

## Performance

- **Duration:** 5 min
- **Started:** 2026-02-20T12:53:38Z
- **Completed:** 2026-02-20T12:58:38Z
- **Tasks:** 2
- **Files modified:** 10

## Accomplishments
- Converted ScriptOp, Expr, and SystemIR from `sealed interface` to `interface`, removing the Kotlin module constraint that prevented external IR extension
- Created three visitor interfaces (ScriptOpVisitorI with 24 methods, ExprVisitorI with 9 methods, SystemIRVisitorI with 6 methods)
- Added `accept(visitor)` to all 39 IR subtypes (24 ScriptOp + 9 Expr + 6 SystemIR)
- Converted ScriptOpVisitor and ExprVisitor to implement the visitor interfaces — all dispatch now uses `op.accept(this)` instead of `when(op)`
- All existing tests pass unchanged

## Decisions Made
- ScriptOpInterpreter kept as `when` with `else` branches (not converted to visitor) — plan explicitly stated not to convert the interpreter; `else -> throw` is correct for simulation that only handles known concrete subtypes
- IRHierarchyTest helper functions rewritten as visitor objects implementing the new interfaces — this proves the visitor interfaces are usable and the dispatch works correctly end-to-end

## Deviations from Plan

### Auto-fixed Issues

- **Found during:** Task 1 (unsealing IR interfaces)
- **Issue:** `when (op)` in `executeOp` was exhaustive only because ScriptOp was sealed. After unsealing, Kotlin requires an `else` branch.
- **Fix:** Added `else -> throw UnsupportedOperationException("Unknown ScriptOp: ${op::class.simpleName}")` to both `executeOp` and `evaluateExpr`
- **Files modified:** gbkt-core/src/main/kotlin/io/github/gbkt/core/test/ScriptOpInterpreter.kt
- **Verification:** `./gradlew :gbkt-core:compileKotlin` passes

- **Fix:** Converted helpers to use visitor objects implementing ScriptOpVisitorI/ExprVisitorI/SystemIRVisitorI; also updated test names to reflect the visitor pattern
- **Files modified:** gbkt-core/src/test/kotlin/io/github/gbkt/core/ir/v2/IRHierarchyTest.kt
