### Task 1: BgPaletteCShapeTest.kt

**File:** `gbkt-gradle-plugin/src/test/kotlin/io/github/gbkt/gradle/tasks/BgPaletteCShapeTest.kt`

C-shape guard test that locks the emitted `_zone_world1Area1Zone_tileset_palettes` first entry to
`RGB8(8,24,32)` — dark-teal, source PLTE index-0 under `-keep_palette_order`.

The test:
1. Skip-guards on `GbdkToolchain.find/getPng2asset` absent (CI without GBDK — returns silently).
2. Skip-guards on `findPlatformerTemplatePng("world1-tileset.png")` absent (gbkt-examples not in
   checkout — returns silently).
3. Stages the real `world1-tileset.png` into a per-test TempDir.
4. Writes a minimal `game_metadata.json` (one `zoneTilesets` entry: id=`world1Area1Zone`,
   path=`graphics/world1-tileset.png`, mapWidth=60, mapHeight=32, bank=2).
5. Registers and runs `ConvertZoneTilesetsTask.convertZoneTilesets()` via ProjectBuilder.
6. Reads the emitted `_zone_world1Area1Zone_tileset.c`.
7. Parses the `_zone_world1Area1Zone_tileset_palettes[16]` array via Regex (matches the palette
   block body, then extracts all `RGB8(r,g,b)` entries).
8. Asserts the first RGB8 entry is `R=8, G=24, B=32` (dark-teal, PLTE index-0).
