No blocking gaps. The WR-01/02/03/04/05 findings from the code review are quality warnings,
not blockers:

- The polarity WARNING comparator cannot fire a false-negative on `world1-tileset.png` — but
  BG is currently correct and not inverted, so no false alarm is silently suppressed at

  (WR-01/02) documents the correct fix (per-sub-palette ranking).

  discovered by this verification. The phase goal — diagnose + fix both inverted pipelines,
