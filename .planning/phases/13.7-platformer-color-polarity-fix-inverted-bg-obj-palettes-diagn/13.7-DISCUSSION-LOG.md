## Diagnose→fix sequencing

| Option | Description | Selected |

**Notes:** Reinforced by `feedback_dont_pay_to_confirm_obvious` — the diagnostic codegen-read IS the gate; if a pipeline is proven inverted, the fix proceeds directly. No "try cheap fix, let binding gate catch it" plan structure (D-01b).

## Inverted-detection mechanic

| Option | Description | Selected |
|--------|-------------|----------|
| Shared PngUtils, vs source PLTE | One luminance-order comparator in PngUtils; baseline = source PNG's own PLTE ranking; single source for warning + diagnostic + tests; exact reversal predicate deferred to research. | ✓ |
| Vs compiled GBDK reference | Compare emitted bytes against the reference ROM's palette; most authoritative but couples build/tests to the external dir — heavy/brittle. | |
| Vs fixed GB ramp convention | Detect deviation from a canonical ascending/descending ramp; no source-PLTE read but bakes in a convention that may not hold → false warnings. | |

**User's choice:** Shared PngUtils, vs source PLTE
**Notes:** Matches SPEC wording ("inverted vs the source PNG PLTE") and DRY `*Shared` precedent. The external compiled reference is reserved for the human visual sign-off, not the build-time warning. Exact reversal predicate (full-reversal vs negative rank-correlation) → research (D-02c).
