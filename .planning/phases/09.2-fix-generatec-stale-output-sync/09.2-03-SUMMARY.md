````markdown
```bash

if [ "$GATE_CFG" = "false" ] || [ ! -f ".planning/verifier-gates.md" ]; then

1. Read `.planning/verifier-gates.md` — parse gate definitions (initial gate: `rom-build`).

   Parse the trigger-path table using awk:
   ```bash
   GATE_GLOBS=$(awk '/^## Gate: rom-build/{f=1} f && /^\| `[^`]+`/{match($0, /`[^`]+`/); print substr($0, RSTART+1, RLENGTH-2)}' .planning/verifier-gates.md)
   ```

2. Compute the phase's diff path set:
   ```bash
   PHASE_BASE=$(gsd-sdk query phase.base-commit "${phase_number}" 2>/dev/null \
       || git merge-base master HEAD)
   PHASE_FILES=$(git diff --name-only "${PHASE_BASE}..HEAD")
   ```

3. For each gate: glob-match each PHASE_FILE against the gate's path list.
   ```bash
   GATE_FIRED=false
   MATCHED_FILE=""
   while IFS= read -r glob; do
     while IFS= read -r file; do
       if [[ "$file" == $glob ]]; then
         GATE_FIRED=true
         MATCHED_FILE="$file"
         break 2
       fi
     done <<< "$PHASE_FILES"
   done <<< "$GATE_GLOBS"
   ```

4. On match → invoke the gate's smoke command (timeout 600). For `rom-build`:
   ```bash
   if [ "$GATE_FIRED" = "true" ]; then
     echo "build_smoke_gates: rom-build gate fired (matched: $MATCHED_FILE)"
     # Check GBDK availability
     if [ -z "${GBDK_HOME:-}" ] && ! command -v lcc &>/dev/null; then
       SMOKE_OUTCOME="SKIPPED"
       SMOKE_NOTE="ROM-build smoke SKIPPED — GBDK not available on verifier machine; human MUST run :gbkt-examples:simple-physics:buildRom locally before sign-off."
     else
       SMOKE_EXIT=0
       timeout 600 ./gradlew :gbkt-examples:simple-physics:clean :gbkt-examples:simple-physics:buildRom 2>&1
       SMOKE_EXIT=$?
       ROM_FILE="gbkt-examples/simple-physics/build/gbkt/output/simple-physics.gb"
       if [ "$SMOKE_EXIT" -eq 0 ] && [ -s "$ROM_FILE" ]; then
         SMOKE_OUTCOME="PASS"
       else
         SMOKE_OUTCOME="FAIL"
       fi
     fi
   fi
   ```

5. Record outcome:
   - **Exit 0 AND ROM file exists with size > 0** → ✓ PASS row in VERIFICATION.md "Build Smoke Gates" table.
   - **Exit non-zero or ROM file missing** → ✗ BLOCKER row; append to gaps; phase status downgrades to `gaps_found`.
   - **GBDK not available** (`GBDK_HOME` unset or `lcc` missing) → ⊘ SKIPPED row with the verbatim V-04 note text. Append note to the `human_verification` list (caught by the next human-UAT loop). Does NOT downgrade status to `gaps_found`.

   | rom-build | {matched file} modified | ✓ PASS | `./gradlew :gbkt-examples:simple-physics:clean :gbkt-examples:simple-physics:buildRom` exit 0 |
   ```
````
