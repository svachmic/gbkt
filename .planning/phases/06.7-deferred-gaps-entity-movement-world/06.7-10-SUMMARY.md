## Decisions Made

- Tests build `GameIR` directly from data class constructors rather than using the DSL (`game {}` block). This tests the IR layer in isolation and avoids DSL parsing complexity in integration tests.
- `ExplorationSystem` is included in the codegen test `GameIR` because `zone_load` functions with `SWITCH_ROM` are only generated when an `ExplorationSystem` is present — required for zone banking codegen to be exercised.
- The `puzzleObjects` rename is a minimal, non-breaking fix: the field stays `internal` so the extension function in `PuzzleBuilder.kt` can still access it. The behavior is identical — only the name changes.
