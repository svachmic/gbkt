## Decisions Made

- **Codegen in GBDKPipelineV2 instead of GBDKSystemVisitor**: Plan's file list included GBDKPipelineV2 and the existing entity collision codegen is also in the pipeline. Keeps NPC collision codegen consistent with existing patterns.
- **Test split across modules**: Plan specified `gbkt-ir/src/test/...` for all tests, but codegen verification tests need access to `GBDKPipelineV2` from `gbkt-backend-gbdk`. Solution: IR model tests in `gbkt-ir`, codegen output tests in `gbkt-backend-gbdk`. Both test suites pass.
- **Integer PUSH displacement**: `dispA = massB / (massA + massB)` uses integer division — appropriate for Game Boy 8-bit math. Small mass values (1-5) used by game developers to control relative displacement.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] ScriptOpVisitor is a singleton object, not a class**
- **Found during:** Task 2 (codegen implementation)
- **Issue:** Initial code tried to instantiate `ScriptOpVisitor(exprVisitor)` as a constructor call, but `ScriptOpVisitor` is a Kotlin `object` (singleton). Caused compile error.
- **Fix:** Changed to `ScriptOpVisitor.visit(op, exprVisitor)` — calling the static `visit` method with both parameters.
- **Files modified:** `GBDKPipelineV2.kt`
- **Verification:** Backend compiles successfully with `./gradlew :gbkt-backend-gbdk:compileKotlin`
- **Committed in:** 4d99303 (Task 2 commit)

**2. [Rule 1 - Bug] Test 10 logic was incorrect (false negative)**
- **Found during:** Task 2 test verification
- **Issue:** Test `actors without npcCollisionConfig are not involved in NPC collision checks` used `assertFalse(func_exists && actor_var_exists)` — but actor position variables are declared globally for ALL actors (including plain ones), so the assertion always failed.
- **Fix:** Rewrote the test to assert what's actually verifiable: the check function IS generated for actors in groups, and `check_all_npc_collisions` is wired. The implicit exclusion of plain_actor is enforced by the group-actor map building logic (skips actors without npcCollisionConfig).
- **Files modified:** `NpcCollisionCodegenTest.kt`
- **Verification:** All 14 codegen tests pass.
- **Committed in:** 4d99303 (Task 2 commit)
