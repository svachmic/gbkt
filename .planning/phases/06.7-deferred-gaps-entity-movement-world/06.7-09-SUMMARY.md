- Zone tilemap data now auto-allocated across ROM banks starting at bank 2, enabling complex multi-zone games exceeding bank 0 capacity

- `game.h` includes `extern` declarations for banked zone tile arrays so zone_load can reference them

## Decisions Made

- **Bank start = 2**: Bank 0 (HOME) and bank 1 (scenes) are reserved; tilemap banks begin at 2. Hardcoded as algorithm default with potential future CartridgeConfig override noted.
- **Backward compatibility**: When `bankAllocation` is empty (no zones or legacy path), tile arrays stay in HOME bank via `buildZoneData()` — no breaking change.
- **Test placement**: Tests placed in `gbkt-backend-gbdk` (not `gbkt-ir` as plan suggested) because they reference `GBDKPipelineV2` which is in the backend module.
- **SWITCH_ROM(1) for restore**: Scene functions live in bank 1, so restoring to bank 1 after tilemap access is the correct restore behavior.
- **internal visibility**: `allocateZoneBanks()` and `buildTilemapBankFiles()` are `internal` (not `private`) to enable direct testing.
