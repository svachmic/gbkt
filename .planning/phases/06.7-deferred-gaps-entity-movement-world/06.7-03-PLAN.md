         - Nested loop over actors in groupA and groupB
         - AABB overlap check using actor positions and hitboxes (reuse existing AABB pattern from EntityCollisionIR)
         - On collision, dispatch based on response:
           - `OVERLAP` → just run onCollide callback
           - `BLOCK` → stop penetrating actor's movement
           - `BOUNCE` → reverse velocity of colliding actor
           - `PUSH` → displace both actors proportional to inverse mass: `dispA = massB / (massA + massB)`, `dispB = massA / (massA + massB)` (integer math)
       - Interval support: `static UINT8 _interval_counter_{ruleId}` incremented each frame, check only when `counter % interval == 0`

    2. Generate a `check_all_npc_collisions()` master function that calls each rule's check function. Wire this into the frame loop in the pipeline.
