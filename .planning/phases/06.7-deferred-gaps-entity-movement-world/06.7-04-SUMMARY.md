## Decisions Made
- SmoothMovementConfig is a nullable field on MovementConfig rather than a separate IR node — zero breaking changes to any existing code using SMOOTH or GRID movement
- DiagonalMode defaults to RAW — no surprise normalization for developers who don't opt in
- Integer 181/256 approximation for 1/sqrt(2) — standard Game Boy integer math pattern, avoids floating point, matches feel of Zelda-style games
- Friction never overshoots zero (inner clamp after subtraction) — prevents velocity oscillation artifact
- Tests in `gbkt-backend-gbdk` test directory (not `gbkt-ir`) — tests exercise ActorVisitor codegen output which lives in the backend module
