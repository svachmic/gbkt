## Detailed Verification Evidence

### SC1: Pool Codegen — Real, Not Stubs

`GBDKSystemVisitor.buildActorPoolFunctions()` (lines 3964-4250) generates:
- `pool_<id>_init()`: for-loop zeroing the active bitmap
- `pool_<id>_spawn(x, y)`: linear scan + goto label + `move_sprite()` positioning + active bitmap set
- `pool_<id>_destroy(slot)`: 0xFF guard + `i = slot - oam_base` + active bit clear + `move_sprite(slot, 0, 0)` (offscreen)
- `pool_<id>_active_count()`: for-loop counting active bitmap slots

Both overflow strategies produce different C:
- `SILENT_NOOP`: returns `CRawExpr("0xFF")` early
- `RECYCLE_OLDEST`: uses `static UINT8 _pool_<id>_oldest` with modulo wrap

### SC3: NPC Collision — AABB + PUSH

`GBDKPipelineV2.buildNpcCollisionFunctions()` (line 5137) generates:
- Per-rule `check_collision_{groupA}_{groupB}()` with nested actor-pair AABB loop
- PUSH response: mass-proportional displacement using `massB/(massA+massB)` integer math
- `static UINT8` interval counter for per-N-frame checking
- `check_all_npc_collisions()` master dispatcher called from frame loop

### SC7: Puzzle Mechanics — Full Event System

Five sealed puzzle types with:
- Switch: toggleable active state + tile swap + activate/deactivate callbacks
- Door: two-tile open/closed state + requires() gating
- Pressure plate: actor position test loop + step-on/step-off transitions
- Timed block: frame counter + `solidTile`/`emptyTile` swap at `interval` frames
- Generic trigger: 5-event dispatch (`INTERACT`, `STEP_ON`, `STEP_OFF`, `TIMER`, `FLAG_CHANGED`) via C switch-case

`requires()` chaining emits C early-return guards like `if (!_switch_sw1_active) return;`

### SC8: Zone Banking — First-Fit Bin-Packing

`allocateZoneBanks()`:
1. Sorts zones by tile array size (descending)
2. First-fit bin-packing into 16KB banks starting at bank 2
3. Manual `bankOverride` zones bypass capacity check (warning logged)

`buildTilemapBankFiles()` generates `zone_bank2.c`, `zone_bank3.c`, etc. with `#pragma bank N` and tile array definitions. Home bank no longer contains zone tile arrays (backward-compat empty-map path preserved).
