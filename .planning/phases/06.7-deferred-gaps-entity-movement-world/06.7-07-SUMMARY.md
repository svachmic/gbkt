# Phase 06.7 Plan 07: Puzzle Objects — Switches, Doors, Pressure Plates, Timed Blocks

Implemented core puzzle mechanics: switch, door, pressure plate, and timed block world objects with delegate-pattern DSL, event handlers, and GBDK codegen for state tracking and tile interaction.

## What Was Built

### Sealed IR Hierarchy (`PuzzleObjectIR.kt`)

Four concrete puzzle object types, all implementing `PuzzleObjectIR` sealed interface:
- **`SwitchObjectIR`** — toggleable switch with `onActivate`/`onDeactivate` ScriptOps
- **`DoorObjectIR`** — door with `openTile`/`closedTile` tile indices and `onOpen`/`onClose` callbacks
- **`PressurePlateObjectIR`** — position-sensing plate with `respondToActorIds` and `onStepOn`/`onStepOff`
- **`TimedBlockObjectIR`** — frame-timer-driven block alternating between `solidTile` and `emptyTile`

All types share: `id`, `x`, `y`, `hidden`, `handlers` (generic `PuzzleEventHandler` list).

### Four New ScriptOps

Added to `ScriptOp.kt` and `ScriptOpVisitorI.kt`:
- `ActivatePuzzleObject(objectId)` — activate a puzzle object (opens doors, toggles switches on)
- `DeactivatePuzzleObject(objectId)` — deactivate a puzzle object (closes doors, toggles switches off)
- `RevealPuzzleObject(objectId)` — make hidden object visible
- `HidePuzzleObject(objectId)` — hide an object

### DSL Delegates (`PuzzleBuilder.kt`)

Four delegate classes with ID inference via `provideDelegate`:

```kotlin
val sw1 by switch(x = 5, y = 3) {
    onActivate { openDoor(bossDoor) }
    onDeactivate { closeDoor(bossDoor) }
}
val bossDoor by door(x = 10, y = 5) {
    openTile(0x20)
    closedTile(0x21)
}
val entryPlate by pressurePlate(x = 7, y = 4) {
    respondTo(player)
    onStepOn { openDoor(exitDoor) }
}
val timerBlock by timedBlock(x = 12, y = 6) {
    solidTile(0x15); emptyTile(0x00); interval(60)
}
```

All references are type-safe `PuzzleObjectRef` — no magic strings.

### GBDK Codegen (`GBDKSystemVisitor.buildPuzzleObjectFunctions`)

Per object type, generates:

| Type | State Variables | Functions |
|------|-----------------|-----------|
| Switch | `UINT8 _switch_{id}_active = 0` | `puzzle_activate_{id}()`, `puzzle_deactivate_{id}()`, reveal/hide |
| Door | `UINT8 _door_{id}_open = 0` | `puzzle_activate_{id}()` (tile swap to openTile), `puzzle_deactivate_{id}()` (tile swap to closedTile), reveal/hide |
| Pressure plate | `UINT8 _plate_{id}_pressed = 0` | `puzzle_check_plate_{id}()` (actor position check), reveal/hide |
| Timed block | `UINT16 _timedblock_{id}_timer = 0`, `UINT8 _timedblock_{id}_solid = 1` | `puzzle_update_timedblock_{id}()` (timer + tile swap on interval), reveal/hide |

The `puzzle_update_all()` function aggregates all pressure plate checks and timed block updates. It is called every frame in the main game loop when `gameIR.puzzleObjects` is non-empty.

### Pipeline Wiring (`GBDKPipelineV2`)

- Puzzle state variables added to `allVariablesWithCollision` in `buildHomeFile`
- Puzzle functions added to the `functions` list in `buildHomeFile`
- `puzzle_update_all()` called in `buildMainFunction`'s game loop body
