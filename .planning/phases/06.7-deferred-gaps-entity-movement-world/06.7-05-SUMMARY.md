## Decisions Made

- Coyote time counter management emits only the decrement; game logic (on_ground tracking) is responsible for resetting counter to COYOTE_N frames when on ground
- Wall contact flag uses 0=none/1=left/2=right encoding for direction-aware wall-jump kick direction
- Platformer mode gates UP/DOWN d-pad input from being used as acceleration — jump is handled by J_A button, not d-pad direction
- All new PhysicsConfig fields default to disabled (false/0) for full backward compatibility
