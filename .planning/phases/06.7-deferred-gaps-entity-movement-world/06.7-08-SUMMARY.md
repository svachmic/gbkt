## Decisions Made

- **TriggerObjectIR as fifth sealed subtype**: All logic lives in handlers; no built-in behavior. Generic trigger covers any custom puzzle behavior beyond Switch/Door/PressurePlate/TimedBlock.
- **requires() uses PuzzleObjectRef not strings**: Type-safe API prevents ID typos; IDs stored internally as strings for codegen.
- **pool: prefix convention**: Avoids adding a new field type to PressurePlateObjectIR; "pool:bullets" in respondToActorIds resolved to `pool_bullets_any_at(x, y)` in codegen.
- **buildRequiresGuard() exhaustive when**: Maps sealed type to correct state variable (switch→`_active`, door→`_open`, plate→`_pressed`, block→`_solid`). TriggerObjectIR and null return null (triggers have no single active state variable).
- **CSwitchCase requires CExpr?**: Fixed `CSwitchCase(value = CLiteral(eventType.ordinal))` — compiler rejected bare Int.
