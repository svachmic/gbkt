## Decisions Made
- `FixedPointMode.INTEGER` is the default for both `PhysicsConfig` and `SmoothMovementConfig` — existing games and actors are unchanged with no code modifications
- `FP44` uses `UINT8`/`INT8` for position/velocity accumulators — compact 8-bit footprint appropriate for Game Boy's 8KB RAM constraint
- `FP88` uses `UINT16`/`INT16` for 256 sub-pixels/pixel — higher precision for gravity accumulation in platformers
- `FixedPointTest.kt` placed in `gbkt-backend-gbdk/src/test` (not `gbkt-ir/src/test` as listed in plan frontmatter) — tests exercise `ActorVisitor` codegen which lives in the backend module
- Two-stage accumulation pattern: `vx_frac += vx` then `x_frac += vx_frac` — allows gravity to accumulate sub-pixel acceleration before affecting integer position
