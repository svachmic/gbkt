## Test Infrastructure

| Property | Value |
|----------|-------|

| **Quick run command** | `./gradlew :gbkt-backend-gbdk:test --tests "*Seed*Test"` |
| **Full suite command** | `./gradlew test :gbkt-examples:metasprites:buildRom :gbkt-examples:metasprites-stress:buildRom` |

---

## Sampling Rate

- **After every task commit:** Run `./gradlew :gbkt-backend-gbdk:test --tests "*Seed*Test"` for the defect just touched
- **After every plan wave:** Run full backend-gbdk test suite + relevant ROM build
- **Before `/gsd:verify-work`:** Both ROMs (`metasprites` + `metasprites-stress`) must `:buildRom` clean (D-21 ROM-build smoke test gate)
- **Max feedback latency:** ~60 seconds for single-defect JVM test, ~150 seconds for full ROM + test suite
