**`buildSceneFile()` now scans scene frameOps for `MoveMetasprite` and conditionally adds `<gbdk/metasprites.h>` to bank1.c — Route A from SEED-009, closing Phase 11 (banks port) prerequisite CR-02.**

## Accomplishments

- Closed CR-02 / SEED-009: any non-HOME bank file produced by `buildSceneFile()` now includes `<gbdk/metasprites.h>` IFF a scene in `gameIR.scenes` has a `MoveMetasprite` op in `frameOps`. Phase 11's banks port (where multi-scene games stop fitting into the HOME fast-path and scene frames land in `bank1.c`) can now consume metasprite ops without SDCC failing on unresolved `move_metasprite_*` inline references.
- Added `Seed009BankIncludeTest` (2 tests) as the regression guard:
  - Test 1 (positive): asserts bank1.c contains `#include <gbdk/metasprites.h>` when a 2-scene game's `play` scene has `MoveMetasprite("elephant")` in `frameOps`. RED pre-fix, GREEN post-fix.
  - Test 2 (negative): asserts bank1.c does NOT contain the include when no scene uses metasprites — locks the conditional-include policy against a future regression that makes the include unconditional.
- Pitfall 2 (RESEARCH lines 919-927) mitigated: the test escapes `BankingAnalysisPass`'s single-scene HOME fast-path via 2 scenes (per the dual-guard `game.scenes.size == 1 && codeUnits.size == 1` introduced in 09.1-06), and `assertNotNull(bank1)` runs before each include check so a fast-path collapse manifests as a clear setup error instead of silently asserting against main.c.

## Decisions Made

- **Route A over Route B (per-bank scan vs unconditional include).** Mirrors `cgbInclude` for `<gb/cgb.h>`, keeps per-bank include policy declarative, costs zero bytes for non-metasprite games, and the negative regression test guards against the policy being silently inverted.
- **2-scene test shape (not 3+, not via `BankingConfig` override).** The dual-guard `game.scenes.size == 1 && codeUnits.size == 1` (09.1-06) is escaped by the simplest valid 2-scene construction; the zero-op `title` stub is enough because the static `scenes.size` check counts authored scenes, not surviving codeUnits.
- **Assertion ordering: `assertNotNull(bank1)` BEFORE `assertTrue(bank1.contains(...))`.** Pitfall 2 mitigation — distinguishes "test setup failed to escape the fast-path" (loud error) from "codegen bug present" (the assertion under test).
