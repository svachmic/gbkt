## Issues Encountered

- **png2asset stem-name derivation surprise.** First isolation experiment named output files A_ref.c, B_port.c, etc. — png2asset auto-derives the tile-array name from the OUTPUT-FILE STEM, not the input PNG stem. So the array was named `A_ref_tiles` (not `elephant_tiles`). Caught immediately when ugrep failed to find `elephant_tiles\[` and had to broaden the regex to `[a-z_]+_tiles`. No fix needed — the count and size still answer the experimental question.
- **ugrep `head -3` interaction.** Initial 4-variant printer with `head -3 "$f"` + ugrep's parallel-file behavior surfaced only the first file in some runs. Switched to `/usr/bin/grep` for the 4-variant table to get deterministic per-file output. Notional bug; sidestepped without investigation.
