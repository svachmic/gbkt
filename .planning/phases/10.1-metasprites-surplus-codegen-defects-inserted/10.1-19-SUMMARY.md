# Phase 10.1 Plan 19: D-V3 Visual GBC Palette Diagnostic — Summary

**Diagnosed the named root cause of DEF-10.1-13-C ("GBC screenshot completely black"):**
GBDKPipelineV2.buildMainFunction() bootstrap-order mismatch — four
`set_sprite_palette()` calls are deferred to `play_enter()` (called AFTER
`DISPLAY_ON`) instead of emitted in `main()` BEFORE `DISPLAY_ON` as the reference
does. First PPU frame composites with uninitialized OCPD palette RAM (all-zero →
all-black sprite render on GBC). Three of the four hypotheses listed in
`deferred-items.md` for DEF-10.1-13-C are FALSIFIED by codegen-level evidence;
only the fourth ("some other GBC bootstrap missing") survives, and the "other"
is now precisely named as **bootstrap ORDER**, not bootstrap PRESENCE.
