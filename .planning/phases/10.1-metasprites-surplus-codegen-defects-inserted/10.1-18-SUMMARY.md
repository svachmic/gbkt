# Phase 10.1 Plan 18: Close DEF-10.1-13-B via 4-row-period checker literal swap Summary

Swapped `MetaspriteBuilder.bgFillCheckerboard()`'s 16-byte BG tile literal from a 2-row-period shape (renders 4w×2h rectangles) to a 4-row-period shape (renders true 4×4-pixel squares), per Plan 10.1-17's named root cause.

## What Changed

### `MetaspriteBuilder.bgFillCheckerboard()` literal swap

**Before** (Plan 10.1-02 shape, DEF-10.1-13-B):
```c
static const UINT8 _checkerboard_bg_pattern[] = {
    0xF0,0xF0,0xF0,0xF0,0x0F,0x0F,0x0F,0x0F,
    0xF0,0xF0,0xF0,0xF0,0x0F,0x0F,0x0F,0x0F};
```
Alternation period = 2 tile rows ⇒ per-tile cells of 4 pixels wide × 2 pixels tall ⇒ user-visible **rectangles**.

**After** (Plan 10.1-18 fix):
```c
static const UINT8 _checkerboard_bg_pattern[] = {
    0xF0,0xF0,0xF0,0xF0,0xF0,0xF0,0xF0,0xF0,
    0x0F,0x0F,0x0F,0x0F,0x0F,0x0F,0x0F,0x0F};
```
Alternation period = 4 tile rows ⇒ per-tile cells of 4 pixels wide × 4 pixels tall ⇒ true **4×4 squares**.

Added an in-source comment above the literal explaining the per-row 2-byte stride trap that misled Plan 10.1-02 (mental model conflated "8-byte row group" with "1 pixel row" — actually 2 pixel rows because each row consumes plane0+plane1).

### Test updates

- **`Seed005CheckerboardBytePatternTest.kt`** — renamed the positive test to `pattern_contains_8_consecutive_0xF0_then_8_consecutive_0x0F`. New assertion locks the corrected 16-byte literal as a single normalized substring (1 occurrence in normalized code). Added a new `pattern_does_not_contain_2_row_period_substring` negative guard against the exact Plan 10.1-02 wrong shape. Kept the diagonal-stripe negative guard (D-V2 v1 regression).
- **`BgCheckerboardEmissionTest.kt` TEST 3** — positive assertions now lock BOTH halves of the corrected literal at file scope in `bank1.c` (top 8× 0xF0 + bottom 8× 0x0F). Added the same 2-row-period negative regression guard. Kept the diagonal-stripe guard.
- **`DV2BgAspectDiagnosticTest.kt`** — NOT MODIFIED. This test was authored in Plan 10.1-17 as a structural-invariant lock that asserts the corrected shape; it flips RED → GREEN automatically with the literal swap. Three assertions: (1) corrected 16-byte literal substring present, (2) wrong 2-row-period substring absent, (3) F0 and 0F byte counts both = 8.
