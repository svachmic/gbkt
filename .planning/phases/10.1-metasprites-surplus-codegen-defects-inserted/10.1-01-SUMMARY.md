# Phase 10.1 Plan 01: GameBuilder Actor Palette Slot Auto-Allocation Fix Summary

GameBuilder.kt actor-palette injection now allocates sequential GBC sprite-palette slot
indices for auto-slotted (slot=-1) palette overrides via a running counter, closing
SEED-007 / D-extra and mirroring the already-merged SceneBuilder.palette() fix from
Phase 10 Plan 16 (commit 2e8fb256).

## What Changed

**Bug site (pre-fix, GameBuilder.kt:710-716):**

```kotlin
val actorPaletteOps =
    actors.mapNotNull { actor ->
        actor.palette?.let { pal ->
            val slot = if (pal.slot >= 0) pal.slot else 0   // ← BUG: all collapse to 0
            SetPalette(pal.name, slot, PaletteType.SPRITE)
        }
    }
```

**Fixed shape (post-fix, GameBuilder.kt:721-728):**

```kotlin
var actorPaletteAutoSlot = 0
val actorPaletteOps =
    actors.mapNotNull { actor ->
        actor.palette?.let { pal ->
            val slot = if (pal.slot >= 0) pal.slot else actorPaletteAutoSlot++
            SetPalette(pal.name, slot, PaletteType.SPRITE)
        }
    }
```

The change is a single-line replacement (`else 0` → `else actorPaletteAutoSlot++`) plus
a one-line `var` declaration, with explanatory comments cross-referencing the
SceneBuilder precedent and recording why `mapIndexedNotNull` (the seed's first proposal)
was rejected.
