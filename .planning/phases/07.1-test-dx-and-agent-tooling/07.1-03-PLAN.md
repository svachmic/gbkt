    **GbktTestRecipes.kt** (`io.github.gbkt.test`):
    Extension functions on `GbktTestExtension` that use metadata-driven logic:

    1. `fun GbktTestExtension.verifyTitleScreen(expectedTexts: List<String> = emptyList())`:
       - Step 120 frames (boot). Assert scene is the first scene in metadata (convention: index 0 or scene named matching common title patterns like "title", "main_menu").
       - If `expectedTexts` provided, assert each text is on screen.
       - Returns the observation after boot.

    2. `fun GbktTestExtension.verifyAllSceneTransitions()`:
       - Reads transitions from metadata (once enriched metadata is available, falls back to scene list).
       - For each transition, navigates to the `from` scene and verifies the agent can reach the `to` scene within 300 frames of pressing the trigger button (START for title transitions, any available button).
       - This is a best-effort metadata-driven check; complex games may skip transitions that require multi-step navigation.

    3. `fun GbktTestExtension.verifyInputResponds(scene: String, button: Button, variableName: String, expectDecrease: Boolean = false)`:
       - Navigate to scene (use bootToScene or manual step). Hold button for 30 frames. Read variable before and after. Assert value changed in expected direction.

    4. `fun GbktTestExtension.verifySpriteVisibility(scene: String, expectedActors: List<String>)`:
       - Navigate to scene. Step 10 frames. For each expected actor name, assert it appears in observation.actors.

    5. `fun GbktTestExtension.bootToScene(sceneName: String, maxFrames: Int = 600)`:
       - If custom `bootScript` was provided in constructor, execute it.
       - Otherwise: step 120 frames (boot), then use `agent.waitForScene(sceneName, maxFrames)`.
       - If scene not reached, attempt pressing START (common title->gameplay transition) and wait again.
       - Returns observation at target scene or throws AssertionError.

    **GbktGameReporter.kt** (`io.github.gbkt.test`):
    A simple utility class (not a JUnit5 extension) that can be called at end of test class to print summary:
    ```kotlin
    class GbktGameReporter(private val gameName: String) {
        private val scenesVerified = mutableSetOf<String>()
        private var assertionsPassed = 0
        private var assertionsFailed = 0
        private var screenshotsCaptured = 0

        fun recordScene(scene: String) { scenesVerified.add(scene) }
        fun recordPass() { assertionsPassed++ }
        fun recordFail() { assertionsFailed++ }
        fun recordScreenshot() { screenshotsCaptured++ }

        fun printSummary() {
            println("=== $gameName Test Summary ===")
            println("  Scenes verified: ${scenesVerified.joinToString(", ").ifEmpty { "none" }}")
            println("  Assertions: $assertionsPassed passed, $assertionsFailed failed")
            println("  Screenshots: $screenshotsCaptured captured")
            println("==============================")
        }
    }
    ```
