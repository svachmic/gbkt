  <action>
    Add the following methods to `McpEmulatorSession`:

    1. **`fun startByName(gameName: String, gbcMode: Boolean = false): JsonObject`**:
       - Uses `GameDiscovery.configForGame(gameName)` to resolve ROM/sym/metadata paths.
       - If config is null, returns error JSON `{"error": "Game '$gameName' not found — run buildRom first"}`.
       - Otherwise delegates to existing `start(config.romFile, config.symFile, config.metadataFile, gbcMode)`.

    2. **`fun saveState(label: String): JsonObject`**:
       - Requires active session (check `agent != null`, return error if not).
       - Create savestate directory: `File("build/gbkt/savestates")`.
       - Save file: `File(savestateDir, "$label.gbst")`.
       - Call `SavestateManager.save(agent.emulator, saveFile)`.
       - Return `{"label": "$label", "frame": currentFrame, "scene": currentScene, "file": saveFile.absolutePath}`.

    3. **`fun loadState(label: String): JsonObject`**:
       - Requires active session.
       - Load file: `File("build/gbkt/savestates/$label.gbst")`.
       - If file doesn't exist, return error `{"error": "Savestate '$label' not found"}`.
       - Call `SavestateManager.load(agent.emulator, loadFile)`.
       - Step one frame to refresh observation.
       - Return `{"restored": true, "label": "$label", "frame": currentFrame, "scene": currentScene}`.

    4. **`fun batchAssert(checks: List<AssertCheck>): JsonObject`**:
       - Data class: `data class AssertCheck(val type: String, val args: Map<String, Any>)`.
       - Supported types:
         - `"variable_equals"`: args `name`, `expected` -> checks `agent.readVariable(name) == expected`
         - `"variable_in_range"`: args `name`, `min`, `max` -> checks value in range
         - `"scene_is"`: args `scene` -> checks current observation scene
         - `"text_on_screen"`: args `text` -> checks bgText/winText via `VramTextVerifier`
         - `"actor_visible"`: args `name` -> checks actor in observation
         - `"sprite_count"`: args `expected` -> checks observation sprite count
       - Returns `{"passed": N, "failed": M, "results": [{type, args, passed, actual}]}`.

    5. **`fun getPlaybook(): JsonObject`**:
       - Requires active session.
       - Look for PLAYBOOK.md relative to the ROM file: if ROM is at `gbkt-examples/pong/build/gbkt/output/pong.gb`, look at `gbkt-examples/pong/PLAYBOOK.md`.
       - Also check project root `PLAYBOOK.md` for standalone projects.
       - If found, return `{"content": fileContent, "path": filePath}`.
       - If not found, return `{"content": null, "message": "No PLAYBOOK.md found for this game"}`.

    6. **`fun listGames(): JsonObject`**:
       - Does NOT require active session.
       - Call `GameDiscovery.scanForBuiltRoms()`.
       - Return `{"games": [{"name": "pong", "romFile": "...", "hasMetadata": true}, ...]}`.

    Add `gbkt-test` as a dependency to `gbkt-mcp-server/build.gradle.kts` for `GameDiscovery` access. Add `implementation(project(":gbkt-test"))`.
