## What Was Built

**Task 1 - GBDKPipelineV2 enrichment:**

- `extractControls(game: GameIR): Map<String, List<ControlMapping>>` — recursive depth-first walk of all scene scripts (enter/frame/exit). For each `IfOp` whose condition is a `CallExpr` with function in `{dpad_held, dpad_pressed, button_held, button_pressed}`, maps GBDK constants (J_UP → "UP", J_START → "START", etc.) to ControlMapping objects with button name and interaction type.
- `extractTransitions(game: GameIR): List<SceneTransition>` — recursive walk finding all `NavigateTo` ops in scene scripts, deduplicates (from, to) pairs.
- `inferVariableSemantic(name: String): String` — top-level internal function applying ordered heuristics: state > position > velocity > score > stat > flag > counter > unknown. Case-insensitive matching.
- `buildMetadataFile()` extended: variables array now includes `"semantic"` field; new `"controls"` and `"transitions"` JSON sections added.

**Task 2 - GenerateGameConstantsTask extension:**

- Reads `json.optJSONObject("controls")`: for each scene key, iterates mappings, generates `{SCENE}_{BUTTON}` constants (e.g., `GAME_UP = "UP"`).
- Reads `json.optJSONArray("transitions")`: generates `{FROM}_TO_{TO}` constants with `"from->to"` values (e.g., `TITLE_TO_GAME = "title->game"`).
- Both use `toConstantName()` for identifier generation and `resolveCollisions()` for deduplication.
- New `object Controls` and `object Transitions` blocks emitted after `object Texts`.

**1. [Rule 1 - Bug] Flag heuristic had substring false-positive for "met"**
- **Found during:** Task 1 GREEN phase
- **Issue:** `lower.contains("met")` matched "frametimer" ("fra**met**imer") before the "counter" rule. Similarly, `has_` with underscore didn't match camelCase "hasKey".
- **Fix:** Changed to `startsWith("met") || contains("_met")` and `startsWith("has") || contains("_has")` for word-boundary-aware matching.
- **Files modified:** GBDKPipelineV2.kt (inferVariableSemantic function)
