  <action>
    Extend `GBDKPipelineV2.buildMetadataFile(game: GameIR)` to emit three new JSON sections in the metadata output:

    1. **Controls extraction**: Add a private function `extractControls(game: GameIR): Map<String, List<ControlMapping>>` that walks each `SceneIR.frameScript` recursively (depth-first into `IfOp.body` and `IfOp.elseBody`). For each `IfOp` whose `condition` is a `CallExpr` with function name in `setOf("dpad_held", "dpad_pressed", "button_held", "button_pressed")`, extract the button from `args[0]` (a `VarRef` with name like `J_UP`). Map GBDK constants to human-readable names: `J_UP`->"UP", `J_DOWN`->"DOWN", `J_LEFT`->"LEFT", `J_RIGHT`->"RIGHT", `J_A`->"A", `J_B`->"B", `J_START`->"START", `J_SELECT`->"SELECT". The type is derived from the function name: `dpad_held`/`button_held`->"held", `dpad_pressed`/`button_pressed`->"pressed". Also check `enter` and `exit` scripts. Emit as JSON:
    ```json
    "controls": {
      "game": [{"button": "UP", "type": "held"}, {"button": "DOWN", "type": "held"}],
      "title": [{"button": "START", "type": "pressed"}]
    }
    ```

    2. **Transitions extraction**: Add a private function `extractTransitions(game: GameIR): List<TransitionEdge>` that walks each scene's `frameScript`, `enterScript`, and `exitScript` recursively. For each `NavigateTo` op found, record `TransitionEdge(from = sceneName, to = navigateTo.sceneId)`. Deduplicate edges. Emit as JSON:
    ```json
    "transitions": [
      {"from": "title", "to": "game"},
      {"from": "game", "to": "gameover"}
    ]
    ```

    3. **Variable semantics**: Add a top-level internal function `inferVariableSemantic(name: String): String` that applies ordered heuristics (most-specific first):
    - Exact match: `name == "current_scene"` -> "state"
    - Suffix: `_x`, `_y` -> "position"
    - Contains: `dx`, `dy`, `vel`, `speed` -> "velocity"
    - Contains: `score`, `point` -> "score"
    - Contains: `hp`, `health`, `mp`, `sp` -> "stat"
    - Contains: `flag`, `met`, `has_`, `is_` -> "flag"
    - Contains: `step`, `count`, `frame`, `timer` -> "counter"
    - Else: "unknown"

    In the existing variables JSON array, add a `"semantic"` field to each variable object.

    Data classes for intermediate representation:
    ```kotlin
    private data class ControlMapping(val button: String, val type: String)
    private data class TransitionEdge(val from: String, val to: String)
    ```

    Write tests in `MetadataEnrichmentTest.kt` using synthetic `GameIR` instances (follow existing `MetadataFileTest.kt` patterns).
