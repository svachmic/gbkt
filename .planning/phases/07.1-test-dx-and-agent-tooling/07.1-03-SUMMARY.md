# Phase 07.1 Plan 03: Test Recipes, Reporter, and Migration Summary

Test recipes implemented and all 9 example StepAgentTests migrated to GbktTestExtension, eliminating 50+ lines of boilerplate per test class.

## What Was Built

### Task 1: Test Recipes and Game Reporter

**GbktTestRecipes.kt** — 5 composable extension functions on `GbktTestExtension`:

- `verifyTitleScreen(expectedTexts)` — boots 120 frames, asserts title/initial scene, checks expected text strings
- `verifyAllSceneTransitions()` — best-effort START-press transition check for non-title scenes from metadata
- `verifyInputResponds(scene, button, variableName, expectDecrease)` — holds button 30 frames, asserts variable changed
- `verifySpriteVisibility(scene, expectedActors)` — navigates to scene, asserts each actor visible
- `bootToScene(sceneName, maxFrames)` — navigates to scene via waitForScene + START fallback

All recipes use metadata when available, falling back to heuristics when not. Zero coupling to any specific game.

**GbktGameReporter.kt** — per-game test summary utility:

```kotlin
class GbktGameReporter(gameName: String) {
    fun recordScene(scene: String)
    fun recordPass()
    fun recordFail()
    fun recordScreenshot()
    fun printSummary()  // prints === gameName Test Summary === block
}
```

**1. [Rule 2 - Missing Feature] Added gbcMode parameter to GbktTestExtension**
- **Found during:** Task 2, PlatformerGbc migration
- **Issue:** PlatformerGbc requires `gbcMode=true` in `AgentSessionConfig` but GbktTestExtension had no way to pass this flag, forcing tests to use raw `StepAgent` directly (violating acceptance criteria)
- **Fix:** Added `gbcMode: Boolean = false` parameter to `GbktTestExtension`; `resolveConfig()` now does `base.copy(gbcMode = true)` when enabled
- **Files modified:** `gbkt-test/src/main/kotlin/io/github/gbkt/test/GbktTestExtension.kt`
