## Decisions Made
- Playbooks live in the game project root as source files (not `build/`) so developers can edit and version-control them — mirrors how README.md files work
- GeneratePlaybookTask never overwrites an existing PLAYBOOK.md; the `!output.exists()` guard preserves human-authored content
- Controls table in generated skeleton sorts by scene name for stable, reproducible output across Gradle incremental builds
- Playbooks are written in natural language for LLM agents — they describe mechanics and intentions, not deterministic test scripts
