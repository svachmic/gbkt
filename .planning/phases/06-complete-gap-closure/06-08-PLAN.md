    2. Walk all ScriptOps recursively (IfOp body, WhileOp body, ForOp body, FadeOp body, etc.).
    3. For each BinaryExpr, check for power-of-2 constant patterns and rewrite:
       - `BinaryExpr(left, MUL, Literal(n))` where n is power of 2 → `BinaryExpr(left, SHL, Literal(log2(n)))`
       - `BinaryExpr(left, DIV, Literal(n))` where n is power of 2 → `BinaryExpr(left, SHR, Literal(log2(n)))`
       - `BinaryExpr(left, MOD, Literal(n))` where n is power of 2 → `BinaryExpr(left, AND, Literal(n-1))`
    4. Only apply to unsigned types (per CONTEXT.md — unsigned integer types only). If type information is not available at IR level, apply unconditionally but document the unsigned assumption.
    5. Emit INFO diagnostic for each rewrite: "Optimized x*N to x<<M (power-of-2 constant)".
    6. Helper: `isPow2(n: Int) = n > 0 && (n and (n - 1)) == 0` and `log2(n: Int) = Integer.numberOfTrailingZeros(n)`.
    7. Wire into DefaultPipeline: insert after ConstantFoldingPass and before BankingAnalysisPass.

    **F2 — BudgetReporter polish:**
    8. Read current BudgetReporter implementation.
    9. Add ANSI escape codes:
       - Green (under 75%): `\u001B[32m`
       - Yellow (75-90%): `\u001B[33m`
       - Red (over 90%): `\u001B[31m`
       - Reset: `\u001B[0m`
    10. Replace current `#`/`.` bars with percentage bars: `[====----] 50%`
    11. Add per-scene breakdown section after bank usage:
        - List each scene with its estimated ROM size, assigned bank, and bank fill contribution
    12. Add overall ROM size estimate at top of report.
    13. Add an `ansiEnabled: Boolean = true` parameter to `formatReport()` to allow disabling ANSI for file output.

    **Tests:**
    14. Test BitwiseOptimizationPass: `x * 4` → `x << 2`, `x / 8` → `x >> 3`, `x % 16` → `x & 15`.
    15. Test BudgetReporter: verify ANSI codes appear in output, verify bar format.
