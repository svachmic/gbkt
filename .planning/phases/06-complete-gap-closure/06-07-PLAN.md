    1. Add `CastExpr` data class implementing Expr:
       ```kotlin
       data class CastExpr(
           val targetType: VarType,
           val inner: Expr,
           override val sourceLocation: SourceLocation? = null
       ) : Expr {
           override fun <T> accept(v: ExprVisitorI<T>): T = v.visitCast(this)
       }
       ```
    2. Add `visitCast(expr: CastExpr): T` to `ExprVisitorI` interface.
    3. In ExprVisitor, implement visitCast to generate `CCast(targetCType, visitedInner)`:

    4. Add extension methods on Expr, AssignableVar, ActorPropertyRef:
       ```kotlin
       fun Expr.toU8(): Expr = ExprWrapper(CastExpr(VarType.U8, this.ir))
       fun Expr.toU16(): Expr = ExprWrapper(CastExpr(VarType.U16, this.ir))
       fun Expr.toI8(): Expr = ExprWrapper(CastExpr(VarType.I8, this.ir))
       fun Expr.toI16(): Expr = ExprWrapper(CastExpr(VarType.I16, this.ir))
       ```
       Add same extensions on AssignableVar and ActorPropertyRef (converting to Expr first).
    5. Update ScriptOpInterpreter to handle CastExpr (truncate/sign-extend as appropriate for the target type).
