    5. Create `GBDKCollectionCodegen` class implementing `CollectionCodegen` interface.

    7. Implement all 8 methods:

       - `generatePoolData(IRCollPool)` → `UINT8 _pool_<name>[N * elemSize]; UINT8 _pool_<name>_bitmap[ceil(N/8)];`
       - `generatePoolFunctions(IRCollPool)` → `pool_<name>_alloc`, `pool_<name>_free`
       - `generateRingBufferData(IRCollRingBuffer)` → data array + head/tail/count
       - `generateRingBufferFunctions(IRCollRingBuffer)` → push/pop/peek

       - `generateFixedSlotsFunctions(IRCollFixedSlots)` → claim/release/isActive
    8. Wire GBDKCollectionCodegen into GBDKPipelineV2: call collection data generation after variable declarations and collection function generation alongside system functions.
