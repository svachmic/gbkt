    **C1 — GBDKSystemVisitor:**
    NOTE: `SystemIRVisitorI` is a v2 interface located at `gbkt-ir/src/main/kotlin/io/github/gbkt/core/ir/v2/SystemIRVisitorI.kt` (after Plan 02 promotion: `gbkt-ir/.../ir/SystemIRVisitorI.kt`). It was NOT affected by Plan 01's v1 deletion. The interface has 6 visit methods: visitDialogSystem, visitSoundSystem, visitSaveSystem, visitExplorationSystem, visitCameraSystem, visitGenericSystem.

    1. Create `GBDKSystemVisitor.kt` implementing `SystemIRVisitorI<List<CFunction>>`:
       - `visitCameraSystem(CameraSystem)`: Generate `_camera_x`, `_camera_y` UINT8 globals and `update_camera()` function that reads target actor position and sets `scroll_x/scroll_y` via SCX_REG/SCY_REG.
       - `visitSaveSystem(SaveSystem)`: Generate `save_game()` function writing variables to SRAM (0xA000 region via ENABLE_RAM/DISABLE_RAM macros) and `load_game()` reading them back.
       - `visitSoundSystem(SoundSystem)`: Return empty list (sound driver handled by Plan 04's buildSoundFunctions). This avoids duplication.
       - `visitExplorationSystem(ExplorationSystem)`: Generate exploration state globals (`_player_x`, `_player_y`, `_current_floor`), `exploration_move()` function with grid movement and encounter check callback.
       - `visitDialogSystem(DialogSystem)`: Delegate to existing `buildDialogHelpers()` already in GBDKPipelineV2 (return the existing dialog functions).
       - `visitGenericSystem(GenericSystem)`: Delegate to existing `buildSystemTriggerFunction()`.

    2. Wire into `buildSystemFunctions()`:
       Replace:
       ```kotlin
       return gameIR.systems.filterIsInstance<GenericSystem>().map { buildSystemTriggerFunction(it) }
       ```
       With:
       ```kotlin
       val visitor = GBDKSystemVisitor(gameIR)
       return gameIR.systems.flatMap { system -> system.accept(visitor) }
       ```
