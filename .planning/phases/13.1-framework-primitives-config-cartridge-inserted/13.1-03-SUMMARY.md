# Phase 13.1 Plan 03: Wave 1 Cartridge Enum + Serializer Summary

**One-liner:** Typed `Cartridge` enum (7 entries, MBC hardware bytes 0x00–0x1B) added to gbkt-ir, `CartridgeConfig` retyped to `Cartridge` + nullable `romBanks`, and `GameIRSerializer` updated to serialize by `.name` with absent-key sentinel for null `romBanks`.

## What Was Built

Wave 1 of Phase 13.1 — the IR foundation layer. Two production files were modified and three existing test files were auto-fixed for compilation correctness.

### Task 1: Cartridge enum + CartridgeConfig retype (Types.kt)

- File: `gbkt-ir/src/main/kotlin/io/github/gbkt/core/ir/Types.kt`
- Commit: `7982eef9`
- Added `enum class Cartridge(val mbcByte: Int)` immediately after `GbcTarget`, with 7 entries in D-01 order: ROM_ONLY(0x00), MBC1(0x01), MBC1_RAM(0x02), MBC1_RAM_BATTERY(0x03), MBC3_TIMER_BATTERY(0x10), MBC5(0x19), MBC5_RAM_BATTERY(0x1B)
- Changed `CartridgeConfig.cartridge: String = "ROM_ONLY"` to `cartridge: Cartridge = Cartridge.ROM_ONLY`
- Changed `CartridgeConfig.romBanks: Int = 2` to `romBanks: Int? = null` (D-05 derive sentinel)
- CartridgeEnumTest turns GREEN (11/11 test methods pass)

### Task 2: GameIRSerializer name<->enum + nullable romBanks (GameIRSerializer.kt)

- File: `gbkt-ir/src/main/kotlin/io/github/gbkt/core/ir/GameIRSerializer.kt`
- Commit: `4b7c3a1a`
- `serializeCartridgeConfig`: changed `.put("cartridge", config.cartridge)` to `.put("cartridge", config.cartridge.name)` — mirrors GbcTarget .name pattern
- `serializeCartridgeConfig`: absent-key sentinel `config.romBanks?.let { put("romBanks", it) }` (key omitted when null)
- `deserializeCartridgeConfig`: changed `cartridge = json.optString(...)` to `cartridge = Cartridge.valueOf(json.optString("cartridge", "ROM_ONLY"))` — mirrors GbcTarget.valueOf pattern
- `deserializeCartridgeConfig`: changed `romBanks = json.optInt("romBanks", 2)` to `romBanks = if (json.has("romBanks")) json.getInt("romBanks") else null` — absent key → null; explicit value → that value (Pitfall 3 guard)
- GameIRSerializerTest remains GREEN (full round-trip preserved)
