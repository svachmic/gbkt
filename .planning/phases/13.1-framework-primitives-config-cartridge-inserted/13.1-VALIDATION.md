---

## Sampling Rate

- **After every task commit:** Run `./gradlew :gbkt-ir:test :gbkt-lang:test :gbkt-analysis:test :gbkt-backend-gbdk:test`
- **After every plan wave:** Run `./gradlew test` (full JVM suite, including all example IR tests)
- **Before `/gsd-verify-work`:** Full suite GREEN **and** the 7-ROM regression smoke sweep EXIT 0 with same-or-smaller `.gb` byte sizes
- **Max feedback latency:** quick suite < ~60s
