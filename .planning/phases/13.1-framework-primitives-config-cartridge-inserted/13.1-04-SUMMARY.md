# Phase 13.1 Plan 04: Wave 2 DSL Surface Summary

**One-liner:** ConfigBuilder.cartridge(Cartridge) typed method, SaveDataDelegate with name-inference, triggerSystem(SystemRef) hard-replace, and registerSaveData() wired — ConfigBuilderCartridgeTest (6/6) and SaveDataDelegateTest (5/5) GREEN.

## What Was Built

Wave 2 of Phase 13.1 — the gbkt-lang DSL surface layer.

### Task 1: ConfigBuilder.cartridge() method + nullable romBanks (D-02/D-05)

- File: `gbkt-lang/src/main/kotlin/io/github/gbkt/core/dsl/SystemBuilders.kt`
- Commit: `8420a54e`
- Changed `ConfigBuilder.cartridge` from `String = "ROM_ONLY"` to `Cartridge = Cartridge.ROM_ONLY`
- Changed `ConfigBuilder.romBanks` from `Int = 2` to `Int? = null` (D-05 derive sentinel)
- Added `fun cartridge(type: Cartridge) { this.cartridge = type }` immediately adjacent to `target(GbcTarget)`, mirroring its exact shape (D-02)
- Added `SystemRef` interface, `SaveDataRef` data class, `SaveDataDelegate` class, and top-level `saveData()` factory (D-08/D-09) in the same file
- `ConfigBuilderCartridgeTest` turns GREEN (6/6 test methods pass)

### Task 2: SaveDataDelegate + SystemRef + SaveDataRef + saveData() factory (D-08/D-10)

Included in commit `8420a54e` (atomically required with Task 1 changes to SystemBuilders.kt).

- `interface SystemRef { val systemId: String }` — marker interface for typed system references
- `data class SaveDataRef(val id: String) : SystemRef { override val systemId get() = id }` — typed reference returned by the delegate
- `class SaveDataDelegate` — mirrors `MetaspriteDelegate.provideDelegate` pattern: reads `property.name`, accesses `GameBuilderContext.current`, builds `SaveDataBuilder(name)`, calls `gameBuilder.registerSaveData(system)`, sets ref
- `fun saveData(block: SaveDataBuilder.() -> Unit): SaveDataDelegate` — top-level factory, no String id param (name comes from property)

### Task 3: triggerSystem(SystemRef) hard-replace + GameBuilder.registerSaveData (D-10/D-11)

- Files: `ScriptBuilder.kt` (commit `527cdd79`), `GameBuilder.kt` (same commit)
- Replaced `fun triggerSystem(systemId: String, ...)` with `fun triggerSystem(ref: SystemRef, args: ...)` — resolves `ref.systemId` at DSL recording time, passes String to `TriggerSystem` IR node (node unchanged)
- Added `internal fun registerSaveData(system: SaveSystem)` mirroring `registerSystem()` — registers to refRegistry and adds to systems list
- Deleted public `fun saveData(id: String, block: SaveDataBuilder.() -> Unit)` (D-11 hard-replace)
- `SaveDataDelegateTest` turns GREEN (5/5 test methods pass)
