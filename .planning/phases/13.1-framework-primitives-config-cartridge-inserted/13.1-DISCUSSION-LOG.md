## Cartridge API shape (Req #1)

### Form
| Option | Description | Selected |
|--------|-------------|----------|
| Flat enum | `enum class Cartridge { ROM_ONLY … MBC5_RAM_BATTERY }`, 1:1 with the 7-entry map | ✓ |
| Composed builder | `cartridge { mbc5(); ram(); battery() }` — expressive but admits illegal combos | |
| Enum + ram/battery flags | Base MBC enum + `.withRam()`/`.withBattery()` modifiers | |

### Assignment
| Option | Description | Selected |
|--------|-------------|----------|
| Method, mirror `target()` | `cartridge(Cartridge.MBC5_RAM_BATTERY)` — matches existing `target(GbcTarget)` | ✓ |
| Field assignment | `cartridge = Cartridge.X` — minimal diff but splits the ConfigBuilder style | |
| Both (field + method) | Expose both like GbcTarget does today | |

### MBC byte location
| Option | Description | Selected |
|--------|-------------|----------|
| Enum owns the byte | Each value carries `mbcByte`; delete `CARTRIDGE_MBC_MAP`; single source of truth | ✓ |
| Gradle map keyed by enum | Keep map in GenerateCTask, key by enum name | |

**User's choice:** Flat enum + method assignment + enum owns the byte.
**Notes:** Verified the gradle plugin reads config reflectively (`getCartridge().toString()` → local map). "Enum owns the byte" is feasible by exposing a reflective byte accessor or resolving in the IR serializer (CONTEXT D-04). No re-decision needed.

## Auto-sized banks (Req #11)

### romBanks default
| Option | Description | Selected |
|--------|-------------|----------|
| Derive, allow override | Omit → derived from BankingAnalysisPass; explicit `romBanks = N` overrides | ✓ |
| Fully automatic, no override | Always derived, remove the knob — conflicts with principle #5 | |

### Override conflict (explicit value too low)
| Option | Description | Selected |
|--------|-------------|----------|
| Warn + auto-upgrade | Use derived count, log warning (matches cartridge auto-upgrade precedent) | |
| Hard compile error | Fail with actionable message (principle #2) | ✓ |
| Respect user value | Honor even if too small (current footgun) | |

### ramBanks single source of truth
| Option | Description | Selected |
|--------|-------------|----------|
| DSL `config { }` | Propagate to `gbkt-build.properties`; deprecate gradle extension | ✓ |
| Gradle extension | Keep in build.gradle.kts, remove from DSL | |

**User's choice:** Derive+override, hard error on undersize, DSL is the single ramBanks source.
**Notes:** Hard error is deliberately stricter than the existing cartridge auto-upgrade. The override can only raise the count, never undersize.
