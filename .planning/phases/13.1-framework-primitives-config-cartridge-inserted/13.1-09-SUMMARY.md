### Task 1: DSL_REFERENCE.md updated

Added a new **"Game Configuration"** section (inserted before "Save System DSL") containing:

**Cartridge type subsection (Req #1):**
- `cartridge(Cartridge.MBC5_RAM_BATTERY)` worked example
- 7-entry table: `ROM_ONLY (0x00)`, `MBC1 (0x01)`, `MBC1_RAM (0x02)`, `MBC1_RAM_BATTERY (0x03)`, `MBC3_TIMER_BATTERY (0x10)`, `MBC5 (0x19)`, `MBC5_RAM_BATTERY (0x1B)`
- Note that the enum owns the MBC hardware byte (D-01/D-03)

**ROM Banking subsection (Req #11):**
- Omit `romBanks` → auto-derived from `BankingAnalysisPass` (D-05)
- Explicit override allowed but must be >= derived count (D-05 advanced control)
- Undersized override → hard build error with actionable message, exact format documented (D-06)
- `ramBanks` lives only in DSL `config { }` — Gradle `gbkt { ramBanks }` extension deprecated (D-07)

**Full config + saveData + triggerSystem worked example (Req #16):**
```kotlin
config {
    cartridge(Cartridge.MBC5_RAM_BATTERY)
    ramBanks = 2
    target(GbcTarget.GBC_COMPATIBLE)
    // romBanks omitted — auto-derived by BankingAnalysisPass
}
@Suppress("UNUSED_VARIABLE") val saves by saveData { slots(2) }

scene("gameplay") {
    every.frame {
        whenever(buttons.select.pressed) { triggerSystem(saves) }
    }
}
```

- Existing "Save Data Fields" content preserved under its own subsection
