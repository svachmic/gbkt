## Decisions Made
- `PickupTypes.kt` lives in `gbkt-engine` (not `gbkt-core`) — shared cross-genre engine constructs belong in the engine module, not the sealed-interface IR module
- Genre-specific conversion extensions (`CollectibleDef.toPickupDef()`, `SportPickupDef.toPickupDef()`) live in each genre module's codegen package — `gbkt-engine` must not depend on genre modules
- Timed effect arrays and `pickup_update` only emitted when any pickup has `effectType="timed"` — keeps generated C minimal
- Respawn arrays and `pickup_respawn_check` only emitted when any pickup has `respawnFrames > 0` — same conditional codegen pattern
