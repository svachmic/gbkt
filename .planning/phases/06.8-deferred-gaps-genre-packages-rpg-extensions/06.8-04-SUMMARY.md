## Decisions Made
- Stamina reuses ExplorationGaugeIR(id='stamina') — StaminaGaugeConfig is a thin bridge; codegen references _gauge_stamina global from exploration gauge codegen, per CONTEXT.md locked decision
- BehaviorPresetType (CHASE, PATROL, ATTACK_WHEN_CLOSE, FLEE) chosen over full BehaviorTree for ARPG behavior — simpler, composable preset list dispatched in a single ai_update function
- ATB var decls emit _atb_gauge_0..3 for all 4 party slots when ATB config present
- ai_update function only emitted when behaviorPresets list is non-empty (zero overhead)
