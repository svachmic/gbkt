## Decisions Made
- `PuzzleVisitor` lives in `gbkt-genre-puzzle` — genre modules own their codegen, ServiceLoader handles runtime discovery without compile-time coupling
- Undo depth capped at 16 in `PuzzleVisitor` (`coerceAtMost(16)`) — WRAM safety guard without requiring developer to set `undoDepth()` explicitly
- Custom cell type IDs start at 10 — reserves 0=NORMAL, 1=EMPTY, 2=WALL for base types
- Gravity swap uses `CRawCode` escape hatch for multi-step temp-var operation — avoids nested `CBlock` complexity in typed AST
