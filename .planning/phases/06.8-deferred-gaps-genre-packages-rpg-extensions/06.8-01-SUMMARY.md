## Decisions Made
- Used `List<Any>` return types in `GenreVisitorResult` rather than a separate `CodeFragment` abstraction to avoid premature over-engineering; genre implementations that target GBDK cast at their call site since they already depend on gbkt-backend-gbdk
- `ServiceLoader.load()` is hoisted above the loop in both methods to load genre visitors once per invocation
- Module rename is Gradle-level only; Kotlin package paths `io.github.gbkt.rpg.*` remain unchanged
