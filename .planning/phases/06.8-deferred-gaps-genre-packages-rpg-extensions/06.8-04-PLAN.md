    **CRITICAL (CONTEXT.md locked decision):** Stamina/energy system MUST reuse existing exploration gauge infrastructure. The `ExplorationGaugeIR` type in `gbkt-ir/src/main/kotlin/io/github/gbkt/core/ir/WorldIR.kt` already models resource gauges with max, initial, decrementPerStep, onLow/onDepleted callbacks. The Action RPG stamina should configure an `ExplorationGaugeIR` instance rather than creating a standalone StaminaConfig.

    **1. Action RPG Domain (`ActionRpgDef.kt`):**
    ```kotlin
    enum class CombatModel { REALTIME_COOLDOWN, HYBRID_ATB }

    data class ActionRpgConfig(
        val model: CombatModel = CombatModel.REALTIME_COOLDOWN,
        val dodgeRoll: DodgeRollConfig? = null,
        val staminaGauge: StaminaGaugeConfig? = null,
        val atb: AtbConfig? = null,
        val behaviorPresets: List<BehaviorPreset> = emptyList(),
    )

    data class DodgeRollConfig(
        val iFrameDuration: Int = 8,
        val cooldownFrames: Int = 16,
    )

    /**
     * Stamina configuration that bridges to the exploration gauge infrastructure.
     * At codegen time, this is converted to an ExplorationGaugeIR with id="stamina",
     * reusing the existing gauge codegen (decrement, onLow, onDepleted callbacks).
     * The attackCost/dodgeCost are ARPG-specific additions that emit stamina deduction
     * calls in the combat codegen functions.
     */
    data class StaminaGaugeConfig(
        val maxStamina: Int = 100,
        val regenRate: Int = 1,
        val attackCost: Int = 20,
        val dodgeCost: Int = 30,
    )

    data class AtbConfig(
        val maxGauge: Int = 100,
        val baseSpeed: Int = 1,
    )

    data class BehaviorPreset(
        val type: BehaviorPresetType,
        val range: Int = 0,
        val threshold: Int = 0,
        val path: List<Pair<Int, Int>> = emptyList(),
    )

    enum class BehaviorPresetType { CHASE, PATROL, ATTACK_WHEN_CLOSE, FLEE }
    ```

    **1. Add ARPG codegen to `RpgVisitor.kt`:**

    `generateActionRpgFunctions(system: GenericSystem): List<CFunction>`:
    - Parse ActionRpgConfig from system.config
    - Emit `arpg_update()` frame function: handles cooldown timers, ATB gauge fill
    - Emit `arpg_dodge_roll()` if dodgeRoll config present: sets i-frame counter
    - Emit `arpg_attack(target_id)` with cooldown check
    - If stamina configured: convert StaminaGaugeConfig to ExplorationGaugeIR (id="stamina", max=maxStamina, decrementPerStep=0 since ARPG stamina is action-based not step-based). The gauge codegen from `GBDKSystemVisitor` handles the gauge global vars. ARPG codegen adds stamina deduction calls (`_gauge_stamina -= attackCost` in arpg_attack, `_gauge_stamina -= dodgeCost` in arpg_dodge_roll) and regen (`_gauge_stamina += regenRate` in arpg_update, clamped to max).
    - Emit ATB functions if atb config present: `atb_check_ready(char_id)`
    - Emit behavior AI functions: `ai_update(entity_id)` dispatches on behavior preset type

    `generateActionRpgVarDecls(system: GenericSystem): List<CVarDecl>`:
    - `_arpg_cooldown_timer` (UINT8)
    - `_arpg_iframes_remaining` (UINT8)
    - ATB gauges per party slot if ATB mode
    - Note: stamina gauge var decls are handled by existing exploration gauge codegen

    **2. Wire into `GBDKSystemVisitor.visitGenericSystem()`:**
    Add: `"arpg_combat" -> RpgVisitor(gameIR).generateActionRpgFunctions(system)`

    **3. Wire var decls in `GBDKPipelineV2.buildSystemGlobalVars()`.**

    **4. Add codegen tests in `RpgCodegenTest.kt`:**

    - Stamina: codegen references gauge infrastructure vars (e.g. `_gauge_stamina`)
    - Behavior AI: `ai_update` function dispatches on preset types
