- GenericSystem config map pattern used consistently — `type=roguelike_system, config=RoguelikeConfig`
- Conditional function generation: `roguelike_daily_seed()` only when `dailyChallenge.enabled == true`, `roguelike_check_room_clear()` only when `roomClearGating == true`

- `roguelike_daily_seed()` uses `rtc_get_date()` for hardware RTC date computation — standard GBDK RTC integration pattern
