## Decisions Made
- Test cast pattern `assertIs<GenericSystem>()` required before accessing `.config[]` — `SystemIR` sealed interface exposes only `id`, not `config`, which lives on `GenericSystem` specifically
- `VehicleDef` created as a top-level data class (not inlined in RacingConfig) to carry `id + name + stats` triplet, matching the `CharacterDef` pattern from RPG module
- `GoalConfig` extracted as separate data class to allow focused `goal { width(); height() }` DSL block in FieldDefBuilder
- `SportPickupDef` placed in `SportTypes.kt` (not in racing or ball sport files) since both sub-genres share it

## Deviations from Plan

None - plan executed exactly as written.

## Issues Encountered
- Initial test run failed due to Kotlin type system: `assertNotNull(system)` alone does not narrow `SystemIR?` to `GenericSystem`, so `system!!.config[...]` would not compile. Fixed by adding `assertIs<GenericSystem>(rawSystem)` before config access.
