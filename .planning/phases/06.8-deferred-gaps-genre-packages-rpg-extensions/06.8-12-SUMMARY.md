## Decisions Made
- SportVisitor lives in `gbkt-genre-sport` (not `gbkt-backend-gbdk`) — genre codegen belongs in the genre module for self-contained packages
- Pickup delegation uses synthetic `GenericSystem` with `type="pickup_system"` + `GBDKSystemVisitor.accept()` — avoids accessing private `buildPickupFunctions` while reusing all pickup logic
- `buildPickupVarDecls` called directly (public method) for var decl generation alongside function delegation
- Rubber-band speed adjustment uses `coerceIn(0, 255)` to prevent UINT8 overflow in generated C
