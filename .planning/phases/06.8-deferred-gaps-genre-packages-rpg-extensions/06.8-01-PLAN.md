    ```kotlin
    interface GenreSystemVisitor {
        /** Check if this visitor handles the given system type string (from GenericSystem.config["type"]). */
        fun canHandle(systemType: String): Boolean

        /** Generate C functions for a genre-specific system. Returns empty list if not applicable. */
        fun generateFunctions(system: GenericSystem, gameIR: GameIR): List<CFunction>

    }
    ```

    The interface needs to import: `io.github.gbkt.core.ir.GenericSystem`, `io.github.gbkt.core.ir.GameIR`, and the C AST types `CFunction`, `CVarDecl` from `io.github.gbkt.backend.gbdk.codegen.ast`.

    IMPORTANT: Since `gbkt-backend-api` currently does NOT depend on `gbkt-backend-gbdk` (and shouldn't), the return types need to be generic. Use `Any` for the return type list, OR define a lightweight `GenreVisitorResult` data class in `gbkt-backend-api`:

    ```kotlin
    data class GenreVisitorResult(
        val functions: List<Any> = emptyList(),  // CFunction instances at runtime
        val varDecls: List<Any> = emptyList(),   // CVarDecl instances at runtime
    )

    interface GenreSystemVisitor {
        fun canHandle(systemType: String): Boolean
        fun visit(systemType: String, systemConfig: Map<String, Any>, gameConfig: Any): GenreVisitorResult
    }
    ```

    Actually, check the dependency graph. `gbkt-backend-api` depends on `gbkt-core` only (which has `GameIR`, `GenericSystem`). C AST types (`CFunction`, `CVarDecl`) live in `gbkt-backend-gbdk`. So the interface MUST use `Any` or a result type without C AST imports.

    The cleanest approach: define the interface with `Any` return type in backend-api, and genre modules cast at their end since they depend on gbdk. The pipeline in GBDKPipelineV2 casts the result back to C AST types.

    2. Modify `GBDKPipelineV2.buildSystemFunctions()` (line ~2025-2042) to discover `GenreSystemVisitor` implementations before falling through to `GBDKSystemVisitor`:

    ```kotlin
    private fun buildSystemFunctions(
        gameIR: GameIR,
        bankAllocation: Map<String, Int> = emptyMap(),
    ): List<CFunction> {
        val genreVisitors = ServiceLoader.load(GenreSystemVisitor::class.java).toList()
        val visitor = GBDKSystemVisitor(gameIR, bankAllocation)
        return gameIR.systems.flatMap { system ->
            val systemType = (system as? GenericSystem)?.config?.get("type") as? String
            val genreVisitor = if (systemType != null) {
                genreVisitors.find { it.canHandle(systemType) }
            } else null
            if (genreVisitor != null && system is GenericSystem) {
                @Suppress("UNCHECKED_CAST")
                val result = genreVisitor.visit(systemType!!, system.config, gameIR)
                result.functions as List<CFunction>
            } else {
                system.accept(visitor)
            }
        }
    }
    ```
