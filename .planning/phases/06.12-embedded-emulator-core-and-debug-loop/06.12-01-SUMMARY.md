## Decisions Made
- `gbkt-emulator` has no dependency on any `gbkt-*` library modules — source map integration happens at the Gradle plugin level, keeping the emulator module clean and independently deployable
- `getMemory()` returns `MemoryAccess` interface (not raw byte array) to encapsulate MMU behavior — bank switching and I/O register side-effects apply on reads/writes
- `DebugLogEntry.timestampMs` tracks emulated Game Boy time (4.194 MHz clock derived), not wall clock, enabling deterministic replay
- `maxLogEntries = 10_000` default prevents OOM during long debug sessions (circular buffer eviction)
