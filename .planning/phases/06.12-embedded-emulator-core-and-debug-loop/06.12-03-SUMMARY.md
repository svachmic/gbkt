## Accomplishments

- Implemented `EmuPrintfInterceptor` with full 4-byte signature verification (0x52, 0x18, offset, 0x64, 0x64)
- Wired interceptor into CoffeeGbEmulator's Coffee-GB tick listener — fires after each micro-op
- 14 unit tests covering: valid detection, 6 false-positive rejection cases, deduplication (5 ticks = 1 fire), multi-PC independence, readCString null termination, readCString 256-char cap
- Interceptor creates `DebugLogEntry(level=GAME)` and routes to `addDebugEntry()` with emulated timestamp

## Decisions Made

- `check()` takes `Registers` and `AddressSpace` separately (not `Cpu` or `Gameboy`) so unit tests can instantiate `Registers()` directly without starting an emulator
- `readCString` is `fun` (public) for direct unit testing
- `EmuPrintfInterceptor` created inside `start()`, not as a class field — clean lifecycle, one interceptor per emulator run
- PC+2 (relative jump offset) is deliberately ignored — any offset value is valid in the EMU_printf sequence
