# Phase 06.12 Plan 10: Gradle Plugin Emulator Integration Summary

**One-liner:** Embedded Coffee-GB emulator wired into all Gradle tasks — RunEmulatorTask, EmulatorTestTask, DebugEmulatorTask rewired from external mGBA/SameBoy to in-process EmulatorSession/CoffeeGbEmulator; `./gradlew run` lifecycle task added.

## What Was Built

### Task 1: gbkt-emulator dependency and RunEmulatorTask rewrite

1. **gbkt-emulator publishing** — Added `id("gbkt.publishing")` to `gbkt-emulator/build.gradle.kts`. Published to mavenLocal via `./gradlew :gbkt-emulator:publishToMavenLocal`.

2. **Gradle plugin dependency** — Added `implementation("io.github.gbkt:gbkt-emulator:$gbktVersion-SNAPSHOT")` to `gbkt-gradle-plugin/build.gradle.kts`.

3. **EmulatorExtension simplified** — Replaced old `path/args/liveReload/liveReloadScript` properties with embedded-first API:
   - `scale: Property<Int>` — display scale factor (default 4)
   - `headless: Property<Boolean>` — headless mode flag (default false)
   - `maxFrames: Property<Int>` — test frame count (default 600)
   - `externalEmulator: Property<String>` — optional external emulator path override

4. **RunEmulatorTask rewritten** — Uses `EmulatorSession(config).launch()` for embedded emulator. Falls back to `ProcessBuilder(externalPath, rom)` when `externalEmulator` is set.

### Task 2: EmulatorTestTask, DebugEmulatorTask, and `run` task

5. **EmulatorTestTask rewritten** — Uses `CoffeeGbEmulator(config)` in headless mode. Pattern: `start() → pause() → repeat(frames) { stepFrame() } → stop()`. Checks for `LogLevel.ERROR` entries and fails the build if any exist. No external emulator required.

6. **DebugEmulatorTask rewritten** — Uses `EmulatorSession(config).launch()` with `sourceMapsDir` and `logFile` configured. Opens full debug tooling (LogCat window, Memory Inspector). Replaced ~200 lines of mGBA/GDB/Lua scripting with ~30 lines of embedded API calls.

7. **`run` lifecycle task** — Registered in `GbktPlugin.registerTasks()`. `dependsOn(buildRom)` + `finalizedBy("runEmulator")`. Enables `./gradlew run` as the single dev loop command.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] stepFrame() requires pause() before use**
- **Found during:** Task 2 — reading CoffeeGbEmulator source
- **Issue:** `stepFrame()` has `check(paused)` guard that throws if emulator is not paused. Plan showed `start()` followed directly by `stepFrame()` without pausing first.
- **Fix:** Added `emulator.pause()` between `emulator.start()` and the `repeat(frames) { emulator.stepFrame() }` loop.
- **Files modified:** `EmulatorTestTask.kt`
- **Commit:** 91a5e84

**2. [Rule 2 - Missing functionality] ValidateRomTask needed externalEmulator wiring**
- **Found during:** Task 1 — GbktPlugin references `extension.emulator.path` for ValidateRomTask
- **Issue:** ValidateRomTask still uses mGBA for Lua scripting; removing `path` property without updating the registration would break existing users who configure an external mGBA path.
- **Fix:** Wired `extension.emulator.externalEmulator` to `ValidateRomTask.emulatorPath` to preserve the escape hatch.
- **Files modified:** `GbktPlugin.kt`
- **Commit:** ab66b0b

**3. [Rule 2 - Missing functionality] runWatch task referenced removed liveReload property**
- **Found during:** Task 1 — updating GbktPlugin defaults
- **Issue:** `runWatch` doLast block referenced `extension.emulator.liveReload.getOrElse(true)` which no longer exists.
- **Fix:** Rewrote runWatch task to print embedded emulator launch message without liveReload logic.
- **Files modified:** `GbktPlugin.kt`
- **Commit:** ab66b0b
