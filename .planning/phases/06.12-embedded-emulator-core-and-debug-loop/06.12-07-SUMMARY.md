## What Was Built

### LogCatPanel (JPanel)

Terminal-styled debug log viewer panel with:

- **Dark background**: `Color(30, 30, 30)` background, `Color(220, 220, 220)` foreground
- **Monospace font**: `Font.MONOSPACED, Font.PLAIN, 12`
- **Auto-scroll**: `textArea.caretPosition = textArea.document.length` after each append
- **No line wrap**: horizontal scrollbar allows reading long lines
- **Filter dropdown**: JComboBox with ALL, GAME, EMU, WARN, ERROR options
- **Filter logic**: `currentFilter = null` (ALL) or specific `LogLevel`; `refreshDisplay()` rebuilds view
- **Clear button**: clears `entries` list and `textArea.text`
- **Count label**: shows visible/total entries (e.g., "3 / 10 entries")
- **Level prefix tags** (7-char padded):
  - `[GAME] ` — game DSL output
  - ` [EMU] ` — emulator internals
  - `[WARN] ` — non-fatal anomalies
  - ` [ERR] ` — fatal errors
- **Thread safety**: `appendEntry()` uses `SwingUtilities.invokeLater`; entries list mutated only on EDT
- **Entry retention**: entries added while a filter is active are stored and appear when switching to ALL

### LogCatWindow (JFrame)

Convenience wrapper with `HIDE_ON_CLOSE` — preserves log history across visibility toggles. Ready to be shown/hidden from an emulator toolbar Log button via `logWindow.isVisible = !logWindow.isVisible`.

### Tests (LogCatPanelTest, 17 test cases)

- Entry accumulation: single, multiple, all levels
- Filtering: each of 5 filter values (ALL, GAME, EMU, WARN, ERROR)
- Filter interaction: narrow then restore, entries added while filtered
- Clear: removes entries, empty display, clear-then-append
- Formatted output: level prefix, timestamp, source location, context, message
- Full line regression: `[GAME] [00:00.000] Test.kt:42 (gameplay/frame) > Hello`
- Auto-scroll: caret at document end
- visibleEntryCount: total and filtered counts
