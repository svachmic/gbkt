Create `EmuPrintfInterceptor` class:

```kotlin
class EmuPrintfInterceptor(
    private val onMessage: (String) -> Unit
) {
    private var lastInterceptedPc: Int = -1  // Prevent duplicate firing

    /**
     * Called after each CPU tick. Checks if the current instruction is an EMU_printf trap.
     *
     * @param opcode The opcode byte at the current PC
     * @param pc The current program counter value
     * @param addressSpace Memory access for reading signature bytes and format string
     * @param cpuRegisters Access to HL register for format string address
     */
    fun check(opcode: Int, pc: Int, addressSpace: AddressSpace, cpuRegisters: /* Cpu or Registers type */) {
        // 1. Quick reject: only opcode 0x52 (ld d,d) is interesting
        if (opcode != 0x52) return

        // 2. Prevent duplicate detection (same PC = same instruction)
        if (pc == lastInterceptedPc) return

        // 3. Verify full signature: PC+1 must be 0x18 (JR), PC+3 and PC+4 must be 0x64
        val byte1 = addressSpace.getByte(pc + 1) and 0xFF
        if (byte1 != 0x18) return

        val byte3 = addressSpace.getByte(pc + 3) and 0xFF
        val byte4 = addressSpace.getByte(pc + 4) and 0xFF
        if (byte3 != 0x64 || byte4 != 0x64) return

        // 4. Valid EMU_printf trap detected!
        lastInterceptedPc = pc

        // 5. Read format string from HL register (GBDK convention)
        val hlAddress = getHLValue(cpuRegisters)
        val message = readCString(addressSpace, hlAddress)

        // 6. Route to callback
        onMessage(message)
    }

    /**
     * Reads a null-terminated C string from emulator memory.
     * Safety: caps at 256 chars to prevent runaway reads.
     */
    private fun readCString(addressSpace: AddressSpace, startAddress: Int): String {
        val sb = StringBuilder()
        var addr = startAddress
        val maxLen = 256
        while (sb.length < maxLen) {
            val byte = addressSpace.getByte(addr) and 0xFF
            if (byte == 0) break
            sb.append(byte.toChar())
            addr++
        }
        return sb.toString()
    }
}
```

IMPORTANT: Coffee-GB's CPU register access API needs investigation at implementation time. The `Cpu` class likely has `getRegisters()` returning a `Registers` object. Check if HL is accessible via `registers.getHL()` or by combining `registers.getH()` and `registers.getL()`.

IMPORTANT: The `check()` method signature must match what CoffeeGbEmulator can provide. After `gameboy.tick()`, read the CPU state. If Coffee-GB doesn't expose the current opcode directly, read it from memory at the PC address: `addressSpace.getByte(cpu.getRegisters().getPC())`.

The interceptor must be stateful to avoid duplicate detection (same instruction fires multiple times due to micro-op model). Use `lastInterceptedPc` to deduplicate.
