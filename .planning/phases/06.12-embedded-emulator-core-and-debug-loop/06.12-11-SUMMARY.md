## Decisions Made

- ROM boot integration test uses `Assumptions.assumeTrue(romFile.exists())` so the test is silently skipped in CI environments where Pong ROM has not been built. The test is tagged `@Tag("integration")` for optional explicit inclusion.
- The `stepFrame()` test includes `emulator.pause()` before the frame loop — this mirrors the fix discovered in Plan 10 where `CoffeeGbEmulator.stepFrame()` has a `check(paused)` guard.
- gbkt-emulator receives a dedicated BOM constraints entry (not folded into gbkt-all's constraint) to allow consumers who want only the emulator without the full stack to depend on it with version coordination.

## Deviations from Plan

None - plan executed exactly as written.

The only minor adaptation: the ROM boot test checks `assertFalse(emulator.isRunning().not())` for the paused state (since `isRunning()` tracks the thread running state, and the emulator thread is still alive when paused). The plan's assertion `assertTrue(emulator.isRunning())` would also have worked since the emulator is not stopped. The final assertion `assertFalse(emulator.isRunning())` after `stop()` is as specified.
