## Decisions Made

- **Internal enrichment not duplicated:** `CoffeeGbEmulator.addDebugEntry()` already enriches entries with source map data and writes to the log file. `EmulatorSession.onDebugEntry` only forwards the enriched entry to the UI panel — no duplication of enrichment logic.
- **Toolbar callback override:** `EmulatorWindow` constructor sets placeholder `onLogViewerToggle` and `onMemoryInspectorToggle` callbacks. `EmulatorSession` overwrites them after construction with real window show/hide behavior.
- **MemoryInspectorWindow safe lambda:** The memory provider lambda returns `null` when the emulator is stopped to prevent `IllegalStateException` from propagating into the inspector panel during refresh.
