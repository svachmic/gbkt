GBDK METASPRITE_DEF shape (from `<gbdk/metasprites.h>`):
```c
typedef struct {
    int8_t dy, dx;
    uint8_t dtile;
} metasprite_t;
#define metasprite_end { 0x80, 0x80, 0x00 }
```

Generated descriptor shape (from reference png2asset output):
```c
const metasprite_t sprite_metasprite_0[] = {
    {0, 0, 0}, {0, 8, 1}, {8, 0, 2}, ..., {metasprite_end}
};
const metasprite_t sprite_metasprite_1[] = {
    ...
};
const metasprite_t* const sprite_metasprites[] = {
    sprite_metasprite_0,
    sprite_metasprite_1,
    ...
};
```

Recommended signature:
```kotlin
fun generateMetaspriteDescriptor(metasprite: MetaspriteIR): CRawCode
```

Use `CRawCode(stringOfCDeclarations)` since CCall/CExprStatement do not support struct-literal initializer lists.

Naming: per-frame array `sprite_metasprite_${i}` (or `_${id}_metasprite_${i}` if multiple metasprites needed in future); pointer table `sprite_metasprites` (or `_${id}_metasprites`). For Phase 10 there is one metasprite — use the simpler `sprite_metasprite_N` / `sprite_metasprites` names matching the reference.
