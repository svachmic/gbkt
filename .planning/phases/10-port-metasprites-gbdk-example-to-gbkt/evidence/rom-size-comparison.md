## Analysis of deltas

**l__CODE +383 bytes (+10.9%):**

The port's larger code footprint relative to the reference is explained by:

1. **GBC palette setup emitted in `play_enter`:** The port calls
   `set_sprite_palette(0u, 1u, ...)` four times at scene enter. The reference
   calls the same pattern once in `main()`. Minor structural difference.
2. **HOME-bank scaffolding (joypad, OAM, sound, dialog, fade helpers):** gbkt
   unconditionally emits ~130 lines of HOME-bank helpers (`update_joypad`,
   `button_pressed/held/released`, `dpad_any`, `delay_frames`,
   `hide_sprites_range`, `show_sprites_range`, `update_sprites`,
   `sound_driver_update`, `play_sound`, `_win_print_at`, `_win_clear_region`,
   `_win_fill_screen`, `fade_out`, `fade_in`, `navigate_to_scene`). The
   reference has none of this — it is a single `main()` function.
   This is the framework's value-add (resource management for free), not a
   defect. Same structural pattern as Phase 9's +132-byte `l__HOME` delta.
3. **Metasprite table inlined into main.c:** gbkt emits the five
   `sprite_metasprite_N[]` tables and the `sprite_metasprites[]` pointer array
   directly into `main.c`. The reference uses `png2asset`-generated `sprite.h`/
   `sprite.c` which are compiled as separate translation units; the code lands
   there rather than in the main C file.
4. **GBC-compatible target flag (`-Wm-yc`):** Adds a small overhead for GBC
   compatibility stubs vs the plain DMG reference build.

**l__HOME +112 bytes (+38.5%):**

Same structural explanation as Phase 9: gbkt's `l__HOME` segment carries the
scene-trampoline scaffolding + all HOME-bank helper functions listed above.
Informational — not counted toward the 2× verdict.

**l__DATA −29 bytes:** gbkt initialises globals as `= 0u` (BSS-eligible, some
are absorbed into the initialised segment); the reference has more static
initialisers. Informational saving.

## D-11 Verdict (ROM size — signal 1)

**PASS** — gbkt port `l__CODE` is 3879 bytes; the 2× reference cap is 6992 bytes
(3496 × 2). gbkt is within 1.110× of the reference, far inside the 2× envelope
demanded by the Phase 10 VALIDATION success criterion.
