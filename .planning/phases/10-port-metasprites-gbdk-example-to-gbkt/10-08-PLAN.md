<interfaces>
From RESEARCH §4 — "the flip OAM attribute byte is managed IMPLICITLY by the move_metasprite_flipx/y/xy function selection, NOT by separate set_sprite_prop() calls". This is the key insight: `metaspriteRef.flipX set Expr` becomes a normal u8 variable assignment to a generated `_${id}_flipX` (or similar) variable that the visitor reads when emitting the switch.

Two viable shapes:
(a) `metaspriteRef.flipX set Expr` → ScriptOpVisitor lowers to `Assign("_${id}_flipX", expr)` → user-visible u8 var auto-declared by the visitor in the IR's variable registry.
(b) The port writes `rot set Expr` directly (canonical name); MetaspriteVisitor reads `_rot & 0x3` (already implemented in Plan 07). The `metaspriteRef.flipX` accessor lowers to writing a derived expression to a generated u8 var that the visitor consults at emission time.

Given Plan 07 already reads `_rot & 0x3` directly (not per-flag flipX/flipY u8 vars), the simpler shape is: `metaspriteRef.flipX` / `.flipY` are user-visible assignable refs, and the visitor emits a per-frame branch that reads `_${id}_flipX` (u8 0|1) and `_${id}_flipY` (u8 0|1) and uses them to pick the move_metasprite variant. This means UPDATING Plan 07's switch to read these per-flag vars instead of `_rot & 0x3` would be a refactor — but reference C uses `_rot & 0x3` and we want fidelity.

Decision: For Phase 10, `metaspriteRef.flipX set bool` simply ASSIGNS a u8 var named `_${id}_flipX`. The visitor (Plan 07) is currently reading `_rot & 0x3` per reference fidelity. The accessors here exist as a public DSL surface but the canonical port (Plan 13) drives flip via `_rot & 0x3` ladder NOT per-flag assignment — matching the reference. If a future port needs per-flag direct control, it can use `metaspriteRef.flipX set true` and the visitor logic extends in Phase 13 (D-13 routing).

Concrete Plan 08 deliverable: wire ScriptOpVisitor.visitAssign so that an Assign with objectId matching a metasprite + property in {"flipX","flipY"} lowers to a normal user-variable assignment `_${objectId}_flipX = <expr>;`. Auto-declare the underlying u8 var in the IR if not present. This makes the DSL surface usable; the visitor change is minimal.
