# Phase 13.8 Plan 05: Slot-from-Sub-Palette + Scene-Scoped Suppression Summary

Two architectural latents in `GBDKPipelineV2` eliminated via a single `MetaspriteIR` IR-field
change: Req 5 derives `set_sprite_palette` OBJ slot from each metasprite's declared
`initialSubPaletteSlot` (not list position), and Req 4 makes asset-driven OBJ upload suppression
scene-scoped via `MetaspriteIR.sceneId`. Both Wave 0 RED tests GREEN; D-03 zero-delta preserved.

## One-liner

MetaspriteIR gains `initialSubPaletteSlot: Int? = null` (Req 5) and `sceneId: String? = null`
(Req 4); pipeline reads both to fix silent slot-mismatch and game-global suppression latents.

## What Was Built

### Task 1: Add initialSubPaletteSlot + sceneId to MetaspriteIR (D-02 diagnose-first)

**MetaspriteIR.kt:**
- Added `val initialSubPaletteSlot: Int? = null` — compile-time OBJ palette slot for
  `set_sprite_palette` upload. KDoc explicitly distinguishes this from the runtime
  `_<id>_subPalette` variable (RESEARCH Pitfall 5 — they are independent concepts).
- Added `val sceneId: String? = null` — owning scene ID for scene-scoped suppression predicate.
- Both fields use nullable-with-null-default pattern; no ripple to ~366 existing call sites.
- MetaspriteIR has NO custom equals/hashCode (confirmed via D-02 read-first), so generated
  data-class semantics apply — no manual equals/hashCode update needed (contrast SceneIR in 13.8-06).

**GameIRSerializer.kt (additive round-trip):**
- Serialize: `ms.initialSubPaletteSlot?.let { obj.put("initialSubPaletteSlot", it) }` — omits key when null (backward-compat for older JSON consumers)
- Serialize: `ms.sceneId?.let { obj.put("sceneId", it) }` — same pattern
- Deserialize: `if (json.has("initialSubPaletteSlot")) json.getInt(...)` — null on older JSON
- Deserialize: `json.optString("sceneId", null)` — null on older JSON

### Task 2: Slot-from-sub-palette + scene-scoped suppression in GBDKPipelineV2

**buildMetaspriteSpritePaletteStatements refactor:**

**Req 5 — slot from declared sub-palette:**
```
// Before:
proceduralMetasprites.mapIndexed { slot, ms ->
    CRawCode("set_sprite_palette(${slot}u, 1u, ${ms.id}_palettes);")
}
// After:
proceduralMetasprites.mapIndexed { listIdx, ms ->
    val slot = ms.initialSubPaletteSlot ?: listIdx
    CRawCode("set_sprite_palette(${slot}u, 1u, ${ms.id}_palettes);")
}
```
Same change applied to asset-driven arm: `ms.initialSubPaletteSlot ?: (proceduralCount + idx)`.

**Req 4 — scene-scoped suppression:**
```
// Before (game-global gate):
val hasSpritePalette = gameIR.palettes.any { it.type == PaletteType.SPRITE }
val assetDrivenStatements = if (!hasSpritePalette) { ... } else emptyList()

// After (per-metasprite scene-scoped check):
val gameHasSpritePalette = gameIR.palettes.any { it.type == PaletteType.SPRITE }
assetDrivenMetasprites.mapIndexed { idx, ms ->
    val suppressed = if (ms.sceneId != null) {
        val owningScene = gameIR.scenes.firstOrNull { it.id == ms.sceneId }
        if (owningScene != null) {
            val allOps = owningScene.enterOps + owningScene.frameOps + owningScene.exitOps
            allOps.any { it is SetPalette && it.type == PaletteType.SPRITE }
        } else { gameHasSpritePalette }
    } else { gameHasSpritePalette }
    if (!suppressed) { CRawCode(...) as CStatement? } else { null }
}.filterNotNull()
```

**Byte-identity preservation (D-03):**
- Platformer: `ms.sceneId = null` + no SPRITE palette anywhere → `gameHasSpritePalette = false` → upload emitted → IDENTICAL
- Metasprites: `ms.sceneId = null` + `gray_pal` SPRITE palette → `gameHasSpritePalette = true` → suppressed → IDENTICAL

**RED test updates:**
- `SpritePaletteSlotEmissionTest`: removed `@kotlin.test.Ignore`; wired `hero.copy(initialSubPaletteSlot = 2)` + `enemy.copy(initialSubPaletteSlot = 0)` — emits slot 2 and slot 0 respectively (not list-index 0 and 1)
- `PlatformerObjPaletteUploadTest`: removed `@kotlin.test.Ignore`; wired `assetDrivenMetasprite(...).copy(sceneId = "gameplay")` — gameplay has no SPRITE SetPalette ops → upload is emitted despite game-level SPRITE palette in "title" scene

## Decisions Made

1. **Option B (MetaspriteIR.sceneId) for scene-scoped suppression** — RESEARCH recommended Option B over Option A (add sceneId to GBCPalette — DSL surface change, wide blast radius) and Option C (ops-based detection — no IR change but fragile). Option B stays within MetaspriteIR blast radius already opened by Req 5.

2. **Scene-scoped predicate via SetPalette(SPRITE) ops in scene scripts** — When `ms.sceneId != null`, the predicate checks if the owning scene's enter/frame/exit ops contain any `SetPalette(type=SPRITE)`. This matches the lowering path for `spritePalette{}` DSL declarations. Unknown scene (sceneId doesn't match any scene) falls back to game-global to be conservative.

3. **Null fallback preserves byte-identity** — Both `initialSubPaletteSlot = null` (→ list-index) and `sceneId = null` (→ game-global) are deliberate D-03 guards. Existing shipped games that populate neither field get identical output.
