**IN-01 (PngUtils.kt):**

Added KDoc inline comment in `checkPalettePolarity` at the Spearman comparator line clarifying the `0.0` sentinel:
- `spearmanCorrelation` returns 0.0 for n <= 1 (degenerate case, documented in its own KDoc)
- Sub-palette groups are always 4 entries after the `n % subPaletteSize != 0` guard, making the n <= 1 path unreachable
- If 0.0 is returned due to perfectly uncorrelated ranks, `0.0 < -1.0 + EPSILON` is `false` (correct: not inverted)

KDoc approach chosen over boolean helper: the 0.0 value is already safely handled; the concern was readability, which a targeted inline comment addresses without adding an exported API surface.
