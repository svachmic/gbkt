<objective>
Consolidate the duplicated palette/RGB conversion into a single `PngUtils` source (Req 2, WR-03 + IN-02) and quantize the comparator's source side onto the RGB555 grid the hardware displays (Req 3, WR-04). Both convert tasks delegate to one helper; empty results consistently coerce to `null`.

Purpose: `parseSpriteRgb555Values` (ConvertSpritesTask) and `parsePaletteRgb555Values` + `parseRgb8OrIntValues` (ConvertZoneTilesetsTask) duplicate the parse/pack near-verbatim and diverge in empty-result handling — drift hazard + the IN-02 latent. The comparator ranks the source on exact 8-bit values while the emitted side is RGB555 — an apples-to-oranges grid that flips ranks near ties.
Output: One parse helper in PngUtils; both tasks delegate; `to5()` source quantization in the comparator.
</objective>
