    Create `SharedConstantTablePass` in `gbkt-backend-gbdk/src/.../codegen/postprocess/`.

    **Purpose:** Scan generated C text for identical constant arrays. When two or more `const` arrays have identical initializer content, keep one as canonical and replace others with `#define` aliases.

    **Interface:**
    ```kotlin
    data class ConstantDeduplicationResult(
        val optimizedContent: String,
        val arraysDeduped: Int,
        val details: List<String>
    )

    object SharedConstantTablePass {
        fun optimize(cContent: String): ConstantDeduplicationResult { ... }
    }
    ```

    **Implementation:**
    1. Use regex to identify `const <type> <name>[] = {<values>};` patterns in the C text. The pattern must handle:
       - Single-line arrays: `const UINT8 foo[] = {0x00, 0x01, 0x02};`
       - Multi-line arrays (values span lines, terminated by `};`)
       - Various types: `UINT8`, `UINT16`, `INT8`, `unsigned char`, `const char*`
    2. Extract the initializer content (everything between `{` and `};`).
    3. Hash the normalized initializer (strip whitespace differences).
    4. Group arrays by initializer hash. For each group with >1 member:
       - Keep the first occurrence as canonical.
       - Replace subsequent definitions with `#define duplicate_name canonical_name`.
    5. Return the modified C text and deduplication count.

    **Edge cases:**
    - Arrays with no duplicates: return input unchanged, arraysDeduped = 0.
    - Empty input: return empty, arraysDeduped = 0.
    - Arrays across different bank files: if processing per-file, duplicates only within same file.

    **IMPORTANT:** Start simple. The regex approach is sufficient for machine-generated C with predictable formatting. Don't build a full C parser.

  <action>
    **FunctionDeduplicationPass:**
    1. Scan generated C text for function definitions. Parse function boundaries using brace-depth tracking:
       - Match function signature line: `<return_type> <name>(<params>) {` (possibly with BANKED keyword)
       - Track brace depth to find the closing `}`
       - Extract the complete function body
    2. Normalize function bodies for comparison: strip the function name from the body, normalize whitespace.
    3. Hash normalized bodies. Group identical bodies.
    4. For each group with >1 member:
       - Keep the first as canonical.
       - Replace duplicate definitions with a comment: `// Deduplicated: see <canonical_name>`
       - Replace all call sites of duplicates with calls to the canonical function.
    5. Call site replacement: use regex to find `duplicate_name(` and replace with `canonical_name(`.

    **Interface:**
    ```kotlin
    data class FunctionDeduplicationResult(
        val optimizedContent: String,
        val functionsDeduped: Int,
        val details: List<String>
    )

    object FunctionDeduplicationPass {
        fun optimize(cContent: String): FunctionDeduplicationResult { ... }
    }
    ```

    **IMPORTANT:** Function dedup is harder than constant dedup. Be conservative:
    - Only dedup functions with identical bodies (exact match after normalization).
    - Don't dedup functions with different signatures (param types/counts).
    - Don't dedup if the function is referenced via function pointer.
    - Start with simple cases: identical void functions, identical value-returning functions.

    **COutputOptimizer:**
    ```kotlin
    data class COutputOptimizationSummary(
        val constantArraysDeduped: Int = 0,
        val functionsDeduped: Int = 0,
        val details: List<String> = emptyList()
    )

    class COutputOptimizer(
        val sharedConstantTablesEnabled: Boolean = true,
        val functionDeduplicationEnabled: Boolean = true
    ) {
        fun optimize(files: Map<String, String>): Pair<Map<String, String>, COutputOptimizationSummary> {
            var totalConstDeduped = 0
            var totalFuncDeduped = 0
            val allDetails = mutableListOf<String>()

            val optimized = files.mapValues { (filename, content) ->
                var result = content
                if (sharedConstantTablesEnabled) {
                    val constResult = SharedConstantTablePass.optimize(result)
                    result = constResult.optimizedContent
                    totalConstDeduped += constResult.arraysDeduped
                    allDetails.addAll(constResult.details)
                }
                if (functionDeduplicationEnabled) {
                    val funcResult = FunctionDeduplicationPass.optimize(result)
                    result = funcResult.optimizedContent
                    totalFuncDeduped += funcResult.functionsDeduped
                    allDetails.addAll(funcResult.details)
                }
                result
            }

            return optimized to COutputOptimizationSummary(totalConstDeduped, totalFuncDeduped, allDetails)
        }
    }
    ```
