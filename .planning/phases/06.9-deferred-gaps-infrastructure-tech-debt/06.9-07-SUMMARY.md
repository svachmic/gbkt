## Decisions Made
- ProjectBuilder unit test for graceful skip: Kotlin DSL TestKit build scripts cannot resolve plugin classpath types at compile time (the type is only on the runtime classpath via `withPluginClasspath()`). Using `ProjectBuilder` directly avoids this limitation.
- SameBoy tester as primary emulator: exits 0 after N frames without crash, making it ideal for CI (no Lua scripting needed).
- Timeout = PASS: if the process runs for the full timeout budget without crashing, the ROM passed (no crash is the success criterion).
