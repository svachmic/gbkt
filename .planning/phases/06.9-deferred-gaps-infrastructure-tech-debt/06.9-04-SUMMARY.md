## Decisions Made
- No compile-time dependency on AnalysisConfig: COutputOptimizer accepts `sharedConstantTablesEnabled: Boolean` and `functionDeduplicationEnabled: Boolean` directly. Plan 08 (integration) reads these from AnalysisConfig and passes them in.
- Per-file deduplication (not cross-file): each file in the Map is processed independently. Aligns with GBDK's bank file model where cross-bank #define aliases would be invalid.
- #define approach for array dedup: preserves pointer equivalence and is valid C preprocessor usage.
- Conservative function dedup: only exact matches after whitespace normalization. Functions with different param types/counts are never merged. No false positives.
