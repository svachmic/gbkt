## Decisions Made
- Wired `COutputOptimizer` in `GBDKBackend.generateV2()` rather than inside `GBDKPipelineV2` — the backend is the right injection point because it holds `AnalysisConfig` (which carries the toggle fields), while the pipeline has no knowledge of config.
- Used null-default optional parameters (`assetManifest: AssetManifest? = null`, `outputDirectory: java.io.File? = null`) to maintain backward compatibility with reflection callers in the Gradle plugin that invoke `generateV2(gameIR)` without extra args.
- C-output summaries only appended to OptimizationReport when `constantArraysDeduped > 0` or `functionsDeduped > 0` — avoids polluting the report with empty entries for games with no duplicate code.
- Secondary report write in `generateV2()` guarded by `report.passes.size > annotatedContext.optimizationReport.passes.size` — prevents overwriting the BudgetAuditPass-written report with a partial one when no C-output deduplication happened.
