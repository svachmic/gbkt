## Decisions Made
- CONTAINER_ELEMENT_SIZE = 4 bytes: category (UINT8, 1) + count (UINT8, 1) + id/padding (2 bytes). Matches inventory slot layout used in codegen.
- TilemapEntry.uniqueTileCount defaults to 0 to maintain backward compatibility with manifests produced before this field was added.
- estimateBgTiles matches on `tilesetPath == tilesetRef.path || path == tilesetRef.path` — covers TMX tilemap entries (where tilesetPath points to the PNG) and edge case where scene directly references a tilemap entry.
- HRAM left at 0 with clear comment — the plan specified this as documentation-only fix (no DSL targets HRAM in v2 IR).
