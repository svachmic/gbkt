### Task 3: Tier-2 Runtime Probe Validation (commits 0021d854, 0cd560d0, 303de4fb)

**Rule 1 Auto-Fix: PlatformerVisitor.kt**

Discovered that `PlatformerVisitor.kt` (not `ActorVisitor.kt`) is the codegen source for the platformer example. Migrated 4 signed-context comparison sites:
- Terminal velocity guard: `CLiteral(cfg.terminalVelocity)` → `CIntLiteral(cfg.terminalVelocity)`
- Jump-cancel: `CLiteral(0)` → `CIntLiteral(0)`

- Wall-slide speed clamp: `CLiteral(wallJump.wallSlideSpeed)` → `CIntLiteral(wallJump.wallSlideSpeed)`

**Additional fix: Physics wiring and `_plat_vx`**

The platformer example's `gameplay_frame()` was not calling `platformer_physics_update()`. Added `GenreVisitorResult.frameOps` injection using a 4-level scene discovery fallback chain (mirrors SportVisitor pattern).

Added `_plat_vx` (INT8) variable and horizontal movement/friction to `buildPhysicsUpdateFunction`:
- LEFT/RIGHT d-pad → decrement/increment `_plat_vx` by 1/frame
- Friction when no horizontal input: `if (_plat_vx > 0)` decrement, `else if (_plat_vx < 0)` increment — using `CIntLiteral(0)` for signed comparisons

**Probe fixes:**

- `Round8CameraMonotonicityProbe`: Fixed assertion direction — camera_y DECREASES (not increases) as car moves UP. `camYMid < camYBaseline && camYEnd <= camYMid`.
- `PlatformerJumpCancelAndFrictionProbe`: 
  - Added `writeVariable("plat_grounded", 1)` before jump test (basic platformer has no tile collision)
  - Changed from `stepN(2)` (no input) to `step(A), step(A)` (hold A) to defer cancel to explicit release
  - Fixed expected formula: `(vyMid + 2) / 2` (gravity runs before cancel on release frame)
  - Added `toSignedInt8()` helper to sign-extend raw unsigned byte reads from emulator
