# Phase 07.9 Plan 01: CIntLiteral sealed subtype + RED test scaffolds Summary

Architecture commitment (Option C — CIntLiteral/CLiteral split) with new AST node, extended emitter dispatch, and two RED test scaffolds establishing the forcing function for Plan 02 visitor migration.

## What Was Built

### Task 1: CIntLiteral sealed subtype + CEmitter dispatch

Added `data class CIntLiteral(val value: Int) : CExpr` to `CExpr.kt` immediately after `CLiteral`:

- **Semantics:** emits bare value with NO `u` suffix — for signed-context comparison RHS only
- **Contrast with CLiteral:** `CLiteral` continues to emit `${value}u` for non-negative values (unsigned-safe default, ~1144 existing call sites untouched)
- **CEmitter.emitExpr:** new arm `is CIntLiteral -> "${expr.value}"` inserted after the `is CLiteral` arm
- **Exhaustiveness preserved:** sealed hierarchy compile-time enforcement still holds; `CAstTest.kt` updated with `is CIntLiteral` arm

**Non-regression gate:** `CameraBoundsClampPrecedenceTest` GREEN (Plan 07.4-34 contract).

### Task 3: Tier-2 runtime RED probe PlatformerJumpCancelAndFrictionProbe

2 runtime test methods for the platformer example:

- `jump_cancel_halves_vy_on_a_release_during_ascent`: boots to gameplay, presses A, reads `_plat_vy` mid-ascent, releases A, asserts `vyAfterRelease == vyMid / 2`
- `friction_decelerates_negative_vx_monotonically`: builds negative vx with LEFT, asserts `|vx_10| < |vx_5| < |vx_0|` (D-N-12 multi-snapshot)

Both **auto-skipped** when ROM is absent (GbktTestExtension handles this). When ROM is present, both are **RED at HEAD** because:
- Jump-cancel emits `_player_vy < 0u` (always false for signed negative → cancel never fires)
- Friction emits `_player_vx < 0u` (always false → friction never fires for negative vx)

## Architecture Choice: Option C (Additive CIntLiteral Split)

**Rationale (per RESEARCH.md §4.6):**
- **Explicit failure mode for future code:** `CIntLiteral(0)` vs `CLiteral(0)` is loud at review; the sealed-interface dispatch forces exhaustive handling at compile time
- **Surgical Tier-3 diff:** only the 17–25 in-scope signed-comparison call sites change in generated C; ~1144 unsigned-typed sites remain on `CLiteral` and emit `Nu` unchanged
- **D-09 #3 literally satisfiable** without reinterpretation: only signed-comparison call sites change in regenerated C
- **Beats Option D:** no 5000+ line text diff requiring reinterpretation
- **Beats Options B/E:** loud at review vs silent fallback
