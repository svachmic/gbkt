## Anomalies Flagged for Plan 06 Review

### Pre-existing const/extern mismatch (explorer, dungeon, rpg-lite)

SDCC error 91 in all three RPG-genre examples. Pattern:
  game.h:  `extern UINT8 _char_hero_hp;`      (no const)
  main.c:  `const UINT8 _char_hero_hp = 20u;`  (with const)

Confirmed present in acf6e2d6 baseline — not a Plan 07.9 regression. The surgical diffs for these 3 examples show 0 diff lines (Plan 07.9 made no changes to them).

Root cause: RPG character stats are generated as `const` in `main.c` but `extern` (without const) in `game.h`. SDCC treats these as distinct types. Fix: either remove `const` from the variable definition or add `const` to the extern declaration in `game.h`.

Recommendation for Plan 06: Accept as pre-existing defect outside Plan 07.9 scope. Open a follow-up plan for the const/extern codegen fix in RPG-genre character stats.
