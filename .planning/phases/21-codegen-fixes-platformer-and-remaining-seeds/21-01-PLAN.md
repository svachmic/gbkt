<objective>
Lift `pivot_adjust` resolution out of the `PlatformerVisitor` metasprite-lookup dance into the `tilemapCollision { }` DSL builder, making the DSL the single source of truth (per D-05 / SEED-021). The visitor becomes a dumb consumer that reads a resolved `pivotAdjust` config value, with the existing companion-constant geometry kept as a fallback (plus a validation diagnostic) when the key is absent. Wire `platformer-template` to declare `pivotAdjust(2)` explicitly, and add a JVM emission test that locks both the config-driven value (D-05) and the foot-snap arithmetic (D-07).

Purpose: Project Rule #1 — the user DSL owns geometry; the visitor stops reverse-engineering it via a fragile metasprite scan. This is a robustness refactor; the underlying numeric pivot value is unchanged (32 − 6 − 24 = 2), so byte-identity holds for existing fixtures and for platformer-template's generated C.
Output: pivotAdjust setter, config-driven visitor read, template declaration, snap-arithmetic emission test.
</objective>
