## Decisions Made

- `readAll()` returns type-correct values without breaking existing UINT8 consumers — raw byte for unsigned, sign-extended for INT8, little-endian 16-bit for UINT16/INT16
- `overrideTypes` silently skips unknown variable names, safe to call with full metadata even when sym file is a subset
- WRAM boundary safety in readTypedValue: U16/I16 at address 0xDFFF falls back to returning low byte only
- Pipeline hardcodes gbdk_offset/direct_ascii as defaults — correct for all current games, extensible via custom type for future game-specific decoders
