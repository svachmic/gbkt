    **Section 7: `## Text Assertions`**

    - text_on_screen in emulator_assert searches both layers
    - When to use scrollAware: true — games with camera scroll that read BG text
    - Tile decoder configuration: games get default decoders from metadata; custom tilesets use custom decoders
    - Default: BG uses GBDK offset decoder, WIN uses direct ASCII decoder

    **Section 8: `## Variable Inspection`**
    - Type-aware reading: INT8 values report signed (-128..127), not unsigned (0..255)
    - 16-bit variables: UINT16 (0..65535), INT16 (-32768..32767)
    - Type comes from DSL declaration (u8Var, i8Var, u16Var, i16Var)
    - Common pitfall: expecting positive value for INT8 variable like ballDx
    - Show example: ballDx declared as i8Var(-1) reports -1, not 255
    - Type range reference table (from UI-SPEC.md):
      | IR Type | Range | Sign |
      |---------|-------|------|
      | UINT8 | 0 to 255 | unsigned |
      | INT8 | -128 to 127 | signed |
      | UINT16 | 0 to 65535 | unsigned |
      | INT16 | -32768 to 32767 | signed |
