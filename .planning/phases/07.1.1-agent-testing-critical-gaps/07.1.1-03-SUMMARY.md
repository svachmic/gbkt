## What Was Built

### Task 1: Scroll-Aware VramTextVerifier

Added two new constants to `VramTextVerifier`:
- `SCY_REG_ADDR = 0xFF42` — BG Y scroll register
- `SCX_REG_ADDR = 0xFF43` — BG X scroll register

Added `scrollAware: Boolean = false` parameter to:
- `readText()` — when true and layer is BACKGROUND, reads SCX/SCY from hardware registers and applies tile offsets; wraps at 32 tiles using `and 31`
- `readRow()` — propagates to readText
- `readAllRows()` — propagates to readRow
- `findText()` — propagates to readRow
- `findTextAnyLayer()` — propagates to findText for both layers (WIN unaffected)

Window layer is explicitly unaffected by `scrollAware` (GB hardware: window has independent WX/WY registers).

8 new tests added covering:
- `scrollAware=false` produces identical results to default
- SCX=64 shifts x by 8 tiles
- SCY=16 shifts y by 2 tiles
- Wrap-around at tile 32 boundary (viewport x=18 + 15 tile offset = tilemap x=1)
- Window layer immunity to SCX/SCY
- Propagation through readRow, readAllRows, findText, findTextAnyLayer

### Task 2: Metadata Decoder Threading + MCP scrollAware

**StepAgent.buildObservation():** Now reads `resolvedMetadata?.bgDecoder()` and `resolvedMetadata?.winDecoder()` (extension functions from Plan 01) and passes them to `VramTextVerifier.readAllRows()`. Games without `tileDecoders` in metadata receive `null` decoders → default behavior (GBDK offset for BG, direct ASCII for WIN) unchanged.

**McpEmulatorSession.batchAssert():** The `text_on_screen` check now parses an optional `scrollAware` field from the check args. The observation's bgText/winText are already decoded by metadata-driven decoders in buildObservation(), so the field is parsed and stored for future targeted reads.

**ToolHandlers.kt:** `emulator_assert` tool description and inputSchema now document the optional `scrollAware` field on `text_on_screen` checks.
