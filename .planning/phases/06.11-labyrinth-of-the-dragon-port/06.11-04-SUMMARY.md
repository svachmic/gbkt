## Decisions Made

- PaddingConfig uses `Map<String, Int>` (contextWidths): simpler than a DSL builder, sufficient for framework-level configuration without requiring the DSL to be active
- Locale suffix is only appended when `-Pgbkt.locale` is explicitly set on the command line — preserves backward compatibility so existing projects still produce `game.gb` not `game_en.gb`
- `locale` is declared as `@Input @Optional` on `GenerateCTask` so Gradle's incremental build cache is correctly invalidated when the locale changes between builds
- Over-width strings produce a warning and are left unchanged — never truncate translated content
