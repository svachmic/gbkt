## Decisions Made

- `GameState` uses a class-with-delegate-properties pattern so all variables are grouped, documented, and accessible by name — compared to an extension function with inline declarations, this is more readable and testable
- `GameState.register(this)` is called inside the `game {}` builder lambda so `GameBuilderContext.current` is set when delegates call `provideDelegate`, ensuring correct registration
- 5 placeholder scenes created with minimal `print()` enter ops — each scene has enough content for IR tests to pass, and detailed scene implementations come in later plans
- `gbkt-genre-rpg` dependency added now rather than in plan 06 — it is needed by `Characters.kt` which already exists in the module
