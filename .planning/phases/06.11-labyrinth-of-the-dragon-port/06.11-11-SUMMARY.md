### Task 1: Scene coordinator and title scene

Created `Scenes.kt` with 7 forward-declared `SceneRef` objects:
- `titleRef` → `"title"` — maps to `init_title_screen()` in original
- `heroSelectRef` → `"hero_select"` — maps to `init_hero_select()`
- `gameplayRef` → `"gameplay"` — maps to `init_world_map()`
- `battleRef` → `"battle"` — maps to battle state machine
- `pauseRef` → `"pause"` — maps to MAP_MENU_OPEN state
- `gameOverRef` → `"gameover"` — maps to death/defeat path
- `victoryRef` → `"victory"` — maps to `init_credits()`

The `register(builder, sounds, combatSystem, state)` function wires all 8 scenes (including gameplay, battle, and pause from plans 12/12b).

Created `TitleScene.kt` porting `title_screen.c`:
- Applies 5 GBC palettes: `titleBg`, `titleDragonFace`, `titleDragonBody`, `titleFire`, `titleSmoke`
- Displays title text: "LABYRINTH", "OF THE DRAGON", "PRESS START"
- Plays `sounds.titleFire` SFX on enter — matches `sfx_title_fire` in original
- START or A button navigates to `heroSelectRef` with `sounds.menuMove` SFX
- Fire animation timing documented: 6 frames/step, 18-frame sequence from `init_fire_animation()`
