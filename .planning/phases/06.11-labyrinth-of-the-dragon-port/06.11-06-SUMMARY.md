## Decisions Made

1. **13 status effects (not 17):** The plan specified 17 effects, but the Original C `StatusEffect` enum in `stats.h` has only 13 active entries. BUFF_UNUSED_0 (idx 8), BUFF_UNUSED_1 (idx 9), and BUFF_UNUSED_2 (idx 10) are explicitly placeholder slots with no code in encounter.h or stats.c. Implementing them would be adding dead code with no gameplay purpose.

2. **`lateinit var` capture pattern for items {}:** `GameBuilder.items {}` accepts `ItemCatalogBuilder.() -> Unit` — it returns `Unit`. The `return@items LabyrinthItems(...)` approach used in an earlier iteration was a type mismatch. The fix: declare all ItemRef vars as `lateinit var` outside the block, assign them inside using `potionRef = item("potion") { ... }`, then construct `LabyrinthItems` after the block. This is documented in Items.kt KDoc under "Implementation Note."

3. **Starting level 4 (not 5):** The plan referenced `NEW_CHARACTER_LEVEL = 5` but the Original C `init_player()` in `player.c` calls `set_player_level(4)`. Verified from source, used 4.
