## Decisions Made

- Floor 8 `safeZone()`: The original `floor8.c on_move` always returns false (no random encounter check). `safeZone()` directly maps this intent.
- Mini-boss NPCs: Floor 8 uses tile-triggered mini-bosses in the original. Port uses NPC objects with `usedFlag` since ZoneBuilder has no tile-trigger primitive — behavior is equivalent (one-time encounter at fixed position).
- Eye puzzle runtime delegation: The complex lookup-table puzzle state machine on Floor 7 is delegated to `callOp("advance_eye_puzzle_f7", ...)` rather than modeling the full state machine in DSL — the DSL is a definition format, not a scripting language.
- Dragon boss victory: `setFlag(worldFlags.floor8DragonDefeated)` + `transition { conditionFlag(...) }` pattern matches how all other bosses gate floor exits.
