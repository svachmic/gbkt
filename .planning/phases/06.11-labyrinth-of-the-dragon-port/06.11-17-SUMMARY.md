# Phase 6.11 Plan 17: Czech Translation PO File Summary

**One-liner:** Czech (cs.po) draft translation with full diacritics for all 376 game strings, stress-testing the multi-language PO localization system.

## What Was Built

Created `LabyrinthOfTheDragon-port/res/strings/cs.po` — a complete Czech translation of all 376 strings from en.po.

The file:
- Mirrors en.po structure exactly (same msgctxt/msgid keys, only msgstr values differ)
- Uses full Czech diacritics: ě, š, č, ř, ž, ý, á, í, é, ú, ů, ď, ť, ň
- Has proper Czech plural forms header: `nplurals=3; plural=(n==1) ? 0 : (n>=2 && n<=4) ? 1 : 2;`
- Contains prominent comment noting Claude-drafted status for user review and correction
- Keeps all %s, %d, %damage, %monster, %c, %exp, %level, %aspect, %1u placeholders in correct positions
- Respects Game Boy screen width constraints (20 tiles, 18 chars/line for dialogs)

## Translation Decisions

| Category | Approach |
|----------|----------|
| Item names | Czech equivalents: Lektvar, Elixír, Éter, Přípravek (Remedy) |
| ATK/DEF abbreviations | UTK+/OBR+ (Czech: útok/obrana) |
| Monster names | Mix: Kobold/Goblin/Zombie kept; Bugbear=Strašák, Owlbear=Sovilev, Will-o-wisp=Bludička |
| Ability names | Full Czech translations: Ohnivá koule (Fireball), Blesk (Lightning), Krupobití (Sleetstorm) |
| Class short names | DRU, BOJ, MNK, ČARO |
| Credits | Names untranslated; section headers in Czech (PROGRAMOVÁNÍ, GRAFIKA PŘÍŠER, etc.) |
| Easter eggs | Kept the spirit: "Ligma" joke kept, "BRAIINNNNSS" → "MOZKYYYY" |
