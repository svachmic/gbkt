## Decisions Made

- `CombatStateId` already existed as `@JvmInline value class` in `gbkt-ir` — added `CombatStates.kt` as a constants object on top, no type duplication
- `FlagRef` placed in `WorldBuilders.kt` alongside `FlagPageBuilder` for co-location of flag types and builders
- `checkFlag()` is a top-level function (not a `ScriptBuilder` method) because it returns an `Expr` for use in `whenever()` conditions, not a side-effecting `ScriptOp`
- `CharacterDef.learningConfig` defaults to `null` for zero breaking changes — `AbilityLearningBuilder`/`AbilityLearningConfig` already existed but weren't wired
