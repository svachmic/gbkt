# Phase 06.11 Plan 20: ROM Build Gap Resolution Summary

Resolved all remaining C compilation and linking errors in the LotD port's generated C, producing a buildable `labyrinth_en.gb` ROM (64KB) with zero lcc errors. Two framework gaps in `GBDKPipelineV2` were fixed: missing global variable declarations (Task 1, committed previously) and missing function definitions that caused linker failures (Task 2, this session).

## What Was Built

### Task 1 (Prior session)
Added 6 helper methods to `GBDKPipelineV2`:
- `buildStatusEffectVarDecls` — 39 `_effect_*_active/duration/stacks` globals
- `buildFlagVarDecls` — 27 `_flag_*` globals from GlobalFlagsIR pages
- `buildZoneObjectVarDecls` — 84 `_sconce_*_lit` + 17 `_lever_*_active` globals
- `buildMonsterAIVarDecls` — monster cooldown vars + shared RPG vars, with BehaviorTree traversal for CooldownNode IDs
- `buildCombatStateDefines` — 9 `_COMBAT_STATE_*` defines for turn-based combat
- Wired all into `buildHomeFile` with `distinctBy { it.name }` deduplication

### Task 2 (This session)
Resolved linker "Undefined Global" errors that prevented `.gb` ROM production:

**`buildCallOpForwardDecls`** — scans all zone object and scene `CallOp` nodes, emits `void func_name(UINT8* p0);` forward declarations in `game.h` to prevent SDCC error 101 (too many parameters from implicit declarations).

**`buildCallOpStubFunctions`** — generates stub definitions in `main.c` for all external callOp functions:
- `add_item(UINT8*)`, `map_textbox(UINT8*)` — inventory/textbox helpers
- `check_boss_sconces_f3()`, `check_color_puzzle_f4(UINT8*)`, `check_lever_puzzle_f4()` etc. — floor puzzle callbacks
- `use_healing_mirror_f8(UINT8*)`, `start_mini_boss_f8(UINT8*)`, `start_beholder_elite_f8()`, `start_dragon_final_boss_f8()` — Floor 8 boss triggers

**`buildMonsterCombatStubs`** — generates stubs for combat engine helpers called by monster AI:
- `monster_basic_attack()`, `monster_flee()`, `find_lowest_hp_target()` — core combat mechanics
- `use_ability_zombie_bite()`, `use_ability_bugbear_war_cry()`, etc. — 12 monster-specific ability stubs (abilities referenced in behavior trees but not defined by `RpgVisitor.generateAbilityFunctions`)

**Combat state defines in `game.h`** — `buildCombatStateDefines` was called from `buildHomeFile` (main.c only) but bank1.c includes game.h not main.c. Fixed by also calling it from `buildHeaderFile`.

**Extended `buildFlagVarDecls`** — now scans zone object `usedFlagId` and `NpcObjectIR.visibleFlagId` fields for inline flags (e.g. `npc_gcube_elite_f5`, `miniboss_goblin_f8`) not registered in GlobalFlagsIR pages. Total flags: 52.

**Added helper tree walkers**:
- `collectCallOpsFromScripts` — recursive IfOp/WhileOp/ForOp descent
- `collectZoneObjectScripts` — collects all scripts from ZoneObjectIR subtypes
- `collectAbilityCallsFromTree` — collects UseAbility abilityIds from BehaviorNode trees
