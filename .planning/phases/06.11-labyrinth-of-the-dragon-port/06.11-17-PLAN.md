**PO header:**
```po
msgid ""
msgstr ""
"Language: cs\n"
"Content-Type: text/plain; charset=UTF-8\n"
"Plural-Forms: nplurals=3; plural=(n==1) ? 0 : (n>=2 && n<=4) ? 1 : 2;\n"
```

**Translation guidelines:**
1. **Natural Czech** — Translate for natural reading, not word-for-word
2. **RPG terminology** — Use established Czech RPG conventions:
   - HP = ZJ (Zdravotni jednotky) or just HP (widely understood)
   - ATK = UTK (Utok) or just ATK
   - DEF = OBR (Obrana) or just DEF
   - Use Czech player's intuition — some English terms are standard in Czech gaming
3. **Character limits** — Game Boy screen is 20 tiles wide, dialog boxes use 18 chars/line
   - Ability names: max 13 chars after auto-padding
   - Item names: shorter is better
   - Battle messages: max 18 chars/line, use newlines for longer messages
4. **Diacritics** — Use full Czech diacritics: ě, š, č, ř, ž, ý, á, í, é, ú, ů, ď, ť, ň
5. **Keep same msgctxt and msgid** — Only change msgstr
6. **Placeholders** — Keep %s, %d, %damage, %monster, %c placeholders in same positions

**Translation categories:**
- `misc`: Item and element names → Czech equivalents
- `ability`: Ability names → Czech (e.g., "Fireball" → "Ohniva koule")
- `battle`: Combat messages → Czech (e.g., "You deal %damage damage!" → "Zpusobil jsi %damage bodu zraneni!")
- `player`: Player action feedback → Czech
- `maps`: Interaction messages → Czech (e.g., "You found a potion!" → "Nasel jsi lektvar!")
- `floor_*`: Floor-specific dialog → Czech
- `chest_item`: Chest interaction → Czech

**Known limit:** Claude's Czech may have errors — this is expected. The CONTEXT.md says "Claude drafts cs.po, user reviews and corrects." Include a comment at the top noting this.

**File structure:** Copy en.po structure exactly, replace only msgstr values with Czech translations.
