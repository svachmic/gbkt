Update the build.gradle.kts to establish the V2 port foundation:

1. **Change game entry point** from `"io.github.gbkt.examples.labyrinth.LabyrinthOfTheDragonKt::labyrinthOfTheDragon"` to `"io.github.gbkt.examples.labyrinth.LabyrinthOfTheDragon::create"` (object-based pattern per CONTEXT.md)

4. **Keep essential config:**
   - `gbcMode.set("ONLY")` — required for palettes
   - `ramBanks.set(4)` — matches Original 4 RAM banks
   - `outputName.set("labyrinth")` — keep for now, locale variant support comes in a framework plan
   - `resourceDirectory.set(file("res"))` — keep for binary resources
   - `assets("res")` — keep

5. **Keep utility tasks** (migrateAssets, debugRom) — they're still useful for development

6. **Update file header comment** to reference V2 port

Do NOT add new configuration for localization or multiple ROMs yet — those depend on framework plans.
