## Decisions Made

- **AST-level vs text-level test assertions:** Asserted on the CFunction body shape (sequence of CStatement / CExprStatement / CCall data classes), not on emitted C text. This locks the visitor contract one layer below the emitter, so CEmitter-level formatting changes (e.g., literal-suffix tweaks) cannot accidentally pass the test while breaking the contract. Plan 07's INV-7 will add a text-level grep as the complementary lock.
- **No helper extraction (D-A1 / D-claude-2):** The sanitizer chain `.replace('-', '_').replace(' ', '_')` appears twice in the same lambda (existing line + new pixelLoad block). Extracting a helper would be cleaner Kotlin but violates the plan's explicit D-A1 constraint and increases the diff surface unnecessarily. The duplication is local to the same 20 lines of code.
- **Preserved the post-11.1-05 caller-miss runtime guard:** The `check(zoneBankAllocation.isNotEmpty() && zones.isNotEmpty())` block above the flatMap was NOT modified — it's still the wiring-bug catch for callers that forgot to thread the new params from 11.1-05.
