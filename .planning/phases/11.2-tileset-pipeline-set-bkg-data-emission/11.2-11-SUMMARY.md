Wave 4 was a single-plan wave dispatched as a worktree-isolated subagent. Per user-memory `feedback_claude_code_worktree_drift_quirks.md`, this is a documented Claude Code worktree-isolation quirk: "isolation=\"worktree\" can leak agent commits onto the parent branch directly, leak test output to the main checkout as untracked files, and let orchestrator CWD drift into a worktree."
