# Phase 11.2 Plan 03: ConvertZoneTilesetsTask Summary

One-liner: New `@CacheableTask` Gradle task reads `game_metadata.json#zoneTilesets`, drives GBDK's `png2asset` over each zone PNG with the plan-02-spike-locked flag set (`-map -spr8x8 -bpp 2 -noflip`), and synthesizes per-zone `_zone_<id>_tileset.h` headers carrying the D-A3 `#define _zone_<id>_tileset <stem>_tiles` alias + `#define _zone_<id>_tileset_count <N>` count macro, with four fail-fast guards (D-C1 missing png2asset, D-C2 missing PNG, D-C3 > 192 tiles, D-C4 non-8-aligned dims) that fire BEFORE the external exec per the spike-log finding that png2asset returns exit 0 even on decoder errors.

## What Shipped

A 311-line `ConvertZoneTilesetsTask.kt` production class (gbkt-gradle-plugin/src/main/kotlin/io/github/gbkt/gradle/tasks/) extending `DefaultTask`, annotated `@CacheableTask`, `@Inject`-ing `ExecOperations`. Four Gradle property inputs (`gbdkHome: Property<String>`, `assetDirectory: DirectoryProperty?`, `metadataFile: RegularFileProperty?`, `cSourceDir: DirectoryProperty`) plus one output (`cSourceDir`). The `@TaskAction convertZoneTilesets()` body:
1. Returns gracefully when `metadataFile`/`assetDirectory` are absent (non-zone games like pong/breakout no-op cleanly).
2. Parses `game_metadata.json` into `org.json.JSONObject` and extracts `zoneTilesets` array.
3. Returns gracefully when `zoneTilesets.length() == 0` (no zone tilesets to convert).
4. Resolves `gbdkHome` → `GbdkToolchain.getPng2asset(gbdkDir)`.
5. For each zone entry: applies path-traversal guard (T-11.2-03-03), then `convertOneTileset(...)`.

`convertOneTileset(zoneId, pngFile, sanitized, png2assetExe, outputDir)` implements the five required guards in order (D-C2 → D-C4 → D-C3 → D-C1 → exec → output-file presence) before delegating to `synthesizeHeader(...)`. The png2asset args list is the spike-locked `[png, -o, outC, -map, -spr8x8, -bpp, 2, -noflip]` with NO `-keep_palette_order` (REMOVED at spike per RGB-PNG rejection). `synthesizeHeader(...)` emits the four-key header: `#ifndef _ZONE_<SANITIZED_UPPER>_TILESET_H`, `extern const uint8_t <stem>_tiles[<tileCount> * 16];`, `#define _zone_<id>_tileset <stem>_tiles`, `#define _zone_<id>_tileset_count <tileCount>`.

A 5-test `ConvertZoneTilesetsTaskTest.kt` JVM test class (gbkt-gradle-plugin/src/test/kotlin/io/github/gbkt/gradle/tasks/) exercises:
- Test 1 (happy path, png2asset-conditioned): real `gbkt-examples/banks/res/tiles/checker.png` → asserts `_zone_play_zone_tileset.c` AND `.h` exist; `.h` contains `#define _zone_play_zone_tileset_count 4` AND `#define _zone_play_zone_tileset checker_tiles`.
- Test 2 (D-C2): missing PNG → `assertFailsWith<IllegalArgumentException>` with `absent_zone` + `not found` in message.
- Test 3 (D-C4): synthetic 7×7 PNG via `BufferedImage` + `ImageIO.write` → `assertFailsWith<IllegalArgumentException>` with `multiple of 8` + `7x7` in message.
- Test 4 (D-C3): synthetic 200×104 PNG → `assertFailsWith<IllegalArgumentException>` with `192 tiles` in message (200/8 × 104/8 = 325 > 192).
- Test 5 (surface): `ConvertZoneTilesetsTask.MAX_ZONE_TILESET_TILES == 192`.

Tests 2/3/4/5 are unconditional GREEN — they fire Kotlin-side guards or read a const before png2asset is invoked. Test 1 gracefully `return`s when GbdkToolchain.find() throws OR png2asset is absent OR the banks fixture is not on disk (CI safe).

**2. [Rule 2 - Critical Functionality] Path-traversal guard (T-11.2-03-03)**
- **Found during:** Task 1 implementation (threat model review)
- **Issue:** Plan's `<threat_model>` row T-11.2-03-03 calls out path traversal as "mitigate" disposition with "Defensive `require(pngFile.canonicalPath.startsWith(...))` is paranoid-but-cheap; include it." This was implicit in the plan but not enumerated in the four `require` count in the acceptance criteria.
- **Fix:** Added a fifth `require(...)` between asset path resolution and `convertOneTileset(...)` enforcing `pngCanonical == assetCanonical || pngCanonical.startsWith(assetCanonical + File.separator)`. The acceptance criterion expected exactly 3 require calls + 1 explicit error throw; this adds one more require (total 5).
- **Files modified:** `gbkt-gradle-plugin/src/main/kotlin/io/github/gbkt/gradle/tasks/ConvertZoneTilesetsTask.kt` (lines 139-147)
- **Commit:** `935c549a`

**3. [Rule 2 - Critical Functionality] ImageIO returning null is a hard error**
- **Found during:** Task 1 implementation (D-C4 guard wiring)
- **Issue:** Plan said `require(w % 8 == 0 && h % 8 == 0)` after `ImageIO.read(pngFile)`. `ImageIO.read` returns null when the file is not a recognizable image — accessing `.width` on null NPEs with an opaque message.
- **Fix:** Added `?: error(...)` between `ImageIO.read` and the dim check so an unreadable PNG fails with a clear `tileset PNG could not be decoded (ImageIO returned null)` message that includes the zone id and absolute path.
- **Files modified:** `gbkt-gradle-plugin/src/main/kotlin/io/github/gbkt/gradle/tasks/ConvertZoneTilesetsTask.kt` (lines 181-186)
- **Commit:** `935c549a`

**4. [Rule 2 - Critical Functionality] png2asset exit-0-on-error secondary guard**
- **Found during:** Plan 02 spike-log review (failure-mode characterization)
- **Issue:** The spike's "Failure Mode Characterization" table established that png2asset returns exit 0 even on decoder errors, missing input files, and `-keep_palette_order` rejection. The plan's behavior step (vi) only checked `exitValue != 0`. That alone is insufficient per the spike's "Key invariant for Plan 03 error handling: Treat any non-empty stderr OR missing output file as failure. Do NOT trust png2asset's exit code."
- **Fix:** After the exit-code check, also verify `outputC.isFile && outputC.length() > 0L` and emit a distinct error if not. Captures the spike's "missing output file" invariant. (Stderr capture would require switching from `execOperations.exec` to a stream-capturing variant; deferred — exit code + output-file check is the cheap-and-correct minimum.)
- **Files modified:** `gbkt-gradle-plugin/src/main/kotlin/io/github/gbkt/gradle/tasks/ConvertZoneTilesetsTask.kt` (lines 238-244)
- **Commit:** `935c549a`
