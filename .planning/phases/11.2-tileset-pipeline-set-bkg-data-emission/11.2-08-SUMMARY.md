## Decisions Made

1. **End-to-end pipeline inspection (`GBDKBackend().generateV2(ir)` → `result.files["main.c"]?.content`)** rather than direct `SportVisitor().visit(...)` inspection. Rationale: the LEGACY-path lock should verify the user-facing C emission (what actually lands in `main.c`), not the visitor's internal `CVarDecl` tree. This also exercises the full analysis + annotation + emission pipeline, catching any path where varDecls might be dropped before reaching `main.c`.
2. **Reused the one-AI-vehicle fixture pattern from `RacingEnterOpsEmissionTest.buildRacerLikeIR`** verbatim (player + 1 rival, 3-waypoint track, race scene, `start = "race"`). Rationale: keeps INV-8 in lockstep with the sibling tests' fixture; any future fixture refactor surfaces at next test run (T-11.2-08-02 mitigation).
3. **Negative assertion checks BOTH `#include "_zone_` AND `_tileset.h"` substrings** (logical OR). Rationale: T-11.2-08-01 mitigation — catches both include-form retrofits and any other tileset-header reference shape. A maintainer encountering a third retrofit shape can extend the OR list.
4. **Did NOT use `git stash`** when verifying that the 2 `TrackSynthesizerCircuitShapeTest` failures pre-date plan 08. Used a temporary `mv` to `/tmp/` instead, per the project rule prohibiting `git stash` in worktrees (it shares state with the main checkout).
