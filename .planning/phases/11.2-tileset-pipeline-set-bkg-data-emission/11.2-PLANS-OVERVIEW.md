4. **ROM-build smoke test is BLOCKING** — per user-memory `feedback_rom_build_smoke_test_for_codegen_phases.md`. Plan 12 must run a CLEAN `:buildRom` for all 4 games and fail the phase if any one regresses. JVM-tier GREEN is not sufficient for a phase touching `GBDKPipelineV2` + `SceneVisitor` + `GbktPlugin`.
5. **REQ-5 visual closure is NOT in 11.2** — it happens during the resumed `/gsd-execute-phase 11.1`. Plan 12's success message must explicitly hand off to that resume, NOT close the SPEC's REQ-5 from inside 11.2.
6. **png2asset CLI assumptions A1+A2** carry RESEARCH-flagged risk. Plan 02 closes them via a manual spike BEFORE plan 03 commits the flag set. If the spike reveals different flags work better, plan 03's task action updates accordingly — this is the safety valve.
