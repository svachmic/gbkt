<objective>
Implement the `ConvertZoneTilesetsTask` Gradle task class. For each entry in `game_metadata.json`'s `zoneTilesets` array (produced by plan 01), invoke GBDK's `png2asset` against the referenced PNG and synthesize a `_zone_<sanitized>_tileset.h` header whose `#define` aliases reach SceneVisitor's emission (plan 05) without source-file mutation. Fail-fast on missing tools, missing PNGs, malformed dimensions, and oversized tilesets.

Purpose: D-A1 — task lives in `gbkt-gradle-plugin/`, sibling to `ConvertSpritesTask`, no base-class extraction. D-A3 — symbolic count via header `#define` decouples Gradle task from codegen literal flow. D-B2 — pixel array lives in HOME bank (no `-b` flag to png2asset). D-B4 — flat output path. D-C1..C4 — four fail-fast modes locked. D-claude-1 — flag set imported from plan 02's spike log. D-claude-2 — sanitizer reused inline, no helper.

Output: A new task CLASS only. Plugin wiring (registering the task + adding `dependsOn` edges) lands in plan 04 to keep the diff atomic. After this plan, the test suite for the task passes against fixture metadata; the task is not yet invoked by any real build.
