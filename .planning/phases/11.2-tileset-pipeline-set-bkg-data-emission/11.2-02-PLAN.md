<task type="checkpoint:human-action" gate="blocking">
  <name>Task 1: Manual png2asset spike + evidence capture</name>
  <what-built>This task is human-driven because it manually invokes png2asset on a fixed PNG and captures stdout/stderr/help-text/produced-C-output to disk as evidence. Claude can drive the bash commands; the human only needs to confirm GBDK is installed and the spike output looks sane.</what-built>
  <how-to-verify>
    Run the spike commands in sequence and capture each output:

    1. Locate png2asset:
       ```
       PNG2ASSET=$(find /opt/gbdk-2020 ~/gbdk-2020 /usr/local /Applications -name png2asset 2>/dev/null | head -1)
       echo "Found: $PNG2ASSET"
       ```
       If empty, set `GBDK_HOME` and retry; do NOT continue until $PNG2ASSET resolves to an executable.

    2. Create the evidence dir:
       ```
       mkdir -p .planning/phases/11.2-tileset-pipeline-set-bkg-data-emission/evidence/png2asset-spike
       cd .planning/phases/11.2-tileset-pipeline-set-bkg-data-emission/evidence/png2asset-spike
       ```

    3. Capture help text:
       ```
       "$PNG2ASSET" --help 2>&1 | tee png2asset-help.txt
       # If --help unsupported, try -h or just $PNG2ASSET (no args)
       ```

    4. Run the RESEARCH-proposed flag set against banks/checker.png:
       ```
       cp "$OLDPWD/gbkt-examples/banks/res/tiles/checker.png" .
       "$PNG2ASSET" checker.png -o checker.c -map -spr8x8 -bpp 2 -keep_palette_order -noflip 2>&1 | tee invocation-1.log
       ls -la checker.{c,h} 2>/dev/null
       cat checker.c | head -30
       ```

    5. If invocation-1 fails on `-bpp 2`, try without:
       ```
       "$PNG2ASSET" checker.png -o checker.c -map -spr8x8 -keep_palette_order -noflip 2>&1 | tee invocation-2.log
       ```

    6. Capture failure modes (each produces a file you save):
       ```
       # Missing PNG
       "$PNG2ASSET" nonexistent.png -o nonexistent.c -map -spr8x8 2>&1 | tee missing-png.log; echo "exit=$?" >> missing-png.log

       # Truncated/malformed PNG (write 4 garbage bytes as a "PNG")
       printf '\x89PN' > malformed.png
       "$PNG2ASSET" malformed.png -o malformed.c -map -spr8x8 2>&1 | tee malformed-png.log; echo "exit=$?" >> malformed-png.log
       ```

    7. Write `spike-log.md` capturing:
       - Locked flag set (the one that produced valid checker.c — likely either invocation-1 or invocation-2)
       - Exact symbol name png2asset chose for the byte array (grep `const.*_tiles\[` checker.c)
       - Byte count in the array (should be 4 tiles × 16 bytes = 64; verify)
       - Whether png2asset also emitted a .h or only a .c (RESEARCH §A2 expects .c only)
       - Failure-mode notes: how png2asset exits when PNG missing/malformed (informs D-C1/C2/C4 — though Kotlin-side IHDR parsing is the primary guard per D-C4, we want to know what the secondary failure looks like)

    Expected: invocation-1 succeeds; checker.c contains `const uint8_t checker_tiles[64] = { ... }` (or close variant); failure modes produce non-zero exit with a stderr message. Plan 03 imports the locked flag set verbatim.
  </how-to-verify>
