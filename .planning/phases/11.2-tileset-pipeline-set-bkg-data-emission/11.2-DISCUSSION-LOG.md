## Area 3: Build-time failure-mode policy

### Q3.1 — png2asset missing

| Option | Description | Selected |
|--------|-------------|----------|
| Fail-fast loud, reuse existing GBDK detection error | Symmetric UX with sprites | ✓ |

### Q3.2 — Tileset PNG missing

### Q3.3 — PNG > 192 tiles

| Option | Description | Selected |

| Defer cap entirely | Leaks deferred scope back into 11.2 | |

**User's choice:** Fail-fast with cap citation. **D-C3.**

### Q3.4 — Bad PNG dimensions

| Option | Description | Selected |
|--------|-------------|----------|
