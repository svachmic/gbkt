- `SemanticValidationPass` reports `ANLZ-07` error when > 8 BACKGROUND or > 8 SPRITE palettes are declared with a GBC target

## Decisions Made

- **GBC mode bridge via gbkt-build.properties**: Rather than making `CompileRomTask` depend on gbkt-lang at runtime, GBC target is serialized to a properties file by `GenerateCTask` and deserialized by `CompileRomTask`. This preserves the existing Gradle plugin architecture.
- **SemanticValidationPass only validates GBC targets**: The 8-palette hardware limit only applies to GBC hardware. DMG games don't have palettes so the check is skipped for `GbcTarget.DMG`.
- **ANLZ-07 diagnostic ID**: Assigned a new ID for GBC-specific hardware limit violations, separate from ANLZ-01 (duplicate IDs) and ANLZ-05 (raw() usage).
