**CEmitter.kt changes:**

The existing `CEmitter.emit(file: CFile): String` is a pure function on a Kotlin `object`. Add an optional `collector: SourceMapCollector? = null` parameter. When non-null, the emitter tracks the current output line number (1-based). As each statement is emitted, if it has a non-null `sourceLocation`, call `collector.record(lineNumber, sourceLocation, irNodeType)`.

Implementation approach:
1. Add a local `var lineNumber = 1` at the top of `emit()`.
2. Every `appendLine()` call increments `lineNumber` (or count newlines in the appended string).
3. Before emitting each `CStatement` in `emitStatement()`, check `stmt.sourceLocation` and record to collector. Pass `lineNumber` context through the emit chain.
4. The simplest approach: change the internal emit methods to return the number of lines they emitted (or use a wrapper that counts), and record mappings at statement entry points. Alternatively, wrap `buildString { }` with a counting delegate.

A practical approach: Instead of threading lineNumber through all emit methods, emit the full string first with `emit(file)`, then perform a second pass to map line numbers. BUT this loses the per-statement association. Better: Add `collector` parameter to `emitStatement` and `emitFunction`. In `emitStatement`, before appending the statement's first line, record `(currentLineInFunction + functionStartLine, stmt.sourceLocation)`. Track line offsets per function by counting newlines in the output of each function block.

RECOMMENDED concrete approach: Use a `LineTrackingBuilder` wrapper around `StringBuilder` that intercepts `appendLine()` to increment a counter. This avoids threading line numbers through every method:
```kotlin
private class LineTrackingBuilder(
    private val sb: StringBuilder = StringBuilder(),
    private val collector: SourceMapCollector?,
    var lineNumber: Int = 1
) {
    fun appendLine(s: String = "") { sb.appendLine(s); lineNumber++ }
    fun append(s: String) { sb.append(s) }
    fun recordMapping(loc: SourceLocation?, irNodeType: String? = null, symbol: String? = null) {
        collector?.record(lineNumber, loc, irNodeType, symbol)
    }
    override fun toString() = sb.toString()
}
```

Then refactor `emit()` to use `LineTrackingBuilder` instead of raw `buildString`, calling `recordMapping()` before each statement that has a sourceLocation.

IMPORTANT: `CEmitter` is an `object` (singleton). All state MUST be local to `emit()` — no mutable properties on the object. The `LineTrackingBuilder` is created per `emit()` call.

**GenerationResultWrapper changes (BackendReflection.kt):**

Add a method to extract source map JSON per file via reflection:
```kotlin
fun getSourceMapJsonForFile(filename: String): String? {
    val filesMap = result.javaClass.getMethod("getFiles").invoke(result) as Map<String, Any>
    val generatedFile = filesMap[filename] ?: return null
    return try {
        generatedFile.javaClass.getMethod("getSourceMapJson").invoke(generatedFile) as String?
    } catch (e: NoSuchMethodException) {
        null  // Backward compat: old GeneratedFile without sourceMapJson
    }
}
```
