## Decisions Made

- `captureV2Location()` is a top-level `internal` function in `SourceLocationCapture.kt` (not a method on each builder) — single source of truth, consistent filtering logic across all builders
- Block-producing ops (`ifOp`/`whileOp`/`forOp`/`whenever`/`fade`) capture location eagerly before executing the body block — ensures the reported location is the outer call site, not something inside the nested lambda
- `SystemIR.sourceLocation` added as abstract interface property (mirrors `SystemIR.id` pattern) — all 6 subtypes `override val sourceLocation` in their constructor
