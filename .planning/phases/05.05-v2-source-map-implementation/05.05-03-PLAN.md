**ErrorEnhancer.kt changes:**

1. Update `formatEnhancedErrors()` to produce Rust-style output per locked decision. The current format shows basic error info. The new format for each error should be:

   For mapped errors (kotlinLocation != null):
   ```
   Error N:
     C code: {cFile}:{cLine}:{cCol}
     Message: '{errorMessage}'

     --> {kotlinFile}:{kotlinLine}
     |  {irNodeType or symbol context}
     ^  {errorMessage}

     Suggestion: {suggestion}
   ```

   For unmapped errors (kotlinLocation == null):
   ```
   Error N:
     C code: {cFile}:{cLine}:{cCol}
     Message: '{errorMessage}'
     (no DSL mapping -- generated scaffolding)

     Suggestion: {suggestion}
   ```

2. Add grouping logic: after enhancing errors, group `EnhancedError` list by `kotlinLocation?.let { "${it.kotlinFile}:${it.kotlinLine}" }`. Errors sharing the same DSL line appear together under one header. Errors with null kotlinLocation are grouped as "(unmapped)".

3. Update `EnhancedError` to carry additional fields:
   - `val irNodeType: String? = null` (from parsed source map)

   Modify `enhanceErrors()`: when looking up the source map for each error's C line, also extract `irNodeType` from `ParsedSourceMapping` and include it in `EnhancedError`.

**CompileRomTask.kt changes:**

Update `enhanceErrorMessage()` to support multi-file source maps:
- Currently it calls `SourceMapLoader.findSourceMapFile(sourceFile)` for a single file.
- For v2 multi-file output, the `sourceFile` might be a directory containing multiple C files and maps.
- Check: if `SourceMapLoader.findSourceMapFile(sourceFile)` succeeds, use it (single-file path).
- Also try `SourceMapLoader.loadAllMaps(sourceFile.parentFile)` to get all maps for the generated directory.
- When looking up an error's source map, use the error's file name (from `GbdkError.file`) to select the right map.

The key change: `enhanceErrorMessage` currently passes a single `ParsedSourceMap?` to `ErrorEnhancer.enhanceErrors()`. Update it to pass the correct map for each error based on the error's reported C file.

   ```kotlin
   private fun setupSourceMapFileWatcher() {
       VirtualFileManager.getInstance().addVirtualFileListener(object : VirtualFileListener {
           override fun contentsChanged(event: VirtualFileEvent) {
               if (!autoRefreshCheckbox.isSelected) return
               if (isDisposed) return
               if (event.file.name.endsWith(".gbkt.map")) {
                   // Verify file belongs to this project
                   val projectPath = project.basePath ?: return
                   if (event.file.path.startsWith(projectPath)) {
                       ApplicationManager.getApplication().invokeLater {
                           if (!isDisposed) {
                               loadCombinedContent()
                               updateStatus("Auto-refreshed from source map change", false)
                           }
                       }
                   }
               }
           }
       }, /* disposable = */ this)
   }
   ```

7. Add a DSL caret listener using `EditorFactory.getInstance().addEditorFactoryListener()` inside the class initializer (alongside `setupAutoRefreshListener()` and `setupSourceMapFileWatcher()`):

   ```kotlin
   private fun setupDslCaretListener() {
       EditorFactory.getInstance().addEditorFactoryListener(object : EditorFactoryListener {
           override fun editorCreated(event: EditorFactoryEvent) {}
           override fun editorReleased(event: EditorFactoryEvent) {}
       }, this)

       // Listen for caret moves across all open editors
       EditorFactory.getInstance().eventMulticaster.addCaretListener(object : CaretListener {
           override fun caretPositionChanged(event: CaretEvent) {
               if (!autoRefreshCheckbox.isSelected) return
               if (isDisposed) return
               val editor = event.editor
               val vFile = FileDocumentManager.getInstance().getFile(editor.document) ?: return
               // Only react to .kt files in this project
               val projectPath = project.basePath ?: return
               if (!vFile.path.startsWith(projectPath)) return
               if (vFile.extension != "kt") return
               val kotlinLine = event.newPosition.line + 1  // convert 0-based to 1-based
               val matches = codegenService.findCLinesForKotlinLocation(vFile.path, kotlinLine)
               if (matches.isNotEmpty()) {
                   val (cFile, cLine) = matches.first()
                   ApplicationManager.getApplication().invokeLater {
                       if (!isDisposed) scrollToMatchingCLine(cFile, cLine)
                   }
               }
           }
       }, this)
   }
   ```

   Call `setupDslCaretListener()` from the class initializer after `setupSourceMapFileWatcher()`.

   The `CaretListener` is added to `EditorFactory.getInstance().eventMulticaster` with `this` (a `Disposable`) as the parent, so it auto-unregisters when the tool window is disposed.
