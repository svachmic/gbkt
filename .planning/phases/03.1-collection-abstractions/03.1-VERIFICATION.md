## Summary

Phase 3.1 goal is fully achieved. All 5 success criteria from ROADMAP.md are satisfied:

1. **18 IR types** exist as sealed subtypes — 4 descriptor types (with `sizeBytes`), 7 operation statements, 7 expressions. All exhaustive `when` expressions in `IRWalker`, `IRSubstitution`, `RecordingContext`, and `SimulationContext` are updated with no `else` branches.

2. **DSL delegate layer** is complete — `hashtable()`, `collPool()`, `ringBuffer()`, `fixedSlots()` factory functions produce property delegates that auto-register with `GameScopeContext` on first access. The generic `<T>` syntax from the ROADMAP description was intentionally deferred to a future phase; the explicit-type API satisfies the recording-into-IR requirement.

3. **GBDK backend generates fully static C** — `CollectionsCodegen.kt` produces `static` arrays and helper functions for all 4 collection types. A dedicated test asserts no `malloc`/`calloc`/`realloc`/`free` calls appear in output.

4. **Backend trait interface** `CollectionCodegen` lives in `gbkt-backend-api` and decouples the contract from the GBDK implementation, enabling alternative backends.

5. **Compile-time `sizeBytes`** is queryable on all 4 IR descriptor types and exposed on domain wrapper classes, ready for Phase 4 RAM budget analysis.
