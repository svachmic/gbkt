**CRITICAL NAMING: Use `IRColl` prefix to avoid collision with existing entity Pool IR (IRPoolSpawn, IRPoolUpdate, etc.)**

**Collection descriptor types (data classes implementing IRStatement):**
These represent the collection declaration itself (emitted once at game build time).

1. `IRCollHashTable(name: String, keyType: GBVar.VarType, valueType: GBVar.VarType, size: Int, sourceLocation: SourceLocation? = null) : IRStatement`
   - `sizeBytes: Int get() = size * (keyType.size + valueType.size + 1)` — +1 for `used` byte per slot

2. `IRCollPool(name: String, elementType: GBVar.VarType, capacity: Int, sourceLocation: SourceLocation? = null) : IRStatement`
   - `sizeBytes: Int get() = capacity * (elementType.size + 1) + 1` — +1 per slot for free-list bitmap, +1 for count

3. `IRCollRingBuffer(name: String, elementType: GBVar.VarType, capacity: Int, sourceLocation: SourceLocation? = null) : IRStatement`
   - `sizeBytes: Int get() = capacity * elementType.size + 3` — +3 for head, tail, count bytes

4. `IRCollFixedSlots(name: String, elementType: GBVar.VarType, count: Int, sourceLocation: SourceLocation? = null) : IRStatement`
   - `sizeBytes: Int get() = count * elementType.size + (if (count <= 8) 1 else 2)` — UINT8 bitfield for <=8, UINT16 for 9-16

**Collection operation statements (data classes implementing IRStatement):**
These represent runtime operations emitted inside script blocks.

5. `IRCollHashTableInsert(tableName: String, key: IRExpression, value: IRExpression, sourceLocation: SourceLocation? = null) : IRStatement`
6. `IRCollHashTableClear(tableName: String, sourceLocation: SourceLocation? = null) : IRStatement`
7. `IRCollPoolAlloc(poolName: String, resultVar: String, sourceLocation: SourceLocation? = null) : IRStatement` — stores allocated index into resultVar
8. `IRCollPoolFree(poolName: String, index: IRExpression, sourceLocation: SourceLocation? = null) : IRStatement`
9. `IRCollRingBufferPush(bufferName: String, value: IRExpression, sourceLocation: SourceLocation? = null) : IRStatement`
10. `IRCollFixedSlotsClaim(slotsName: String, resultVar: String, sourceLocation: SourceLocation? = null) : IRStatement`
11. `IRCollFixedSlotsRelease(slotsName: String, index: IRExpression, sourceLocation: SourceLocation? = null) : IRStatement`

**Collection expression types (data classes implementing IRExpression):**
These return values usable in conditions/assignments.

12. `IRCollHashTableLookup(tableName: String, key: IRExpression) : IRExpression` — returns value or 0xFF
13. `IRCollPoolActiveCount(poolName: String) : IRExpression`
14. `IRCollPoolHasSpace(poolName: String) : IRExpression` — returns 1/0
15. `IRCollRingBufferPop(bufferName: String) : IRExpression`
16. `IRCollRingBufferPeek(bufferName: String) : IRExpression`
17. `IRCollRingBufferCount(bufferName: String) : IRExpression`
18. `IRCollFixedSlotsIsActive(slotsName: String, index: IRExpression) : IRExpression`

Place all types in package `io.github.gbkt.core.ir`. Import `GBVar` from `io.github.gbkt.core.ir.Variables`. Follow MPL-2.0 license header convention.

Test sizeBytes calculations with concrete examples:
- HashTable(U8 key, U16 value, size=64) should be 64*(1+2+1) = 256 bytes
- Pool(U8 element, capacity=16) should be 16*(1+1)+1 = 33 bytes
- RingBuffer(U8 element, capacity=128) should be 128*1+3 = 131 bytes
- FixedSlots(U16 element, count=3) should be 3*2+1 = 7 bytes (<=8 so UINT8 bitfield)
- FixedSlots(U8 element, count=12) should be 12*1+2 = 14 bytes (>8 so UINT16 bitfield)
