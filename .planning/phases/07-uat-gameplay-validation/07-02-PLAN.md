```kotlin
// .sym file format: "DEF _score 00:C100"
// Parse: parts[0]=="DEF", parts[1]=="_score" (strip "_"), parts[2]="00:C100" (extract hex after ":")
symFile.readLines().forEach { line ->
    val parts = line.trim().split("\\s+".toRegex())
    if (parts.size >= 3 && parts[0] == "DEF" && parts[1].startsWith("_")) {
        val name = parts[1].removePrefix("_")
        val address = parts[2].substringAfter(":").toInt(16)
    }
}
```

Type inference heuristic from NamedVariablesTab:

```kotlin
fun inferVariableType(name: String): String {
    val lower = name.lowercase()
    return when {
        lower.contains("16") || lower.contains("addr") || lower.contains("ptr") -> "UINT16"
        lower.contains("dx") || lower.contains("dy") || lower.contains("vel") || lower.contains("dir") -> "INT8"
        else -> "UINT8"
    }
}
```

  <behavior>
    SavestateManager:
    - save(emulator, file) snapshots WRAM (0xC000-0xDFFF, 8KB) + OAM (0xFE00-0xFE9F, 160 bytes) + HRAM (0xFF80-0xFFFE, 127 bytes) to file
    - load(emulator, file) restores the saved state by writing bytes back via MemoryAccess
    - File format: simple binary — 4-byte magic "GBST", then WRAM bytes, then OAM bytes, then HRAM bytes
    - Emulator must be paused before save/load
    - Round-trip: save then load produces identical memory contents

    VisualDiff:
    - compare(expected, actual, tolerance=0) compares two PNG files pixel-by-pixel
    - Returns DiffResult(match: Boolean, diffCount: Int, totalPixels: Int, diffImage: File?)
    - tolerance: percentage of pixels that can differ (0 = pixel-perfect, 5 = allow 5% difference)
    - When mismatch: generates a diff image highlighting changed pixels in red
    - Diff image written to same directory as actual image, named {actual}_diff.png
    - Both images must be 160x144, throws on size mismatch
  </behavior>
  <action>
    Create `SavestateManager.kt` with:
    - `object SavestateManager`
    - Constants: `WRAM_START = 0xC000`, `WRAM_SIZE = 0x2000` (8KB), `OAM_START = 0xFE00`, `OAM_SIZE = 0xA0` (160 bytes), `HRAM_START = 0xFF80`, `HRAM_SIZE = 0x7F` (127 bytes)
    - `MAGIC = byteArrayOf('G'.code.toByte(), 'B'.code.toByte(), 'S'.code.toByte(), 'T'.code.toByte())`
    - `fun save(emulator: GbEmulator, file: File)` — require(emulator.isPaused()), read all bytes from memory ranges, write magic + bytes to file using DataOutputStream
    - `fun load(emulator: GbEmulator, file: File)` — require(emulator.isPaused()), verify magic, write bytes back via writeByte()
    - Total file size: 4 (magic) + 8192 (WRAM) + 160 (OAM) + 127 (HRAM) = 8483 bytes

    Create `VisualDiff.kt` with:
    - `data class DiffResult(val match: Boolean, val diffCount: Int, val totalPixels: Int, val diffImage: File?)`
    - `object VisualDiff`
    - `fun compare(expected: File, actual: File, tolerance: Double = 0.0, diffOutputDir: File? = null): DiffResult`
    - Read both PNGs via ImageIO.read(). Require both 160x144.
    - Compare each pixel. Count mismatches.
    - If diffCount / totalPixels > tolerance, match=false. Generate diff image: copy actual, paint mismatched pixels red (0xFF0000).
    - tolerance=0.0 means pixel-perfect. tolerance=0.05 means 5% of pixels can differ.

    - VisualDiff: create two identical 160x144 BufferedImages, save as PNG, verify compare returns match=true
    - VisualDiff: create two different images, verify match=false and diff image created with red pixels
    - VisualDiff: test tolerance — 5% diff with 5% tolerance should pass
    - VisualDiff: test size mismatch throws
