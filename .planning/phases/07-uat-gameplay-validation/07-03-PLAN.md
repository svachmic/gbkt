<objective>
Build the AgentDebugSession orchestrator that provides a unified API over all agent debugging primitives (InputScript, ScreenshotCapture, VariableInspector, SavestateManager, VisualDiff).

Purpose: Agent DX toolkit primitives from Plans 01 and 02 are individual components. AgentDebugSession is the single entry point that agents (and Gradle tasks) use to drive all debugging operations on a ROM. It manages the emulator lifecycle, wires the EventBus for input injection, and provides high-level convenience methods.

Output: AgentDebugSession and AgentSessionConfig classes with lifecycle management and tests.
</objective>

<task type="auto" tdd="true">
  <name>Task 2: AgentDebugSession orchestrator</name>
  <files>
    gbkt-emulator/src/main/kotlin/io/github/gbkt/emulator/agent/AgentDebugSession.kt,
    gbkt-emulator/src/test/kotlin/io/github/gbkt/emulator/agent/AgentDebugSessionTest.kt
  </files>
  <behavior>
    - Constructor takes AgentSessionConfig
    - start() creates CoffeeGbEmulator, calls start() then pause(), initializes VariableInspector from symFile
    - stop() calls emulator.stop() and nulls references
    - runFrames(n) calls stepFrame() n times, increments internal frameCount
    - captureScreenshot(label) captures frame buffer, reads watchVariables for sidecar, delegates to ScreenshotCapture
    - executeInputScript(script) delegates to InputScriptPlayer (passes eventBus from CoffeeGbEmulator)
    - readVariable(name) delegates to VariableInspector.readNamed(name)
    - readAllVariables() delegates to VariableInspector.readAll()
    - saveState(file) delegates to SavestateManager.save()
    - loadState(file) delegates to SavestateManager.load()
    - diffScreenshots(expected, actual, tolerance) delegates to VisualDiff.compare()
    - getDebugLog() delegates to emulator.getDebugLog()
    - frameCount property tracks total frames advanced
    - All methods throw ISE if start() hasn't been called yet
  </behavior>
  <action>
    Create `AgentDebugSession.kt` with:
    - `class AgentDebugSession(private val config: AgentSessionConfig)`
    - Private fields: `emulator: CoffeeGbEmulator?`, `inspector: VariableInspector?`, `inputPlayer: InputScriptPlayer?`
    - `var frameCount: Int = 0; private set`
    - `fun start()` — creates CoffeeGbEmulator from config.toEmulatorConfig(), starts, pauses, creates VariableInspector, creates InputScriptPlayer
    - Important: InputScriptPlayer needs the eventBus from CoffeeGbEmulator. Access via `(emulator as CoffeeGbEmulator).eventBus!!` after start().
    - `fun stop()` — emulator?.stop(), null out all references
    - `fun runFrames(n: Int)` — repeat(n) { emulator!!.stepFrame() }, frameCount += n
    - `fun captureScreenshot(label: String): File` — reads watchVariables via inspector.readAll() filtered to config.watchVariables (or all if empty), calls ScreenshotCapture.capture()
    - `fun executeInputScript(script: InputScript)` — delegates to inputPlayer!!.play(script). Update frameCount by script's total frame count.
    - `fun readVariable(name: String): Int?` — inspector!!.readNamed(name)
    - `fun readAllVariables(): Map<String, Int>` — inspector?.readAll() ?: emptyMap()
    - `fun saveState(file: File)` — SavestateManager.save(emulator!!, file)
    - `fun loadState(file: File)` — SavestateManager.load(emulator!!, file)
    - `fun diffScreenshots(expected: File, actual: File, tolerance: Double = 0.0): DiffResult` — VisualDiff.compare(expected, actual, tolerance)
    - `fun getDebugLog() = emulator!!.getDebugLog()`
    - All !! access wrapped with `checkNotNull(emulator) { "AgentDebugSession not started. Call start() first." }`
    - Implement `Closeable` for use-with-resources: `override fun close() = stop()`

    Tests:
    - Use TestRomFactory or create a minimal test that verifies session lifecycle (start, runFrames, stop) without crashing. If TestRomFactory provides a test ROM, use it. Otherwise, test with a stub/mock GbEmulator.
    - Test that calling methods before start() throws ISE
    - Test that frameCount increments correctly after runFrames()
    - Test readVariable delegation (with mock)
    - Test AgentSessionConfig.toEmulatorConfig() produces correct headless config
  </action>
