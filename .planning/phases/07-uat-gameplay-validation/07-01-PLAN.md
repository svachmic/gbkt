  <name>Task 1: InputScript DSL and InputScriptPlayer</name>
  <files>
    gbkt-emulator/src/main/kotlin/io/github/gbkt/emulator/agent/InputScript.kt,
    gbkt-emulator/src/main/kotlin/io/github/gbkt/emulator/agent/InputScriptPlayer.kt,
    gbkt-emulator/src/test/kotlin/io/github/gbkt/emulator/agent/InputScriptTest.kt,
    gbkt-emulator/src/test/kotlin/io/github/gbkt/emulator/agent/InputScriptPlayerTest.kt
  </files>
  <behavior>
    - InputScript DSL builds a list of InputStep entries: press(button, frames), hold(button), release(button), wait(frames)
    - press(Button.A) creates a press+release pair over 1 frame by default
    - press(Button.RIGHT, frames=30) holds for 30 frames then releases
    - wait(60) advances 60 frames with no input
    - hold(Button.LEFT) presses without releasing (until explicit release)
    - InputScriptPlayer.play(script) dispatches ButtonPressEvent/ButtonReleaseEvent into EventBus and calls stepFrame() for timing
    - Player requires emulator to be in paused state before play()
    - Button enum maps to Coffee-GB button types: UP, DOWN, LEFT, RIGHT, A, B, START, SELECT
  </behavior>
  <action>
    Create `InputScript.kt` with:
    - `enum class Button { UP, DOWN, LEFT, RIGHT, A, B, START, SELECT }` mapping to Coffee-GB button types
    - `sealed interface InputStep` with subclasses: `Press(button, frames)`, `Hold(button)`, `Release(button)`, `Wait(frames)`
    - `class InputScript(val steps: List<InputStep>)` — immutable data holder
    - `fun inputScript(block: InputScriptBuilder.() -> Unit): InputScript` — top-level DSL entry
    - `class InputScriptBuilder` with methods: `press(button, frames=1)`, `hold(button)`, `release(button)`, `wait(frames)`

    Create `InputScriptPlayer.kt` with:
    - `class InputScriptPlayer(private val emulator: GbEmulator)` — note: needs access to CoffeeGbEmulator's internal `eventBus`. Accept `eventBus: EventBusImpl` as constructor parameter alongside emulator.
    - `fun play(script: InputScript)` — iterates steps, dispatching events and calling stepFrame()
    - For Press(button, N): dispatch ButtonPressEvent, stepFrame() N times, dispatch ButtonReleaseEvent
    - For Hold(button): dispatch ButtonPressEvent only
    - For Release(button): dispatch ButtonReleaseEvent only
    - For Wait(N): stepFrame() N times
    - Require emulator.isPaused() before play(), throw ISE otherwise
    - Map `Button` enum to Coffee-GB `eu.rekawek.coffeegb.joypad.Button` enum values

    Tests:
    - InputScriptTest: verify DSL builds correct step list (no emulator needed)
    - InputScriptPlayerTest: use a mock/stub for EventBus dispatching to verify correct events fired in correct order. For the stepFrame verification, count invocations. Use TestRomFactory pattern from existing tests if a real emulator instance is needed, otherwise stub the GbEmulator interface.
  </action>
  <verify>
    <automated>./gradlew :gbkt-emulator:test --tests "*InputScript*" -x detekt -x spotlessCheck</automated>
  </verify>
  <done>InputScript DSL constructs correct step sequences. InputScriptPlayer dispatches correct ButtonPress/ButtonRelease events with correct frame timing. All tests green.</done>
</task>
