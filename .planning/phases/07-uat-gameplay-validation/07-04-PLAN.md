  <action>
    Create all 5 task classes following the EmulatorTestTask pattern (abstract class, DefaultTask, @Input/@InputFile properties, @TaskAction).

    **CaptureScreenshotTask:**
    - group = "gbkt-agent"
    - Properties: romFile (InputFile), frames (Input, convention=60), label (Input, convention="screenshot"), symFile (InputFile, optional), screenshotDir (DirectoryProperty)
    - @TaskAction: Create AgentSessionConfig, create AgentDebugSession, start(), runFrames(frames), captureScreenshot(label), stop(). Log output path.
    - Usage: `./gradlew captureScreenshot --frames=120 --label=title_screen`

    **RunInputScriptTask:**
    - group = "gbkt-agent"
    - Properties: romFile (InputFile), scriptFile (InputFile -- a .kts file defining an InputScript), symFile (optional)
    - @TaskAction: Load script file, compile/evaluate it to get InputScript object, create session, start, executeInputScript, optionally capture final screenshot, stop.
    - For simplicity in v1: instead of eval'ing .kts files (complex), accept a simple JSON or line-based format:
      ```
      wait 60
      press RIGHT 30
      press A
      wait 120
      screenshot after_input
      ```
    - Parse the text file into InputScript, execute.
    - Usage: `./gradlew runScript --script=scripts/pong_test.txt`

    **ReadVariableTask:**
    - group = "gbkt-agent"
    - Properties: romFile (InputFile), frames (Input, convention=60), variableName (Input), symFile (InputFile, optional)
    - @TaskAction: Create session, start, runFrames, readVariable(name), print value to logger.lifecycle. If variableName is "all", readAllVariables and print all.
    - Usage: `./gradlew readVariable --variable=score --frames=300`

    **SaveStateTask:**
    - group = "gbkt-agent"
    - Properties: romFile (InputFile), frames (Input), stateFile (RegularFileProperty -- output path), symFile (optional)
    - Can also operate in "load" mode: loadStateFile (InputFile, optional) -- if provided, load state first, then run frames, then optionally save
    - @TaskAction: Create session, start, optionally loadState if loadStateFile set, runFrames, saveState(stateFile), stop.
    - Usage: `./gradlew saveState --frames=300 --state-file=build/gbkt/states/checkpoint.gbst`

    **DiffScreenshotsTask:**
    - group = "gbkt-agent"
    - Properties: expectedFile (InputFile), actualFile (InputFile), tolerance (Input, convention=0.0)
    - @TaskAction: Call VisualDiff.compare(). Log result. If match=false, throw GradleException with diff count info. Diff image path logged.
    - Usage: `./gradlew diffScreenshots --expected=ref.png --actual=current.png --tolerance=0.05`

    All tasks (except DiffScreenshotsTask) depend on "buildRom" so the ROM is current. All use headless mode. All print results to logger.lifecycle for agent consumption.
