```bash
mkdir -p gbkt-examples/racer/src/test/resources/golden
```

**Session flow:**

1. **Boot and load context:**
   - `emulator_start(game = "racer")`
   - `emulator_get_playbook()`
   - `emulator_describe_game()`
   - `emulator_step(frames = 120)`

2. **Title screen verification:**
   - `emulator_assert`: `scene_is: "title"`
   - Check for title text (may be "RACER" or game-specific — read from playbook)
   - `emulator_screenshot(label = "racer-title")` — golden #1
   - `emulator_save_state(label = "title")`
   - Report: confirm GBC color mode visible (colors vs DMG grey)

3. **Title to race transition:**
   - `emulator_press(button = "start")`
   - `emulator_wait_for_scene(scene = "race", maxFrames = 120)`
   - `emulator_assert`: `scene_is: "race"`, `variable_equals: lap=0`, `actor_visible: "car"`
   - `emulator_save_state(label = "race-start")`
   - `emulator_screenshot(label = "racer-race")` — golden #2

4. **Gameplay mechanics:**
   - Move car with D-pad: UP to accelerate, LEFT/RIGHT to steer
   - `emulator_press(button = "up", frames = 60)` — hold up for 1 second
   - `emulator_press(button = "right", frames = 30)` — steer right
   - Check `raceTime` is incrementing (raw frame count, NOT seconds)
   - Check `position` — starts at 1
   - Verify camera follows car (scrolling world)

5. **Lap detection:**
   - Navigate car to lap detection zone: `car.x < 50 AND car.y in [95, 115)`
   - May need to use `emulator_write_variable` to position car near zone for faster testing
   - Verify `lap` increments from 0 to 1
   - Complete 3 laps (or set `lap = 2` and trigger final lap)

6. **Results screen:**
   - After 3 laps: `emulator_wait_for_scene(scene = "results", maxFrames = 300)`
   - `emulator_assert`: `scene_is: "results"`
   - `emulator_screenshot(label = "racer-results")` — golden #3

7. **Move golden screenshots:**
   ```bash
   cp build/gbkt/screenshots/racer-title-*.png gbkt-examples/racer/src/test/resources/golden/racer-title.png
   cp build/gbkt/screenshots/racer-race-*.png gbkt-examples/racer/src/test/resources/golden/racer-race.png
   cp build/gbkt/screenshots/racer-results-*.png gbkt-examples/racer/src/test/resources/golden/racer-results.png
   ```

9. **Bug handling:** Fix immediately, regression test, atomic commit, `./gradlew test`, resume.

Run an interactive MCP play-test session for Shmup. This game tests entity pools (bullets, enemies), cooldown timers, and destroyAll() cleanup.

**Pre-session setup:**
```bash
/clear
mkdir -p gbkt-examples/shmup/src/test/resources/golden
```

**Session flow:**

1. **Boot and load context:**
   - `emulator_start(game = "shmup")`
   - `emulator_get_playbook()`
   - `emulator_describe_game()`
   - `emulator_step(frames = 120)`

2. **Title screen verification:**
   - `emulator_assert`: `scene_is: "title"`
   - `emulator_screenshot(label = "shmup-title")` — golden #1
   - `emulator_save_state(label = "title")`

3. **Title to gameplay:**
   - `emulator_press(button = "start")`
   - `emulator_wait_for_scene(scene = "gameplay", maxFrames = 120)`
   - `emulator_assert`: `scene_is: "gameplay"`, `variable_equals: score=0`, `variable_equals: lives=3`
   - `emulator_save_state(label = "gameplay-start")`

4. **Shooting mechanics:**
   - Press A to fire: `emulator_press(button = "a")`
   - `emulator_step(frames = 10)` — bullet should appear
   - Read `shootCooldown` — should be 8 (just fired)
   - Wait for cooldown: `emulator_step(frames = 10)`
   - Press A again: verify second bullet appears
   - Verify bullet pool (max 8 bullets) — fire 8+ times rapidly, verify pool limit

5. **Enemy spawning:**
   - `emulator_step(frames = 60)` — wait for first enemy wave (timer = 60 frames)
   - Read `waveTimer` — should reset after spawn
   - Verify enemy actors visible
   - `emulator_screenshot(label = "shmup-gameplay")` — golden #2 (with bullets AND enemies visible)

6. **Player movement:**
   - Move with D-pad: UP/DOWN/LEFT/RIGHT
   - Verify player actor position changes
   - Check `scrollY` incrementing (background scroll)

7. **Game over:**
   - `emulator_write_variable(name = "lives", value = 1)` — last life
   - Navigate player into enemy or advance frames until collision
   - `emulator_wait_for_scene(scene = "gameover", maxFrames = 600)`
   - `emulator_assert`: `scene_is: "gameover"`
   - `emulator_screenshot(label = "shmup-gameover")` — golden #3

8. **destroyAll() verification:**
   - From gameover, go back to title, then re-enter gameplay
   - Verify no stale bullets or enemies from previous run (pools cleared)

9. **Move golden screenshots:**
   ```bash
   cp build/gbkt/screenshots/shmup-title-*.png gbkt-examples/shmup/src/test/resources/golden/shmup-title.png
   cp build/gbkt/screenshots/shmup-gameplay-*.png gbkt-examples/shmup/src/test/resources/golden/shmup-gameplay.png
   cp build/gbkt/screenshots/shmup-gameover-*.png gbkt-examples/shmup/src/test/resources/golden/shmup-gameover.png
   ```

10. **Write UAT report:** `.planning/phases/07.2-interactive-game-uat/UAT-shmup.md`

11. **Bug handling:** Fix immediately, regression test, atomic commit, `./gradlew test`, resume.

12. `emulator_stop()`
