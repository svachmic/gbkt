**Pre-session setup:**
```bash
mkdir -p gbkt-examples/rpg-lite/src/test/resources/golden
```

**Session flow:**

1. **Boot and load context:**
   - `emulator_start(game = "rpg-lite")`
   - `emulator_get_playbook()`
   - `emulator_describe_game()`
   - `emulator_step(frames = 120)`

2. **Title screen verification:**
   - `emulator_assert`: `scene_is: "title"`
   - `emulator_screenshot(label = "rpg-lite-title")` — golden #1
   - `emulator_save_state(label = "title")`

3. **Title to town:**
   - `emulator_press(button = "start")`
   - `emulator_wait_for_scene(scene = "town", maxFrames = 120)`
   - `emulator_assert`: `scene_is: "town"`, `variable_equals: hp=30`, `variable_equals: gold=0`, `variable_equals: dungeonLevel=1`
   - `emulator_save_state(label = "town-start")`
   - `emulator_screenshot(label = "rpg-lite-town")` — golden #2

4. **Town mechanics — heal:**
   - Healing requires `gold >= 5 AND hp < 30`
   - Set conditions: `emulator_write_variable(name = "gold", value = 10)`, `emulator_write_variable(name = "hp", value = 20)`
   - Press A in town (heal button per playbook)
   - Read `hp` — should have increased
   - Read `gold` — should have decreased by 5

5. **Town to dungeon:**
   - Press A to enter dungeon (per playbook instructions)
   - `emulator_wait_for_scene(scene = "dungeon", maxFrames = 120)`
   - `emulator_assert`: `scene_is: "dungeon"`, `variable_equals: stepCount=0`
   - `emulator_save_state(label = "dungeon-start")`
   - `emulator_screenshot(label = "rpg-lite-dungeon")` — golden #3

6. **Dungeon movement and encounter:**
   - Move RIGHT to accumulate steps: `emulator_press(button = "right", frames = 60)`
   - Read `stepCount` — should be incrementing
   - Set stepCount near trigger: `emulator_write_variable(name = "stepCount", value = 59)`
   - Take one more step
   - `emulator_wait_for_scene(scene = "combat", maxFrames = 120)` — encounter at stepCount >= 60
   - `emulator_assert`: `scene_is: "combat"`
   - `emulator_screenshot(label = "rpg-lite-combat")` — golden #4
   - `emulator_save_state(label = "in-combat")`

7. **Combat resolution:**
   - Follow playbook combat instructions (press A to attack)
   - Wait for combat to resolve — should return to dungeon or gameover
   - If returned to dungeon: verify `stepCount` reset, `gold` may have increased

8. **Dungeon level progression:**
   - Navigate RIGHT toward dungeon exit: x >= 152
   - Use `emulator_write_variable` to position near exit if needed
   - Move RIGHT past exit threshold
   - `dungeonLevel` should increment from 1 to 2
   - Position should reset for new dungeon floor

9. **Game over path:**
   - `emulator_write_variable(name = "hp", value = 1)` — near death
   - Trigger combat encounter, take damage
   - `emulator_wait_for_scene(scene = "gameover", maxFrames = 300)`
   - `emulator_screenshot(label = "rpg-lite-gameover")` — golden #5

10. **Move golden screenshots:**
    ```bash
    cp build/gbkt/screenshots/rpg-lite-title-*.png gbkt-examples/rpg-lite/src/test/resources/golden/rpg-lite-title.png
    cp build/gbkt/screenshots/rpg-lite-town-*.png gbkt-examples/rpg-lite/src/test/resources/golden/rpg-lite-town.png
    cp build/gbkt/screenshots/rpg-lite-dungeon-*.png gbkt-examples/rpg-lite/src/test/resources/golden/rpg-lite-dungeon.png
    cp build/gbkt/screenshots/rpg-lite-combat-*.png gbkt-examples/rpg-lite/src/test/resources/golden/rpg-lite-combat.png
    cp build/gbkt/screenshots/rpg-lite-gameover-*.png gbkt-examples/rpg-lite/src/test/resources/golden/rpg-lite-gameover.png
    ```

11. **Write UAT report:** `.planning/phases/07.2-interactive-game-uat/UAT-rpg-lite.md`

12. **Bug handling:** Fix immediately, regression test, atomic commit, `./gradlew test`, resume.

13. `emulator_stop()`

- Dungeon exit at `x >= 152` increments `dungeonLevel` and resets position
- `fireball` ability declared but unused (no test needed)
- Town -> Dungeon -> Town loop via dungeon exit
