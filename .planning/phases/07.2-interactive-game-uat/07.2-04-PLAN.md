Run an interactive MCP play-test session for Explorer. This is the first RPG-genre game — tests HUD, torch gauge, encounters, zone transitions, pause menu, and combat.

**Pre-session setup:**
```bash
mkdir -p gbkt-examples/explorer/src/test/resources/golden
```

**Session flow:**

1. **Boot and load context:**
   - `emulator_start(game = "explorer")`
   - `emulator_get_playbook()`
   - `emulator_describe_game()`
   - `emulator_step(frames = 120)`

2. **Title screen verification:**
   - `emulator_assert`: `scene_is: "title"`
   - `emulator_screenshot(label = "explorer-title")` — golden #1
   - `emulator_save_state(label = "title")`

3. **Title to gameplay:**
   - `emulator_press(button = "start")`
   - `emulator_wait_for_scene(scene = "gameplay", maxFrames = 120)`
   - `emulator_assert`: `scene_is: "gameplay"`, `variable_equals: hp=100`, `variable_equals: stepCount=0`, `variable_equals: keys=0`, `variable_equals: torchLevel=255`
   - `emulator_save_state(label = "gameplay-start")`

4. **HUD verification:**
   - `emulator_observe()` — check winText field for HUD content
   - HUD should show: HP bar, torch level, keys count
   - `emulator_screenshot(label = "explorer-gameplay")` — golden #2 (with HUD visible)
   - Verify HUD text appears on WIN layer (not BG)

5. **Movement and step counting:**
   - Move RIGHT for 30 frames: `emulator_press(button = "right", frames = 30)`
   - Read `stepCount` — should have incremented
   - Read `torchLevel` — should have decremented (decrements per step)
   - Move in other directions — verify smooth 2px movement (vs Dungeon's 8px grid)

6. **Pause menu:**
   - `emulator_press(button = "start")` — should open pause
   - `emulator_wait_for_scene(scene = "pause", maxFrames = 60)`
   - `emulator_assert`: `scene_is: "pause"`
   - Verify menu items visible: "Resume" and "Quit to Title" (check winText)
   - `emulator_screenshot(label = "explorer-pause")` — golden #3
   - Press A to Resume: `emulator_press(button = "a")`
   - `emulator_wait_for_scene(scene = "gameplay", maxFrames = 60)`

7. **Encounter trigger (120 steps):**
   - `emulator_write_variable(name = "stepCount", value = 119)` — one step from encounter
   - `emulator_press(button = "right")` — trigger encounter
   - `emulator_wait_for_scene(scene = "combat_scene", maxFrames = 120)`
   - `emulator_assert`: `scene_is: "combat_scene"`
   - `emulator_screenshot(label = "explorer-combat")` — golden #4
   - `emulator_save_state(label = "in-combat")`

8. **Combat resolution:**
   - Interact with combat (press A to attack, follow playbook combat instructions)
   - Wait for combat to resolve back to gameplay or gameover
   - Read `hp` after combat — should have changed

9. **Zone transition (floor1 to floor2):**
   - `emulator_load_state(label = "gameplay-start")`
   - Navigate to east edge of floor1 (move RIGHT for extended time)
   - Or use `emulator_write_variable` to position near east edge
   - Verify zone transition triggers and loads floor2
   - Check that player position resets appropriately

10. **Torch depletion / gameover:**
    - `emulator_write_variable(name = "torchLevel", value = 51)` — just above threshold
    - Take a step — torchLevel decrements to 50
    - At torchLevel 50: gameover triggers (torch warning IS gameover)
    - `emulator_wait_for_scene(scene = "gameover", maxFrames = 120)`
    - `emulator_screenshot(label = "explorer-gameover")` — golden #5 (optional)

11. **Move golden screenshots:**
    ```bash
    cp build/gbkt/screenshots/explorer-title-*.png gbkt-examples/explorer/src/test/resources/golden/explorer-title.png
    cp build/gbkt/screenshots/explorer-gameplay-*.png gbkt-examples/explorer/src/test/resources/golden/explorer-gameplay.png
    cp build/gbkt/screenshots/explorer-combat-*.png gbkt-examples/explorer/src/test/resources/golden/explorer-combat.png
    cp build/gbkt/screenshots/explorer-pause-*.png gbkt-examples/explorer/src/test/resources/golden/explorer-pause.png
    ```

12. **Write UAT report:** `.planning/phases/07.2-interactive-game-uat/UAT-explorer.md`

13. **Bug handling:** Fix immediately, regression test, atomic commit, `./gradlew test`, resume.

14. `emulator_stop()`
