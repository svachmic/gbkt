  <action>
Run an interactive MCP play-test session for Platformer. Tests physics (gravity, jump, landing), horizontal camera scrolling, and coordinate-based goal detection.

**Pre-session setup:**
```bash
mkdir -p gbkt-examples/platformer/src/test/resources/golden
```

**Session flow:**

1. **Boot and load context:**
   - `emulator_start(game = "platformer")`
   - `emulator_get_playbook()`
   - `emulator_describe_game()`
   - `emulator_step(frames = 120)`

2. **Title screen verification:**
   - `emulator_assert`: `scene_is: "title"`
   - Check for title text — may need `scrollAware: true` if on BG layer
   - `emulator_screenshot(label = "platformer-title")` — golden #1
   - `emulator_save_state(label = "title")`

3. **Title to gameplay:**
   - `emulator_press(button = "start")`
   - `emulator_wait_for_scene(scene = "gameplay", maxFrames = 120)`
   - `emulator_assert`: `scene_is: "gameplay"`, `variable_equals: lives=3`
   - `emulator_save_state(label = "gameplay-start")`

4. **Physics mechanics:**
   - **Gravity:** Step 30 frames with no input — verify player falls (y position changes)
   - **Jump:** Press A button: `emulator_press(button = "a")` — verify player goes up momentarily
   - **Movement:** Hold RIGHT: `emulator_press(button = "right", frames = 60)` — verify horizontal movement
   - **Camera scroll:** After moving right, verify camera has scrolled (player should stay roughly centered)
   - `emulator_screenshot(label = "platformer-gameplay")` — golden #2 (mid-jump or mid-platform)

5. **Platform landing:**
   - Navigate to a platform area
   - Jump onto a platform — verify player lands and stops falling
   - Coyote time: walk off platform edge, jump slightly after — should still work
   - Jump buffer: press jump just before landing — should buffer the jump

6. **Win condition:**
   - Navigate toward the goal zone (coordinate check, not a named actor)
   - Read playbook for goal zone coordinates
   - May use extended RIGHT movement to reach goal area
   - `emulator_wait_for_scene(scene = "win", maxFrames = 600)` (may take many frames of movement)
   - If goal is far, use `emulator_write_variable` to position player near goal for faster testing
   - `emulator_assert`: `scene_is: "win"`
   - `emulator_screenshot(label = "platformer-win")` — golden #3

7. **Lives reset verification:**
   - From win, return to title, re-enter gameplay
   - `emulator_assert`: `variable_equals: lives=3` — fresh start each run

8. **Move golden screenshots:**
   ```bash
   cp build/gbkt/screenshots/platformer-title-*.png gbkt-examples/platformer/src/test/resources/golden/platformer-title.png
   cp build/gbkt/screenshots/platformer-gameplay-*.png gbkt-examples/platformer/src/test/resources/golden/platformer-gameplay.png
   cp build/gbkt/screenshots/platformer-win-*.png gbkt-examples/platformer/src/test/resources/golden/platformer-win.png
   ```

9. **Write UAT report:** `.planning/phases/07.2-interactive-game-uat/UAT-platformer.md`

10. **Bug handling:** Fix immediately, regression test, atomic commit, `./gradlew test`, resume.

11. `emulator_stop()`

**Known Platformer quirks from RESEARCH.md:**
- Goal zone is a coordinate check, NOT a named collision zone actor
- `lives` resets to 3 on every gameplay enter (fresh start each run)
- Camera scrolls horizontally — `scrollAware: true` needed for BG layer text assertions
- Physics: gravity, coyote time, jump buffer all implemented

**Platformer variables:** `lives` (UINT8)
