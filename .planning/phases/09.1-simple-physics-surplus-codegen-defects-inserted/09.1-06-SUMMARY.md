# Phase 09.1 Plan 06: BankingAnalysisPass Fast-Path Dual Guard (CR-01 / G-02 Gap Closure) Summary

Surgically closes the single remaining gap in Phase 09.1: the BankingAnalysisPass single-scene HOME fast-path lacked the static authored-scene-count guard (`game.scenes.size == 1`) that Plan 04's must_haves.truths explicitly specified. Reinstates the Plan 04 spec verbatim as a dual-clause AND guard layered on the existing post-filter `codeUnits.size == 1` check, and locks the 1-real + N-zero-op-stub regression shape with a new JVM-tier @Test case.
