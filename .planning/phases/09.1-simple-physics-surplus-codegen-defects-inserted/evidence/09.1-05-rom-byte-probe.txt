Diff vs Plan 03 Baseline
------------------------

Plan 03 recorded all successfully-built examples as byte 0x19 (MBC5 upgraded at compile time).
After Plan 05:

  simple-physics: 0x19 → 0x00 (FLIPPED — gap-closure payoff)
    - DSL declares cartridge = "ROM_ONLY"
    - Plan 04 assigned scene to bank 0 (HOME fast-path)
    - Plan 05 suppresses bank1.c entirely (allScenesInHome predicate fires)
    - detectMaxBank returns 0 (no #pragma bank N in any source file)
    - readMbcType NOT called — no MBC5 upgrade
    - lcc invoked without -Wm-yt flag → default ROM type 0x00 written to byte 0x0147

  pong: 0x19 → 0x19 (UNCHANGED — expected, multi-scene game)
    - PongV2.kt defines 3 scenes (gameover, game, title)
    - Multi-scene → allScenesInHome predicate does NOT fire
    - bank1.c present with #pragma bank 1
    - NOTE: MbcTypeProbeTest pong-like fixture uses a SINGLE scene (50 ops) to test the
      analysis-layer fast-path in isolation; the REAL pong DSL is multi-scene → 0x19 is correct

  breakout: 0x19 → 0x19 (UNCHANGED — expected, multi-scene game)
  platformer: 0x19 → 0x19 (UNCHANGED — expected, multi-scene game)
  platformer-gbc: 0x19 → 0x19 (UNCHANGED — expected, multi-scene game)
  racer: 0x19 → 0x19 (UNCHANGED — expected, multi-scene game)
  shmup: 0x19 → 0x19 (UNCHANGED — expected, multi-scene game)

  dungeon, explorer, rpg-lite: pre-existing SDCC error 91 (unchanged)
    - extern definition for _char_*_hp mismatches with declaration
    - RPG genre codegen issue, unrelated to banking analysis
    - Logged to deferred-items.md per Plan 03 triage

Verification Commands
---------------------

# Confirm simple-physics byte
od -A x -t x1 -j 0x147 -N 1 gbkt-examples/simple-physics/build/gbkt/output/simple-physics.gb
# Expected output: 0000147    00

# Confirm bank1.c absent for simple-physics
ls gbkt-examples/simple-physics/build/gbkt/generated/bank1.c
# Expected: no such file or directory

# Confirm breakout bank1.c present
grep -c '#pragma bank 1' gbkt-examples/breakout/build/gbkt/generated/bank1.c
# Expected: 1

# Direct byte probe for each banked game (should all return 19)
for ex in pong breakout platformer platformer-gbc racer shmup; do
  echo -n "$ex: "; od -A x -t x1 -j 0x147 -N 1 gbkt-examples/$ex/build/gbkt/output/$ex.gb | awk 'NR==1{print $2}'
done
