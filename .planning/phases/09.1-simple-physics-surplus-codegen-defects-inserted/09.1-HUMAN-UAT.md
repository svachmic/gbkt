    runtime. Plan a 09.2 (or fold into Phase 11 — banks port) to add a "single-scene HOME

## Gaps

### G-01: Single-scene-fits-HOME fast-path missing — compiled ROM byte still MBC5 despite DSL ROM_ONLY setting

**Source:** 09.1-VERIFICATION.md truth #13 (UNCERTAIN), CR-02 fixer-flagged human-verification item

**Symptom:** `simple-physics.gb` size = 32768 bytes (fits ROM_ONLY exactly), `gbkt-build.properties` records `cartridge=ROM_ONLY, mbcType=0x00`, but `od -A x -t x1 -j 0x147 -N 1 simple-physics.gb` returns `0x19` (MBC5). End-state contract from CONTEXT.md ("single-scene games end up MBC 0x00 (ROM_ONLY) cleanly") not fully delivered.

**Root cause:** `bank1.c` is always emitted with `#pragma bank 1` for any non-empty scene. `CompileRomTask.readMbcType()` sees a bank-1-using ROM and upgrades ROM_ONLY → MBC5 unconditionally. The D-10 zero-op filter only excludes scenes whose enter/frame/exit are ALL empty; real simple_physics has ~30 ops in its single scene.

**Fix direction (for gap-closure plan):**
- Extend `BankingAnalysisPass` (or add a follow-on pass) with a "single-scene-fits-HOME" detector: if there is exactly one scene AND its code volume fits within the remaining HOME bank budget, route it to bank 0 instead of bank 1.
- Suppress `bank1.c` emission when no code maps to bank 1.
- Add a JVM-tier test (extending `MbcTypeProbeTest.kt`) that asserts: simple_physics-like single-scene game → `bankAssignments` has either no entries OR exactly one entry at bank 0 → compiled ROM byte at 0x0147 is `0x00`.
- Regenerate `simple-physics.gb` and assert byte 0x0147 == 0x00 in a build-time probe (or document the byte-level invariant in REQUIREMENTS.md / phase truths).

**Owner:** Phase 09.1 gap-closure plan (next: `/gsd-plan-phase 09.1 --gaps`).
**Status:** failed

**Decision rationale:** User chose Option B on 2026-05-14: the project intent is a genuinely-MBC0 simple_physics ROM at runtime, not just at the build-metadata layer. The bank0 fast-path is in-scope for 09.1 (the surplus-cleanup phase that owns D-10), not deferred to Phase 11.
