## Source Edits Applied

### Fix 3a — Warning 84: `_d` uninitialized in `delay_frames`

**File:** `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/pipeline/GBDKPipelineV2.kt`
**Line:** 2242

Before:
```kotlin
val loopVar = CVarDecl("_d", CU8, initializer = null)
```
After:
```kotlin
val loopVar = CVarDecl(name = "_d", type = CU8, initializer = CLiteral(0))
```
Generated C: `UINT8 _d = 0u;` (was uninitialized `UINT8 _d;`)

### Fix 3b — Warning 85x2: `from` and `to` unused in `show_sprites_range`

**File:** `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/visitor/ActorVisitor.kt`
**Lines:** 263-270 + added import `CRawCode`

Before (body):
```kotlin
body = listOf(CComment("Sprites shown by moving to valid positions via update_sprites()"))
```
After (body):
```kotlin
body = listOf(
    CRawCode("(void)from;"),
    CRawCode("(void)to;"),
    CComment("Sprites shown by moving to valid positions via update_sprites()"),
)
```
Generated C: `(void)from;` and `(void)to;` casts prepended to function body. Stub-removal explicitly out of scope per D-08.

### Fix 3c — Warning 126: Unreachable `return;` after `while(1)` in `main()`

**File:** `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/pipeline/GBDKPipelineV2.kt`
**Line:** ~3521 (removed)

Removed: `add(CReturn())` following `add(CWhile(CVar("1"), gameLoopBody))`. The `while(1)` never exits, making the trailing `return;` unreachable dead code.
