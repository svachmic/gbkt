# Phase 06.10 Plan 07: Shmup Example Game Summary

**One-liner:** 246-line vertical shoot-em-up showcasing entity pools (bulletPool max=8, enemyPool max=4), forEachActive iteration, spawn/destroy lifecycle, and AABB collision detection.

## What Was Built

Created `Shmup.kt` — a complete vertical scrolling shoot-em-up game definition using exclusively V2 DSL APIs. The game demonstrates the entity pool system as its primary showcase feature.

### Game Structure

- **3 scenes:** `title` → `gameplay` → `gameover` → `title` (cycle via forward-declared `titleRef`)
- **5 variables:** `score`, `lives`, `scrollY`, `shootCooldown`, `waveTimer`
- **4 sound effects:** `shootSfx` (HIT), `explodeSfx` (EXPLODE), `hitSfx` (BUMP), `scoreSfx` (COIN)
- **3 actors:** `bullet` (pool template), `enemy` (pool template), `player` (ship)
- **2 entity pools:** `bulletPool` (max 8), `enemyPool` (max 4)

### Entity Pool Usage

```kotlin
val bulletPool by pool(bullet, max = 8)
val enemyPool by pool(enemy, max = 4)

// Shooting: spawn from pool at player position
spawn(bulletPool, player.x.toExpr(), player.y.toExpr())

// Per-frame update: iterate active slots, destroy offscreen
forEachActive(bulletPool, "bi") {
    whenever(bullet.y isBelow 4) {
        destroy(bulletPool, VarRef("bi"))
    }
}

// Reset on scene enter
destroyAll(bulletPool)
```

### Gameplay Logic

- Vertical scroll: `scrollY += 1` each frame (visual simulation variable)
- Player movement: 4-directional via `dpad.up/down/left/right.held` with screen bounds
- Shooting: `buttons.a.pressed` with `shootCooldown` guard (8-frame cooldown)
- Enemy waves: spawn enemy every 60 frames via `waveTimer`
- Collision: `bullet.collides(enemy)` → score+10, `enemy.collides(player)` → lives-1
