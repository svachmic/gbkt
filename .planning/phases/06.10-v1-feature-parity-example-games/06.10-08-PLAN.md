    **Game design:**
    - Title: "Racer"
    - Config: ROM_ONLY cartridge, 2 ROM banks
    - GBC target: GBC_COMPATIBLE (color enhances the racing visuals)
    - 3 scenes: title, race, results
    - Scene flow: title -> race -> results -> title
    - Forward-declare titleRef for circular navigation

    **Racing system (the showcase feature):**
    ```kotlin
    racing("track1") {
        laps(3)
        maxRacers(2)
        vehicleStats {
            topSpeed(4)
            acceleration(1)
            braking(2)
            handling(3)
        }
        track("circuit") {
            waypoint(40, 40, radius = 16)
            waypoint(120, 40, radius = 16)
            waypoint(120, 120, radius = 16)
            waypoint(40, 120, radius = 16)
        }
        ai {
            difficulty(3)
            rubberBanding(true)
        }
        countdown(3)
    }
    ```

    **Camera follow (showcase feature):**
    ```kotlin
    camera {
        target("car")
        smoothing(0.3f)
        bounds(0, 0, 256, 256)
    }
    ```

    **Zone:**
    - circuit zone: size(32, 32) — track area

    **Actors:**
    - car (player): position(40, 100), sprite car.png, size(8, 16), movement { style(SMOOTH); speed(3) }
    - Opponent car: AI-driven via racing AI config

    **Variables:**
    - var lap by u8Var(0)
    - var raceTime by u8Var(0)
    - var position by u8Var(1) (race position: 1st, 2nd)

    - engineSfx (BEEP) — engine/movement

    - lapSfx (COIN) — lap completion

    - enter: hideSprites, clear, print position + time
    - frame: press start -> navigate(titleRef)
