### Dungeon docs
- `README.md`: Features cover `exploration { preset(DUNGEON_CRAWLER) }`, `gauge("torch")` with callbacks, `keys()`, `zone()` encounter table, `flags()`, HUD/dialog
- `CLAUDE.md`: Exploration preset + gauge pattern, zone encounter table, flag system, full code structure map

### Shmup docs
- `README.md`: Features cover `pool()`, `spawn()`, `destroy()`, `destroyAll()`, `forEachActive()`, cooldown pattern, wave spawning, pool-to-pool collision
- `CLAUDE.md`: Actor pool spawn/despawn patterns, cooldown gate pattern, pool collision, code structure

### Racer docs
- `README.md`: Features cover `racing()` DSL, `mode(RacingMode.AI_OPPONENT)`, `track/waypoints`, `vehicle stats`, `ai { rubberBanding }`, camera follow, `GBC_COMPATIBLE` target
- `CLAUDE.md`: Full racing() block pattern, GBC target config, smooth movement actor, code structure

### Explorer docs (advanced reference)

- `CLAUDE.md`: Multi-floor zone transitions, pause menu via MenuHandle, HUD with bar+number+icons, entity collision, key architectural decisions, how-to-modify guide, localization section
