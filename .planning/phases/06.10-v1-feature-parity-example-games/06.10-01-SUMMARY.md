Scaffolded 4 new example game modules (platformer, platformer-gbc, shmup, racer) with Gradle registration, build configs, directory structures, and recognizable sprite assets.

## Summary

Registered platformer, platformer-gbc, shmup, racer in settings.gradle.kts and created build.gradle.kts for each with correct genre dependencies (gbkt-genre-platformer for platformer variants, no genre for shmup, gbkt-genre-sport for racer). - Created recognizable sprite PNG assets (4-color indexed, GB palette):

  - `racer/res/sprites/car.png` (8x16): top-down car with visible wheel shapes
