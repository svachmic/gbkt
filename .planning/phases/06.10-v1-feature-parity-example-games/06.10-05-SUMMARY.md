## What Was Built

`Platformer.kt` defines a minimal DMG platformer game with:

- **Physics system:** `platformerPhysics { gravity(2); jumpForce(8); terminalVelocity(12); coyoteTime(6); jumpBuffer(8) }`
- **Camera system:** `platformerCamera { smoothFollow(); horizontal(); deadZone(x=16, y=8) }`
- **Platform definitions:** ground (SOLID), mid_platform (ONE_WAY), high_platform (ONE_WAY)
- **Goal zone:** `goalZone("exit")` at position (112, 40) size 16x16
- **Player actor:** position (20, 104), 8x16 sprite, MovementStyle.PHYSICS, speed 2
- **Variables:** `lives` (u8, initial 3)
- **Sound effects:** jumpSfx (HIT), landSfx (BUMP), winSfx (WIN)
- **3 scenes:** title, gameplay, win — with forward-declared `titleRef` for circular navigation
- **Navigation cycle:** title → gameplay → win → title

### Scene Logic

**title:** Shows "PLATFORMER" + "PRESS START", navigates to gameplay on start button.

**gameplay:** Player moves left/right with dpad, jump SFX on A button press, fall detection (player.y > 136 → lose life + respawn), goal zone check via coordinate comparison (player reaches top-left of high platform area → navigate to win).

**win:** Shows "YOU WIN!" + "PRESS START", navigates back to titleRef.

- **Issue:** `GoalZoneBuilder` only supports `position()` and `size()` — no `onReach { }` callback exists in the builder API (the plan incorrectly suggested `onReach { navigate(winScene) }`)
