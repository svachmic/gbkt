# Phase 06.10 Plan 04: Dungeon Crawler Game Definition Summary

**One-liner:** Dungeon crawler game showcasing exploration presets, torch gauge depletion, zone encounters, and RPG combat (adventurer vs bat/skeleton) using V2 DSL.

## What Was Built

Created `Dungeon.kt` — a complete dungeon crawler example game definition at:
`gbkt-examples/dungeon/src/main/kotlin/io/github/gbkt/examples/dungeon/Dungeon.kt`

### Key Features Demonstrated

**Exploration System:**
- `exploration { preset(ExplorationPreset.DUNGEON_CRAWLER) }` — applies tileSize=8, GRID movement, movementSpeed=8
- Custom `gauge("torch")` with `onLow(50)` and `onDepleted` navigate callbacks
- `keys("room_key") { max(9) }` for locked door mechanics
- `onStep { playSound(stepSfx) }` and `onBlocked { playSound(bumpSfx) }`

**Zone System:**
- `val floor1 = zone("floor1") { ... }` with 16x16 map, encounter table (safeSteps=10, "combat" entry weight 30)
- `flags("dungeon_flags") { page("dungeon") { flag("bossDefeated"); flag("gotTreasure"); flag("foundKey") } }`

**RPG Combat (gbkt-genre-rpg):**
- `adventurer`: hp=25, atk=7, def=4, agl=8
- `bat`: hp=8, atk=5, def=1, agl=15, exp=3
- `skeleton`: hp=15, atk=6, def=3, agl=5, exp=8
- `simpleBattle("combat")` with two encounter groups: `{+bat}` and `{+bat; +skeleton}`
- `battleUpdate("combat")` called in battle scene frame block

**V2 DSL Patterns:**
- All variables via delegate syntax: `var torchLevel by u8Var(255)`
- All sounds via delegate syntax: `val bumpSfx by soundEffect { preset(SoundPreset.BUMP) }`
- All actors via delegate syntax: `val player by actor { ... }`
- All navigation via typed `SceneRef` (zero string navigate calls)
- Forward-declared `titleRef = sceneRef("title")` and `gameoverRef = sceneRef("gameover")` for circular navigation
- Type-safe input: `dpad.up.held`, `buttons.start.pressed`, `dpad.any`
- Torch depletion: every 4 steps via `(steps and 3) isEqualTo 0` bitwise check

**Scenes (4):**
1. `gameover` — defined first; "GAME OVER" + reset + navigate(titleRef)
2. `battle` — drives `battleUpdate("combat")` each frame
3. `gameplay` — grid movement, torch depletion, encounter triggers, HUD
4. `title` — press start resets and navigates to gameplay
