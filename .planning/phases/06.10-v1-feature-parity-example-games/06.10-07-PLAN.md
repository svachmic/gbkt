    - Use a scrollY variable incremented each frame to simulate vertical scrolling

    - This creates the illusion of upward movement

    **Entity pools (the showcase feature):**
    - bullet actor: position(-8, -8) offscreen, sprite bullet.png, size(4, 8)
    - enemy actor: position(80, 0), sprite enemy.png, size(16, 16)
    - `val bulletPool by pool(bullet, max = 8)` — 8 concurrent bullets
    - `val enemyPool by pool(enemy, max = 4)` — 4 concurrent enemies

    **Player:**
    - player actor: position(80, 120), sprite ship.png, size(16, 16), hitbox(2, 0, 12, 16)

    **Variables:**
    - var score by u8Var(0)
    - var lives by u8Var(3)
    - var scrollY by u8Var(0)
    - var shootCooldown by u8Var(0)
    - var waveTimer by u8Var(0)

    **Sound effects:**
    - shootSfx (SHOOT) — firing
    - explodeSfx (EXPLODE) — enemy destroyed
    - hitSfx (HIT) — player hit
    - scoreSfx (COIN) — score milestone

    **Gameplay scene:**
    - enter: clear, showSprites, reset score/lives/scroll
    - frame:
      - Scroll: scrollY += 1 (vertical scroll simulation)

      - Collision: enemy hits player -> lives -= 1, playSound(hitSfx)
      - Game over: lives == 0 -> navigate(gameoverScene)

    **Gameover scene:**
    - enter: hideSprites, clear, print "GAME OVER" + score
    - frame: press start -> navigate(titleRef)
