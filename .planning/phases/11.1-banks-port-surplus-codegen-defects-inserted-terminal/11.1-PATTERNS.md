### `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/postprocess/FunctionDeduplicationPass.kt` (codegen post-process, modify callsite-rewrite at :127-135)

**Analog:** Self — the existing callsite-rewrite loop at lines 127-135 is THE bug.

**Existing buggy block** (lines 127-135):

```kotlin
// Rewrite call sites: replace `duplicateName(` with `canonicalName(`
for ((dupName, canonicalName) in callSiteRedirects) {
    // Use word boundary to avoid matching partial names (e.g., my_func vs my_func2)
    val callPattern = Regex("""\b${Regex.escape(dupName)}\s*\(""")
    result =
        callPattern.replace(result) { matchResult ->
            matchResult.value.replace(dupName, canonicalName)
        }
}
```

**Bug mechanism (RESEARCH §SEED-015 hypothesis C, verified):** The pattern `\b{name}\s*\(` matches `title_enter (bank 1)` in the trampoline section comment `// Trampoline: title_enter (bank 1)` because `\s*` matches the space and `\(` matches the `(` from `(bank 1)`. The replacement rewrites comment text alongside code.

**Fix pattern (RESEARCH Pattern 4 — skip-comments variant; recommended over the tighter-regex alternative):**

```kotlin
for ((dupName, canonicalName) in callSiteRedirects) {
    val callPattern = Regex("""\b${Regex.escape(dupName)}\s*\(""")
    result = result.lines().joinToString("\n") { line ->
        val trimmed = line.trimStart()
        // Skip comment lines — the regex `\b{name}\s*\(` matches comment text like
        // "// Trampoline: title_enter (bank 1)" where `\s*\(` matches " (" before "bank".
        // The rewriter has no semantic awareness; skip comment lines explicitly.
        if (trimmed.startsWith("//") || trimmed.startsWith("/*") || trimmed.startsWith("*")) {
            line
        } else {
            callPattern.replace(line) { m -> m.value.replace(dupName, canonicalName) }
        }
    }
}
```

**RESEARCH-confirmed locked output** (§Pitfall 3 re-interpretation): The trampoline IS still emitted for banks's title scene (FFD places title in bank 1, not HOME), and its BODY may still legitimately call `pause_enter()` (because `title_enter` and `pause_enter` have byte-identical bodies and dedup is correct). The only bug is COMMENT TEXT. INV-5 sentinel must assert the section comment retains `title_enter`, not assert "no trampoline".

**Apply to:** All new JVM-tier emission tests (INV-5, INV-6, and any future banks-emission INV).
**Pattern:**
```kotlin
private fun extractFunctionBody(cSource: String, functionName: String): String {
    val lines = cSource.lines()
    val startIdx = lines.indexOfFirst { it.contains("void $functionName(") }
    if (startIdx == -1) return ""
    val body = StringBuilder()
    var depth = 0; var started = false
    for (i in startIdx until lines.size) {
        val line = lines[i]
        body.appendLine(line)
        for (ch in line) { if (ch == '{') { depth++; started = true }; if (ch == '}') depth-- }
        if (started && depth == 0) break
    }
    return body.toString()
}
```
Rationale: file-grepping `bank1.c` for `_bkg_tiles_load_banked(` would false-positive across functions; per-function brace-walk locks the assertion to the intended scope.
