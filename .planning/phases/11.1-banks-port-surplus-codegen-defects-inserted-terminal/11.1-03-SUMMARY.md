## What Was Built

**SavestateManager.kt changes:**
- Added `const val SRAM_START = 0xA000` and `const val SRAM_SIZE = 0x2000` constants before WRAM_START
- Bumped MAGIC fourth byte from `'T'.code.toByte()` to `'2'.code.toByte()` (ASCII "GBS2")
- Inserted SRAM loop `for (addr in SRAM_START until SRAM_START + SRAM_SIZE)` in `save()` between MAGIC write and WRAM loop
- Inserted mirror SRAM loop in `load()` between MAGIC validation and WRAM loop
- Updated error message in `load()` to reference 'GBS2' instead of 'GBST'
- Updated KDoc: file format GBS2, total size 16675 bytes (was 8483), SRAM region documented, breaking change note

**SavestateManagerTest.kt changes:**
- `saved file has correct total size`: assertion updated from `8483L` to `16675L`
- `saved file starts with GBST magic bytes` renamed to `saved file starts with GBS2 magic bytes`, expected bytes updated to GBS2
- SRAM round-trip test comment updated from "RED-by-design" to "GREEN" (per SEED-016 NARROW fix)

**File format arithmetic:**
4 (magic) + 8192 (SRAM) + 8192 (WRAM) + 160 (OAM) + 127 (HRAM) = 16675 bytes
