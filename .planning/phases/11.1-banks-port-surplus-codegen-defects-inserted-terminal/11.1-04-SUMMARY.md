- Used `emptyList()` default for `SceneIR.zoneRefs` — all 4 zone-using games (dungeon, explorer, racer, banks) have no existing `zone()` calls, so backward compat is preserved automatically
- 1-zone-per-scene cap enforced in DSL (SceneBuilder) not in IR (SceneIR) — IR stores the list, cap logic belongs in the recording layer per CONTEXT D-01 scoped-exception rationale
- No import needed for ZoneRef in SceneBuilder: ZoneRef lives in the same package (`io.github.gbkt.core.dsl`)
