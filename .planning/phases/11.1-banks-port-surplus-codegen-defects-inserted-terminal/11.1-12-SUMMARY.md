## Decisions Made

- Use `git show <pre-plan10-commit>:path` overwrite for RED-by-design cycle (not `git stash push`) since Plan 10 is already committed and `git stash push` only stashes local modifications.
- Re-open MBC5 RAM gate after `SavestateManager.load()` for the post-load read-back: load() ends with DISABLE_RAM so a second ENABLE_RAM write is needed to read back the restored byte from 0xA000.
- `bootBanksEmulatorPaused()` returns `GbEmulator` (not `CoffeeGbEmulator`) to avoid leaking implementation detail into the test body.
- 10 PPU frames to settle: matches the frame count established in `RealEmulatorAgentTest`.
