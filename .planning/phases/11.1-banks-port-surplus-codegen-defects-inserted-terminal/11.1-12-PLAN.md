<objective>
Close REVIEW CR-01 (BLOCKER) at the unit-tier: add a JVM-tier emulator-backed
`SavestateManager` round-trip test that uses a real CoffeeGB `GbEmulator` (with
MBC5 cartridge semantics intact), exercises the same recipe Anchor 4 uses on
the runtime ROM, and asserts the SRAM round-trip actually restores bytes — NOT
through an `IntArray`-backed mock that bypasses MBC.

Purpose: The existing 9/9 `SavestateManagerTest` tests use an `IntArray`-backed
`MemoryAccess` mock that has no MBC5 between `MemoryAccess.writeByte` and the
underlying memory. They cannot catch CR-01. Without a real-MBC5-backed JVM
test, SEED-016 closes against a known-false-green sentinel: a future regression
that re-introduces the no-op load path would not be caught by any JVM-tier
test. Plan 11's hardening of BanksUatTest covers the UAT tier, but UAT tests
require a pre-built ROM and are slower; a JVM-tier emulator-backed twin closes
the loop at the unit-test level so the contract is locked at the lowest tier
that can see the bug.

Output: A new `@Test` (or `@Nested` group) in `SavestateManagerTest.kt` that
loads `gbkt-examples/banks/build/gbkt/output/banks.gb` via `CoffeeGbEmulator`,
pauses it, drives the SRAM round-trip through `SavestateManager.save/load`, and
asserts the restored byte differs from a mid-mutation sentinel value. Uses
JUnit `Assumptions.assumeTrue` to skip if the banks ROM is absent (matching
the BanksUatTest skip-guard pattern), so this stays CI-safe even when the ROM
hasn't been built yet.

This plan depends on Plan 10 (SavestateManager.load() ENABLE_RAM bracket) — its
GREEN state depends on Plan 10 being in place. It does NOT touch BanksUatTest
(that is Plan 11).

**RED-by-design cycle is MANDATORY (per user memory `feedback_quality_over_shortcuts.md`):**
Because Plan 12 executes AFTER Plan 10, the only way to prove the new test is
non-tautological (i.e. it would FAIL without Plan 10's bracket) is a stash-revert
cycle. See `<acceptance_criteria>` for the exact sequence; the failure-output
capture is a binding evidence artifact.
