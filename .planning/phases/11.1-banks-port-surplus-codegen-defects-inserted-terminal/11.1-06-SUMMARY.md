## What Was Built

**Banks.kt DSL wiring (SEED-014 Phase 11.1 D-01 scoped DSL exception):**

Two surgical edits to `Banks.kt`:

1. Added `size(20, 18)` inside the `playZone` declaration — matches the Game Boy visible screen exactly (160×144 px / 8×8 tiles = 20×18 tiles). Without this, `ZoneBuilder` default `mapWidth=32, mapHeight=32` would emit `_bkg_tiles_load_banked(2u, 0u, 0u, 32u, 32u, ...)` writing 1024 tile indices over a 4-byte checker tile-data array (undefined behavior; PATTERNS gotcha #6 / RESEARCH §A5 / §R1).

2. Added `zone(playZone)` as the first statement inside `scene("play") { }` — per D-claude-1 option i. The `zone()` DSL call takes a typed `ZoneRef` (not a magic string), unwraps to `.id = "play_zone"` for `SceneIR.zoneRefs`, which the `SceneVisitor` reads during codegen to emit the `_bkg_tiles_load_banked(...)` + `SHOW_BKG;` pair in `play_enter()`.

**Generated C (post-regen):**
- `main.c`: contains `void _bkg_tiles_load_banked(UINT8 bank, UINT8 x, UINT8 y, UINT8 w, UINT8 h, const UINT8* tiles)` helper definition (INV-2 GREEN)
- `bank1.c` `play_enter`: emits `_bkg_tiles_load_banked(2u, 0u, 0u, 20u, 18u, _zone_play_zone_tiles);` followed by `SHOW_BKG;` (INV-6 GREEN)
- `banks.gb` ROM: 64 KB, BUILD SUCCESSFUL — BANKED helper call works at runtime
