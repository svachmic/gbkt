## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] COutputOptimizer cross-file rewrite also rewrites comments**

- **Found during:** Task 1 — INV-5 remained RED after fixing FunctionDeduplicationPass
- **Issue:** `COutputOptimizer.optimize()` has a second callsite-rewrite loop (lines 91-102) that applies cross-file redirects using `\b{name}\b`. This pattern also matches comment text like `// Trampoline: title_enter (bank 1)`. The intra-file fix in `FunctionDeduplicationPass` was correct but the cross-file loop in `COutputOptimizer` was the active culprit that rewrote the comment.
- **Fix:** Applied the same line-by-line comment-skip filter (`trimStart().startsWith("//")` etc.) to the cross-file rewrite loop in `COutputOptimizer.optimize()`
- **Files modified:** `gbkt-backend-gbdk/.../codegen/postprocess/COutputOptimizer.kt`
- **Commit:** da08609a

**2. [Rule 3 - Blocking] INV-5 test used wrong pipeline layer (unannotated IR, no dedup)**

- **Found during:** Task 1 — INV-5 failed at `trampolineIdx >= 1` (function not found), not at the comment assertion
- **Issue:** `BanksEmissionTest.INV-5` called `GBDKPipelineV2().generate(banks.build())`. Raw `GBDKPipelineV2` doesn't run bank analysis, so `bankSlot == null` for all scenes → `buildTrampolineStubs` filters them all out → `title_enter_trampoline` never emitted. Separately, raw pipeline doesn't run `FunctionDeduplicationPass`. The test was structurally incapable of testing the SEED-015 dedup-rewrite bug.
- **Fix:** Updated INV-5 to use `GBDKBackend().generateV2(banks.build())` which: (1) runs `DefaultPipeline` to assign bank slots; (2) calls `GBDKPipelineV2` with annotated IR so trampolines are emitted; (3) runs `COutputOptimizer`/`FunctionDeduplicationPass`.
- **Files modified:** `gbkt-examples/banks/src/test/kotlin/io/github/gbkt/examples/banks/BanksEmissionTest.kt`
- **Commit:** da08609a

### Root Cause Clarification

The RESEARCH doc (Pattern 4) correctly identified `FunctionDeduplicationPass.kt:127-135` as the bug location and correctly described the `\bname\s*\(` over-match on section comments. However, there are TWO callsite-rewrite loops:

1. **Intra-file** — `FunctionDeduplicationPass.optimize()` rewriting `dupName(` within each file separately (the fix target per RESEARCH)
2. **Cross-file** — `COutputOptimizer.optimize()` rewriting all redirects across all files using `\b{name}\b` (the actual active culprit for main.c's trampoline comment)

The intra-file loop processes main.c before the cross-file loop sees it. The trampoline section comment starts with `//` so the intra-file fix correctly skips it. But the cross-file loop then re-processes the already-correct main.c and rewrites the comment again. Both loops needed the skip-comments filter.
