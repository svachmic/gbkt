## SEED-014 fix architecture (THE wide-blast-radius decision)

### Initial framing

Codebase scout confirmed the seed's hypothesis needs sharpening:
`_bkg_tiles_load_banked` is gated on `hasSportRacing && bank > 1` at
`GBDKPipelineV2.kt:972-980`, BUT dungeon doesn't use the helper either — dungeon
emits its `set_bkg_tiles` inline inside `zone_load_X`, generated ONLY by
`GBDKSystemVisitor.visitExplorationSystem`. Banks has zones at game scope without
ExplorationSystem → neither path fires → blank DMG frame. The fix is structurally
about decoupling zone-tilemap-loading from genre/exploration systems, not just
un-gating the racing helper.

### Option table

| Option | Description | Selected |
|--------|-------------|----------|
| (A) Decouple zone_load_X from genre systems | Move zone_load_X / zone_transition_X out of visitExplorationSystem into a new ZoneVisitor. Any GameIR with zones gets zone_load_X. Auto-call zone_load_X(0) from main() or first-scene-enter when game has zones but no ExplorationSystem. | |
| (B) Un-gate helper + auto-emit scene-enter call | Un-gate _bkg_tiles_load_banked + auto-emit a call to it from any scene's enter when game has zones. Helper becomes universal path. | |
| (C) Add minimal DSL hook to bind zone-to-scene | Introduce scene { zone(playZone) } DSL that explicitly wires zone load to scene enter. Backend knows which scenes need the SWITCH_ROM wrapper call. NEW DSL surface. | ✓ |
| (D) Research first, decide after | Spawn gsd-phase-researcher with this specific question; lock smallest correct fix before deciding. | |

**User's choice:** (C) Add minimal DSL hook to bind zone-to-scene.

### Follow-up question — where does the new DSL hook ship?

| Option | Description | Selected |
|--------|-------------|----------|
| Ship in 11.1 as scoped exception (Phase 10.1 D-13 pattern) | Smallest surface that lets banks declare intent without ExplorationSystem. 11.1 CONTEXT documents the exception. Mirrors Phase 10.1 D-13 (MoveMetasprite var-ref IR fields). | ✓ |

| Ship hook in 11.1 AND add Phase 13 generalization requirement | Ship the minimal hook AND add a Phase 13 requirement to generalize. | |

**User's choice:** Ship in 11.1 as scoped exception (Phase 10.1 D-13 pattern).

**Notes:** Locked as CONTEXT D-01 + D-02. Exact DSL surface (scene-block method
call vs. zone-builder binder vs. IR-only field) is planner discretion (D-claude-1);
