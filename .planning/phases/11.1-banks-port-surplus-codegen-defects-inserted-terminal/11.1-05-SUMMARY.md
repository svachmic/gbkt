# Phase 11.1 Plan 05: Backend Gate Widening + SceneVisitor Zone-Load Emission (SEED-014) Summary

Widen the `_bkg_tiles_load_banked` helper-emission gate in `GBDKPipelineV2` to admit games whose scenes declare `zoneRefs`, and teach `SceneVisitor` to prepend a `_bkg_tiles_load_banked(bank, 0, 0, w, h, tiles) + SHOW_BKG;` call to the `scene_enter` body when `scene.zoneRefs` is non-empty. Backend tests and dungeon/explorer/racer regression tests remain GREEN; INV-2 and INV-6 stay RED pending Plan 06 DSL wire-up.

## What Was Built

**Task 1 — Gate widening (GBDKPipelineV2.kt lines 972-982):**

Added `val hasZoneSceneBinder = gameIR.scenes.any { it.zoneRefs.isNotEmpty() }` immediately after `hasSportRacing`. Widened the `if` controlling `crossBankHelper` emission from `if (hasSportRacing && ...)` to `if ((hasSportRacing || hasZoneSceneBinder) && bankAllocation.values.any { it > 1 })`. The `> 1` floor is preserved per RESEARCH Pattern 2. One-line comment cites SEED-014 / Phase 11.1 D-01.

**Task 2 — SceneVisitor extension (SceneVisitor.kt) + caller threading (GBDKPipelineV2.kt):**

Extended `SceneVisitor.visit(...)` with two new default-empty parameters: `zoneBankAllocation: Map<String, Int> = emptyMap()` and `zones: List<ZoneIR> = emptyList()`. Added runtime caller-miss guard (`check(zoneBankAllocation.isNotEmpty() && zones.isNotEmpty())`) that throws `IllegalStateException` when a scene has `zoneRefs` but the caller did not thread the new params.

Changed the enter-emission branch from `if (scene.enterOps.isNotEmpty())` to `if (scene.enterOps.isNotEmpty() || scene.zoneRefs.isNotEmpty())` — scenes with only a zone binder (no user enter ops) now generate an enter function.

Inside the branch, computes `zoneLoadStatements` by `scene.zoneRefs.flatMap { ... }`. For each `zoneId`: looks up `ZoneIR` by id; looks up `bank` from `zoneBankAllocation`; sanitizes the zone id (replacing `-` and spaces with `_`); emits two statements: `CExprStatement(CCall("_bkg_tiles_load_banked", [CLiteral(bank), CLiteral(0), CLiteral(0), CLiteral(zone.mapWidth), CLiteral(zone.mapHeight), CVar("_zone_<id>_tiles")]))` and `CRawCode("SHOW_BKG;")`. The body is `zoneLoadStatements + userEnterOps`.

Updated the single `SceneVisitor.visit(...)` call site in `GBDKPipelineV2.buildSceneFile` (line ~1357) to pass `zoneBankAllocation = bankAllocation` and `zones = gameIR.zones`.
