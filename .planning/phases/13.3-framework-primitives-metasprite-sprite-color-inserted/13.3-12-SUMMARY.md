## What Was Built

### Metasprite Primitives section (new)

Two sub-sections added between "Sprite Animations" and "State Machine DSL":

**Asset-Driven Metasprite (recommended):** Documents `sprite(asset("sprites/elephant.png")) { mode/pivot/frameSize }` + `frames(N)` with the canonical 5-frame elephant example directly from the migrated `Metasprites.kt`. Includes the note "An author never writes METASPR_ITEM / frame{} blocks for PNG-sourced metasprites."

**Procedural Metasprite (frame{} escape hatch, D-04):** Documents the `frame { tile(x, y, id) }` blocks pattern with a 2-frame cursor example. Distinguished from the asset-driven path. Includes D-08 mutual-exclusion table (both paths cannot coexist in one metasprite block).

### GBC Color — Color Namespace section (new)

Added after "DMG Color Constants" section:

- `Color.rgb888(r, g, b)` with precision-loss warning explanation
- `Color.rgb555(r, g, b)` with 0–31 range note
- `Color.hex("#RRGGBB")` with accepted format variants
- All 16 named constants listed with their hardware RGB555 values
- 4-palette sub-palette cycling worked example (gray/pink/cyan/green using `Color.rgb555`)

### GBC Palette Slot Assignment section (new)

Documents the two `palette()` overloads:

- Auto-increment: `palette(gray); palette(pink)` → slots 0, 1 in declaration order
- Explicit slot: `palette(heroSpritePalette, slot = 0)` for precise hardware control
- D-11 duplicate-slot guard behaviour explained
