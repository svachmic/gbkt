## What Was Built

### Task 1: D-08 Guard + frames(N) DSL

**MetaspriteIR.kt:** Added `frameCount: Int?` field (default null) with KDoc explaining D-07 semantics and distinction from `frames.size` (procedural frames) and `idxVar.wrapAt`.

**MetaspriteBuilder.kt:**
- Added `private var declaredFrameCount: Int? = null` field
- Added `fun frames(n: Int)` DSL method with `require(n >= 1)` guard and full KDoc (Phase 13.3 D-07)
- Replaced the old `require(frameBuilders.isNotEmpty())` in `build()` with D-08 exactly-one guard:
  - Both sprite(asset) AND frame{} present → throws naming id and "sprite"/"frame" keywords
  - Neither sprite nor frame{} → throws naming id
  - Exactly one → succeeds
- Wired `declaredFrameCount` to `MetaspriteIR(frameCount = declaredFrameCount)` in build()

### Task 2: Sidecar + Extern + Validate

**GBDKPipelineV2.kt:** Extended `buildMetadataFile()` metasprite sidecar entries with:
- `"frameCount": ms.frameCount` (only emitted when non-null)
- `"isMetasprite": true` (always for metasprite entries; absent for actor sprite entries)

**ConvertSpritesTask.kt:**
- Added `internal fun validateFrameCount(declaredCount, png2assetCOutput, stemName)` at file scope — parses `<stemName>_metasprites[(\d+)]` via Regex, throws `IllegalArgumentException` naming both counts when they disagree; passes silently when the declaration is absent (unknown count shape)
- Extended `convertSprites()` to read `frameCount` and `isMetasprite` from sidecar (backward-compat: uses `entry.has("frameCount")` and `entry.optBoolean("isMetasprite", false)`)
- Extended `convertSprite()` signature with `declaredFrameCount: Int? = null` and `isMetaspriteEntry: Boolean = false`
- In `convertSprite()`: after `fixZeroSizeArrays`, if `declaredFrameCount != null` invoke `validateFrameCount` and wrap `IllegalArgumentException` in `GradleException`
- Added `isMetasprite: Boolean = false` parameter to `generateSpriteHeader()`; when true emits `extern const metasprite_t* const ${stemName}_metasprites[];` after the palette extern (D-01 alias bridge)
