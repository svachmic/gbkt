# Phase 13.3 Plan 04: Migrate gbkt-lang Production Color Call Sites to Color.* Summary

Production `gbc()` / `GbcColor.*` consumer call sites in `gbkt-lang` migrated to `Color.rgb555` — 64 GbcPresets.kt calls + 11 PaletteBuilder.kt doc-comment references cleaned up; UIBuilders.kt was already clean.

## What Was Built

Migrated all production (non-test) color call sites in `gbkt-lang` to the unified `Color.*` namespace introduced in Plan 13.3-01:

- **GbcPresets.kt** — 64 `gbc(r, g, b)` calls replaced with `Color.rgb555(r, g, b)`. One doc-comment `GbcColor.WHITE` reference updated to `Color.WHITE`. No import changes (both `gbc()` and `Color` live in the same package `io.github.gbkt.core.dsl`).
- **PaletteBuilder.kt** — 11 doc-comment `GbcColor.*` references (WHITE, BLACK, LIGHT_GRAY) updated to `Color.*`. 10 doc-comment `gbc(...)` call examples updated to `Color.rgb555(...)` for documentation consistency.
- **UIBuilders.kt** — No changes required; zero `gbc()/GbcColor./gbcHex()` references found (already clean).

`GbcColor.kt` intentionally left in place — deletion deferred to Plan 13.3-07 after all consumers (tests + Labyrinth) complete migration.
