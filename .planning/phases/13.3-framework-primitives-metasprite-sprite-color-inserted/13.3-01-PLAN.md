<objective>
Introduce the unified `Color` namespace (Req #7, D-12) in `gbkt-lang` as a thin,
discoverable facade over the existing `gbkt-ir` `GBCColor` converters, and pin its
contract with a Wave-0 RED test suite (`ColorTest`, VALIDATION.md Wave-0 gap). This is
the foundation for the whole D-13 hard-replace sweep — every downstream Color-migration
plan depends on this object existing.

Purpose: One clean color entry point (`Color.rgb888` / `Color.rgb555` / `Color.hex` /
named constants) that hides the RGB888→RGB555 `>>= 3` arithmetic, replacing the three
legacy surfaces `gbc()` / `GbcColor.*` / `gbcHex()`.
Output: `Color.kt` (object) + `ColorTest.kt` (RED-first contract).
</objective>
