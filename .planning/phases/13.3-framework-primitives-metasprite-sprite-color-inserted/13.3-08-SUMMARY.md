# Phase 13.3 Plan 08: Palettes.kt Color Migration Summary

## One-liner

Migrated all 136 `gbc()` calls + 4 `GbcColor.WHITE` references in `Palettes.kt` to `Color.rgb555` / `Color.WHITE` — the largest single-file D-13 mass.

## What Was Built

The `LabyrinthOfTheDragon-port/Palettes.kt` file (35 GBC palette definitions, ~800 lines) was fully migrated from the legacy `gbc()`/`GbcColor.*` surfaces to the unified `Color.*` namespace:

| Replacement | Count | Notes |
|-------------|-------|-------|
| `gbc(r, g, b)` → `Color.rgb555(r, g, b)` | 136 | Lossless: gbc() channels are 0-31 RGB555, same as rgb555() |
| `GbcColor.WHITE` → `Color.WHITE` | 4 | In `deathFade5` palette (fully-faded death animation) |
| Import: removed `import io.github.gbkt.core.dsl.GbcColor` | 1 | |
| Import: removed `import io.github.gbkt.core.dsl.gbc` | 1 | |
| Import: added `import io.github.gbkt.core.dsl.Color` | 1 | |
