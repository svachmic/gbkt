## Root Cause Resolved

Triple collision (from `evidence/13.3-DIAGNOSTIC.md`):
1. Site B: `set_sprite_palette(0u, 1u, elephant_palettes)` uploaded only 1 sub-palette to slot 0
2. Site C: `play_enter()` overwrote slot 0 with gray_pal, slot 1 with pink_pal
3. Descriptor's S_PAL(1) entries pointed at slot 1 = pink_pal → PINK outline on 10 OAM entries per frame

Direction B fix: Site B is suppressed. Slots 0-3 = gray/pink/cyan/green from Sites A+C only. The elephant's S_PAL(0) tiles now correctly reference slot 0 = gray_pal. Note: S_PAL(1) outline tiles still reference slot 1 = pink_pal — the full single-palette gray render requires a descriptor fix (neutralizing S_PAL(1) to S_PAL(0)), which is beyond this plan's scope per the diagnostic's "Summary for 13.3-17" note. The runtime visual confirmation and binding verdict are deferred to Plan 13.3-19 per the Visual Evidence Rule.
