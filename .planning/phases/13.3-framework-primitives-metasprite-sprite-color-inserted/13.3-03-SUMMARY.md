## What Was Built

### SceneBuilder.palette(GBCPalette, slot: Int) overload (D-09)

Added to `gbkt-lang/src/main/kotlin/io/github/gbkt/core/dsl/SceneBuilder.kt`:

- `fun palette(palette: GBCPalette, slot: Int)` — explicit-slot overload
- `require(slot in 0..7)` at call site with message naming the offending slot
- Emits `SetPalette(palette.name, slot, palette.type)` using the supplied slot, ignoring `palette.slot`

### D-11 Duplicate-slot guard in build()

In `SceneBuilder.build()` before merging palette ops:
- Groups all `SetPalette` ops by slot number
- `require` that no slot appears more than once within the same scene
- Error message names the duplicate slot number

### Auto-increment default preserved (D-10)

The existing `fun palette(palette: GBCPalette)` overload is unchanged — it still assigns sequential slots 0, 1, 2, 3 when `palette.slot == -1`.

### Test coverage added to Seed007GameBuilderPaletteSlotTest

Five new test methods:
1. `scene palette with explicit slot emits SetPalette with that slot ignoring palette declared slot` — D-09 correctness
2. `scene auto_increment palette default is preserved sequential 0_1_2_3` — D-10 regression guard
3. `scene palette with slot 8 throws at build time naming bad slot` — D-11 range
4. `two palettes claiming same slot within one scene throws at build time` — D-11 duplicate
5. `same slot in different scenes does not throw` — D-11 scope is per-scene
