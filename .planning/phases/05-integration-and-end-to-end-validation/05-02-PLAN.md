**Step 1: Run the full build pipeline.**
```bash
./gradlew :gbkt-examples:pong:clean :gbkt-examples:pong:buildRom 2>&1
```

**Step 2: If `generateC` fails** — the 05-01 bridge isn't working. Check the 05-01-SUMMARY.md and verify the bridge was wired correctly. Don't proceed until `generateC` succeeds.

**Step 3: If `compileRom` fails with lcc errors** — this is expected. The v2 C codegen may produce C that doesn't match GBDK expectations. Common issues to diagnose and fix:

a. **Missing `#include` directives:** `GBDKPipelineV2.buildHomeFile()` or `buildSceneFile()` may be missing `#include <gb/gb.h>`, `#include <stdio.h>`, `#include "game.h"`. Check generated `main.c` and `bank1.c` headers.

b. **Missing BANKED keyword:** Bank 1 functions need `BANKED` suffix. The `GBDKPipelineV2.buildSceneFile()` should add `BANKED` via `CFunction.bank` field. Verify `CEmitter` emits `BANKED` for functions with non-null bank.

c. **Undefined identifiers:** Variables declared in `main.c` but used in `bank1.c` need `extern` declarations in `game.h`. Check `GBDKPipelineV2.buildHeaderFile()` generates all needed externs.

d. **Type mismatches:** GBDK uses `UINT8`, `INT8`, `UINT16`, etc. Verify `CEmitter.emitType()` produces correct GBDK type names. The v2 pipeline uses `CU8`, `CI8`, `CU16`, `CI16` — check these map to correct GBDK typedefs.

e. **Forward declaration issues:** `game.h` needs function prototypes with `BANKED` for all bank-resident functions. Verify these match the actual function signatures in `bank1.c`.

f. **Missing `main()` function:** `main.c` must have a `void main(void)` entry point. Check `GBDKPipelineV2.buildHomeFile()` generates it.

g. **`#pragma bank N` placement:** `bank1.c` must start with `#pragma bank 1` before any code. Verify `CEmitter` emits this pragma.

**Step 4: For each error, fix the codegen** (in the visitor or pipeline files), NOT the generated C. Re-run `./gradlew :gbkt-examples:pong:clean :gbkt-examples:pong:buildRom` after each fix.

**Step 5: Iterate** until `buildRom` succeeds and produces `pong.gb`.
