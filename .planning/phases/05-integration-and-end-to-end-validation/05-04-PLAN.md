**Part A — Create `ValidateRomTask.kt`:**

Create a new Gradle task class at `gbkt-gradle-plugin/src/main/kotlin/io/github/gbkt/gradle/tasks/ValidateRomTask.kt`.

```kotlin
abstract class ValidateRomTask : DefaultTask() {
    @get:InputFile abstract val romFile: RegularFileProperty
    @get:Optional @get:Input abstract val emulatorPath: Property<String>
    @get:Input abstract val frameCount: Property<Int>

    init {
        group = "gbkt"
        description = "Validate ROM boots without crash using mGBA"
        frameCount.convention(300)
    }

    @TaskAction
    fun validate() { ... }
}
```

**Emulator detection:** Reuse the same detection logic as `RunEmulatorTask`:
1. Check `emulatorPath` property (user override)
2. Check `which mgba-sdl` (preferred for automation — supports `-S` flag reliably)
3. Check `/Applications/mGBA.app/Contents/MacOS/mGBA` on macOS
4. If none found, log WARNING and skip validation (do not fail the build — mGBA may not be installed)

**Lua validation script:** Generate a temporary `validate-rom.lua` in `temporaryDir`:
```lua
local TARGET_FRAMES = <frameCount>
local frame_count = 0

callbacks:add("frame", function()
    frame_count = frame_count + 1
    if frame_count >= TARGET_FRAMES then
        emu:quit(0)
    end
end)

callbacks:add("crashed", function()
    emu:quit(1)
end)
```

Note: The mGBA Lua scripting API uses `emu:quit(code)` to exit. If `emu:quit` is not available in the version detected, fall back to `os.exit()`.

**Execution:** Run emulator with process timeout:
```kotlin
val process = ProcessBuilder(emulatorPath, "-S", scriptFile.absolutePath, romFile.absolutePath)
    .redirectErrorStream(true)
    .start()

val completed = process.waitFor(15, TimeUnit.SECONDS)
if (!completed) {
    process.destroyForcibly()
    // Process survived 15 seconds = ROM is running = PASS
    logger.lifecycle("ROM validated: ${romFile.name} survived ${frameCount.get()} frames (timeout = pass)")
} else {
    val exitCode = process.exitValue()
    if (exitCode != 0) {
        throw GradleException("ROM validation failed: crash detected within ${frameCount.get()} frames")
    }
    logger.lifecycle("ROM validated: ${romFile.name} booted ${frameCount.get()} frames without crash")
}
```

**Graceful degradation:**
- If mGBA not found: print `"WARNING: mGBA not found. Skipping ROM validation. Install via: brew install mgba"` and return (do NOT fail)
- If `-S` flag not supported (mGBA < 0.10.0): print WARNING and skip
- If timeout reached but process exited non-zero: report as failure
