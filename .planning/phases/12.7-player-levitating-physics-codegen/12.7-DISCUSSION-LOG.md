## Snap-to-tile-top formula shape inside the foot probe

| Option | Description | Selected |
|--------|-------------|----------|
| Bit-shift algebraic | Compute `foot_tile_row = (player_real_y + height) >> 3`; `posYSym = ((foot_tile_row << 3) - height) << 4`. Single deterministic assignment. Matches `>> 4` sub-pixel and `>> 3` tile-row conventions used elsewhere. | ✓ |
| Multiplied algebraic | Same math expressed as `posYSym = (((player_real_y + height) / 8) * 8 - height) * 16`. Functionally identical but generates `/` and `*` ops; SDCC may emit slower div/mul vs shifts. | |
| Per-foot-probe snap (left + right) | Two snaps: one per left-foot hit, one per right-foot hit, using the higher tile when both hit. Handles slope-edge case. Adds complexity; platformer-template has only flat ground (unobserved). | |

**User's choice:** Bit-shift algebraic (Recommended).
**Notes:** → D-02. Per-foot-probe snap deferred to Phase 13+ if slope support lands.
