#### `extractFunctionBody` helper — copy verbatim from `TilemapCollisionEmissionTest.kt` lines 90–110:
```kotlin
private fun extractFunctionBody(cSource: String, functionSignaturePrefix: String): String {
    val lines = cSource.lines()
    val startIdx = lines.indexOfFirst { it.startsWith(functionSignaturePrefix) }
    if (startIdx == -1) return ""
    val body = StringBuilder()
    var depth = 0
    var started = false
    for (i in startIdx until lines.size) {
        val line = lines[i]
        body.appendLine(line)
        for (ch in line) {
            if (ch == '{') { depth++; started = true }
            if (ch == '}') depth--
        }
        if (started && depth == 0) break
    }
    return body.toString()
}
```

Anchor for this test: `"void platformer_physics_update"` (NOT `"UINT8 is_tile_solid"`).
The emitted C signature is `void platformer_physics_update(void) {` — the prefix without
`(void)` matches the start of the line per the `startsWith` check (RESEARCH Finding 10,
Pitfall 3).

## Shared Patterns

### C-AST Builder: `CLiteral` vs `CIntLiteral`

**Source:** `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/ast/CExpr.kt`
(lines 24, 38) + `gbkt-backend-gbdk/CLAUDE.md` §"Literal Emission Convention"

**Apply to:** All `CBinaryExpr` nodes in PlatformerVisitor changes.

