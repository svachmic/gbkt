<objective>
W7 GREEN. Fix the operator-precedence bug in `PlatformerVisitor.buildVerticalFootProbe`
by restructuring the snap-to-tile-top emission to use intermediate `CVarDecl` locals.
Each line of the emitted C will have AT MOST ONE binary-op class, making C precedence
unable to misparse the expression.

The bug:

```c
_player_y = foot_tile_row << 3u - 24u << 4u;
// C precedence: + / - is HIGHER than << / >>
// Parses as: foot_tile_row << (3u - 24u) << 4u
// (3u - 24u) underflows unsigned → huge shift → garbage → _playerY ≈ 0 → player glued to top of screen
```

The fix (intermediate-vars / Path A):

```c
UINT16 foot_tile_row     = (player_real_y + height) >> 3;   // emits: player_real_y + 24u >> 3u (OK — + binds tighter than >>)
UINT16 foot_pixel_top    = foot_tile_row << 3;              // ONE op per line
UINT16 foot_pixel_anchor = foot_pixel_top - height;          // ONE op per line
_player_y                = foot_pixel_anchor << 4;          // ONE op per line
```
