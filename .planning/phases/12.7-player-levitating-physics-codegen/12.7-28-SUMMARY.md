# Phase 12.7 Plan 28: GREEN — H3 level-end trigger grounded guard fix

## One-liner

Added `&& _grounded != 0` conjunction to the level-end trigger CIf in `PlatformerVisitor.buildTilemapPhysicsUpdateFunction`, flipping Plan 12.7-27's RED assertion GREEN and preventing mid-air trigger fire.

## What Was Built

**Task 1: Extend level-end trigger CIf with `groundedSym != 0` conjunction**

Modified `PlatformerVisitor.kt` at the trigger emit-site (section 8, lines 1204-1218). The existing single-condition `CBinaryExpr(CVar("player_real_x"), ">", ...)` was wrapped as the LHS of a new outer `CBinaryExpr(..., "&&", CBinaryExpr(CVar(groundedSym), "!=", CIntLiteral(0)))`.

**Kotlin diff (conceptual):**

Before:
```kotlin
add(CComment("Level-end trigger: increment _next_level when past the right margin"))
add(CIf(
    condition = CBinaryExpr(CVar("player_real_x"), ">",
        CBinaryExpr(CVar("_current_level_width"), "-", CLiteral(levelEndRightMargin))),
    thenBody = listOf(CExprStatement(CUnaryExpr("++", CVar("_next_level")))),
))
```

After:
```kotlin
add(CComment("Level-end trigger: increment _next_level when past the right margin (grounded-only — Round-6 H3 fix per Plan 12.7-26 verdict; player must be on the floor at trigger fire per SPEC R-03 wording)"))
add(CIf(
    condition = CBinaryExpr(
        CBinaryExpr(CVar("player_real_x"), ">",
            CBinaryExpr(CVar("_current_level_width"), "-", CLiteral(levelEndRightMargin))),
        "&&",
        CBinaryExpr(CVar(groundedSym), "!=", CIntLiteral(0)),
    ),
    thenBody = listOf(CExprStatement(CUnaryExpr("++", CVar("_next_level")))),
))
```

**Generated C post-fix:**
```c
// Level-end trigger: increment _next_level when past the right margin (grounded-only — ...)
if (player_real_x > _current_level_width - 32u && _grounded != 0) {
    ++_next_level;
}
```
