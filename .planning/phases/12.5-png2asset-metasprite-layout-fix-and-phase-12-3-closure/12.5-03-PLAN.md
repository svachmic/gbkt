<objective>
Per D-04, D-04a, D-04b: add the typed DSL flag builders (`mode()`, `pivot()`, `frameSize()`) inside the `sprite()` block on `MetaspriteBuilder`, plus the 5 corresponding additive nullable fields on `MetaspriteIR`. This is the user-facing DSL surface that replaces the implicit `-spr8x8` height-heuristic with explicit per-metasprite declarations.

Purpose: REQ-2 (3col×2row layout correction) can only happen if the png2asset cutting flags (-px, -py, -sw, -sh) reach `ConvertSpritesTask` from the DSL. This plan adds the DSL→IR carrier; Plan 04 emits them into the sidecar; Plan 05 reads them back; Plan 06 enforces non-null at codegen boundary.

Output: 2 source-file edits + 1 new test file in gbkt-lang. Zero runtime behavior change — Plan 04 emits the new IR fields into the sidecar, and Plan 05 wires them to png2asset. Migration plans (07, 08) populate them per-game.
</objective>
