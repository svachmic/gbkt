## What Was Built

**ConvertSpritesTask.kt** — The previously unguarded `JSONObject(metaFile.readText())` call at line 99 is now wrapped:

```kotlin
val json =
    try {
        JSONObject(metaFile.readText())
    } catch (e: JSONException) {
        throw GradleException(
            "Sprite sidecar at ${metaFile.absolutePath} is malformed: ${e.message}. " +
                "Re-run :generateC to regenerate the sidecar.",
            e,
        )
    }
```

**ConvertSpritesTaskSidecarTest.kt** — New test `malformed_sidecar_throws_actionable_gradle_exception`:
- Writes `{"sprites": [` (truncated mid-array) to a temp `game_metadata.json`
- Calls `task.convertSprites()`
- Asserts `GradleException` is thrown (not raw `JSONException`)
- Asserts message contains `metaFile.absolutePath`
- Asserts message contains `"Re-run :generateC"`
