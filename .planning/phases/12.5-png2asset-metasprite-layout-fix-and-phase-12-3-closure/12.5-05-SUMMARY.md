## What Was Built

### ConvertSpritesTask.kt (refactored)

1. **Extended sidecar reader** in `convertSprites()` loop — reads 5 new fields per entry using `opt*` for backward compat:
   ```kotlin
   val spriteMode = SpriteMode.valueOf(entry.optString("spriteMode", "SPR8x16"))
   val pivotX = entry.optInt("pivotX", 0)
   val pivotY = entry.optInt("pivotY", 0)
   val frameWidth = entry.optInt("frameWidth", 8)
   val frameHeight = entry.optInt("frameHeight", 8)
   ```

2. **Updated `convertSprite()` signature** — accepts 5 new cutting-flag params (spriteMode, pivotX, pivotY, frameWidth, frameHeight) plus existing mirrorDedup.

3. **Extracted `internal fun buildPng2AssetArgs(...)`** at file scope — builds the complete png2asset arg list:
   - Input PNG + `-o outputC`
   - Optional `-spr8x8` for SPR8x8 mode (SPR8x16 is default, no flag)
   - `-px <pivotX> -py <pivotY>`
   - `-sw <frameWidth> -sh <frameHeight>`
   - Optional `-noflip` when mirrorDedup=false

4. **Deleted `spriteModeFromHeight()`** — function body, KDoc, and all references removed. Zero occurrences in the file.

5. **Preserved `#pragma bank 1` injection** — `injectBankPragma()` helper and `val pragmaLine = "#pragma bank $bankNum"` literal remain intact (verified via grep count = 1).
