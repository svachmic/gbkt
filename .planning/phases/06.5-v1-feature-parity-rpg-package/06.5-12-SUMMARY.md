## Accomplishments

- `generateMovementRangeFunction()`: full iterative BFS with parallel queue arrays (queue_x, queue_y, queue_cost) and head/tail pointers; clears _tg_reachable[], seeds from unit position, explores 4 cardinal neighbors with terrain cost and visited checks; CContinue for bounds/passability/visited skips; no recursion
- `generateLineOfSightFunction()`: Bresenham tile-walk using CI8 signed locals, CTernary for sx/sy, CWhile(1) infinite loop with CReturn(1) on target reached and CReturn(0) on wall terrain; wall index resolved at Kotlin compile time from cfg.terrainTypes
- `generateFacingBonusFunction()`: dominant-axis approach direction, CIf/CTernary for horizontal vs vertical, `(approach_dir + 4 - face_dir) % 4` diff computation, returns backstabBonus (diff==2), flankingBonus (diff==1||3), 0 (front)
- `generateElevationBonusFunction()`: reads _tg_elevation[attacker] and _tg_elevation[defender], returns (a_elev - d_elev) * elevationDamageBonus when higher, 0 otherwise
- `generateAoeTargetingFunction()`: CSwitch on shape parameter with CSwitchCase for each pattern; SINGLE marks center; LINE extends north (radius steps); CROSS marks cardinal directions from center; DIAMOND uses Manhattan distance filter; SQUARE uses full bounding box; all with bounds checks

## Decisions Made

- CTernary used for sx/sy sign computation and direction offsets — matches the algorithm formula directly and generates clean `(cond) ? a : b` C output without an if/else block
- Wall terrain index resolved at Kotlin compile time from `cfg.terrainTypes.indexOfFirst { it.movementCost == -1 }` — the generated C constant avoids any runtime table lookup overhead for LOS
- AoE function signature extended with third `shape` UINT8 parameter — enables runtime ability shape selection from a single generated function
- CI8 type used for signed locals (dx, dy, sx, sy, err, e2, odx, ody) — CI8 maps to INT8 in GBDK, correct for negative offsets and Bresenham signed arithmetic
- CContinue (not CBreak) inside for-loops — CBreak would exit the loop, CContinue skips to next iteration as intended
