    1. **Add ATB branch to CombatVisitor.buildStateMachineSwitch()**: When `system.combatType == CombatType.ATB`, the state machine gets additional states and per-frame gauge logic:

       ATB state machine additions:
       - COMBAT_STATE_GAUGE_FILL (new state ID, register as custom state): Per-frame gauge update loop for all combatants
       - In GAUGE_FILL state: for each combatant, increment `_combat_<id>_gauge[i]` by `base + (agl_<i> / 4)`. When gauge >= maxGauge, transition to action state.
       - WAIT mode: emit `if (_combat_<id>_menu_open) { /* skip gauge fill */ }` check
       - CHARGE model: replace fill with per-action charge counter that counts down from ability.chargeTurns

       C code pattern for gauge fill (all typed C AST):
       ```c
       /* GAUGE_FILL state */
       for (UINT8 i = 0; i < _combat_<id>_count; i++) {
           if (_combat_<id>_active[i] && !_combat_<id>_acted[i]) {
               _combat_<id>_gauge[i] += ATB_BASE_RATE + (_combat_<id>_agl[i] >> 2);
               if (_combat_<id>_gauge[i] >= ATB_MAX_GAUGE) {
                   _combat_<id>_gauge[i] = ATB_MAX_GAUGE;
                   /* combatant ready to act */
               }
           }
       }
       ```

       Emit gauge globals: `_combat_<id>_gauge[N]` as UINT8 array, `ATB_BASE_RATE` and `ATB_MAX_GAUGE` as CDefine constants.
