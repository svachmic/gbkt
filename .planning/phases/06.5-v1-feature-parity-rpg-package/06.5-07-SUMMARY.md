## Decisions Made
- Sell override sentinel 0xFF (UINT8 max) chosen for _shop_<id>_sell_override array — consistent with 0xFF-as-null convention used throughout codebase (_equipped_slot, etc.)
- Guest member codegen added as standalone functions (is_guest/remove_guest/update_ai_guest) rather than modifying CombatVisitor — preserves engine layer purity
- Save checksum uses CIf loop body instead of CWhile/CFor — loop variable declaration before loop body required for C89 compliance
- PLAYER_TURN dispatch generated as standalone update_rpg_player_turn_<id>() — game author wires it in combat frame; does not modify CombatVisitor
