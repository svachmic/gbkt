**1. generateMovementRangeFunction()** (line ~1134):

Data model assumptions (consistent with existing tactical grid globals):
- `_tg_<id>_terrain[]` — flat array [gridWidth * gridHeight] of terrain type indices
- `_tg_<id>_terrain_cost[]` — array mapping terrain type index to movement cost
- `_tg_<id>_reachable[]` — output: array [gridWidth * gridHeight] marking cells reachable (1) or not (0)
- `_tg_<id>_unit_x[]` / `_tg_<id>_unit_y[]` — unit positions

Algorithm (iterative BFS with cost tracking):
```c
void calc_movement_range_<id>(UINT8 unit_idx, UINT8 range) {
    UINT8 i, head, tail, cx, cy, nx, ny, cost, ncost;
    UINT8 queue_x[64];  /* BFS queue X coords */
    UINT8 queue_y[64];  /* BFS queue Y coords */
    UINT8 queue_cost[64]; /* remaining movement at each queued cell */
    /* Clear reachable array */
    for (i = 0; i < gridWidth * gridHeight; i++) _tg_<id>_reachable[i] = 0;
    /* Seed: unit starting position */
    head = 0; tail = 0;
    queue_x[tail] = _tg_<id>_unit_x[unit_idx];
    queue_y[tail] = _tg_<id>_unit_y[unit_idx];
    queue_cost[tail] = range;
    tail++;
    _tg_<id>_reachable[queue_y[0] * gridWidth + queue_x[0]] = 1;
    /* BFS loop */
    while (head < tail) {
        cx = queue_x[head]; cy = queue_y[head]; cost = queue_cost[head]; head++;
        /* Check 4 neighbors: up, down, left, right */
        for (dir = 0; dir < 4; dir++) {
            /* compute nx, ny from direction */
            /* bounds check: 0 <= nx < gridWidth, 0 <= ny < gridHeight */
            /* terrain cost check: ncost = terrain_cost[terrain[ny*w+nx]] */
            /* if ncost > 0 (passable) and cost >= ncost and not already reachable */
            /* mark reachable, enqueue with remaining cost */
        }
    }
}
```

**2. generateLineOfSightFunction()** (line ~1152):

Algorithm:
```c
UINT8 check_line_of_sight_<id>(UINT8 from, UINT8 to) {
    INT8 x0, y0, x1, y1, dx, dy, sx, sy, err, e2;
    x0 = from % gridWidth; y0 = from / gridWidth;
    x1 = to % gridWidth; y1 = to / gridWidth;
    dx = abs(x1 - x0); dy = abs(y1 - y0);
    sx = (x0 < x1) ? 1 : -1;
    sy = (y0 < y1) ? 1 : -1;
    err = dx - dy;
    while (1) {
        if (x0 == x1 && y0 == y1) return 1; /* reached target */
        if (_tg_<id>_terrain[y0 * gridWidth + x0] == WALL_IDX) return 0; /* blocked */
        e2 = err * 2;
        if (e2 > -dy) { err -= dy; x0 += sx; }
        if (e2 < dx) { err += dx; y0 += sy; }
    }
    return 1;
}
```

**3. generateFacingBonusFunction()** (line ~1168):
Implement flanking/backstab bonus. Receives attacker and defender cell indices, returns bonus percentage (0, flanking, or backstab).

Algorithm: Compare attacker direction relative to defender's facing direction.
- Compute attacker's approach direction from cell positions (dx, dy between attacker and defender)
- The facing direction is stored in `_tg_<id>_facing[]` array (0=UP, 1=RIGHT, 2=DOWN, 3=LEFT)
- If attacker approaches from behind defender's facing → backstab bonus
- If attacker approaches from the side → flanking bonus
- Otherwise → 0

C AST:
```
UINT8 calc_facing_bonus_<id>(UINT8 attacker, UINT8 defender) {
    UINT8 ax, ay, dx, dy, approach_dir, face_dir, diff;
    ax = attacker % gridWidth; ay = attacker / gridWidth;
    dx = defender % gridWidth; dy = defender / gridWidth;
    /* Determine approach direction */
    if (abs(ax - dx) > abs(ay - dy)) approach_dir = (ax > dx) ? 3 : 1; /* LEFT or RIGHT */
    else approach_dir = (ay > dy) ? 0 : 2; /* UP or DOWN */
    face_dir = _tg_<id>_facing[defender];
    diff = (approach_dir + 4 - face_dir) % 4;
    if (diff == 2) return backstabBonus; /* directly behind */
    if (diff == 1 || diff == 3) return flankingBonus; /* from side */
    return 0;
}
```

Use cfg.flankingBonus and cfg.backstabBonus for the return values. Remove TODO comment. Remove `@Suppress("UNUSED_PARAMETER")` from cfg.
