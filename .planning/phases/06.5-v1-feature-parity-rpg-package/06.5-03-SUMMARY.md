## Decisions Made

- Behavior tree compiled to flat iterative C if/else chains at codegen time — zero C recursion for Game Boy ~128-byte stack
- BehaviorTreeBuilder.build() returns SelectorNode wrapping all accumulated root nodes
- MonsterDef.allowGlobalRepeatPrevention emits `_mon_<id>_last_action` UINT8 global and `!= current_action` guard before each action branch in update_ai_<id>()
- difficulty=EASY overrides all TargetStrategy to RANDOM (dumb); difficulty=HARD overrides to LOWEST_HP (smart); difficulty=NORMAL uses tree-specified strategy
- GAP-5: flat stat subtraction `chance = applyChance - (target_resistStat - caster_matk)` — no clamping at codegen level
- GAP-6: per-effect boolean `_char_<target>_immune_to_<effectId>` guard in apply_effect; bitmask allocation deferred to combat init codegen
- GAP-8: separate remove_effect_<id>() per-effect clear + dispel_buffs(target_idx) iterates all BUFF-category effects
