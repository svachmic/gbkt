## Decisions Made

- **Wave IR types in gbkt-ir**: `CombatEngineSystem.waveSurvivalConfig` field type must be in the same module as `CombatEngineSystem` (Kotlin sealed interface constraint). Moving wave types to `gbkt-rpg/domain/` would create a circular dependency. Placed in `WaveSurvivalIR.kt` in `gbkt-ir` alongside `CombatEngineIR.kt`.
- **6-state machine vs 5-state**: Wave survival has a fundamentally different progression cycle (wave loop) from normal combat (linear turn flow). 6 states required: INIT, WAVE_ACTIVE, WAVE_COMPLETE, BETWEEN_WAVE, VICTORY, DEFEAT.
- **maxWaves=0 = endless mode**: Zero is the natural "no limit" sentinel for unsigned integers in C/GBDK context. Endless mode emits no victory state request in `advance_wave`.
