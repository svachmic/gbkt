       The `encounters` and `partyIds` from SimpleBattleDef need to be mapped into CombatEngineSystem fields. **Committed approach:** Add `val encounterConfig: Map<String, Any>? = null` to CombatEngineSystem with a null default (backward-compatible). CombatVisitor reads encounterConfig when generating initialization code for TURN_BASED combats that have encounter data. Do NOT use customStates (those are for state machine extensions). Do NOT keep SimpleBattleDef as a separate type.
