    1. **Add equipment codegen to RpgVisitor**:
       - `generateEquipmentFunctions(system: GenericSystem): List<CFunction>`:
         - Emit `equip_item_<slotName>(item_id)`: stat modifier application (flat then percent), set bonus check, two-handed/dual-wield exclusion
         - Emit `unequip_<slotName>()`: reverse modifiers, clear slot
         - Emit equipment slot globals: `_equipped_<slotName>` as UINT8 (item ID or 0xFF for empty)
         - Emit set bonus tracking: `_set_<id>_count` counter, `check_set_bonus_<id>()` function
         - If durability enabled: `_equip_durability_<slotName>` globals and `degrade_equipment()` function
         - **GAP-1 (equipment upgrades codegen):** If enableUpgrades is true:
           - Emit `_equip_<slot>_upgrade_level` UINT8 globals (one per slot, default 0)
           - Emit `upgrade_item_<slot>(level)` function: validates level <= maxUpgradeLevel, sets `_equip_<slot>_upgrade_level = level`, recalculates stats as `base + flat + (upgrade_bonus * level) + percent`. The upgrade_bonus is a fixed value per upgrade level (e.g., +2 per level).
           - Stat recalculation in `equip_item_<slot>()` must account for upgrade level when applying modifiers
         - **GAP-2 (elemental enchanting codegen):** If enableEnchanting is true:
           - Emit `_equip_<slot>_enchant` UINT8 globals (one per slot, stores Aspect ordinal; 0 = NONE)
           - Emit `enchant_item_<slot>(aspect_id)` function: sets `_equip_<slot>_enchant = aspect_id`, applies elemental modifier to damage calculation (adds aspect-typed bonus damage)
           - If EquipmentItemData.enchantAspect is non-null, emit initial enchant assignment in `equip_item_<slot>()`
       - All typed C AST — zero CRawCode

    2. **Add class codegen to RpgVisitor**:

         - Emit `check_ability_learn_<classId>(level)`: CSwitch on level for auto-learn at thresholds
       - If job change enabled: emit `change_class(char_id, new_class_id)` with mode-dependent behavior
