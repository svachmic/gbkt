**2. generateSpeedBasedTurnOrderFunction()** (line ~1050):
Replace the TODO comment body with an insertion sort over `maxCombatants` entries. The function sorts `_turn_order_<id>[]` indices by descending `_combat_<id>_agl[]` values. Remove the `@Suppress("UNUSED_PARAMETER")` annotation from the maxCombatants parameter.

Algorithm (insertion sort, O(n^2) — fine for N<=8 on GB):
```
// Initialize turn order: 0, 1, 2, ..., n-1
for (i = 0; i < n; i++) _turn_order[i] = i;
// Insertion sort descending by agl
for (i = 1; i < n; i++) {
    key = _turn_order[i];
    key_agl = agl[key];
    j = i - 1;
    while (j >= 0 && agl[_turn_order[j]] < key_agl) {
        _turn_order[j+1] = _turn_order[j];
        j--;
    }
    _turn_order[j+1] = key;
}
```

C AST structure: Two CFor loops. First initializes order array. Second does outer loop of insertion sort. Inner loop uses CWhile with the comparison and swap. Use CVarDecl for `key`, `key_agl`, `j` local variables (declared BEFORE the loops per C89 rule). The UNUSED_PARAMETER suppress can be removed since maxCombatants is now used.
