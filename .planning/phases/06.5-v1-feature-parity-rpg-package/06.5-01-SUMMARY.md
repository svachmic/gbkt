## Tasks Completed

### Task 1: Extend CombatStats, CharacterDef, CharacterBuilder with full RPG stats and leveling

Extended the RPG domain layer with backward-compatible new fields:

**CombatStats** now has 7 stat fields:
- `hp`, `atk`, `def` (existing) + `sp`, `matk`, `mdef`, `agl` (new with `= 0` defaults)
- All new fields have `require(field >= 0)` validation

**ExpCurve enum** created with STANDARD/SLOW/FAST strategies for leveling progression.

**CharacterDef** extended:
- `level: Int = 1`, `maxLevel: Int = 99`, `expCurve: ExpCurve = ExpCurve.STANDARD`
- `onLevelUpOps: List<ScriptOp> = emptyList()`
- `require(level in 1..maxLevel)` validation

**CharacterBuilder** updated:
- `CombatStatsBuilder` now has all 7 stat setters
- `fun level(initial, maxLevel, expCurve)` DSL method
- `fun onLevelUp(block)` DSL method using ScriptBuilder pattern

**RpgExtensions.character()** now registers a `GenericSystem(type="rpg_character_system")` alongside domain registry so the backend can emit C stat structures.

All 27 existing RPG tests continue to pass (backward-compatible defaults).

### Task 2: Create RpgVisitor skeleton + _item_names[] table + codegen dispatch wiring

**RpgVisitor** created following CombatVisitor/InventoryVisitor pattern:
- `generateCharacterStatStructs(system)`: generates `level_up_<id>()` function (only when onLevelUpOps non-empty)
- `generateStatVarDecls(system)`: generates 7 const UINT8 stat globals + mutable UINT8 level + mutable UINT16 exp

**GBDKSystemVisitor** updated with dispatch branches:
- `"rpg_character_system"` → `RpgVisitor(gameIR).generateCharacterStatStructs(system)`
- `"rpg_ability"`, `"rpg_status_effect"` → `emptyList()` (data-only, no trigger function)

**InventoryVisitor** extended with `generateItemNamesTable()`:
- Returns `null` when `gameIR.items.isEmpty()` (no dead code)
- Returns `CVarDecl(name="_item_names", type=CArray(CPointer(CU8), N), isConst=true)` with `CRawExpr` initializer

**GBDKPipelineV2** wired with:
- `buildRpgCharStatVars(gameIR)` — collects rpg_character_system GenericSystems → RpgVisitor.generateStatVarDecls
- `itemNamesTable` — InventoryVisitor.generateItemNamesTable(), null-safe via listOfNotNull()

**gbkt-backend-gbdk** added `implementation(project(":gbkt-rpg"))` dependency for CombatStats type access.

**RpgCodegenTest** created with 6 tests:
- All 7 stat globals present in main.c
- Mutable level and exp variables present
- Const qualifier on stat globals
- _item_names table with string literals
- Empty items → no _item_names table
- level_up function generated for non-empty onLevelUpOps
