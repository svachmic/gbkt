## Decisions Made

- `EquipmentConfig` is a single config object (not builder-time flags) — passed through GenericSystem config map for clean serialization
- Equipment upgrade codegen (`upgrade_item_<slot>`) validates `level <= maxUpgradeLevel` before applying — Game Boy-safe bounds check
- `ClassDef.equipRestrictions: Set<EquipSlot>` defaults to all slots — restrictive DSL means removing slots, not adding
- `enchantAspect` in `EquipmentItemData` is the initial/default enchantment — runtime enchanting overrides via `enchant_item_<slot>(aspect_id)` at runtime
