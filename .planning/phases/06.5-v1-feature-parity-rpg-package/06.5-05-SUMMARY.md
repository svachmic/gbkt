## Decisions Made

- ATB INIT transitions to GAUGE_FILL (state 5) not PLAYER_TURN (state 1). Classic ATB starts in gauge-fill mode where all combatants fill their bars before any action becomes available.
- WAIT mode guard is placed at the GAUGE_FILL case level (`if (!menu_open) call update_atb_gauges()`), not inside the update function itself. This allows the PLAYER_TURN case to also call `update_atb_gauges` without the menu_open check (ACTIVE-like behavior during player action selection).
- CHARGE case (case 6u) is only emitted when `gaugeModel == CHARGE` — zero dead code for FILL model games.
- Insertion sort for SPEED_BASED turn order: O(n^2) is appropriate for n ≤ 8 combatants on 4MHz Game Boy hardware. Minimal code size vs quicksort.
- `generateAtbGlobals` includes `_combat_<id>_charge[]` array only for CHARGE model, `_turn_order_<id>[]` only when `turnOrderStrategy != null`.
- `buildAtbStateMachineSwitch` is dispatched from `buildStateMachineSwitch` via combatType check — consistent with `buildWaveSurvivalStateMachineSwitch` pattern established in plan 06.5-09.
