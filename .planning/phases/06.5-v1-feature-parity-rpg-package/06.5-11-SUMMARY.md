## Decisions Made

- Used `j < i` as the CWhile termination guard (not `j >= 0`) because j is declared `CU8` (UINT8). When j decrements past 0 it wraps to 255, which is always > i (i <= 8 for Game Boy), giving correct termination without signed arithmetic.
- All CFor init parameters are `CVarDecl` (CStatement subtype) and increment parameters are `CUnaryExpr` (CExpr subtype) — matching the actual CFor data class signatures, not CRawExpr.
- C89 compliance maintained: all local variable declarations (`CVarDecl("i", CU8, null)`, etc.) placed before any CFor/CWhile statements in speed-based sort function body.
