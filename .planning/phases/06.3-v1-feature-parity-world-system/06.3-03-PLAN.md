```kotlin
/** Collision mode for entity-player interaction during exploration. */
enum class EntityCollisionMode {
    BLOCK,              // Entity acts as wall — movement stops
    PASSTHROUGH,        // Entity has no collision — player walks through
    BLOCK_AND_TRIGGER,  // Movement stops, trigger fires with entity ref
    OVERLAP_TRIGGER,    // Player moves onto entity tile, trigger fires
    PUSH,               // Entity is pushed if destination is free
}

/** Direction constraints for pushable entities. */
enum class PushDirection {
    ANY,                // Push in any direction
    HORIZONTAL_ONLY,    // Push left/right only
    VERTICAL_ONLY,      // Push up/down only
    SPECIFIC,           // Specific directions set via allowedDirections
}

/** Collision shape type for entity-player collision. */
enum class CollisionShape {
    TILE,               // Full grid tile collision (8x8 or configured tile size)
    HITBOX,             // Pixel-based hitbox (from actor hitbox definition)
}

/** Configuration for an entity's collision behavior in the exploration system. */
data class EntityCollisionConfig(
    val mode: EntityCollisionMode = EntityCollisionMode.BLOCK,
    val shape: CollisionShape = CollisionShape.TILE,
    val pushDirection: PushDirection = PushDirection.ANY,
    val allowedPushDirections: Set<TransitionEdge> = emptySet(),
    val tilesWide: Int = 1,
    val tilesHigh: Int = 1,
    val onBlockedStatements: List<ScriptOp> = emptyList(),
    val onOverlapStatements: List<ScriptOp> = emptyList(),
    val onPushedStatements: List<ScriptOp> = emptyList(),
    val bumpFeedback: Boolean = true,
)
```

```kotlin
@GbktDsl
class EntityCollisionBuilder {
    private var mode: EntityCollisionMode = EntityCollisionMode.BLOCK
    private var shape: CollisionShape = CollisionShape.TILE
    private var pushDir: PushDirection = PushDirection.ANY
    private var allowedDirs: Set<TransitionEdge> = emptySet()
    private var tilesW: Int = 1
    private var tilesH: Int = 1
    private var onBlockedCallback: (ScriptBuilder.() -> Unit)? = null
    private var onOverlapCallback: (ScriptBuilder.() -> Unit)? = null
    private var onPushedCallback: (ScriptBuilder.() -> Unit)? = null
    private var bump: Boolean = true

    fun mode(m: EntityCollisionMode) { mode = m }
    fun shape(s: CollisionShape) { shape = s }
    fun pushDirection(d: PushDirection) { pushDir = d }
    fun allowDirections(vararg dirs: TransitionEdge) { allowedDirs = dirs.toSet() }
    fun tiles(wide: Int, high: Int) { tilesW = wide; tilesH = high }
    fun onBlocked(block: ScriptBuilder.() -> Unit) { onBlockedCallback = block }
    fun onOverlap(block: ScriptBuilder.() -> Unit) { onOverlapCallback = block }
    fun onPushed(block: ScriptBuilder.() -> Unit) { onPushedCallback = block }
    fun bumpFeedback(enabled: Boolean) { bump = enabled }

    internal fun build(): EntityCollisionConfig = EntityCollisionConfig(
        mode = mode,
        shape = shape,
        pushDirection = pushDir,
        allowedPushDirections = allowedDirs,
        tilesWide = tilesW,
        tilesHigh = tilesH,
        onBlockedStatements = onBlockedCallback?.let { recordStatements(it) } ?: emptyList(),
        onOverlapStatements = onOverlapCallback?.let { recordStatements(it) } ?: emptyList(),
        onPushedStatements = onPushedCallback?.let { recordStatements(it) } ?: emptyList(),
        bumpFeedback = bump,
    )
}
```

**2. Generate entity collision functions** in GBDKSystemVisitor.kt:

Add a new private method `buildEntityCollisionFunctions(sanitizedId: String, actors: List<ActorIR>): List<CFunction>` that generates:

a) **_entity_register(entity_id, tile_x, tile_y, mode)** — sets bit in `_entity_grid`, stores position and mode. For multi-tile entities, set bits for all occupied tiles.

b) **_entity_remove(entity_id)** — clears bits in `_entity_grid`, resets mode to PASSTHROUGH. Auto-clear on remove.

c) **_entity_check(nx, ny)** — Dispatches based on entity's collision shape (Gap 2 — CONTEXT.md: "Both tile-based and pixel-based hitbox available"):
   - **TILE shape (default)**: checks `_entity_grid` bit at (nx, ny). Returns entity_id if present, 0xFF if empty. Uses bit manipulation: `_entity_grid[idx / 8] & (1 << (idx % 8))`.
   - **HITBOX shape**: For each entity with `_entity_collision_shape[i] == 1` (HITBOX), perform AABB pixel collision check between player position (nx * tileSize, ny * tileSize, tileSize, tileSize) and entity hitbox (entity pixel position + hitbox offset/size from ActorIR sprite definition). Use the same AABB overlap pattern as the existing actor collision system (`collides()` in core). Return entity_id if AABB overlap, continue to next entity otherwise.
   - Generate both code paths: iterate entities, check `_entity_collision_shape[i]` to decide TILE vs HITBOX path.

d) **_entity_handle_block(entity_id, nx, ny, direction)** — switch on `_entity_collision_mode[entity_id]`:
   - BLOCK (0): if bumpFeedback, call bump sound/visual → return
   - BLOCK_AND_TRIGGER (2): **Set `_blocking_entity_id = entity_id` before emitting onBlocked callback statements** (Gap 1 — CONTEXT.md: "onBlocked receives the blocking entity reference"). Call bump + emit onBlocked callback → return
   - OVERLAP_TRIGGER (3): emit onOverlap callback → don't return (continue movement)
   - PUSH (4): check if destination of push is free (tile + entity grid), if free: **set `_pushed_entity_id = entity_id` and `_push_direction = direction` before emitting onPushed callback statements** (Gap 1 — CONTEXT.md: "onPushed callback fires with entity reference and push direction"). Move entity, update grid, emit onPushed callback; if blocked: bump feedback → return

e) **_entity_set_collision_mode(entity_id, mode)** — runtime mode change setter.

All using typed C AST: CSwitch for mode dispatch, CBinaryExpr for bitwise ops, CArrayAccess for grid lookups.
