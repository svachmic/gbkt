**1. Create AudioMixerBuilder.kt** in `gbkt-lang/src/main/kotlin/io/github/gbkt/core/dsl/`:

The AudioMixer uses GenericSystem with `type="audio_mixer"` config pattern (per RESEARCH.md recommendation — no new SystemIR type needed).

```kotlin
@GbktDsl
class AudioMixerBuilder(private val id: String = "audio_mixer") {
    private val groups = mutableListOf<ChannelGroupDef>()
    private var masterVolume: Int = 7  // 0-7 (Game Boy hardware range)
    private var autoDucking: Boolean = false
    private var autoDuckLevel: Int = 3  // volume to duck to during SFX

    fun group(name: String, block: ChannelGroupBuilder.() -> Unit) {
        groups += ChannelGroupBuilder(name).apply(block).build()
    }

    fun masterVolume(vol: Int) { masterVolume = vol.coerceIn(0, 7) }
    fun autoDucking(enabled: Boolean, duckLevel: Int = 3) {
        autoDucking = enabled
        autoDuckLevel = duckLevel.coerceIn(0, 7)
    }

    /**
     * Gap 3 — CONTEXT.md: "Predefined defaults (music, sfx, ui) plus custom group definitions"
     * If no group() calls are made by the time build() is called, insert default groups:
     *   music (channels 1,2, priority 0), sfx (channels 3,4, priority 1), ui (channel 3, priority 2)
     * If the user has called group() at least once, no defaults are added — the user is in full control.
     * This provides a good starting point while remaining fully overridable.
     */

    internal fun build(): GenericSystem {
        // Gap 3: Add default groups if none defined
        val effectiveGroups = if (groups.isEmpty()) {
            listOf(
                ChannelGroupDef(name = "music", channels = setOf(1, 2), defaultVolume = 7, priority = 0),
                ChannelGroupDef(name = "sfx", channels = setOf(3, 4), defaultVolume = 7, priority = 1),
                ChannelGroupDef(name = "ui", channels = setOf(3), defaultVolume = 7, priority = 2),
            )
        } else {
            groups
        }
        return GenericSystem(
            id = id,
            config = mapOf(
                "type" to "audio_mixer",
                "groups" to effectiveGroups,
                "master_volume" to masterVolume,
                "auto_ducking" to autoDucking,
                "auto_duck_level" to autoDuckLevel,
            ),
        )
    }
}

data class ChannelGroupDef(
    val name: String,
    val channels: Set<Int> = emptySet(), // GB channels: 1=CH1(pulse), 2=CH2(pulse), 3=CH3(wave), 4=CH4(noise)
    val defaultVolume: Int = 7,
    val priority: Int = 0,
)

@GbktDsl
class ChannelGroupBuilder(private val name: String) {
    private var channels: Set<Int> = emptySet()
    private var volume: Int = 7
    private var priority: Int = 0

    fun channels(vararg ch: Int) { channels = ch.toSet() }
    fun volume(vol: Int) { volume = vol.coerceIn(0, 7) }
    fun priority(p: Int) { priority = p }

    internal fun build(): ChannelGroupDef = ChannelGroupDef(
        name = name,
        channels = channels,
        defaultVolume = volume,
        priority = priority,
    )
}
```

**2. Replace buildAudioMixerStubs** in GBDKSystemVisitor.kt:

Rename to `buildAudioMixerFunctions`. Extract `groups` from `system.config["groups"]` cast to `List<ChannelGroupDef>`. Note: `ChannelGroupDef` is defined in gbkt-lang (AudioMixerBuilder.kt) and is accessible from gbkt-backend-gbdk via the transitive `api()` dependency chain: gbkt-backend-gbdk -> gbkt-backend-api -> gbkt-core -> gbkt-lang. Import `io.github.gbkt.core.dsl.ChannelGroupDef`. Generate:

a) **set_group_volume(group, vol)** — store `_mixer_group_vol[group] = vol`. Recalculate effective volume = `(vol * _mixer_master_vol) / 7`. Write NR50_REG with combined L/R volume:
```kotlin
// NR50_REG = (effective_vol << 4) | effective_vol
val effectiveVol = CBinaryExpr(
    CBinaryExpr(CVar("vol"), "*", CVar("_mixer_master_vol")),
    "/", CLiteral(7)
)
```
Use CBinaryExpr for all register writes — NOT CRawCode. The nrWrite helper pattern already exists.

b) **mute_group(group)** — set `_mixer_group_muted[group] = 1`. Clear NR51_REG bits for this group's channels. NR51_REG has 8 bits: bits 7-4 are L-channel enables (CH4,CH3,CH2,CH1), bits 3-0 are R-channel enables:
```kotlin
// NR51_REG &= ~channel_mask;
val clearMask = CBinaryExpr(CVar("NR51_REG"), "&=",
    CUnaryExpr("~", CVar("_mixer_channel_mask_" + groupName)))
```

c) **unmute_group(group)** — set `_mixer_group_muted[group] = 0`. Restore NR51_REG bits:
```kotlin
// NR51_REG |= channel_mask;
val restoreMask = CBinaryExpr(CVar("NR51_REG"), "|=",
    CVar("_mixer_channel_mask_" + groupName))
```

d) **set_master_volume(vol)** — update `_mixer_master_vol`. Recalculate NR50 from master. Loop through non-muted groups and re-apply volume.

e) **fade_group(group, target_vol, frames)** — per-frame interpolation loop. Use CVarDecl + CFor loop: compute step = (target - current) per frame, apply each frame via set_group_volume call. Use CWhile with frame counter and vsync() call for timing.

f) **audio_mixer_request_channel(group, priority)** — NEW (Gap 5 — CONTEXT.md: "Each sound has a priority level. Higher priority can interrupt lower when channels are full"). Body:
   - For each channel in the group's channel set, check `_mixer_priority[ch]`
   - If any channel has priority < requested priority, preempt the lowest-priority channel: set `_mixer_priority[ch] = priority`, return channel number
   - If all channels have priority >= requested, return 0xFF (denied — all channels occupied by higher/equal priority sounds)
   - Use CFor loop over group channels with CIf for priority comparison

g) **audio_mixer_duck()** and **audio_mixer_unduck()** — NEW (Gap 6 — CONTEXT.md: "Music volume automatically reduces during important SFX or dialog playback"). Body:
   - `audio_mixer_duck()`: Save current music group volume to `_mixer_preduck_vol`. Set music group volume to `autoDuckLevel` from config. Only acts if `autoDucking` is enabled in config.
   - `audio_mixer_unduck()`: Restore music group volume from `_mixer_preduck_vol`. Call `set_group_volume(MIXER_GROUP_MUSIC, _mixer_preduck_vol)`.
   - Add `_mixer_preduck_vol` (UINT8, init 7) to buildSystemGlobalVars.
   - If `autoDucking` config is false, these functions are still generated but the duck() function is a no-op (immediate return).

h) **audio_mixer_save_state(ptr)** and **audio_mixer_load_state(ptr)** — NEW (Gap 4 — CONTEXT.md: "Audio settings saveable/restorable as part of game save data"). Body:
   - `save_state(UINT8 *ptr)`: Write mixer globals to buffer: `ptr[0] = _mixer_master_vol; ptr[1] = _mixer_group_vol[0]; ptr[2] = _mixer_group_vol[1]; ...` for each group volume, then mute states. Return total bytes written (or use a fixed-size struct).
   - `load_state(UINT8 *ptr)`: Read buffer back into mixer globals, then call `set_group_volume` for each group to apply restored volumes to hardware registers.
   - Use CArrayAccess and sequential CExprStatements for buffer read/write.

i) Keep **trigger_<id>()** as no-op entry point for TriggerSystem compatibility.
