## Decisions Made

- Used bit-packed UINT8 array for entity grid (129 bytes for 32x32 map) — matches tile collision grid pattern already used in map collision
- Chose entity ordinal values for C switch cases (BLOCK=0, PASSTHROUGH=1, BLOCK_AND_TRIGGER=2, OVERLAP_TRIGGER=3, PUSH=4) — stable because enums declared in fixed order
- HITBOX shape uses entity tile position as AABB origin (entity_tile_x * 8, entity_tile_y * 8) — avoids needing separate pixel-position tracking arrays
- CFor uses `increment: CExpr?` parameter (not `update`) — discovered from CStatement.kt data class signature
- Plan 02's stub (`buildEntityCollisionFunctions` returning `emptyList()`) was in place from wave 2 coordination — replaced cleanly
