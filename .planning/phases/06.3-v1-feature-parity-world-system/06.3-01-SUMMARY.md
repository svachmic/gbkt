## Accomplishments

- Created WorldIR.kt with 9 data classes covering zones, encounters, flags, gauges, and keys — the complete world system IR vocabulary
- Expanded ExplorationSystem from a 5-field skeleton to a 14-field IR node carrying all exploration configuration (tileSize, movement, gauges, keys, all callbacks)

- Added ExplorationPreset.DUNGEON_CRAWLER that sets tileSize=8, GRID movement, and a default torch gauge as a baseline
- Added zone() and flags() DSL entry points to GameBuilder wired to GameIR.zones and GameIR.flags

## Decisions Made

- WorldIR types in a single WorldIR.kt file (not split into FlagsIR.kt per RESEARCH.md suggestion) — all world-related data types in one location keeps imports simple for codegen consumers
- ExplorationPreset enum placed in SystemBuilders.kt (not WorldBuilders.kt) — preset is ExplorationBuilder configuration, mirrors SoundPreset placement in same file
- recordStatements() as internal top-level function in WorldBuilders.kt — accessible from both WorldBuilders and SystemBuilders without cross-package dependency since they share the dsl package
