## Decisions Made

- `AudioMixerBuilder` uses `GenericSystem` with `type="audio_mixer"` config — no new sealed type needed
- `ChannelGroupDef` in `gbkt-lang` (not `gbkt-ir`) — DSL-specific, accessed transitively from backend
- Default groups only added when config["groups"] absent — single `group()` call disables all defaults
- `audio_mixer_duck()` is a no-op (not omitted) when `autoDucking=false` — consistent API surface
- NR50/NR51 writes use typed `CBinaryExpr` AST nodes, never `CRawCode` — per project convention
