Tile-index map (LOCK these constants in this plan; SportVisitor in Plan 05 reads them):
- 0 = wall (outside polygon)
- 1 = drivable (inside polygon AND near boundary)
- 2 = grass (inside polygon AND far from boundary)

Algorithm steps (RESEARCH.md "Polygon → Tilemap Rasterization", with Pitfall 5 fixes):
1. Validate input: require waypoints.size >= 3; require not all collinear; require not all coincident; require waypoints.size <= 16 (RESEARCH A5 — keep edge table on stack).
2. Build a Boolean[mapHeight][mapWidth] inside[][] using scan-line polygon fill.
   - For each row y in 0 until mapHeight:
     a. Find all edges where ymin <= y < ymax (HALF-open interval — Pitfall 5 fix #1).
     b. Skip horizontal edges (where ymin == ymax) — Pitfall 5 fix #2.
     c. For each non-horizontal edge, compute x-intersection at y using integer math: x = x0 + (x1 - x0) * (y - y0) / (y1 - y0). Add to a sorted list.
     d. Even-odd rule: sort intersections, fill between pairs. inside[y][x] = true for x in [x_2k, x_2k+1).
3. Build a distance-from-boundary array distFromEdge[mapHeight][mapWidth]: for each (x, y) inside the polygon, compute the minimum distance (in tile units) to any polygon edge. Use a simple O(N*M*E) approach for v1 (16 edges × 32 × 32 cells = 16K ops; fine at compile-time).
4. Compose tileData[y * mapWidth + x]:
   - if !inside[y][x] → 0 (wall)
   - else if distFromEdge[y][x] < corridorWidth.toFloat() / 2 → 1 (drivable)
   - else → 2 (grass)
5. Force perimeter to walls (D-17): for x in 0 until mapWidth: tileData[0 * mapWidth + x] = 0 AND tileData[(mapHeight-1) * mapWidth + x] = 0; for y in 0 until mapHeight: tileData[y * mapWidth + 0] = 0 AND tileData[y * mapWidth + (mapWidth-1)] = 0.
6. Return SynthesizedTrack(tileData = tileData.toList(), collisionData = List(mapWidth * mapHeight) { 0 })

Validation invariants enforced by tests:
- Output size exactly mapWidth * mapHeight.
- At least one drivable tile and at least one wall tile.
- Perimeter cells are walls.
- No checkerboard: for any row, no 5+ consecutive alternating 0/1 sequence.
- Degenerate input throws IllegalArgumentException.

Implement validate(waypoints, mapWidth, mapHeight):
- require(waypoints.size >= 3) { "polygon requires >= 3 waypoints, got ${waypoints.size}" }
- require(waypoints.size <= 16) { "polygon vertex count ${waypoints.size} exceeds max 16 (RESEARCH A5 stack-bound)" }
- val coincident = waypoints.toSet().size < 3; require(!coincident) { "polygon waypoints are coincident — distinct vertices required" }
- val collinear = areCollinear(waypoints); require(!collinear) { "polygon waypoints are collinear — non-degenerate area required" }
- require(mapWidth > 0 && mapHeight > 0) { "mapWidth and mapHeight must be > 0" }

Implement areCollinear(waypoints): use the cross-product test on the first three distinct vertices: take w0, w1, w2 (skip duplicates); compute cross = (w1.x - w0.x) * (w2.y - w0.y) - (w1.y - w0.y) * (w2.x - w0.x); collinear iff for ALL triples the cross product is 0. For correctness across all triples, iterate; for v1, the simpler "all points share the same x or all share the same y" test misses some cases — use the per-triple cross-product loop:
  for i in 0..waypoints.size-3:
    if cross(w[0], w[1], w[i+2]) != 0 return false
  return true

Implement scanlineFill(waypoints, mapWidth, mapHeight): Boolean[mapHeight][mapWidth].
- Build edges: list of (x0, y0, x1, y1) for each consecutive pair (waypoints[i], waypoints[(i+1) % size]).
- Skip horizontal edges where y0 == y1 (Pitfall 5 fix #2).
- For each row y in 0 until mapHeight:
  - Compute intersections: for each non-horizontal edge with min(y0,y1) <= y < max(y0,y1) (Pitfall 5 fix #1: HALF-open interval; the upper-y vertex does NOT count for that edge's y-row), compute x-intersection using integer math:
    x_intersect = x0 + (x1 - x0) * (y - y0) / (y1 - y0)
  - Sort intersections ascending.
  - Fill between pairs: for k in 0 until intersections.size step 2: for x in intersections[k] until intersections[k+1]: inside[y][x] = true.
  - If intersections.size is odd (numerical edge case), drop the last intersection.

Implement distanceFromEdges(waypoints, mapWidth, mapHeight, inside): Float[mapHeight][mapWidth] (or Int if you want to keep it tile-precise). For each (x, y) where inside[y][x] is true, compute the minimum perpendicular distance from (x + 0.5, y + 0.5) (center of cell) to any polygon edge. Use the standard point-to-segment distance formula:
  d = abs((x1-x0)*(y0-py) - (x0-px)*(y1-y0)) / sqrt((x1-x0)^2 + (y1-y0)^2)
  with the projection-onto-segment clamp.
For non-inside cells, value is irrelevant; set 0 or Float.POSITIVE_INFINITY.

Implement composeTiles(inside, distFromEdge, mapWidth, mapHeight, corridorWidth): IntArray[mapWidth * mapHeight].
- val halfCorridor = corridorWidth / 2.0  (Float)
- For each (x, y):
  val idx = y * mapWidth + x
  tileData[idx] = when {
    !inside[y][x] -> 0  // wall
    distFromEdge[y][x] < halfCorridor -> 1  // drivable
    else -> 2  // grass
  }

Implement forcePerimeterToWalls(tileData, mapWidth, mapHeight): zero out the four edges:
- for x in 0 until mapWidth: tileData[x] = 0; tileData[(mapHeight-1) * mapWidth + x] = 0
- for y in 0 until mapHeight: tileData[y * mapWidth] = 0; tileData[y * mapWidth + (mapWidth-1)] = 0

Edge cases to handle:
- A polygon vertex exactly on a row boundary: the half-open ymin <= y < ymax rule attributes the vertex to exactly one edge (the edge starting at that vertex if it goes downward, NOT the edge ending at that vertex going upward). This avoids double-counting.
- Polygon goes clockwise vs counter-clockwise: the even-odd fill rule is direction-agnostic; this is fine.
- If the cross-product collinearity test gives 0 for all triples but waypoints are NOT actually collinear (numerical edge case in degenerate inputs): the validate step will throw correctly because the polygon area is 0 and no row produces a non-empty intersections list. Defensive: if scanlineFill produces an inside[][] with zero true cells, throw IllegalArgumentException("polygon encloses zero area").
