<objective>
Fix the TRACK-NAVIGABILITY gap (VERIFICATION.md lines 240-242) with TWO minimal codegen changes:

**Change A — TrackSynthesizer guarantees waypoint-cell drivability:** After `forcePerimeterToWalls()` runs, a NEW post-pass `forceWaypointNeighborhoodsToDrivable()` overwrites every waypoint cell AND its 3x3 tile neighborhood (the cell + its 8 immediate neighbors) to TILE_DRIVABLE (value 1). The 3x3 force radius matches the AI's sample-center heuristic (sprite half-extents 4 px x 8 px ≈ 1 tile in each direction), so the AI's wall-collision-guard accepts moves into any cell within sprite-sample distance of a waypoint. The perimeter-walls invariant is preserved EXCEPT where a waypoint or its neighborhood falls on the perimeter — in which case the waypoint cell wins (otherwise the polygon vertex is unreachable, which contradicts D-17).

**Change B — SportVisitor.buildAiPoolBodyStatements adds a 3-level wall-aware heading pick:** The existing logic picks `heading = if (dx >= dy) (E or W based on px<tgtX) else (S or N based on py<tgtY)`. After Plan 16, the emitted C body samples the proposed tile at the chosen cardinal direction; if that tile is wall, it tries the perpendicular axis's cardinal direction (W ↔ E if originally N/S, N ↔ S if originally E/W); if BOTH are blocked, the emitted code probes the four cardinal directions in fixed order {0=N, 1=E, 2=S, 3=W} and picks the FIRST unblocked direction; if ALL four are blocked, the AI keeps its previous heading (stays in place — a degenerate but stable terminal state).

Why three levels and not two: the corridor erosion in TrackSynthesizer (`composeTiles` + `forcePerimeterToWalls`) does NOT guarantee a minimum-width invariant for arbitrary polygons. Concave corners and narrow tips can produce mid-corridor inside-the-polygon cells whose primary AND fallback (perpendicular) cardinal neighbors are both outside the polygon — i.e. wall-classified. A 2-level pick would freeze on those cells. The third-level scan is a fixed-cost (4-probe) escape hatch.

Why "stay put" rather than panic-pick when ALL four cardinals are blocked: this is a bounded degenerate state. Change A's 3x3 force around every waypoint means the AI cannot freeze far from a waypoint — once Change A places the AI within 1 tile of any waypoint, all four cardinal neighbors become drivable. The "stay put" terminal is therefore reachable only outside any waypoint neighborhood, and the next waypoint advance (proximity check) will reset wp_idx and pull the AI's heading toward an unblocked neighborhood.

Together, the three changes guarantee: (a) every checkpoint cell is drivable, (b) every checkpoint's immediate neighborhood is drivable (so the sprite-sample heuristic accepts the waypoint cell), (c) when the cardinal-heading pick is blocked, the AI tries an alternative — the 3-level pick is exhaustive over the 4 cardinals, so the AI either makes progress or stays put (never wall-locks).

    tileData: IntArray,
    mapWidth: Int,

/**
 * Emit a 3-level wall-aware cardinal-heading pick for an AI vehicle. Replaces the bare
 * if-else heading assignment with a probe-tile-and-fallback ladder that lets the AI
 * navigate any reachable corridor, even when both the primary AND perpendicular
 * cardinals are blocked by walls (concave corners, narrow tips).
 *
 * Levels:
 *   1. Primary — largest-axis cardinal toward target.
 *   2. Fallback — perpendicular cardinal toward target.
 *   3. Tertiary — first unblocked of {0=N, 1=E, 2=S, 3=W} (skipping primary/fallback).
 *      If none → keep current heading (stay put; bounded by Change A's 3x3 force).
 *
 * Closes Phase 07.4 round-2 TRACK-NAVIGABILITY gap (VERIFICATION.md lines 240-242).
 *
 * @param aiVehicleId Sanitized AI vehicle id (e.g. "carAi").
 * @param zoneId Racing system id (used to reference _zone_<id>_tiles).
 * @param mapWidth Map width in tiles (literal at codegen time).
 * @param mapHeight Map height in tiles.
 * @param spriteHalfW Sprite half-width in pixels (sample center offset).
 * @param spriteHalfH Sprite half-height in pixels.
 * @return One CRawCode block emitting the 3-level wall-aware heading pick.
 */
@Suppress("LongMethod")
private fun buildAiHeadingPickWithFallback(
    aiVehicleId: String,
    zoneId: String,
    mapWidth: Int,
    mapHeight: Int,
    spriteHalfW: Int,
    spriteHalfH: Int,
): CStatement {
    val maxX = mapWidth * 8 - spriteHalfW * 2
    val maxY = mapHeight * 8 - spriteHalfH * 2
    val text = """{
    UINT8 ai_primary, ai_fallback;
    if (dx_${aiVehicleId} >= dy_${aiVehicleId}) {
        ai_primary = (_pool_${aiVehicleId}_x[i_${aiVehicleId}] < tgt_x_${aiVehicleId}) ? 1u : 3u;
        ai_fallback = (_pool_${aiVehicleId}_y[i_${aiVehicleId}] < tgt_y_${aiVehicleId}) ? 2u : 0u;
    } else {
        ai_primary = (_pool_${aiVehicleId}_y[i_${aiVehicleId}] < tgt_y_${aiVehicleId}) ? 2u : 0u;
        ai_fallback = (_pool_${aiVehicleId}_x[i_${aiVehicleId}] < tgt_x_${aiVehicleId}) ? 1u : 3u;
    }
    UINT8 ai_delta_probe = _pool_${aiVehicleId}_speed_cur[i_${aiVehicleId}] >> 5;
    if (ai_delta_probe == 0u) ai_delta_probe = 1u;

    /* probe(dir): returns 1u if the proposed-tile sample at heading `dir` is wall, else 0u. */
    UINT8 cd;
    UINT8 blocked[4];
    for (cd = 0u; cd < 4u; cd++) {
        INT8 pvx = 0;
        INT8 pvy = 0;
        switch (cd) {
            case 0u: pvy = -(INT8)ai_delta_probe; break;
            case 1u: pvx = (INT8)ai_delta_probe; break;
            case 2u: pvy = (INT8)ai_delta_probe; break;
            case 3u: pvx = -(INT8)ai_delta_probe; break;
        }
        INT16 pXs = (INT16)_pool_${aiVehicleId}_x[i_${aiVehicleId}] + (INT16)pvx;
        INT16 pYs = (INT16)_pool_${aiVehicleId}_y[i_${aiVehicleId}] + (INT16)pvy;
        UINT8 b = 1u;  /* default: blocked (out of bounds counts as blocked) */
        if (pXs >= 0 && pXs < ${maxX} && pYs >= 0 && pYs < ${maxY}) {
            UINT8 sX = (UINT8)pXs + ${spriteHalfW}u;
            UINT8 sY = (UINT8)pYs + ${spriteHalfH}u;
            UINT8 tCol = sX >> 3;
            UINT8 tRow = sY >> 3;
            if (tCol < ${mapWidth}u && tRow < ${mapHeight}u) {
                UINT8 t = _zone_${zoneId}_tiles[tRow * ${mapWidth}u + tCol];
                if (t != 0u) b = 0u;
            }
        }
        blocked[cd] = b;
    }

    UINT8 primary_blocked = blocked[ai_primary];
    UINT8 fallback_blocked = blocked[ai_fallback];
    UINT8 both_blocked = (primary_blocked && fallback_blocked) ? 1u : 0u;

    if (!primary_blocked) {
        _pool_${aiVehicleId}_heading[i_${aiVehicleId}] = ai_primary;
    } else if (!fallback_blocked) {
        _pool_${aiVehicleId}_heading[i_${aiVehicleId}] = ai_fallback;
    } else {
        /* Both primary and fallback blocked — scan {0,1,2,3} in order, skip primary/fallback,
         * pick first unblocked. If none → keep current heading (stay put). Stable degenerate
         * state bounded by Change A's 3x3 waypoint force radius. */
        UINT8 ai_tertiary = 0xFFu;
        for (cd = 0u; cd < 4u; cd++) {
            if (cd == ai_primary || cd == ai_fallback) continue;
            if (!blocked[cd]) { ai_tertiary = cd; break; }
        }
        if (ai_tertiary != 0xFFu) {
            _pool_${aiVehicleId}_heading[i_${aiVehicleId}] = ai_tertiary;
        }
        /* else: leave _pool_<id>_heading[i] unchanged (stay put). `both_blocked` remains
         * 1u; the wall-collision-guard in the write-back rejects whatever cardinal move
         * is produced from the unchanged heading. */
        (void)both_blocked;  /* sentinel reference so optimizer keeps the variable */
    }
}"""
    return CRawCode(text)
}
