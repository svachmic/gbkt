Pattern: when a single fix unblocks a deeper bug, the next plan must diagnose with experimental evidence, not guess. CLAUDE.md visual-evidence rule + the "quality over shortcuts" project rule both forbid a speculative second fix.

**What this plan ships:**
1. H-1 SHOW_BKG line re-introduced in `GBDKPipelineV2.kt` (one atomic commit).
2. Four hypothesis experiments H-A..H-D on throwaway branches; each yields one WRAM snapshot + one MCP screenshot.
3. DIAGNOSIS.md naming the confirmed root cause with Plan 28's RED test contract.

**Out of scope (deferred to Plan 28):** the production fix for the confirmed hypothesis. This plan ONLY confirms which hypothesis is right.
