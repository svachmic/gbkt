GBDK 2bpp interleaved tile encoding (background tiles, used by `set_bkg_data`):

Each 8x8 tile is 16 bytes = 8 row pairs. For row r (0..7), byte[2r] holds the LOW bit of each of the 8 pixels in that row, byte[2r+1] holds the HIGH bit. Combined per pixel: (high_bit << 1) | low_bit gives the 2bpp palette index in 0..3. Under default DMG BGP=0xE4: 00→white, 01→light gray, 10→dark gray, 11→black.

Concrete examples:
- Pixel matrix all-0 (white) → row bytes (0x00, 0x00) × 8 → 16 bytes of 0x00.
- Pixel matrix all-3 (black) → row bytes (0xFF, 0xFF) × 8 → 16 bytes of 0xFF.
- Pixel matrix all-1 (light gray) → row bytes (0xFF, 0x00) × 8.
- Pixel matrix all-2 (dark gray) → row bytes (0x00, 0xFF) × 8.
- Pixel matrix checkerboard {2, 0, 2, 0, 2, 0, 2, 0; 0, 2, 0, 2, 0, 2, 0, 2; ...}:
  - Row 0 has high-bit pattern 1, 0, 1, 0, 1, 0, 1, 0 (= 0xAA), low-bit pattern 0, 0, 0, 0, 0, 0, 0, 0 (= 0x00). Row bytes (0x00, 0xAA).
  - Row 1 has high-bit pattern 0, 1, 0, 1, 0, 1, 0, 1 (= 0x55), low-bit 0. Row bytes (0x00, 0x55).
  - Total: (0x00, 0xAA, 0x00, 0x55, 0x00, 0xAA, 0x00, 0x55, 0x00, 0xAA, 0x00, 0x55, 0x00, 0xAA, 0x00, 0x55).

The tilePatternToBytes helper:
```kotlin
/**
 * Convert an 8x8 palette-index matrix to GBDK 2bpp interleaved bytes (16 bytes total).
 * Each pixel must be in 0..3. The output is suitable for `set_bkg_data`.
 *
 * Encoding (per Game Boy programming reference): for row r, byte[2r] holds the low bit
 * of pixel (col, r) for col in 0..7; byte[2r+1] holds the high bit. Pixel at (col, r)
 * occupies bit (7-col) of each byte.
 */
internal fun tilePatternToBytes(matrix: List<List<Int>>): List<Int> {
    require(matrix.size == 8) { "tile matrix must have 8 rows; got ${matrix.size}" }
    require(matrix.all { it.size == 8 }) { "tile matrix rows must each have 8 columns" }
    require(matrix.all { row -> row.all { it in 0..3 } }) { "palette indices must be in 0..3" }
    val out = mutableListOf<Int>()
    for (row in matrix) {
        var lowByte = 0
        var highByte = 0
        for (col in 0..7) {
            val px = row[col]
            val bitPos = 7 - col
            if (px and 1 != 0) lowByte = lowByte or (1 shl bitPos)
            if (px and 2 != 0) highByte = highByte or (1 shl bitPos)
        }
        out += lowByte
        out += highByte
    }
    return out
}
```

The brightness-signature for the contrast test:
```kotlin
private fun brightnessSignature(tileBytes: List<Int>): Int {
    require(tileBytes.size == 16)
    var sum = 0
    for (r in 0..7) {
        val low = tileBytes[2 * r]
        val high = tileBytes[2 * r + 1]
        for (c in 0..7) {
            val bit = 7 - c
            val px = (((high shr bit) and 1) shl 1) or ((low shr bit) and 1)
            sum += px
        }
    }
    return sum
}

 * Each pixel must be in 0..3. The output is suitable for `set_bkg_data`.
 *
 * Encoding (Game Boy programming reference):
 *   - For row r in 0..7: byte[2r] holds the LOW bit of each pixel in that row;
 *     byte[2r+1] holds the HIGH bit.
 *   - Pixel at (col, row) occupies bit (7-col) of each byte (MSB = leftmost pixel).
 *   - Combined: palette = (high_bit << 1) | low_bit.
 *

 * pixel matrices instead of hand-tuned byte literals — Phase 07.4-17 closes the
 * TILESET-VISUAL-CONTRAST gap.
 *
 * @param matrix An 8x8 list of lists; each cell is a palette index in 0..3.
 * @return 16 bytes (List<Int>) in GBDK 2bpp interleaved order.
 * @throws IllegalArgumentException if matrix is not 8x8 or any cell is out of 0..3.
 */
private fun tilePatternToBytes(matrix: List<List<Int>>): List<Int> {
    require(matrix.size == 8) { "tile matrix must have 8 rows; got ${matrix.size}" }
    require(matrix.all { it.size == 8 }) { "tile matrix rows must each have 8 columns" }
    require(matrix.all { row -> row.all { it in 0..3 } }) {
        "palette indices must be in 0..3"
    }
    val out = mutableListOf<Int>()
    for (row in matrix) {
        var lowByte = 0
        var highByte = 0
        for (col in 0..7) {
            val px = row[col]
            val bitPos = 7 - col
            if (px and 1 != 0) lowByte = lowByte or (1 shl bitPos)
            if (px and 2 != 0) highByte = highByte or (1 shl bitPos)
        }
        out += lowByte
        out += highByte
    }
    return out
}
```

        val matrix = mutableListOf<List<Int>>()
        for (r in 0..7) {

            val high = bytes[2 * r + 1]
            val row = mutableListOf<Int>()
