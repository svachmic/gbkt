## Accomplishments

- Fixed the root cause of the GAP-RACE-BLANK-AFTER-START hang: `SWITCH_ROM(2)` inside BANKED `race_enter` (bank1.c, 0x4000+) caused MBC to remap 0x4000-0x7FFF to bank 2, so subsequent CPU instruction fetches executed bank 2 tilemap data as code, writing 0x39 to LCDC

## Decisions Made

- **Root cause is SWITCH_ROM in BANKED code, not just display_off()**: LCDC=0x39 (not 0x41) proves the write came from garbage execution of bank 2 tilemap bytes, not from `display_off()` which would yield 0x41. DIAGNOSIS.md's fix was partially correct (DISPLAY_ON needed) but insufficient alone.
- **HOME-bank helper is the primary fix**: Any SWITCH_ROM call must execute from HOME bank (0x0000-0x3FFF) which is never remapped by MBC. BANKED code at 0x4000+ cannot safely call SWITCH_ROM inline.
- **hasSportRacing guard prevents non-racing genre regressions**: `bankAllocation.values.any { it > 1 }` alone fires for dungeon/explorer games with bank-2 zones, breaking ZoneTilemapBankingTest. Guard added: emit helper only when `GenericSystem(config["type"] == "sport_racing")` is present.
