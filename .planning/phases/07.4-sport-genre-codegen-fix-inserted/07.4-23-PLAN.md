Extract `race_enter` body via awk brace-walk and grep within scope:

       ```bash
       # Extract race_enter body to a temp file (brace-aware extraction):
       awk '
         /void race_enter\(/ { in_func = 1 }
         in_func {
           for (i = 1; i <= length($0); i++) {
             c = substr($0, i, 1)
             if (c == "{") { depth++; if (depth == 1) { printing = 1; continue } }
             if (c == "}") { depth--; if (depth == 0) { in_func = 0; printing = 0; print ""; exit } }
           }
           if (printing) print $0
         }
       ' gbkt-examples/racer/build/gbkt/generated/bank1.c > /tmp/race_enter_body.c

       # Now grep WITHIN race_enter only:
       RACE_CLS=$(grep -c "cls()" /tmp/race_enter_body.c || true)
       RACE_GOTOXY=$(grep -c "gotoxy(" /tmp/race_enter_body.c || true)
       RACE_PRINTF=$(grep -c "printf(" /tmp/race_enter_body.c || true)
       RACE_WIN_PRINT=$(grep -c "_win_print_at(" /tmp/race_enter_body.c || true)
       RACE_WIN_CLEAR=$(grep -c "_win_clear_region(" /tmp/race_enter_body.c || true)
       RACE_HIDE=$(grep -c "HIDE_SPRITES" /tmp/race_enter_body.c || true)

       echo "race_enter scope: cls=$RACE_CLS gotoxy=$RACE_GOTOXY printf=$RACE_PRINTF win_print_at=$RACE_WIN_PRINT win_clear=$RACE_WIN_CLEAR hide_sprites=$RACE_HIDE"

       # Required (post-fix):
       # cls=0, gotoxy=0, printf=0, win_print_at>=1, win_clear>=1, hide_sprites>=1
       test "$RACE_CLS" = "0" || { echo "FAIL: race_enter still contains cls()"; exit 1; }
       test "$RACE_GOTOXY" = "0" || { echo "FAIL: race_enter still contains gotoxy("; exit 1; }
       test "$RACE_PRINTF" = "0" || { echo "FAIL: race_enter still contains printf("; exit 1; }
       test "$RACE_WIN_PRINT" -ge 1 || { echo "FAIL: race_enter missing _win_print_at"; exit 1; }
       test "$RACE_WIN_CLEAR" -ge 1 || { echo "FAIL: race_enter missing _win_clear_region"; exit 1; }
       test "$RACE_HIDE" -ge 1 || { echo "FAIL: race_enter missing HIDE_SPRITES"; exit 1; }
       echo "race_enter scope check PASSED"
       ```

       **Independent of title_enter:** title_enter (back-compat) is allowed to contain cls() / gotoxy / printf — the scope-level grep above guarantees those don't bleed into race_enter and never asserts at the file level.
