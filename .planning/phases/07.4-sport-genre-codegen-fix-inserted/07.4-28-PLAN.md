- **H-H: Stack overflow into HRAM.** Read SP via `readByte(0xFFFE)` / `readByte(0xFFFF-1)` (HRAM top region) at race_enter+1. If SP has wrapped below the C runtime's safe minimum, stack overflow → corrupt return address → infinite loop.
