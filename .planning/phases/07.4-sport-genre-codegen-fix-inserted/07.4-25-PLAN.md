<objective>
Capture authoritative round-5 evidence of `GAP-RACE-BLANK-AFTER-START`: rebuild the racer ROM at HEAD, run an MCP play-through that documents the blank-screen symptom with PNG screenshots, capture a variable trace at three timestamps, extract the relevant generated-C function bodies via awk brace-walk, compute a pixel-signature probe to confirm visual blankness from PNG bytes alone, and write a `DIAGNOSIS.md` evidence note that proposes a ranked list of root-cause hypotheses for Plan 07.4-26 to act on.

**This plan does NOT attempt a fix.** Diagnosis is the deliverable. The fix lives in Plan 07.4-26 (Wave 2, depends_on: [07.4-25]).

**Why diagnose-first as its own plan:** The verification methodology bug that took 5 plans (Plans 15-18) to surface was caused by jumping to fixes before runtime evidence was captured. Plans 19-22 closed codegen-tier preconditions; Plan 23's codegen GREEN verdict was visually REJECTED because no one had captured runtime evidence that the codegen-tier fix actually produced a visible BG. Making the diagnosis its own committed plan ensures the evidence note lands in `evidence/round-5-gap-race-blank-after-start/` as a committed artifact before any fix is attempted — so a future round can re-read it independently of the fix's correctness.

**Strong root-cause leads (planner-supplied, NOT prescriptive — the executor MUST capture evidence and let the evidence speak):**

**Anti-anchoring requirement for DIAGNOSIS.md (binding):** The five leads below are useful starting points but are EXPLICITLY NOT the closed set of hypotheses. DIAGNOSIS.md (Task 5) MUST:
1. Rerank hypotheses purely from the captured evidence (variable trace, scope-extracted C bodies, pixel-signature probe) — NOT from the order or rhetorical weight of the planner's list.
2. Include at least ONE hypothesis NOT enumerated below (e.g. OAM/sprite-table issue, scene-machine race, GBC LCDC.BG mapping difference, bank-1 BANKED call from main, frame-buffer write-window timing, ...). Even if that hypothesis is ranked last, its presence proves the executor considered the search space outside the planner's steer.
3. Explicitly call out any planner-listed lead the evidence rules OUT (e.g. "H-3 cross-bank: REFUTED — 09-scope-grep-counts.txt shows SWITCH_ROM count is 1 in race_enter scope; Plan 22 guard is intact").

The pixel-signature probe (Task 4) is the structural backstop: if the post-Task-3 race-entry screenshot has `unique_pixels >= 4`, hypothesis H-1 is automatically refuted before DIAGNOSIS.md ranking begins.

1. **Missing `SHOW_BKG` in main() init or scene-enter.** Pre-plan grep of `main.c` and `bank1.c` at HEAD shows DISPLAY_ON + SHOW_SPRITES but NO `SHOW_BKG` anywhere in the codegen. GBDK's `DISPLAY_ON` enables the LCD but does NOT enable the LCDC.BG bit. Pong/Breakout/Explorer ROMs don't render BG so this omission has been latent. Racer renders BG via `set_bkg_tiles` — but if LCDC.BG=0, the tilemap is never composited.

2. **Camera clamp expression evaluates to constant 0.** Generated `update_camera_camera` at HEAD reads:
   ```c
   _camera_x = (UINT8)(rawX < 0u) ? 0u : (rawX > 0u) ? 0u : rawX;
   ```
   `kotlin.math.max(0, boundsWidth - 160)` returns 0 when track is 19*8=152px wide. Both branches of the ternary force 0 — `_camera_x` is permanently 0. The ternary precedence with the outer `(UINT8)` cast may also produce unexpected truncation. Camera locked at (0,0) does not directly explain blank BG (the BG should still composite at SCX/SCY=0) but it may interact with other issues.

3. **Cross-bank tilemap data not paged in correctly.** Plan 22 added `SWITCH_ROM(2)` before `set_bkg_tiles(_zone_track1_tiles, ...)` in race_enter. Confirm the SWITCH_ROM happens BEFORE the const-data read at runtime. If `_zone_track1_tiles` lives in bank 2 and bank 2 is not active during the read, `set_bkg_tiles` writes garbage/zeros to VRAM.

4. **The racing genre's enter-ops splice order.** `race_enter` body (from pre-plan inspection):
   `_camera_target=0`, `set_bkg_data`, `SWITCH_ROM(2)`, `set_bkg_tiles`, `_current_tileset_id=1`, `pool_carAi_spawn`, `HIDE_SPRITES`, `_win_clear_region`, `SHOW_SPRITES`, then user state inits, then `_win_print_at`. The `HIDE_SPRITES` runs AFTER `pool_carAi_spawn`. `SHOW_SPRITES` re-enables OBJ. If anything between these two disables BG (cannot from grep alone) — the BG never re-enables.

5. **BG palette uninitialized in GBC_COMPATIBLE mode.** Racer.kt sets `target(GbcTarget.GBC_COMPATIBLE)`. If GBC palette init never runs and DMG palette defaults to all-zero (black-on-black), BG may render but be invisible. CONTEXT.md routes the full palette story to Phase 07.7, but if it overlaps with the blank-screen symptom it must be flagged in DIAGNOSIS.md.

The diagnosis note must rank these (and any others surfaced by the evidence) and recommend ONE for Plan 07.4-26 to attempt.
</objective>

    import struct, zlib, os, sys

    def png_pixels(path):
        with open(path, 'rb') as f:
            data = f.read()
        if data[:8] != b'\x89PNG\r\n\x1a\n':
            return None
        # IHDR chunk: bytes 8..29
        ihdr_len = struct.unpack('>I', data[8:12])[0]
        w, h, depth, ctype = struct.unpack('>IIBB', data[16:26])
        idx = 8
        idat = b''
        while idx < len(data):
            clen = struct.unpack('>I', data[idx:idx+4])[0]
            ctype_str = data[idx+4:idx+8]
            cdat = data[idx+8:idx+8+clen]
            if ctype_str == b'IDAT':
                idat += cdat
            idx += 8 + clen + 4
            if ctype_str == b'IEND':
                break
        if not idat:
            return (w, h, set())
        try:
            raw = zlib.decompress(idat)
        except Exception as e:
            return (w, h, set([f"DECOMPRESS_FAIL:{e}"]))
        bpp = {0: 1, 2: 3, 3: 1, 4: 2, 6: 4}.get(ctype, 4)
        stride = w * bpp + 1  # +1 filter byte per row
        seen = set()
        for y in range(h):
            off = y * stride + 1
            for x in range(w):
                pix = bytes(raw[off + x*bpp: off + x*bpp + bpp])
                seen.add(pix)
        return (w, h, seen)

    for name in ['01-title-pre-start.png', '02-race-entry-frame30.png', '03-race-after-hold-up-60f.png']:

            continue
        result = png_pixels(name)
        if result is None:

            continue
        w, h, seen = result
        verdict = ""
        if len(seen) == 1:
            verdict = "  # UNIFORM — visually blank"
        elif len(seen) <= 3:
            verdict = "  # nearly uniform — possibly BG-off with HUD only"
        else:
