# Phase 07.4 Plan 16: TRACK-NAVIGABILITY closure (Wave 13)

**One-liner:** TrackSynthesizer forces every waypoint's 3x3 tile neighborhood drivable; SportVisitor emits a 4-tier wall-aware AI heading pick (primary -> prev-perpendicular-commit -> perpendicular fallback -> tertiary scan -> stay put). All 9 RacingTrackNavigabilityTest tests now GREEN.

## What was built

### Change A — TrackSynthesizer waypoint-force post-pass

`TrackSynthesizer.synthesize()` now runs a new private helper
`forceWaypointNeighborhoodsToDrivable(tileData, mapWidth, mapHeight, waypoints)` AFTER
`forcePerimeterToWalls()`. The helper iterates `(dx, dy) in -1..1` for each waypoint
and writes `TILE_DRIVABLE` (= 1) to `tileData[ny * mapWidth + nx]`. A bounds check
silently skips out-of-map cells. The radius is pinned at a private file-level constant
`WAYPOINT_FORCE_RADIUS = 1`.

The pass intentionally runs AFTER perimeter-forcing so a waypoint or its neighborhood
on the perimeter wins (D-17 — the polygon vertex must be reachable, otherwise lap
completion is impossible). For interior waypoints (the typical case), the pass is a
no-op on already-drivable cells.

### Change B — SportVisitor 4-tier AI heading pick

`SportVisitor.buildAiPoolBodyStatements` now delegates the cardinal-heading pick to a
new private helper `buildAiHeadingPickWithFallback(...)` that emits one CRawCode block.
The emitted C is a self-contained `{ ... }` block that:

1. Computes `ai_primary` (largest-axis cardinal toward target) and `ai_fallback`
   (perpendicular cardinal toward target) — same shape as the previous if-else, but
   captured in two locals.
2. Computes `ai_delta_probe = speed_cur >> 5`, coerced to at least 1u so a stationary
   AI can still sample a neighbor cell.
3. Probes all four cardinal directions in a `for cd in 0..3` loop, sampling
   `_zone_<id>_tiles[tRow * mapWidth + tCol]` at the proposed sample center
   (mirrors Plan 12's wall-collision-guard literal shape) and storing the
   blocked/unblocked bit in `blocked[4]`.
4. Reads the previous heading: `ai_prev_heading = _pool_<id>_heading[i_<id>]`.
   Computes `ai_prev_is_perp = ((ai_prev_heading & 1u) != (ai_primary & 1u))`
   (perpendicular axis = differing bit-0).
5. Picks heading by 4-tier priority:
   - Tier 1: `!primary_blocked` → `ai_primary`.
   - Tier 2: `ai_prev_is_perp && !blocked[ai_prev_heading]` → `ai_prev_heading`
     (prev-perpendicular-commit — anti-oscillation).
   - Tier 3: `!fallback_blocked` → `ai_fallback`.
   - Tier 4: tertiary scan `for cd in 0..3` skipping primary/fallback, pick first
     unblocked → `ai_tertiary`.
   - Tier 5 (degenerate): keep prev heading (stay put). Bounded by Change A's 3x3
     force radius around every waypoint.

The helper uses `TILE_SIZE_PIXELS` and the shared `DEFAULT_VEHICLE_SPRITE_*` /
`DEFAULT_RACING_MAP_TILES` constants (already pinned by Plan 12) for
codegen-time literals — no magic numbers introduced (D-04 / D-02).

### Test-side change — simulateAi mirror

`RacingTrackNavigabilityTest.simulateAi()` was updated so the pure-Kotlin simulation
mirrors the new 4-tier emitted C exactly. Added `prevHeading` carry-forward (initial
0=N to match the C-side zero-initialized UINT8 array) and the same axis-bit
perpendicular check `(prevHeading and 1) != (primary and 1)`. The `probeBlocked`
nested helper produces the same blocked/unblocked classification as the inlined C
probe loop.

The plan explicitly listed this test file in `files_modified` — the test contract
flips from RED to GREEN by virtue of (a) the production-side fix and (b) the
simulation faithfully reproducing the emitted C semantics.

## Deviations from Plan

### [Rule 3 - Blocking] Added `prev-perpendicular-commit` tier between primary and fallback

- **Found during:** Task 2 (running RacingTrackNavigabilityTest after the bare 3-level pick landed)
- **Issue:** The plan's intended 3-level pick (primary -> fallback -> tertiary scan + stay put) produced a degenerate oscillation in the racer fixture:
  - At `(120, 44)` targeting waypoint 2 `(120, 120)`: primary=S blocked (col 15 row 7+ is wall), fallback=W unblocked (force-area at row 6 col 15) -> heading=W.
  - At `(116, 44)` next frame: primary=S still blocked, fallback now=E (since `px<tgtX`) and unblocked -> heading=E.
  - Result: AI oscillates between `(116, 44)` and `(120, 44)` for the entire 1500-frame budget without making southward progress, even though the col-14 interior corridor is reachable (sample col=14 needs `px<=115`).
  - Tertiary scan never triggers because fallback is always unblocked on alternating frames.
- **Fix:** Added a 4th tier (`Tier 2 — prev-perpendicular-commit`) between primary and fallback. When primary is blocked AND the previous heading is perpendicular to primary AND still unblocked, take the previous heading. This commits to the perpendicular escape direction across multiple frames, letting the AI traverse narrow corridors that need >1 lateral step before primary unblocks.
- **Files modified:** `gbkt-genre-sport/src/main/kotlin/io/github/gbkt/genre/sport/codegen/SportVisitor.kt`, `gbkt-genre-sport/src/test/kotlin/io/github/gbkt/genre/sport/codegen/RacingTrackNavigabilityTest.kt` (simulation mirror)
- **Commit:** `d8435f8f`
- **Why this is the right fix:** Pure cardinal-only AI without per-AI memory cannot handle this geometry (the corridor entrance requires moving AWAY from target perpendicular axis, then committing for multiple frames). The prev heading (already stored in `_pool_<id>_heading[i]` from the previous frame) is free state — using it preserves the codegen's no-extra-IR-ops constraint (D-01) and keeps the AI body's bank footprint within budget.

### [Rule 1 - Bug] Initial axis-perpendicular check used wrong bit

- **Found during:** Task 2 (first run with prev-perp-commit logic still failed the AI simulation tests)
- **Issue:** I initially encoded "perpendicular axis" as differing bit-1 (`(heading & 2)` mask). With heading IDs `N=0, E=1, S=2, W=3`, bit-1 is the same for `{N=0, E=1}` (both 0) and for `{S=2, W=3}` (both 1) — so the check is wrong. The correct axis bit is bit-0 (`heading & 1`): N=0, S=2 are even (vertical); E=1, W=3 are odd (horizontal).
- **Fix:** Changed the C emission and the simulation mirror to use `(prev_heading & 1) != (primary & 1)`.
- **Files modified:** same as above
- **Commit:** included in `d8435f8f`
