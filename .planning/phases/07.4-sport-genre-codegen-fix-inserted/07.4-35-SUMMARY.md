## Lessons & Follow-ups

- **Empirically-calibrated test sequences are bug-state-dependent.** `RacingPlayerTraversabilityTest` Tests 2 & 3 sequence parameters were calibrated against the buggy arena, where row 4 was wall and the player blocked at py=29 after UP×20. With the corrected corridor (row 4 drivable), the player descends to py=17 and overshoots CP-0. **Generalization:** when a downstream test depends on the observable shape of an upstream codegen output, recalibration of the test data is part of the production fix — flag this in the plan's `must_haves` rather than discovering it as a regression after the fact.
- **Three-tier verification pattern works.** JVM (synthesizer.synthesize direct call) + codegen (emitted const UINT8 array) + runtime (VRAM probe via emulator) — all three locked by independent test fixtures (Plan 33 + Plan 35 evidence files 14, 15, 16). This is the structural defense against the round-2 / round-4 false-positive class where a single tier's PASS masked a downstream tier's failure (see `CLAUDE.md` § Verification Methodology — Visual Evidence Rule).
- **`forceWaypointNeighborhoodsToDrivable` is now redundant but kept as safety net.** With the new corridor straddling polygon edges, every waypoint's 3×3 neighborhood is in the rasterized + thickened band by construction (waypoints are at polygon vertices, which become rasterized edge cells, which get Chebyshev-stamped). The force pass still runs AFTER `forcePerimeterToWalls` and provides safety for waypoints near the map perimeter (none of the racer waypoints are on the perimeter, so the force pass is a no-op for the current fixture, but the contract holds for arbitrary user-defined polygons).
- **No follow-ups for Plan 36.** Plan 07.4-36 (verification aggregator) can now consume the post-fix racer ROM with confidence — the track-corridor truth is closed at all three tiers, evidence captured at locked paths, and the JVM contract is regression-protected by `TrackSynthesizerCircuitShapeTest` (Plan 33's RED tests now serve as GREEN guards against future drift).
