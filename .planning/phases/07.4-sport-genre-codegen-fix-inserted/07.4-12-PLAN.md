Extend `SportVisitor.buildRacingTickBody` (the per-frame physics body emitted by Plan 07.4-05) so the position write-back to `_<actor>_x` / `_<actor>_y` is gated on a wall-collision check against the synthesized tilemap. The proposed-position tile (sampled from `_zone_<racingId>_tiles[(<y>+<sprite_h>/2)/8 * <mapWidth> + (<x>+<sprite_w>/2)/8]`) must be non-zero (i.e. drivable, tile==1, OR grass, tile==2). If the proposed tile is 0 (wall) or the proposed position is out of world bounds, the move is rejected and the actor stays put.

This is the cleaner long-term fix matching D-17 ("a lap means a real lap"). With wall-collision the player physically cannot cross the perimeter walls or the grass-island tiles' walls, so traversal must follow the corridor.

Out-of-bounds (`tileCol >= mapWidth || tileRow >= mapHeight`) is treated as "wall" (move rejected). This naturally forbids `_car_y` from underflowing into 0xFC etc. — the moment `(INT8)_car_y + vy` underflows past 0, propY becomes 0xFC (252), sampleY becomes 4 (after +8 it wraps to 0xFC+8=4 — wait, 252+8=260 which wraps to 4 in UINT8). Hmm — 252+8u where 252 is UINT8 and 8 is UINT8: arithmetic in C promotes to int but assigning back to UINT8 truncates, so the result is 260 mod 256 = 4. tileRow = 4/8 = 0. The tile at (0, sampleX>>3) is the perimeter wall (tile 0) — correctly rejected.

But there is an edge case: when propY underflows but happens to land in a corridor tile, the move would be wrongly accepted. To make the bounds check robust, use a SIGNED check first:
```c
INT16 propXs = (INT16)_car_x + vx;
INT16 propYs = (INT16)_car_y + vy;

    /* reject — out of world bounds */
} else {
    /* sample the tile and check wall */
}
```

Use INT16 to avoid the underflow edge case. After the bounds check, downcast to UINT8 for the actual sample.

This is the safer path. The executor implements it with `CIf` chains and `CRawExpr` for the INT16 promotion if no native CInt16Cast exists in the C-AST helpers.

The helper signature:

```kotlin
/**
 * Emit a collision-guarded position write-back for an actor in racing_tick. Replaces the naive
 * `_<actor>_x += vx; _<actor>_y += vy;` pair with an INT16-bounds-check + tile-sample guard
 * against the synthesized tilemap. If the proposed position is out of world bounds OR the
 * sampled tile equals 0 (wall, per Plan 07.4-04), the move is rejected.
 *
 * Closes Phase 07.4 GAP-C — the UINT8 underflow that wraps the player off-screen on sustained
 * UP held — and upholds D-17 by construction (player cannot drive across walls).
 *
 * @param actorRefX Name of the actor's X global, e.g. "_car_x" (player) or array access for AI
 * @param actorRefY Same for Y
 * @param vxName Name of the local INT8 vx variable in scope (e.g. "vx")
 * @param vyName Name of the local INT8 vy variable in scope
 * @param zoneId The racing system id (used to reference _zone_<id>_tiles)
 * @param mapWidth Map width in tiles (compile-time literal)
 * @param mapHeight Map height in tiles (compile-time literal)
 * @param spriteHalfW sprite half-width in pixels (sample center offset; e.g. 4 for 8-wide)
 * @param spriteHalfH sprite half-height in pixels
 * @return A list of CStatement wrapping the proposed-pos compute, bounds check, tile sample,
 *         and conditional write-back. Replaces what used to be the bare CBinaryExpr += pair.
 */
private fun buildPositionWriteBackWithCollision(
    actorRefX: String,
    actorRefY: String,
    vxName: String,
    vyName: String,
    zoneId: String,
    mapWidth: Int,
    mapHeight: Int,
    spriteHalfW: Int,
    spriteHalfH: Int,
): List<CStatement> {
    // Use a single CRawCode block — simpler than threading 8 nested CIf/CBinaryExpr structures.
    // The text is auditable + greppable in the emitted main.c, which is what the unit tests
    // assert against.
    val maxX = mapWidth * 8 - spriteHalfW * 2
    val maxY = mapHeight * 8 - spriteHalfH * 2
    val text = """{
    INT16 propXs = (INT16)$actorRefX + (INT16)$vxName;
    INT16 propYs = (INT16)$actorRefY + (INT16)$vyName;
    if (propXs >= 0 && propXs < ${maxX} && propYs >= 0 && propYs < ${maxY}) {
        UINT8 propX = (UINT8)propXs;
        UINT8 propY = (UINT8)propYs;
        UINT8 sampleX = propX + ${spriteHalfW}u;
        UINT8 sampleY = propY + ${spriteHalfH}u;
        UINT8 tileCol = sampleX >> 3;
        UINT8 tileRow = sampleY >> 3;
        if (tileCol < ${mapWidth}u && tileRow < ${mapHeight}u) {
            UINT8 tile = _zone_${zoneId}_tiles[tileRow * ${mapWidth}u + tileCol];
            if (tile != 0u) {
                $actorRefX = propX;
                $actorRefY = propY;
            }
        }
    }
}"""
    return listOf(CRawCode(text))
}
```

The CRawCode primitive is the same one used by the RawOp lowering (Plan 05 confirmed).     val mapW = 19
    val mapH = 19
    val tiles = IntArray(mapW * mapH).apply {
        for (y in 0 until mapH) for (x in 0 until mapW) {
            this[y * mapW + x] = when {
                y == 0 || y == mapH - 1 || x == 0 || x == mapW - 1 -> 0  // perimeter wall
                y in 8..10 && x in 8..10 -> 0  // grass-island walls (sample)
                else -> 1  // drivable
            }
        }
    }
    val spriteHalfW = 4
    val spriteHalfH = 8
    var carX = 80
    var carY = 80
    var speedCur = 0
    val accel = 160
    val speedCap = 200
    val heading = 0  // North
    repeat(60) {
        // Throttle ramp (from Plan 05 buildRacingTickBody pseudocode):
        speedCur = minOf(speedCur + (accel shr 4) + 1, speedCap)

        val propYs = carY + vy

                if (tile != 0) {

                    carY = propYs
                }
            }
        }
