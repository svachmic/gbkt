<objective>
**Lock the Defect-6 option-(c-prime) fix from Plan 12.1-11 with a JVM emission-invariant test that prevents future regressions.**

The production code change from Plan 12.1-11 rewrites the consumer-side bank reference inside `buildSetupCurrentLevelFunctionIfNeeded` from `_current_area_bank = BANK(_zone_<id>_tilemap);` (which has no SDCC linker producer for data arrays) to `_current_area_bank = <N>u;` (literal-bank shape sourced from `bankAllocation`). Without a test locking this shape, a future plan author looking at the original Plan 12-17 docstring (which references `BANK()`) might revert the fix.

This plan adds two new `@Test` methods to `LevelSwitchEmissionTest` (the natural home — it already locks the `setup_current_level` helper's column-0 signature + first-statement + switch-dispatch + per-case `_current_area_bank` substring):

1. **Test (positive — bound case):** Build a 2-gameplay-zone `GameIR` (reusing the existing `buildTilemapCollisionGameDsl()` fixture), generate via `GBDKPipelineV2`, brace-walk the `setup_current_level` body, assert: (a) the body matches `Regex("_current_area_bank = \\d+u;")` AT LEAST 2 times (one per gameplay zone case); (b) the body contains ZERO occurrences of `BANK(_zone_` (per CLAUDE.md §"Scope-level grep gates corollary", the assertion fires against the brace-walked body, not the file).
2. **Test (defensive — missing-bank fallback):** Construct a synthetic scenario where `bankAllocation` omits a zone ID (test-level hook — Plan 12.1-11 added a `?: 1` fallback). Assert the emission contains `_current_area_bank = 1u;` for the affected case AND a fallback-comment substring `/* fallback: bankAllocation missing zoneId; safe HOME-adjacent */`.

This plan also updates the stale docstring example at `GBDKPipelineV2.kt:2242` (currently shows `_current_area_bank = BANK(_zone_<id0>_tilemap);`) to reflect the new option-(c-prime) shape. The docstring update is coupled with the test (both reference the same shape contract) so reviewers see them as a single edit.

**Closes:** SPEC requirement 12.1-R1 amendment — Defect 2 resolution path = option (b) + option (c-prime), now locked by both production code (Plan 12.1-11) AND a regression-guard test (this plan).

**Output:** Modified `LevelSwitchEmissionTest.kt` with two new test methods PASSING; modified `GBDKPipelineV2.kt` docstring example.
