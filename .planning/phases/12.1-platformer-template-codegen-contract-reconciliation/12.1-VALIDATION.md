# Phase 12.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Derived from `12.1-RESEARCH.md` §Validation Architecture.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | kotlin.test + JUnit5 (Kotlin 2.3.0) |
| **Config file** | per-module `build.gradle.kts` (uses `useJUnitPlatform()`) |
| **Quick run command** | `./gradlew :gbkt-genre-platformer:test :gbkt-gradle-plugin:test :gbkt-backend-gbdk:test` |
| **Full suite command** | `./gradlew test` |
| **Estimated runtime** | Quick: ~30s · Full: ~3–5 min |

---

## Sampling Rate

- **After every task commit:** Run `./gradlew :gbkt-genre-platformer:test` (~30s)
- **After every plan wave:** Run quick command above
- **Before `/gsd:verify-work`:** Full suite must be green + `:gbkt-examples:platformer-template:buildRom` GREEN + 5-ROM regression sweep GREEN
- **Max feedback latency:** ~30 seconds for the per-task cycle
