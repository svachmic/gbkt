<objective>
**Defect 6 root-cause fix — Option (c-prime) from `12.1-VERIFICATION.md` §Recommended path.**

Rewrite `GBDKPipelineV2.buildSetupCurrentLevelFunctionIfNeeded` so each gameplay zone case branch emits `_current_area_bank = <N>u;` (literal bank number from the in-memory `bankAllocation` map) instead of `_current_area_bank = BANK(_zone_<id>_tilemap);`. This eliminates the SDCC link-time dependency on the never-synthesized `__bank__zone_<id>_tilemap` symbol while preserving Plan 12.1-01's `#pragma bank N` emission (which still routes the data to bank N correctly).

**Why this works:** SDCC's `#pragma bank N` directive places file contents into `_CODE_N` but does NOT auto-synthesize a `__bank_<sym>` symbol for data arrays (only for banked function definitions — verified by manual `lcc -c -Wa-l` in `12.1-VERIFICATION.md` §"Evidence — SDCC does not synthesize __bank_<sym> for data arrays"). The bank number is already known at codegen time via `allocateZoneBanks(gameIR)` (called at `GBDKPipelineV2.kt:536` inside `generate()`). Substituting the literal at the consumer site mirrors the working pattern in `gbkt-examples/banks/build/gbkt/generated/bank1.c:23` (`_bkg_tiles_load_banked(2u, ...)`) and threads the bank assignment through a single source of truth.

**Closes:** SPEC requirement 12.1-R1 amendment (Defect 2 resolution path = option (b) `#pragma bank N` + option (c-prime) literal-bank consumer-side substitution).

**Output:** Modified `GBDKPipelineV2.kt` with rewritten function signature + per-case body emission. Plan 12.1-12 will lock the new emission shape with a JVM emission-invariant test; Plan 12.1-13 will run the 6-ROM regression sweep; Plan 12.1-14 closes the terminal smoke + flips `12.1-VERIFICATION.md` to `passed`.
