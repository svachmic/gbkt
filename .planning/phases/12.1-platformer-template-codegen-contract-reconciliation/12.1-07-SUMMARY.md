### Why the new test still landed (decision rationale)

1. **Plan 12.1-07 frontmatter explicitly mandates the new file path:** `must_haves.artifacts[0].path = "...TilemapPhysicsPlayerSymbolEmissionTest.kt"`. Skipping the file would violate the plan's literal output contract.
2. **Single-page contract review:** the new file consolidates the visitor-read (Tests 1+2) and the builder-write (Test 3) under one file. The 12.1-06 file covers the read; the 12.1-05 file covers the write; neither covers both. A reviewer auditing Defect 4 closure now reads one file instead of two.
3. **Scope-level grep gate uniformity:** all three tests use the `extractFunctionBody` brace-walk helper inline per RESEARCH §D-claude-5. The plan locks the convention; this file is the canonical example for future Defect-N-class tests.
4. **Independent regression surface:** if `Defect4SymbolRewriteEmissionTest.kt` is ever deleted (e.g. as cleanup after the test convention drifts), the contract still holds in `TilemapPhysicsPlayerSymbolEmissionTest.kt`. Redundancy at the test-lock layer is cheap insurance.

A pure-deduplication alternative — deleting 12.1-06's test or merging both into one file — was considered and rejected: the orchestrator constraint forbids modifying STATE.md/ROADMAP.md and the plan does not authorize deletion of prior-plan artifacts.
