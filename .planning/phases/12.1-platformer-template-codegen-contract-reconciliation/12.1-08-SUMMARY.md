## Contract Locked

### Test 1 (BOUND)
- **Input:** `MetaspriteIR(id="player", posXVarName="playerX", posYVarName="playerY", ...)` — BARE Kotlin property names (no leading underscore), matching the IR-level convention captured by `AssignableVar.name`.
- **Caller transformation (mirrors `ScriptOpVisitor.visitMoveMetasprite:1917-1923`):**
  ```kotlin
  val posXVar = boundMetasprite.posXVarName?.let { "_$it" } ?: "_posX"  // → "_playerX"
  val posYVar = boundMetasprite.posYVarName?.let { "_$it" } ?: "_posY"  // → "_playerY"
  ```
- **Assertions:**
  - `result.code.contains("(_playerX >> 4)")` (positive)
  - `result.code.contains("(_playerY >> 4)")` (positive)
  - `!result.code.contains("(_posX >> 4)")` (negative — must NOT fall back to magic)
  - `!result.code.contains("(_posY >> 4)")` (negative)

### Test 2 (UNBOUND)
- **Input:** `MetaspriteIR(id="ghost", posXVarName=null, posYVarName=null, ...)`.
- **Caller transformation (mirrors Elvis fallback):**
  ```kotlin
  val posXVar = unboundMetasprite.posXVarName?.let { "_$it" } ?: "_posX"  // → "_posX"
  val posYVar = unboundMetasprite.posYVarName?.let { "_$it" } ?: "_posY"  // → "_posY"
  ```
- **Assertions:**
  - `result.code.contains("(_posX >> 4)")` (positive — magic fallback preserved)
  - `result.code.contains("(_posY >> 4)")` (positive)

2. **The `gbkt-examples/metasprites` shipping ROM's reliance on `_posX/_posY` magic fallback is structurally protected by Test 2.** Test 2 explicitly asserts that when `posXVarName = null` and the Elvis fallback resolves to `"_posX"`, the visitor emits `(_posX >> 4)` / `(_posY >> 4)` — the exact emission shape the existing `gbkt-examples/metasprites` ROM depends on (user-DSL `var posX by i16Var(...)` happens to produce a `_posX` global by name coincidence; see RESEARCH §"existing-example regression sensitivity" row `metasprites`).

3. **`gbkt-examples/metasprites-stress` (which already exercises the bound path) is indirectly protected by Test 1** — and is hereby flagged as a candidate for the regression sweep in Plan 12.1-09. Any future change to the prefix-transformation convention that breaks the `_playerX` emission would simultaneously break the `metasprites-stress` ROM at the integration level; Test 1 catches it at the JVM-tier so the failure surfaces before a ROM build is attempted.

4. **Both tests explicitly mirror the production `ScriptOpVisitor.visitMoveMetasprite:1917-1923` prefix transformation (closing checker B1).** Each test method computes the C-symbol name in-test via `boundMetasprite.posXVarName?.let { "_$it" } ?: "_posX"` (and symmetric for posY), rather than hardcoding `posXVar = "_playerX"`. A regression in the IR-field underscore-handling convention (e.g. if `MetaspriteIR.posXVarName` were ever changed to store the prefixed name, or if the Elvis fallback string were ever changed from `"_posX"` to `"_pos_x"`) would now fail one of these tests at the JVM tier.
