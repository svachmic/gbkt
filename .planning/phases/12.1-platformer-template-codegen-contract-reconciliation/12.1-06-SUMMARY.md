# Phase 12.1 Plan 06: Defect 4 — PlatformerVisitor symbol rewrite — Summary

Rewrites `PlatformerVisitor.buildTilemapPhysicsUpdateFunction` (and its three private helpers `buildHorizontalProbe`, `buildVerticalFootProbe`, `buildVerticalHeadProbe`) to emit user-DSL property names (`_playerX`, `_playerY`, `_playerVx`, `_playerVy`, `_grounded`) instead of the hardcoded legacy (`_player_x`, `_player_y`, `_player_vx`, `_player_vy`). Symbol names are read from the `tilemap_collision` GenericSystem's config map (Plan 12.1-05 substrate) with a legacy-fallback default for any caller that opts into tilemap collision via Path A (`platformerPhysics { solidThreshold(N) }`) only — preserving byte-identical emission for the 4 existing genre-platformer EmissionTests. `_jump_increase_timer` is preserved unchanged per RESEARCH §Risks #1 (cross-path leakage hazard). Hitbox auto-derivation and `cfg.solidThreshold` are out of 12.1 scope per checker W4.
