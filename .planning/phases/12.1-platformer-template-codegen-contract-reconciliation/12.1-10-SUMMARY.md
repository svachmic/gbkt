### Task 1 — Terminal `:clean :buildRom` smoke + verify .gb + .noi + bank-size cap

- **Result:** FAILED — 3 SDCC error 20 instances
- **Command:** `./gradlew :gbkt-examples:platformer-template:clean :gbkt-examples:platformer-template:buildRom`
- **Errors:**
  ```
  main.c:146: error 20: Undefined identifier '__bank__zone_world1Area1Zone_tilemap'
  main.c:159: error 20: Undefined identifier '__bank__zone_world1Area2Zone_tilemap'
  main.c:172: error 20: Undefined identifier '__bank__zone_world2Area1Zone_tilemap'
  ```
- **Root cause diagnosis:** Manual `lcc -c -Wa-l _zone_world1Area1Zone_tilemap.c` confirms SDCC emits `__zone_world1Area1Zone_tilemap` (data symbol, single underscore) into `_CODE_2` (bank 2, as per `#pragma bank 2`) — but no `__bank__zone_world1Area1Zone_tilemap` symbol is synthesized. SDCC's `__bank_<sym>` synthesis is exclusive to banked function definitions; it does not fire for `const uint8_t[]` data arrays under `#pragma bank N`. The `BANK(_zone_<id>_tilemap)` macro at the consumer site (`setup_current_level` in main.c) therefore has no link-time producer. This is **Defect 6** — see 12.1-VERIFICATION.md §Defect 6.
- **Inline absorption authority:** The plan grants authority to inline-absorb only an MBC1 → MBC5 cartridge change (RESEARCH §Risks #4). The MBC1 limit was not the failure mode — `lcc -Wm-yt0x01` and `-Wm-yo4` (4 banks) did not trigger the 16-bank MBC1 ceiling. No MBC absorption was needed or performed.
- **Other zones (`titleZone`, `nextLevelZone`):** Not referenced from `setup_current_level`, so no error 20 fires for them — but the same Defect 6 would surface if they were referenced via `BANK()`.
- **`.gb`/`.noi`:** Not produced — `:compileRom` failed before the link step.
