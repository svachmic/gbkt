<objective>
Resolve Defect 2 from `.planning/phases/12-port-platformer-template-gbdk-example-to-gbkt/evidence/first-buildrom.md`: SDCC reports `error 20: Undefined identifier '__bank__zone_<id>_tilemap'` because new-path zone tilemap arrays (those emitted by `ConvertZoneTilesetsTask`, not the legacy `buildTilemapBankFiles` path) sit in HOME bank without a `#pragma bank N` directive — so SDCC never synthesizes the `__bank_<sym>` companion symbol that `BANK(_zone_<id>_tilemap)` expands to.

Per D-01 (CONTEXT.md), this plan picks option (b) — emit `#pragma bank N` on the tilemap.c file via `ConvertZoneTilesetsTask`. RESEARCH §BankingAnalysisPass confirms `GBDKPipelineV2.allocateZoneBanks` already computes per-zone bank assignments for the NEW path's tilemaps (line 596-655), but its output today flows only into `buildTilemapBankFiles` which filters new-path zones out (`tilesetPath != null` → `return@mapNotNull null` at line 696). This plan routes that allocation through `game_metadata.json` so the Gradle task can read the bank and emit the pragma.

Purpose: Make `BANK(_zone_<id>_tilemap)` resolve at link time without changing the existing SWITCH_ROM machinery (Plan 07.4-30 wrapper at GBDKPipelineV2.kt:~1882). Activates already-existing-but-vestigial code per RESEARCH §Architectural Responsibility Map.

Output: A modified `GBDKPipelineV2.buildMetadataFile` that emits `bank` in each `zoneTilesets` JSON entry, plus a modified `ConvertZoneTilesetsTask.synthesizeScreenTilemap` that prepends `#pragma bank N` to the generated `.c` file.
</objective>
