**Why mirror the prefix transformation in the test setup (not invoke visitor with bare names):**
`MetaspriteIR.posXVarName` stores the BARE Kotlin property name (`"playerX"` — no underscore prefix). The `_` prefix is applied at the call boundary by `ScriptOpVisitor.visitMoveMetasprite` (lines 1917-1923) before delegating to `MetaspriteVisitor.generateMetaspriteFrameSwitch`. Testing the visitor with already-prefixed strings without explicitly performing the prefix transformation would be tautological and would NOT structurally guard Defect 5. The test setup MUST do `posXVar = boundMetasprite.posXVarName?.let { "_$it" } ?: "_posX"` (mirroring the production line) so that a regression in the IR field's underscore-handling convention is caught by the test.
