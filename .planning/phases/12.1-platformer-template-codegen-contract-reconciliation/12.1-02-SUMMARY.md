Per Plan 12.1-02 `<acceptance_criteria>` for Task 1: "If Plan 12.1-01 is reverted (synthesize without the pragma), the test fails (manual sanity — not required in CI but document in SUMMARY)."

- **Task 1 RED leg:** Reverting Plan 12.1-01's `appendLine("#pragma bank $bank")` line in `ConvertZoneTilesetsTask.synthesizeScreenTilemap` (file line 471) would flip `convertZoneTilesets emits #pragma bank N at head of tilemap_c` RED, since the synthesized `_zone_play_zone_tilemap.c` would no longer carry a pragma at column 0.

Both RED legs are reasoned from the code paths in `ConvertZoneTilesetsTask.kt` (lines 156, 471) — not manually executed because (a) the orchestrator policy prefers atomic non-destructive commits over reset-and-reverify cycles and (b) the per-line correspondence between the test assertions and the production code is unambiguous.

## Decisions Made

- **Co-located in `ConvertZoneTilesetsTaskTest.kt` (not the dedicated `*PragmaBankTest.kt`):** The plan's `<files_modified>` explicitly targets `ConvertZoneTilesetsTaskTest.kt`. Co-locating the contract lock with the rest of the task contract tests preserves scan-ability — a future maintainer reading the task's primary test file sees all 6 contract dimensions (happy-path .c+.h, WIDTH/HEIGHT defines, missing-PNG, non-mult-8 dims, > 192 tiles, **`#pragma bank N` + D-01 fail-fast**) in one place.
