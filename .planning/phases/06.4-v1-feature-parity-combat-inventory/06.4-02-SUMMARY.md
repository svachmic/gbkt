## Decisions Made

- Sub-state IDs start at 64 — leaves 5-63 for custom states; typical Game Boy games have <10 custom states so 64 headroom is sufficient
- `buildConditionCheck()` extracts first IfOp condition from `onVictoryCondition`/`onDefeatCondition` list — DSL's `whenever()` always produces IfOp so this is reliable; fallback path for non-IfOp ops included defensively
- `CLiteral(0xFF)` emits as `255u` in CEmitter — test assertions check for `255u` not `0xFF`
- `combat_parent_state()` returns `state` itself for top-level states via switch default case
