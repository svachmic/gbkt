## Decisions Made

- ItemEffectIR is a non-sealed interface — RPG module can extend with domain-specific effects without touching core IR
- ItemDef.maxStack is nullable — null means inherit from ItemCategoryDef.defaultMaxStack; set means override category default
- Two overloads for combatEngine() and container(): explicit-id variant returns typed ref; no-id variant returns delegate for property name inference
- GBDKSystemVisitor.visitCombatEngineSystem() stub returns emptyList() with TODO 06.4-02 comment — Plan 02 implements real codegen
- CombatTypes.kt and InventoryTypes.kt use @file:Suppress(MatchingDeclarationName) — multiple top-level declarations per file
