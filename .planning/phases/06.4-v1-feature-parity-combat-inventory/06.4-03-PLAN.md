    **1. Create InventoryVisitor.kt** in `gbkt-backend-gbdk/src/main/kotlin/io/github/gbkt/backend/gbdk/codegen/visitor/`:

    Class: `InventoryVisitor(private val gameIR: GameIR)` — generates C code for items, containers, and drop tables.

    **a) Item catalog constants:**
    Method `fun generateItemConstants(): List<CVarDecl>` — for each `ItemDef` in `gameIR.items`:
    - `const UINT8 ITEM_<ID_UPPER>_ID = <index>u;` — item index (0-based order in items list)
    - `const UINT8 ITEM_<ID_UPPER>_STACK = <resolvedMaxStack>u;` — resolved max stack: uses `item.maxStack` if non-null, otherwise looks up `gameIR.itemCategories.find { it.id == item.categoryId }?.defaultMaxStack ?: 1` (category default, fallback to 1)
    - Use `CVarDecl` with `isConst=true`. ID uppercased for C constant naming convention.
    - Also generate `const UINT8 CATEGORY_<ID_UPPER>_DEFAULT_STACK = <defaultMaxStack>u;` for each `ItemCategoryDef` in `gameIR.itemCategories`.

    **b) Container globals:**
    Method `fun generateContainerGlobals(): List<CVarDecl>` — for each `ContainerIR` in `gameIR.containers`:
    - `UINT8 _inv_<id>_items[<slots>];` — item ID array (0xFF = empty slot)
    - `UINT8 _inv_<id>_counts[<slots>];` — stack count array
    - `UINT8 _inv_<id>_size = 0u;` — current occupied slot count
    - Items/counts arrays use `CArray(CU8, slots)` type.

    **c) Container operation functions:**
    Method `fun generateContainerFunctions(container: ContainerIR): List<CFunction>` — generates:

    **inv_<id>_add(UINT8 item_id, UINT8 count)** → UINT8 (1=success, 0=full):
    - C89 pattern: `CVarDecl("i", CU8)` before loop (no mixed declarations)
    - First loop: find existing stack of same item_id, increment count, return 1u
    - If not found: check `_inv_<id>_size < <slots>`, add new slot, increment size, return 1u
    - If full: return 0u
    - Use `CFor` with `init=null` (C89 compliance — variable declared above)

    **inv_<id>_remove(UINT8 item_id, UINT8 count)** → UINT8 (1=success, 0=not found):
    - Find slot with matching item_id, decrement count
    - If count reaches 0: compact by shifting last slot into this position (O(1) swap-remove), decrement size
    - Return 1u on success, 0u if item not found

    **inv_<id>_count(UINT8 item_id)** → UINT8:
    - Linear scan, return count of matching item_id, 0u if not found

    **inv_<id>_contains(UINT8 item_id)** → UINT8:
    - Linear scan, return 1u if found, 0u if not

    **d) Item use effect dispatcher:**
    Method `fun generateUseItemFunction(container: ContainerIR): List<CFunction>` — if any items have effects:
    - `void use_item_<containerId>(UINT8 item_id)` with `CSwitch` on item_id
    - Each case maps to the item's effects:
      - `HealEffect(amount)`: emit heal operation (e.g., variable += amount via CExprStatement)
      - `BuffEffect(statId, amount, duration)`: emit buff operation as comment + raw ops
      - `ScriptEffect(ops)`: emit ops via ScriptOpVisitor
    - Only generate if at least one item has non-empty effects

    **e) Drop table functions:**
    Method `fun generateDropTableFunctions(): List<CFunction>` — for each `DropTableIR`:
    - `UINT8 roll_drop_table_<id>(void)` — weighted random selection:
      - Calculate total weight sum at compile time
      - Generate: `UINT8 roll = _prng() % <totalWeight>;` (uses simple LCG PRNG helper)
      - Cumulative weight check: `if (roll < w1) return ITEM_X_ID; if (roll < w1+w2) return ITEM_Y_ID; ...`
      - Returns `0xFF` if no match (empty table fallback)
    - Also generate `_prng()` helper if any drop tables exist:
      - Simple 8-bit LCG: `_prng_state = _prng_state * 5 + 1; return _prng_state;`
      - `UINT8 _prng_state = 1u;` global

    **2. Wire into GBDKPipelineV2.kt:**
    - Use `mcp__serena__search_for_pattern` to find where other visitors are called (e.g., `buildSystemFunctions`, `buildDialogFunctions`)
    - Add `buildInventoryFunctions(gameIR)` and `buildItemCatalog(gameIR)` calls at appropriate places
    - Add `buildInventoryFunctions` method:
      - Creates InventoryVisitor, calls generateContainerFunctions for each container, generateUseItemFunction, generateDropTableFunctions
      - Returns all generated CFunction list
    - Add `buildItemCatalog` method:
      - Creates InventoryVisitor, calls generateItemConstants
      - Returns CVarDecl list for inclusion in main.c globals
    - Add container globals to `buildSystemGlobalVars()` or a new `buildInventoryGlobals()` method
    - Add item constants and container extern declarations to `buildHeaderFile()` so banked scene code can access them

    **C89 considerations:**
    - All loop variables use CVarDecl before CFor with init=null
    - All unsigned comparisons use unsigned literals (CLiteral values emit as "Nu")
    - No function pointers — switch dispatch only
    - Arrays are fixed-size at compile time (slots from ContainerIR)
