## Decisions Made

- InventoryVisitor uses three GBDKPipelineV2 entry points (buildItemCatalog, buildInventoryGlobals, buildInventoryFunctions) rather than a single method — mirrors the existing pattern for sound, dialog, and HUD systems
- resolveMaxStack() captures item.maxStack into local val before null check — required for Kotlin cross-module smart cast (public API property declared in different module)
- generatePrngGlobal() and generatePrngFunction() are separate methods — global emitted in allVariables, function emitted in functions list, consistent with other global/function split pattern
- use_item_<id>() generated per container (not per game) — future-proofs multi-container games where different containers may use different item sets
