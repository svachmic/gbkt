## Sampling Rate

- **After every task commit:** Run quick command (filtered emission + DSL tests)
- **After every plan wave:** Run full suite
- **Before `/gsd:verify-work`:** Full suite green + `:gbkt-examples:platformer-template:buildRom` clean (D-09 ROM smoke gate)
- **Max feedback latency:** ~45 seconds for quick, ~180 seconds for full
