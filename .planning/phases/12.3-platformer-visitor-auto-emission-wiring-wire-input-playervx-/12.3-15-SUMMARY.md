## What Changed Since Phase 12.3-14 (Plan 12.3-15 original PARTIAL scope)

### Phase 12.4 (sprite pipeline png2asset integration)
- ConvertSpritesTask wired to invoke real png2asset binary (instead of emitting 64-byte checkerboard stub)
- `sprite(AssetRef)` DSL binder added to `MetaspriteBuilder`
- Sidecar JSON (`game_metadata.json sprites[]`) introduced as cross-task communication channel

### Phase 12.5 (png2asset metasprite layout fix)
- 5 new typed DSL methods on `sprite()` builder: `mode()`, `pivot()`, `frameSize()`, `mirrorDedup()` (required for every metasprite — explicit > implicit)
- `MetaspriteIR` gained 5 additive fields: `spriteMode`, `pivotX`, `pivotY`, `frameWidth`, `frameHeight`
- `game_metadata.json sprites[]` extended with 5 new cutting-flag fields
- `ConvertSpritesTask` refactored: `spriteModeFromHeight` height-heuristic deleted; now reads cutting flags from sidecar and passes `-spr8x16 -px 12 -py 6 -sw 24 -sh 32` to png2asset binary
- All 7 sprite-using games migrated to declare `mode()/pivot()/frameSize()` explicitly
- Platform-template player metasprite `PlatformerTemplate.kt` updated with correct flag set
- Fresh anchor4 PNGs captured (Plan 12.5-09) from post-12.5 ROM with updated flags
- VisualDiff tolerance tightened from 0.05 to 0.10 (per D-08/REQ-3b)

### Debug session fixes (three compounding bugs: E-02, E-03, E-04)
- **E-03 (PRIMARY blob cause):** All 36 `tile(x, y, id)` calls in PlatformerTemplate.kt had x/y swapped — author transcribed reference `METASPR_ITEM(dy,dx)` arguments directly instead of DSL `tile(dx,dy)` convention. Fixed by swapping all coordinates. PlayerMetaspriteGeometryTest tightened to assert 3 x-columns at {-12,-4,4} AND 2 y-rows at {-6,10}.
- **E-02:** `GBDKPipelineV2.kt` unconditionally emitted `SPRITES_8x8` for all metasprite games. Fixed to emit `SPRITES_8x16` when `gameIR.metasprites.any { it.spriteMode == SpriteMode.SPR8x16 }`.
- **E-04:** `set_sprite_data` tile count formula was `maxTileId+1` (off-by-one for 8x16 mode). Fixed to `maxTileId+2` for SPR8x16 (tile ID N requires tiles N and N+1 as a pair). Shared helper `tileCountForMetasprite()` added to `MetaspriteVisitor`.
