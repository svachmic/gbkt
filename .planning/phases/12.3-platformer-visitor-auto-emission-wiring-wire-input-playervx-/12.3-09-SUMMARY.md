# Phase 12.3 Plan 09: PlatformerWalkCycleEmissionTest (R5 Acceptance + D-03 Contract Guard) Summary

**One-liner:** JVM-tier per-function awk brace-walk emission test (3 `@Test` methods + 3 evidence `.c` files) that locks Plan 12.3-08's walk-cycle (threeFrameCounter → walkFrameIdx advance) emission inside `void platformer_physics_update`. Positive case affirms the cycle shape (`_player_vx != 0` signed RHS, `++_threeFrameCounter`, `++_walkFrameIdx`, `_walkFrameIdx = 0u` reset) plus multiplicity sanity (`_walkFrameIdx` >= 3 references). Two NEGATIVE cases — the architectural job of this plan — enforce the D-03 SKIP-WHEN-UNSET contract: binders-unset fixture confirms binders=null → ZERO walk-cycle references inside the function (no magic-string fallback per `feedback_no_magic_strings.md`); no-system fixture confirms the outermost `gameUsesPlatformerInput` gate works.

## Result

**R5 ACCEPTANCE LOCKED + D-03 CONTRACT REGRESSION-GUARDED.** Plan 12.3-08's section-0b walk-cycle emission shape is now guarded by a JVM-tier per-function awk brace-walk test that runs in the standard `:gbkt-genre-platformer:test` suite. Three test methods, all GREEN on first run (since Plan 12.3-08's emission is already in the parent branch). No regression in the 7 adjacent emission tests on `:gbkt-genre-platformer:test --rerun-tasks` (full module suite passes BUILD SUCCESSFUL in 7s — 37 actionable tasks executed). Evidence files captured for human review.

The KEY architectural value of this test is the negative #1 case (binders unset). A future PlatformerVisitor refactor that "helpfully" auto-emits `_walkFrameIdx` as a fallback when the user forgot the AssignableVar binders would re-introduce a magic-string emission — exactly the regression `feedback_no_magic_strings.md` was written to prevent, and exactly the regression the D-03 contract was designed to forbid. This test fails RED immediately when that regression lands.

// Phase 12.3 — Walk-cycle (3-frame counter → frame-index advance)
if (_player_vx != 0) {
    ++_threeFrameCounter;
    if (_threeFrameCounter >= 6u) {
        _threeFrameCounter = 0u;
        ++_walkFrameIdx;

    _threeFrameCounter = 0u;
}
