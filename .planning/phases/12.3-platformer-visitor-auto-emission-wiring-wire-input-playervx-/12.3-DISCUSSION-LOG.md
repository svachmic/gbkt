## Area 2a — Friction model (air vs ground)

| Option | Description | Selected |
|--------|-------------|----------|
| Ground-only | Friction applies only when `_grounded != 0`. Matches reference player.c lines 268-289. Airborne keeps momentum (classic platformer feel). | |
| Always (in-air + grounded) | Friction applies every frame regardless of `_grounded`. SPEC formula reads this way verbatim. Makes jumps feel slidey. | |
| Configurable via platformerInput | Add `airFriction(F)` setter alongside `friction(F)`; default `airFriction=0` (no air friction, matches reference) but tunable per-game. | ✓ |

**User's choice:** Configurable via platformerInput
**Notes:** Captured as D-04. Adds `airFriction(F)` setter beyond SPEC req 1's explicit field list — out-of-spec but consistent with "scalable abstraction" principle. Default `airFriction=0` matches reference. Emission gates friction value by `_grounded` symbol resolved from existing `tilemapCollision { grounded(grounded) }` binder.

## Area 2b — Emission order

| Option | Description | Selected |
|--------|-------------|----------|
| input → physics → camera → metasprite | Input sets `_playerVx` first; physics integrates same frame. Zero-frame input lag. Mirrors reference player.c order. Matches the 12-21 inline cEmit ordering that produced GREEN anchor 3. | ✓ |
| physics → input → camera → metasprite (SPEC verbatim) | Follows SPEC req 3 wording exactly. Input sets `_playerVx` AFTER physics integrated this frame's `_playerX`. 1-frame input lag. | |
| input → physics → input-friction → camera → metasprite | Split input into two phases: pre-physics sets vx from dpad held; post-physics applies friction-on-release. | |

**User's choice:** input → physics → camera → metasprite (Recommended)
**Notes:** Captured as D-05. DIVERGES from SPEC req 3 wording — downstream agents should treat "physics_update → input" in SPEC as a wording typo and emit `input → physics_update`. Zero input lag. `_grounded` referenced in D-04's friction expression reads LAST frame's physics state — acceptable per standard platformer convention.
