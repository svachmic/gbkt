### 2. `gbkt-genre-platformer/.../dsl/PlatformerBuilders.kt` — `PlatformerInputBuilder` class

**Role + data flow:** DSL builder — captures user-DSL config into a `GenericSystem.config: Map<String, Any>` payload.
**Closest analog:** `PlatformerPhysicsBuilder` (same file:92-210) for numeric setters + `TilemapCollisionBuilder` (PlatformerExtensions.kt:432-542) for AssignableVar binders.

**Excerpt (TilemapCollisionBuilder — AssignableVar binder shape, 24 lines):**
```kotlin
// gbkt-genre-platformer/.../dsl/PlatformerExtensions.kt:431-485 (compacted)
@GbktDsl
class TilemapCollisionBuilder(val id: String) {
    private var posXVar: String? = null
    private var vxVar: String? = null
    private var groundedVar: String? = null
    private var solidThreshold: Int = 17

    fun position(x: AssignableVar, y: AssignableVar) {
        posXVar = x.name; posYVar = y.name      // ← captures property delegate name
    }
    fun velocity(vx: AssignableVar, vy: AssignableVar) { vxVar = vx.name; vyVar = vy.name }
    fun grounded(g: AssignableVar) { groundedVar = g.name }
    fun solidThreshold(v: Int) { solidThreshold = v }

    fun build(): GenericSystem {
        val cfg = mutableMapOf<String, Any>("type" to "tilemap_collision")
        posXVar?.let { cfg["posXVar"] = it }   // ← skip-on-null pattern
        vxVar?.let { cfg["vxVar"] = it }
        groundedVar?.let { cfg["groundedVar"] = it }
        cfg["solidThreshold"] = solidThreshold
        return GenericSystem(id = id, config = cfg.toMap())
    }
}
```

**Required adjustments (CONTEXT D-01..D-04, D-11, D-12, D-16):**
- Class name: `PlatformerInputBuilder` (D-11). Must be `open` (mirrors `PlatformerPhysicsBuilder` at line 92) so `OverrideTrackingInputBuilder` can subclass it.
- Constructor: `(val id: String = "input")` (mirrors `PlatformerPhysicsBuilder` at line 92).
- Setters (all `open fun`, return `Unit`): `walkSpeed(value: Int)`, `friction(value: Int)`, `airFriction(value: Int)`, `walkFrameCount(value: Int)`, `cyclePeriod(value: Int)`.
- AssignableVar binders (NOT `open` — they only make sense at game-level per D-03): `walkFrameIdx(v: AssignableVar) { walkFrameIdxVar = v.name }`, `threeFrameCounter(v: AssignableVar) { threeFrameCounterVar = v.name }`.
- `build()`: emit `GenericSystem(id, config = mapOf("type" to "platformer_input", "walkSpeed" to walkSpeed, "friction" to friction, "airFriction" to airFriction, "walkFrameCount" to walkFrameCount, "cyclePeriod" to cyclePeriod) + walkFrameIdxVar?.let{...} + threeFrameCounterVar?.let{...})`. Skip-on-null for binders (matches TilemapCollisionBuilder shape — D-03 fallback contract).
- `@GbktDsl` annotation per existing builder convention.

**Landmines:**
- **L-2.1** `AssignableVar` import path: `io.github.gbkt.core.dsl.AssignableVar` (NOT a magic-string `String` setter — `feedback_no_magic_strings.md`).
- **L-2.2** Builder MUST be `open` (RESEARCH §Pattern 2) — `OverrideTrackingInputBuilder` (file #3 below) subclasses it. Numeric setters MUST be `open fun`. The 2 AssignableVar binders MUST NOT be `open` — per-zone shadowing of binder names doesn't make semantic sense.
- **L-2.3** Setter ORDER: D-16 says planner picks alphabetic vs grouped. Recommend grouped (numeric setters first, then AssignableVar binders) — mirrors `TilemapCollisionBuilder`'s position/velocity/grounded/hitbox/solidThreshold grouping.

### 6. `gbkt-backend-gbdk/.../codegen/visitor/MetaspriteVisitor.kt` — `cameraOffsetX: String? = null` parameter

**Role + data flow:** codegen visitor — `MoveMetasprite` IR op → C `move_metasprite_*` call emission.

**Excerpt (analog — current 4-case switch at MetaspriteVisitor.kt:237-325, compacted to 18 lines):**
```kotlin
fun generateMetaspriteFrameSwitch(
    metasprite: MetaspriteIR,
    posXVar: String = "_posX",
    posYVar: String = "_posY",
    idxVar: String = "_idx",
    rotVar: String = "_rot",
): CRawCode {
    val buf = StringBuilder()
    val frames = "sprite_${metasprite.id}_frames"
    buf.append("    switch ($rotVar & 0x3u) {\n")
    // case 1: flip Y only
    buf.append("        case 1:\n")
    buf.append("            hiwater += move_metasprite_flipy($frames[$idxVar], 0, subpal, hiwater,\n")
    buf.append("                                              DEVICE_SPRITE_PX_OFFSET_X + ($posXVar >> 4),\n")
    buf.append("                                              DEVICE_SPRITE_PX_OFFSET_Y + ($posYVar >> 4));\n")
    // ... cases 2, 3, default — all use the same `DEVICE_SPRITE_PX_OFFSET_X + ($posXVar >> 4)` formula
}
```

**Required adjustments (SPEC R4 + CONTEXT D-07):**
- Add 5th parameter: `cameraOffsetX: String? = null` (positional after `rotVar`).
- Define a single `val xExpr: String = if (cameraOffsetX != null) "DEVICE_SPRITE_PX_OFFSET_X + (UINT8)(((INT16)($posXVar >> 4)) - (INT16)$cameraOffsetX)" else "DEVICE_SPRITE_PX_OFFSET_X + ($posXVar >> 4)"` ABOVE the switch — then substitute `$xExpr` in all 4 case branches (case 1 / case 2 / case 3 / default).
- Y unchanged across all 4 cases (no vertical camera in Phase 12).
- KDoc: 5th `@param cameraOffsetX When non-null, emits screen-relative X formula `DEVICE_SPRITE_PX_OFFSET_X + (UINT8)(((INT16)(<posXVar> >> 4)) - (INT16)<cameraOffsetX>)`. When null (default), emits absolute world-coordinate formula. Set to `"_camera_x"` by `ScriptOpVisitor.visitMoveMetasprite` when the parent scene's zone has tilemap-camera mode (Phase 12 D-13).`

**Landmines:**
- **L-6.1 (Pitfall 5 — integer promotion):** RESEARCH Assumption A2 flags the `(INT16)` casts as `[ASSUMED]`-compile-clean. If SDCC produces warning 158/207 on the first ROM build, fall back to `(UINT8)(($posXVar >> 4) - $cameraOffsetX)` (drop explicit INT16 casts — the subtraction of two UINT16s is well-defined for screen-visible range 0..255).
- **L-6.2 (back-compat — D-08):** Default `cameraOffsetX = null` MUST preserve byte-identical output of the existing 4-case emission. private fun extractFunctionBody(cSource: String, functionSignaturePrefix: String): String {
    val lines = cSource.lines()
    val startIdx = lines.indexOfFirst { it.startsWith(functionSignaturePrefix) }
    if (startIdx == -1) return ""
    val body = StringBuilder()
    var depth = 0
    var started = false
    for (i in startIdx until lines.size) {
        val line = lines[i]
        body.appendLine(line)
        for (ch in line) {
            if (ch == '{') { depth++; started = true }
            if (ch == '}') depth--
        }
        if (started && depth == 0) break
    }
    return body.toString()
}
