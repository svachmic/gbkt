# gbkt-world -- World & Exploration Types

Placeholder module for world and exploration type definitions. Currently contains only `package-info.kt` files with no exported symbols.

## Dependencies

- **Depends on:** `gbkt-ir`, `gbkt-lang`
- **Used by:** `gbkt-core`

## Contents

| File | Role |
|------|------|
| `core/world/package-info.kt` | Package declaration for world types |
| `core/exploration/package-info.kt` | Package declaration for exploration types |

## Status

This module is reserved for future extraction of world and exploration types from `gbkt-core`. The actual world/exploration logic (floors, encounters, zones, dungeon crawling) currently lives in `gbkt-core` under the same package names.
