# Assets Module

Type-safe asset references for compile-time validation.

## Files

| File | Purpose | LOC |
|------|---------|-----|
| `AssetRef.kt` | Type-safe asset reference classes | ~140 |
| `AssetRegistry.kt` | Registry interface for organized assets | ~69 |

## AssetRef Hierarchy (AssetRef.kt)

Sealed class hierarchy for type-safe asset paths:

```
AssetRef (sealed)
├── SpriteAsset   - Sprites/images (.png, .bmp)
├── TileAsset     - Tilesets for backgrounds
├── SoundAsset    - Sound effects (.wav, .raw)
├── MusicAsset    - Music tracks (.mod, .gbs)
└── FontAsset     - Font images for text
```

### Usage

```kotlin
// Define assets as type-safe references
object Assets {
    object Sprites {
        val player = SpriteAsset("player.png")
        val enemy = SpriteAsset("sprites/enemy.png")
    }
    object Sounds {
        val jump = SoundAsset("jump.wav")
    }
}

// Use in game definition
val player by entity {
    sprite(Assets.Sprites.player) { size = 8 x 16 }
}
```

### Benefits

1. **Compile-time safety**: Typos caught at compile time, not build time
2. **IDE support**: Autocomplete for asset names
3. **Refactoring**: Rename assets safely across codebase
4. **Organization**: Group related assets in objects

### AssetType Enum


Each asset type has a `fromPath` companion method:

```kotlin

```

## Asset Registry (AssetRegistry.kt)

Interface for organizing all game assets:

```kotlin
object Assets : AssetRegistry {
    object Sprites {
        val player = SpriteAsset("player.png")
        val enemy = SpriteAsset("enemy.png")
    }

    object Sounds {
        val jump = SoundAsset("jump.wav")
    }

    // Registry implementation
    override val sprites = mapOf(
        "player" to Sprites.player,
        "enemy" to Sprites.enemy
    )
    override val sounds = mapOf("jump" to Sounds.jump)
}
```

### Registry Methods

```kotlin
interface AssetRegistry {
    val sprites: Map<String, SpriteAsset>
    val tiles: Map<String, TileAsset>
    val sounds: Map<String, SoundAsset>
    val music: Map<String, MusicAsset>
    val fonts: Map<String, FontAsset>

    // Lookup by name
    operator fun get(name: String): AssetRef?

    // Get all assets
    fun allAssets(): List<AssetRef>
}
```

### EmptyAssetRegistry

Default for games not using the registry system:

## Best Practices

### Do

```kotlin
// Use typed assets
sprite(Assets.Sprites.player) { ... }

// Group related assets
object Assets {
    object Player {
        val idle = SpriteAsset("player/idle.png")
        val walk = SpriteAsset("player/walk.png")
        val jump = SpriteAsset("player/jump.png")
    }
}
```

### Don't

```kotlin
// Avoid string paths (no compile-time checking)
sprite("player.png") { ... }  // Works but no type safety

// Avoid duplicating paths
val sprite1 = SpriteAsset("player.png")
val sprite2 = SpriteAsset("player.png")  // Define once, reference everywhere
```
